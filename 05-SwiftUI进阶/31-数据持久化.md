# 31-数据持久化方案

> 🎯 **本章目标**：理解数据持久化的概念和意义，掌握 UserDefaults、FileManager、SwiftData 三种持久化方案，能根据实际场景选择最合适的存储方式。

---

## 数据持久化概述

### 什么是数据持久化

数据持久化就是把数据**从内存保存到磁盘**，让 App 关闭后数据不会丢失。

```
┌──────────────────────────────────────────────┐
│                   内存（RAM）                  │
│  App 运行时，数据存在这里                      │
│  App 关闭 → 数据全部消失 ❌                    │
└──────────────────────────────────────────────┘
                    ↕ 读写
┌──────────────────────────────────────────────┐
│                   磁盘（Storage）              │
│  持久化数据存在这里                            │
│  App 关闭 → 数据依然存在 ✅                    │
└──────────────────────────────────────────────┘
```

💡 **通俗理解**：内存就像"草稿纸"，App 关了就擦掉了；磁盘就像"笔记本"，写上去的东西一直都在。持久化就是把草稿纸上的内容抄到笔记本上。

### 为什么需要持久化

| 场景 | 不持久化的后果 | 持久化的好处 |
|------|-------------|------------|
| 用户设置（深色模式、语言） | 每次 App 重启都恢复默认 | 记住用户偏好 |
| 登录状态 | 每次都要重新登录 | 保持登录 |
| 离线数据 | 没网就没内容 | 缓存数据离线可用 |
| 用户收藏/历史 | 关 App 就没了 | 数据永久保留 |
| 草稿/未提交表单 | 意外退出丢失 | 自动保存 |

### iOS 数据持久化方案对比表

| 方案 | 适合存什么 | 数据量 | 复杂度 | 持久性 | 最低系统版本 |
|------|----------|:------:|:------:|:------:|:----------:|
| **UserDefaults** | 简单键值对、用户偏好 | 小 | ⭐ | 永久 | iOS 2+ |
| **FileManager** | 文件、JSON、图片 | 中~大 | ⭐⭐ | 永久 | iOS 2+ |
| **SwiftData** | 结构化数据、关系数据 | 中~大 | ⭐⭐ | 永久 | iOS 17+ |
| **Core Data** | 结构化数据（SwiftData 前身） | 中~大 | ⭐⭐⭐⭐ | 永久 | iOS 3+ |
| **Keychain** | 密码、Token 等敏感信息 | 小 | ⭐⭐⭐ | 永久 | iOS 2+ |

💡 **提示**：本书重点介绍 UserDefaults、FileManager、SwiftData 三种方案。Core Data 是 SwiftData 的前身，语法更复杂，新项目推荐直接用 SwiftData。Keychain 用于存储敏感信息，将在后续章节介绍。

## UserDefaults 进阶

UserDefaults 是最简单的持久化方案，就像一个**全局的字典**，用键值对存取数据。

### 存储自定义对象

UserDefaults 原生只支持基本类型（String、Int、Double、Bool、Data 等），要存储自定义对象，需要借助 `Codable` 先转成 `Data`。

#### Codable 编码为 Data

```swift
struct UserPreference: Codable {
    let username: String
    let theme: String
    let fontSize: Int
}

let preference = UserPreference(username: "张三", theme: "dark", fontSize: 16)

// 编码为 Data
if let data = try? JSONEncoder().encode(preference) {
    UserDefaults.standard.set(data, forKey: "userPreference")
}
```

#### 存取方法

```swift
// 存
UserDefaults.standard.set(data, forKey: "userPreference")

// 取
if let data = UserDefaults.standard.data(forKey: "userPreference") {
    let preference = try? JSONDecoder().decode(UserPreference.self, from: data)
}
```

#### 示例

```swift
import SwiftUI

struct AppSettings: Codable {
    var username: String
    var isDarkMode: Bool
    var fontSize: Int
    var favoriteCategory: String

    static var `default`: AppSettings {
        AppSettings(username: "", isDarkMode: false, fontSize: 16, favoriteCategory: "全部")
    }
}

struct UserDefaultsObjectView: View {
    @AppStorage("username") private var username: String = ""
    @AppStorage("isDarkMode") private var isDarkMode: Bool = false
    @AppStorage("fontSize") private var fontSize: Double = 16

    var body: some View {
        Form {
            Section("基本设置") {
                TextField("用户名", text: $username)
                Toggle("深色模式", isOn: $isDarkMode)
                VStack(alignment: .leading) {
                    Text("字体大小：\(Int(fontSize))")
                    Slider(value: $fontSize, in: 12...24, step: 1)
                }
            }

            Section("预览") {
                Text("你好，\(username.isEmpty ? "用户" : username)！")
                    .font(.system(size: CGFloat(fontSize)))
            }
        }
        .navigationTitle("设置")
    }
}
```

💡 **提示**：`@AppStorage` 是 SwiftUI 提供的属性包装器，它会自动把值同步到 UserDefaults，修改即保存，非常方便！

⚠️ **警告**：`@AppStorage` 只支持基本类型（String、Int、Double、Bool、URL、Data）。自定义对象需要手动编码为 `Data` 后再用 `@AppStorage("key") var data: Data` 存储。

### UserDefaults 封装

直接用 `UserDefaults.standard` 散落在各处不好维护，我们来做一个类型安全的封装。

#### 创建 UserDefaultsManager

```swift
final class UserDefaultsManager {
    static let shared = UserDefaultsManager()
    private let defaults = UserDefaults.standard

    private init() {}
}
```

#### 类型安全封装

```swift
final class UserDefaultsManager {
    static let shared = UserDefaultsManager()
    private let defaults = UserDefaults.standard

    private init() {}

    enum StorageKey: String {
        case hasLaunchedBefore
        case username
        case appSettings
        case recentSearches
    }

    func set<T>(_ value: T, forKey key: StorageKey) {
        defaults.set(value, forKey: key.rawValue)
    }

    func get<T>(_ type: T.Type, forKey key: StorageKey) -> T? {
        return defaults.object(forKey: key.rawValue) as? T
    }

    func setObject<T: Codable>(_ object: T, forKey key: StorageKey) {
        if let data = try? JSONEncoder().encode(object) {
            defaults.set(data, forKey: key.rawValue)
        }
    }

    func getObject<T: Codable>(_ type: T.Type, forKey key: StorageKey) -> T? {
        guard let data = defaults.data(forKey: key.rawValue) else { return nil }
        return try? JSONDecoder().decode(type, from: data)
    }

    func remove(forKey key: StorageKey) {
        defaults.removeObject(forKey: key.rawValue)
    }

    func clearAll() {
        if let bundleID = Bundle.main.bundleIdentifier {
            defaults.removePersistentDomain(forName: bundleID)
        }
    }
}
```

```swift
                                    .foregroundStyle(.tertiary)

        guard !searchText.trimmingCharacters(in: .whitespaces).isEmpty else { return }
        searches.insert(SearchRecord(keyword: searchText), at: 0)
        searchText = ""
        saveSearches()

    func saveSearches() {
        manager.setObject(searches, forKey: .recentSearches)

        searches = manager.getObject([SearchRecord].self, forKey: .recentSearches) ?? []
    }
```

## FileManager 文件读写

FileManager 是 iOS 文件系统的"管家"，可以创建、读取、删除、移动文件和目录。

### 文件操作基础

#### 获取 Documents 目录

每个 App 都有自己的沙盒（独立存储空间），最常用的目录是 `Documents`：

```swift
let documentsDirectory = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask).first!
print(documentsDirectory.path)
// 例如：/Users/.../Documents/
```

| 目录 | 用途 | 是否被 iTunes 备份 |
|------|------|:----------------:|
| `Documents` | 用户产生的数据 | ✅ |
| `Library/Caches` | 缓存数据（可被系统清理） | ❌ |
| `Library/Application Support` | App 运行支持文件 | ✅ |
| `tmp` | 临时文件（随时可能被清理） | ❌ |

⚠️ **警告**：不要把缓存数据放在 `Documents` 目录，否则会占用用户的 iCloud 备份空间！

#### 创建/删除/移动文件

```swift
let fileManager = FileManager.default
let documentsURL = fileManager.urls(for: .documentDirectory, in: .userDomainMask).first!

// 创建目录
let folderURL = documentsURL.appendingPathComponent("MyFolder")
try? fileManager.createDirectory(at: folderURL, withIntermediateDirectories: true)

// 创建文件
let fileURL = folderURL.appendingPathComponent("note.txt")
let textData = "Hello, FileManager!".data(using: .utf8)
fileManager.createFile(atPath: fileURL.path, contents: textData)

// 检查文件是否存在
let exists = fileManager.fileExists(atPath: fileURL.path)

// 移动文件
let newURL = documentsURL.appendingPathComponent("note.txt")
try? fileManager.moveItem(at: fileURL, to: newURL)

// 删除文件
try? fileManager.removeItem(at: newURL)
```

#### 示例

```swift
                            .foregroundStyle(.blue)

                    }
                }
            }
            .navigationTitle("文件管理")
            .onAppear { listFiles() }
        }

        do {
            files = try fileManager.contentsOfDirectory(atPath: documentsURL.path)

            message = "❌ 读取失败：\(error.localizedDescription)"

        do {

            for file in existingFiles {
                let fileURL = documentsURL.appendingPathComponent(file)
                try fileManager.removeItem(at: fileURL)
            }
            files = []
            message = "🗑️ 已清空目录"
        } catch {
            message = "❌ 清空失败：\(error.localizedDescription)"
        }
    }
}
```

### 读写 JSON 文件

#### 编码写入

把 Swift 对象编码为 JSON，然后写入文件：

```swift
func saveToFile<T: Codable>(_ object: T, fileName: String) throws {
    let fileURL = documentsURL.appendingPathComponent(fileName)
    let data = try JSONEncoder().encode(object)
    try data.write(to: fileURL, options: .atomic)
}
```

💡 **提示**：`.atomic` 选项会先写入临时文件，再替换原文件，避免写入过程中崩溃导致数据损坏。

#### 解码读取

从文件读取 JSON 数据，解码为 Swift 对象：

```swift
func loadFromFile<T: Codable>(_ type: T.Type, fileName: String) throws -> T {
    let fileURL = documentsURL.appendingPathComponent(fileName)
    let data = try Data(contentsOf: fileURL)
    return try JSONDecoder().decode(type, from: data)
}
```

#### 完整示例

```swift
    var content: String

    }

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                VStack(spacing: 8) {
                    TextField("标题", text: $newTitle)
                    TextField("内容", text: $newContent)
                }
                .textFieldStyle(.roundedBorder)
                .padding(.horizontal)

                HStack {
                    Button("添加笔记") { addNote() }

                }
                .buttonStyle(.bordered)
                .padding(.horizontal)

                if !message.isEmpty {
                    Text(message)
                        .font(.caption)
                        .foregroundStyle(.secondary)
                        .padding(.horizontal)
                }

                List {
                    ForEach(notes) { note in
                        VStack(alignment: .leading, spacing: 4) {
                            Text(note.title)
                                .font(.headline)
                            Text(note.content)
                                .font(.subheadline)
                                .foregroundStyle(.secondary)
                            Text(note.updatedAt, style: .relative)
                                .font(.caption2)
                                .foregroundStyle(.tertiary)
                        }
                        .padding(.vertical, 4)
                    }
                    .onDelete { indexSet in
                        notes.remove(atOffsets: indexSet)
                    }
                }
            }
            .navigationTitle("笔记本")
            .onAppear { loadNotes() }
        }
    }

    func addNote() {
        guard !newTitle.isEmpty else { return }
        notes.append(Note(title: newTitle, content: newContent))
        newTitle = ""
        newContent = ""
        saveNotes()
    }

    func saveNotes() {
        do {
            let fileURL = documentsURL.appendingPathComponent(fileName)
            let data = try JSONEncoder().encode(notes)
            try data.write(to: fileURL, options: .atomic)
            message = "✅ 已保存 \(notes.count) 条笔记"
        } catch {
            message = "❌ 保存失败：\(error.localizedDescription)"
        }
    }

    func loadNotes() {
        do {
            let fileURL = documentsURL.appendingPathComponent(fileName)
            if fileManager.fileExists(atPath: fileURL.path) {
                let data = try Data(contentsOf: fileURL)
                notes = try JSONDecoder().decode([Note].self, from: data)
                message = "📂 已加载 \(notes.count) 条笔记"
            } else {
                message = "文件不存在，将创建新文件"
            }
        } catch {
            message = "❌ 加载失败：\(error.localizedDescription)"
        }
    }
}
```

### 文件管理器封装

将常用文件操作封装成一个工具类，方便复用：

#### 封装常用操作

```swift
final class FileManagerHelper {
    static let shared = FileManagerHelper()
    private let fileManager = FileManager.default

    private init() {}

    var documentsDirectory: URL {
        fileManager.urls(for: .documentDirectory, in: .userDomainMask).first!
    }

    var cachesDirectory: URL {
        fileManager.urls(for: .cachesDirectory, in: .userDomainMask).first!
    }

    func fileURL(for name: String) -> URL {
        documentsDirectory.appendingPathComponent(name)
    }

    func fileExists(at url: URL) -> Bool {
        fileManager.fileExists(atPath: url.path)
    }

    func save<T: Codable>(_ object: T, to fileName: String) throws {
        let url = fileURL(for: fileName)
        let data = try JSONEncoder().encode(object)
        try data.write(to: url, options: .atomic)
    }

    func load<T: Codable>(_ type: T.Type, from fileName: String) throws -> T {
        let url = fileURL(for: fileName)
        let data = try Data(contentsOf: url)
        return try JSONDecoder().decode(type, from: data)
    }

    func loadIfExists<T: Codable>(_ type: T.Type, from fileName: String) -> T? {
        let url = fileURL(for: fileName)
        guard fileExists(at: url) else { return nil }
        return try? load(type, from: fileName)
    }

    func delete(fileName: String) throws {
        let url = fileURL(for: fileName)
        if fileExists(at: url) {
            try fileManager.removeItem(at: url)
        }
    }

    func listFiles() throws -> [String] {
        try fileManager.contentsOfDirectory(atPath: documentsDirectory.path)
    }

    func fileSize(of fileName: String) -> Int? {
        let url = fileURL(for: fileName)
        guard let attributes = try? fileManager.attributesOfItem(atPath: url.path) else { return nil }
        return attributes[.size] as? Int
    }
}
```

```swift
                                .foregroundStyle(.tertiary)
                        }
                        .padding(.vertical, 4)
                    }
                    .onDelete(perform: deleteBookmarks)
                }
            }
            .navigationTitle("书签管理")
            .onAppear { loadBookmarks() }
        }
    }

    private var dateFormatter: DateFormatter {
        let formatter = DateFormatter()
        formatter.dateStyle = .medium
        formatter.timeStyle = .short
        formatter.locale = Locale(identifier: "zh_CN")
        return formatter
    }

    func addBookmark() {
        guard !newTitle.isEmpty, !newURL.isEmpty else {
            statusMessage = "⚠️ 请填写完整信息"
            return
        }
        bookmarks.append(Bookmark(title: newTitle, url: newURL))
        newTitle = ""
        newURL = ""
        saveBookmarks()
    }

    func deleteBookmarks(at offsets: IndexSet) {
        bookmarks.remove(atOffsets: offsets)
        saveBookmarks()
    }

    func saveBookmarks() {
        do {
            try helper.save(bookmarks, to: fileName)
            statusMessage = "✅ 已保存 \(bookmarks.count) 个书签"
        } catch {
            statusMessage = "❌ 保存失败"
        }
    }

    func loadBookmarks() {
        if let loaded: [Bookmark] = helper.loadIfExists([Bookmark].self, from: fileName) {
            bookmarks = loaded
            statusMessage = "📂 已加载 \(loaded.count) 个书签"
        }
    }
}
```

## SwiftData（iOS 17+）入门

SwiftData 是 Apple 在 iOS 17 推出的现代数据持久化框架，用 Swift 原生的方式操作数据库，比 Core Data 简单得多。

💡 **通俗理解**：如果说 UserDefaults 是"便利贴"，FileManager 是"文件夹"，那 SwiftData 就是"数据库"——它能存储大量结构化数据，支持查询、排序、过滤。

### Model 定义

#### @Model 宏

用 `@Model` 宏标记一个类，SwiftData 会自动为它创建数据库表：

```swift
import SwiftData

@Model
class TodoItem {
    var title: String
    var isDone: Bool
    var createdAt: Date

    init(title: String, isDone: Bool = false, createdAt: Date = Date()) {
        self.title = title
        self.isDone = isDone
        self.createdAt = createdAt
    }
}
```

就这么简单！`@Model` 宏会自动帮你：
- 生成 `Codable` 实现
- 创建数据库表
- 追踪属性变化

#### 属性定义

SwiftData 支持的属性类型：

| 类型 | 示例 | 说明 |
|------|------|------|
| 基本类型 | `String`、`Int`、`Double`、`Bool` | 直接使用 |
| 日期 | `Date` | 自动处理 |
| 数据 | `Data` | 二进制数据 |
| URL | `URL` | 链接地址 |
| 枚举 | `enum`（需遵循 `Codable`） | 枚举值 |
| 关系 | `@Relationship` | 模型间关联 |
| 忽略 | `@Transient` | 不存储的属性 |

特殊属性宏：

```swift
@Model
class Article {
    @Attribute(.unique) var slug: String       // 唯一约束
    var title: String
    var content: String
    @Relationship(deleteRule: .cascade) var comments: [Comment] = []  // 级联删除
    @Transient var tempFlag: Bool = false       // 不存入数据库
    var createdAt: Date
}
```

#### 示例

```swift
import SwiftData

@Model
class TodoItem {
    var title: String
    var isDone: Bool
    var priority: Int
    var createdAt: Date
    var category: String

    init(title: String, isDone: Bool = false, priority: Int = 0, category: String = "默认") {
        self.title = title
        self.isDone = isDone
        self.priority = priority
        self.category = category
        self.createdAt = Date()
    }
}
```

### ModelContainer

`ModelContainer` 是 SwiftData 的"数据库管理器"，负责创建和管理数据库。

#### 配置容器

```swift
// 最简配置
let container = try ModelContainer(for: TodoItem.self)

// 自定义配置
let schema = Schema([TodoItem.self])
let config = ModelConfiguration(
    schema: schema,
    isStoredInMemoryOnly: false,     // 是否仅存内存（测试用）
    allowsSave: true                  // 是否允许保存
)
let container = try ModelContainer(for: schema, configurations: [config])
```

#### 注入环境

在 App 入口注入 `ModelContainer`，整个 App 就能访问数据库了：

```swift
import SwiftUI
import SwiftData

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        .modelContainer(for: TodoItem.self)
    }
}
```

💡 **提示**：`.modelContainer(for:)` 会自动创建 `ModelContainer` 并注入 SwiftUI 环境，所有子视图都能访问。

如果需要多个 Model：

```swift
.modelContainer(for: [TodoItem.self, Category.self])
```

### CRUD 操作

CRUD 是数据操作的四个基本动作：**C**reate（创建）、**R**ead（读取）、**U**pdate（更新）、**D**elete（删除）。

#### Create：ModelContext.insert()

```swift
@Environment(\.modelContext) private var modelContext

func addTodo() {
    let newItem = TodoItem(title: "学习 SwiftData")
    modelContext.insert(newItem)
    // 不需要手动 save，SwiftData 会自动保存！
}
```

💡 **提示**：SwiftData 会在合适的时机自动保存，不需要手动调用 `save()`。

#### Read：@Query 查询

```swift
@Query private var todos: [TodoItem]

// 带排序
@Query(sort: \TodoItem.createdAt, order: .reverse) private var todos: [TodoItem]

// 带过滤
@Query(filter: #Predicate<TodoItem> { !$0.isDone }) private var pendingTodos: [TodoItem]
```

#### Update：直接修改属性

```swift
func toggleDone(item: TodoItem) {
    item.isDone.toggle()
    // 修改属性后 SwiftData 自动追踪变化，无需额外操作！
}
```

#### Delete：ModelContext.delete()

```swift
func deleteTodo(item: TodoItem) {
    modelContext.delete(item)
}
```

#### 完整示例

```swift
import SwiftUI
import SwiftData

@Model
class TodoItem {
    var title: String
    var isDone: Bool
    var priority: Int
    var createdAt: Date

    init(title: String, isDone: Bool = false, priority: Int = 0) {
        self.title = title
        self.isDone = isDone
        self.priority = priority
        self.createdAt = Date()
    }
}

struct SwiftDataCRUDView: View {
    @Environment(\.modelContext) private var modelContext
    @Query(sort: \TodoItem.createdAt, order: .reverse) private var todos: [TodoItem]
    @State private var newTitle: String = ""
    @State private var newPriority: Int = 0

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                HStack {
                    TextField("新任务...", text: $newTitle)
                        .textFieldStyle(.roundedBorder)
                    Button("添加") {
                        addTodo()
                    }
                    .buttonStyle(.borderedProminent)
                    .disabled(newTitle.isEmpty)
                }
                .padding(.horizontal)

                Picker("优先级", selection: $newPriority) {
                    Text("低").tag(0)
                    Text("中").tag(1)
                    Text("高").tag(2)
                }
                .pickerStyle(.segmented)
                .padding(.horizontal)

                if todos.isEmpty {
                    ContentUnavailableView("暂无任务", systemImage: "checkmark.circle", description: Text("添加你的第一个待办事项"))
                } else {
                    List {
                        ForEach(todos) { item in
                            HStack {
                                Button {
                                    toggleDone(item: item)
                                } label: {
                                    Image(systemName: item.isDone ? "checkmark.circle.fill" : "circle")
                                        .foregroundStyle(item.isDone ? .green : .gray)
                                        .font(.title3)
                                }

                                VStack(alignment: .leading, spacing: 2) {
                                    Text(item.title)
                                        .strikethrough(item.isDone)
                                        .foregroundStyle(item.isDone ? .secondary : .primary)
                                    HStack {
                                        priorityLabel(item.priority)
                                        Text(item.createdAt, style: .relative)
                                            .font(.caption2)
                                            .foregroundStyle(.tertiary)
                                    }
                                }
                            }
                            .padding(.vertical, 2)
                        }
                        .onDelete(perform: deleteTodos)
                    }
                }
            }
            .navigationTitle("待办事项")
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    EditButton()
                }
            }
        }
    }

    func priorityLabel(_ priority: Int) -> some View {
        let (text, color) = switch priority {
        case 2: ("高", Color.red)
        case 1: ("中", Color.orange)
        default: ("低", Color.green)
        }
        return Text(text)
            .font(.caption2)
            .padding(.horizontal, 6)
            .padding(.vertical, 2)
            .background(color.opacity(0.15))
            .foregroundStyle(color)
            .clipShape(Capsule())
    }

    func addTodo() {
        guard !newTitle.isEmpty else { return }
        let item = TodoItem(title: newTitle, priority: newPriority)
        modelContext.insert(item)
        newTitle = ""
        newPriority = 0
    }

    func toggleDone(item: TodoItem) {
        item.isDone.toggle()
    }

    func deleteTodos(at offsets: IndexSet) {
        for index in offsets {
            modelContext.delete(todos[index])
        }
    }
}
```

### 查询与排序

#### #Predicate 过滤

`#Predicate` 是 SwiftData 的查询语法，类似 SQL 的 `WHERE` 子句：

```swift
// 未完成的任务
@Query(filter: #Predicate<TodoItem> { !$0.isDone }) private var pendingTodos: [TodoItem]

// 高优先级任务
@Query(filter: #Predicate<TodoItem> { $0.priority >= 2 }) private var highPriorityTodos: [TodoItem]

// 组合条件
@Query(filter: #Predicate<TodoItem> { !$0.isDone && $0.priority >= 1 }) private var urgentTodos: [TodoItem]
```

💡 **提示**：`#Predicate` 使用的是 Swift 原生语法，不是字符串，所以有编译时类型检查，写错了编译器会报错！

⚠️ **警告**：`#Predicate` 中不能使用自定义函数、可选链等复杂语法，只支持基本的比较和逻辑运算。

#### SortDescriptor 排序

`SortDescriptor` 定义排序规则，类似 SQL 的 `ORDER BY`：

```swift
// 按创建时间降序
@Query(sort: \TodoItem.createdAt, order: .reverse) private var todos: [TodoItem]

// 按优先级降序，再按创建时间降序
@Query(sort: [
    SortDescriptor(\TodoItem.priority, order: .reverse),
    SortDescriptor(\TodoItem.createdAt, order: .reverse)
]) private var todos: [TodoItem]
```

## 数据存储方案选择指南

### 决策流程图（文字描述）

选择数据存储方案时，按以下步骤思考：

```
1. 数据是否敏感（密码、Token）？
   → 是：使用 Keychain
   → 否：继续 ↓

2. 数据量是否很小（几个键值对）？
   → 是：使用 UserDefaults
   → 否：继续 ↓

3. 数据是否是文件（图片、文档、JSON 缓存）？
   → 是：使用 FileManager
   → 否：继续 ↓

4. 数据是否是结构化的（需要查询、排序、过滤）？
   → 是：使用 SwiftData（iOS 17+）或 Core Data
   → 否：使用 FileManager（JSON 文件）
```

### 各方案适用场景对比表

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 用户偏好（主题、语言） | UserDefaults | 简单键值对，读写快 |
| 首次启动标记 | UserDefaults | 一个 Bool 值搞定 |
| 登录 Token | Keychain | 敏感信息需要加密 |
| 缓存 API 返回的 JSON | FileManager | 文件形式，方便管理 |
| 保存用户创建的图片 | FileManager | 二进制文件 |
| 待办事项列表 | SwiftData | 需要增删改查、排序、过滤 |
| 笔记/日记 App | SwiftData | 结构化数据，可能有关联 |
| 离线数据同步 | SwiftData | 需要复杂查询和状态管理 |
| 临时计算结果 | 不持久化（内存） | 不需要保存 |
| 搜索历史 | UserDefaults | 数据量小，结构简单 |

💡 **提示**：一个 App 通常会组合使用多种方案。比如一个笔记 App 可能同时用 UserDefaults 存设置、FileManager 存图片缓存、SwiftData 存笔记数据。

⚠️ **警告**：不要用 UserDefaults 存储大量数据！UserDefaults 启动时会全部加载到内存，数据量大会拖慢 App 启动速度。一般建议不超过几百 KB。

## 小结

本章我们学习了 iOS 开发中三种核心的数据持久化方案：

| 方案 | 核心用法 | 适合场景 |
|------|---------|---------|
| **UserDefaults** | `@AppStorage`、Codable 编码存储 | 简单设置、小数据 |
| **FileManager** | Documents 目录读写 JSON 文件 | 文件缓存、中等数据 |
| **SwiftData** | `@Model`、`@Query`、`ModelContext` | 结构化数据、增删改查 |

🔑 **核心记忆点**：
1. UserDefaults 适合存简单键值对，不要存大数据
2. FileManager 适合存文件和 JSON 缓存
3. SwiftData 是 iOS 17+ 的现代数据库方案，新项目首选
4. SwiftData 的 CRUD：insert / @Query / 直接修改属性 / delete
5. 根据数据特点和场景选择方案，可以组合使用
