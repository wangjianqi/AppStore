## 1. CoreLocation 基础

### 1.1 什么是 CoreLocation？

CoreLocation 是 Apple 提供的定位框架，就像一个"GPS 导航仪"——你告诉它"我需要位置"，它就去问手机的 GPS、Wi-Fi、蓝牙等硬件，然后把经纬度交给你。

> 💡 生活类比：CoreLocation 就像外卖小哥的手机导航，它知道"你在哪"，但不会随便告诉别人——必须经过你同意。

### 1.2 核心类一览

| 类名 | 作用 | 生活类比 |
|------|------|----------|
| `CLLocationManager` | 定位管理器，负责请求权限、获取位置 | 导航仪的"开关" |
| `CLLocation` | 表示一个位置（经纬度+海拔+精度等） | 一个"地点坐标" |
| `CLGeocoder` | 地理编码/反编码 | "地址翻译官" |

### 1.3 请求定位权限

**第一步：在 Info.plist 中添加权限描述**

| Key | 值示例 | 用途 |
|-----|--------|------|
| `NSLocationWhenInUseUsageDescription` | "我们需要您的位置来推荐附近咖啡店" | 前台定位 |
| `NSLocationAlwaysAndWhenInUseUsageDescription` | "我们需要始终获取位置以提供导航服务" | 前台+后台定位 |

> ⚠️ 如果不添加这些描述，App 会直接崩溃！这是 iOS 的硬性要求。

**第二步：创建 CLLocationManager 并请求权限**

```swift
import CoreLocation

class LocationManager: NSObject, CLLocationManagerDelegate, ObservableObject {
    private let manager = CLLocationManager()
    @Published var location: CLLocation?

    override init() {
        super.init()
        manager.delegate = self
        manager.desiredAccuracy = kCLLocationAccuracyBest
        manager.requestWhenInUseAuthorization()
    }

    func start() {
        manager.startUpdatingLocation()
    }

    // 代理方法：获取到新位置
    func locationManager(_ manager: CLLocationManager, didUpdateLocations locations: [CLLocation]) {
        location = locations.last
    }

    // 代理方法：定位失败
    func locationManager(_ manager: CLLocationManager, didFailWithError error: Error) {
        print("定位失败：\(error.localizedDescription)")
    }
}
```

### 1.4 获取经纬度

拿到 `CLLocation` 后，经纬度就在里面：

```swift
if let location = locationManager.location {
    let latitude = location.coordinate.latitude   // 纬度，如 39.9042
    let longitude = location.coordinate.longitude  // 经度，如 116.4074
    print("当前位置：纬度 \(latitude)，经度 \(longitude)")
}
```

> 💡 经纬度就像地球的"门牌号"——纬度是南北方向（-90 到 90），经度是东西方向（-180 到 180）。北京的经纬度大约是 (39.9, 116.4)。

### 1.5 前台定位 vs 后台定位

| 特性 | 前台定位 (WhenInUse) | 后台定位 (Always) |
|------|---------------------|-------------------|
| Info.plist Key | `NSLocationWhenInUseUsageDescription` | `NSLocationAlwaysAndWhenInUseUsageDescription` |
| App 在前台时可定位 | ✅ | ✅ |
| App 在后台时可定位 | ❌（默认） | ✅ |
| 用户看到的权限弹窗 | "使用App时允许" | "始终允许" |
| 审核要求 | 较低 | 较高，需说明为什么后台也要定位 |

**后台定位的额外配置：**

1. 在 Info.plist 中添加 `UIBackgroundModes`，包含 `location`
2. 调用 `manager.allowsBackgroundLocationUpdates = true`

```swift
manager.allowsBackgroundLocationUpdates = true
manager.pausesLocationUpdatesAutomatically = true  // 自动暂停以省电
```

> ⚠️ 后台定位非常耗电！除非你的 App 真的需要（如导航、跑步记录），否则不要轻易开启。审核时 Apple 也会重点审查。

## 2. 位置权限类型详解

### 2.1 三种权限类型

| 权限类型 | 说明 | 适用场景 |
|----------|------|----------|
| `whenInUse` | 仅 App 在前台时定位 | 找附近餐厅、天气查询 |
| `always` | 前台+后台均可定位 | 导航、运动追踪、地理围栏 |
| 临时精确位置（Precise: Temporary） | iOS 14+ 用户可只给大概位置 | 用户不想暴露精确位置时 |

### 2.2 权限状态枚举

```swift
enum CLAuthorizationStatus {
    case notDetermined       // 还没问过用户
    case restricted          // 家长控制等限制
    case denied              // 用户拒绝
    case authorizedAlways    // 始终允许
    case authorizedWhenInUse // 使用时允许
}
```

### 2.3 检查与响应权限变化

```swift
func locationManager(_ manager: CLLocationManager, didChangeAuthorization status: CLAuthorizationStatus) {
    switch status {
    case .authorizedWhenInUse, .authorizedAlways:
        manager.startUpdatingLocation()
    case .denied, .restricted:
        print("用户拒绝了定位权限")
    case .notDetermined:
        manager.requestWhenInUseAuthorization()
    @unknown default:
        break
    }
}
```

### 2.4 iOS 14+ 精确位置与临时授权

iOS 14 开始，用户可以选择只给"大概位置"（模糊定位）。你的 App 可以请求临时的精确位置：

```swift
// 检查当前精度级别
let accuracy = manager.accuracyAuthorization

if accuracy == .reducedAccuracy {
    // 请求临时精确位置
    manager.requestTemporaryFullAccuracyAuthorization(
        withPurposeKey: "PreciseLocation"  // 必须在 Info.plist 的
        // NSLocationTemporaryUsageDescriptionDictionary 中定义
    )
}
```

**Info.plist 配置：**

```xml
<key>NSLocationTemporaryUsageDescriptionDictionary</key>
<dict>
    <key>PreciseLocation</key>
    <string>我们需要精确位置来为您导航到咖啡店</string>
</dict>
```

> 💡 这就像告诉用户："我知道你不想透露精确位置，但导航确实需要，能不能临时开一下？"——用完即关，更尊重隐私。

## 3. MapKit 与 SwiftUI

### 3.1 基本地图视图

SwiftUI 提供了原生的 `Map` 视图，就像在 App 里嵌入了一个"迷你高德地图"：

```swift
import SwiftUI
import MapKit

struct SimpleMapView: View {
    @State private var region = MKCoordinateRegion(
        center: CLLocationCoordinate2D(latitude: 39.9042, longitude: 116.4074),
        span: MKCoordinateSpan(latitudeDelta: 0.05, longitudeDelta: 0.05)
    )

    var body: some View {
        Map(initialPosition: .region(region))
            .ignoresSafeArea()
    }
}
```

### 3.2 区域（Region）详解

`MKCoordinateRegion` 定义了地图显示的区域，就像相机的"取景框"：

| 属性 | 含义 | 生活类比 |
|------|------|----------|
| `center` | 地图中心点坐标 | 相机对准的位置 |
| `span.latitudeDelta` | 纬度跨度（南北范围） | 取景框的高度 |
| `span.longitudeDelta` | 经度跨度（东西范围） | 取景框的宽度 |

```swift
// 小区域（看一条街）
MKCoordinateRegion(
    center: CLLocationCoordinate2D(latitude: 39.9042, longitude: 116.4074),
    span: MKCoordinateSpan(latitudeDelta: 0.01, longitudeDelta: 0.01)
)

// 大区域（看整个城市）
MKCoordinateRegion(
    center: CLLocationCoordinate2D(latitude: 39.9042, longitude: 116.4074),
    span: MKCoordinateSpan(latitudeDelta: 0.5, longitudeDelta: 0.5)
)
```

### 3.3 添加标注（Marker / Annotation）

标注就像在地图上"插旗子"，告诉用户"这里有东西"：

**使用 Marker（iOS 16+，SwiftUI 原生）：**

```swift
struct CoffeeShop: Identifiable {
    let id = UUID()
    let name: String
    let coordinate: CLLocationCoordinate2D
}

struct MapWithMarkersView: View {
    let shops = [
        CoffeeShop(name: "星巴克·国贸店", coordinate: CLLocationCoordinate2D(latitude: 39.9087, longitude: 116.4605)),
        CoffeeShop(name: "瑞幸·望京店", coordinate: CLLocationCoordinate2D(latitude: 39.9942, longitude: 116.4713)),
        CoffeeShop(name: "Manner·三里屯店", coordinate: CLLocationCoordinate2D(latitude: 39.9339, longitude: 116.4539))
    ]

    @State private var region = MKCoordinateRegion(
        center: CLLocationCoordinate2D(latitude: 39.93, longitude: 116.45),
        span: MKCoordinateSpan(latitudeDelta: 0.1, longitudeDelta: 0.1)
    )

    var body: some View {
        Map(initialPosition: .region(region)) {
            ForEach(shops) { shop in
                Marker(shop.name, coordinate: shop.coordinate)
            }
        }
    }
}
```

**使用 Annotation（自定义标注样式）：**

```swift
Map(initialPosition: .region(region)) {
    ForEach(shops) { shop in
        Annotation(shop.name, coordinate: shop.coordinate) {
            Image(systemName: "cup.and.saucer.fill")
                .foregroundColor(.brown)
                .font(.title2)
                .padding(6)
                .background(.white)
                .clipShape(Circle())
                .shadow(radius: 3)
        }
    }
}
```

> 💡 `Marker` 是系统标准样式（彩色气球），`Annotation` 可以自定义外观。就像 Marker 是"标准旗帜"，Annotation 是"自己画的旗帜"。

### 3.4 标注样式对比

| 特性 | Marker | Annotation |
|------|--------|------------|
| 最低系统版本 | iOS 16+ | iOS 16+ |
| 外观 | 系统标准气球图标 | 完全自定义 |
| 自定义难度 | 仅可改颜色（tint） | 任意 SwiftUI 视图 |
| 点击弹出标签 | 自动显示标题 | 自动显示标题 |
| 适用场景 | 快速标注、不需要自定义外观 | 品牌化 UI、复杂标注 |

## 4. 地图交互

### 4.1 用户位置跟踪

让地图自动跟踪用户当前位置，就像导航时"蓝点跟着你走"：

```swift
struct TrackingMapView: View {
    @State private var position: MapCameraPosition = .userLocation(fallback: .automatic)

    var body: some View {
        Map(position: $position) {
            UserAnnotation()
        }
        .mapControls {
            MapUserLocationButton()
            MapCompass()
            MapScaleView()
        }
    }
}
```

> ⚠️ 使用 `UserAnnotation()` 和 `MapUserLocationButton()` 前，确保已获取定位权限，否则地图上不会显示蓝点。

**需要在 App 入口配置 LocationManager：**

```swift
@main
struct CoffeeApp: App {
    @StateObject private var locationManager = LocationManager()

    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(locationManager)
        }
    }
}
```

### 4.2 地图拖拽与区域变化监听

用户拖拽地图时，你可能想知道"他现在看的是哪块区域"——比如拖到新区域后加载附近的咖啡店：

```swift
struct InteractiveMapView: View {
    @State private var position = MapCameraPosition.automatic
    @State private var currentCenter: CLLocationCoordinate2D?

    var body: some View {
        Map(position: $position) {
            UserAnnotation()
        }
        .onMapCameraChange(frequency: .onEnd) { context in
            currentCenter = context.region.center
            print("新中心：纬度 \(context.region.center.latitude)，经度 \(context.region.center.longitude)")
            print("缩放级别：\(context.camera.distance)")
        }
    }
}
```

**`onMapCameraChange` 的 frequency 参数：**

| 值 | 含义 | 适用场景 |
|----|------|----------|
| `.continuous` | 每帧都触发 | 实时动画、跟随效果 |
| `.onEnd` | 拖拽结束后触发 | 加载附近数据（推荐，省性能） |

> 💡 就像翻书——`.continuous` 是每翻一页都告诉你，`.onEnd` 是翻完了才告诉你。大多数场景用 `.onEnd` 就够了。

### 4.3 相机控制

你可以通过代码控制地图的视角，就像"远程遥控无人机"：


## 5. 地理编码与反编码

### 5.1 什么是地理编码？

| 术语 | 输入 | 输出 | 生活类比 |
|------|------|------|----------|
| 地理编码 (Geocoding) | 地址文字 | 经纬度坐标 | "北京市朝阳区三里屯路19号" → (39.9339, 116.4539) |
| 反编码 (Reverse Geocoding) | 经纬度坐标 | 地址文字 | (39.9339, 116.4539) → "北京市朝阳区三里屯路19号" |

> 💡 就像查字典——地理编码是"按字查页码"，反编码是"按页码查字"。

### 5.2 使用 CLGeocoder

```swift
import CoreLocation

class GeocoderHelper {
    static let shared = CLGeocoder()

    // 地理编码：地址 → 坐标
    static func geocode(address: String) async throws -> CLLocationCoordinate2D {
        let placemarks = try await shared.geocodeAddressString(address)
        guard let location = placemarks.first?.location else {
            throw GeocoderError.noResult
        }
        return location.coordinate
    }

    // 反编码：坐标 → 地址
    static func reverseGeocode(coordinate: CLLocationCoordinate2D) async throws -> String {
        let location = CLLocation(latitude: coordinate.latitude, longitude: coordinate.longitude)
        let placemarks = try await shared.reverseGeocodeLocation(location)
        guard let placemark = placemarks.first else {
            throw GeocoderError.noResult
        }
        return placemark.name ?? "未知地址"
    }
}

enum GeocoderError: Error {
    case noResult
}
```

### 5.3 在 SwiftUI 中使用

```swift
struct GeocodingView: View {
    @State private var addressInput = ""
    @State private var resultText = ""
    @State private var isLoading = false

    var body: some View {
        VStack(spacing: 16) {
            TextField("输入地址，如：天安门", text: $addressInput)
                .textFieldStyle(.roundedBorder)

            Button("地址 → 坐标") {
                geocodeAddress()
            }
            .disabled(addressInput.isEmpty || isLoading)

            if !resultText.isEmpty {
                Text(resultText)
                    .padding()
                    .background(Color(.systemGray6))
                    .cornerRadius(8)
            }
        }
        .padding()
    }

    private func geocodeAddress() {
        isLoading = true
        Task {
            do {
                let coordinate = try await GeocoderHelper.geocode(address: addressInput)
                resultText = "纬度：\(coordinate.latitude)\n经度：\(coordinate.longitude)"
            } catch {
                resultText = "编码失败：\(error.localizedDescription)"
            }
            isLoading = false
        }
    }
}
```

> ⚠️ CLGeocoder 有频率限制，不要短时间内发送大量请求，否则会被 Apple 限流甚至封禁。建议每次请求间隔至少 1 秒。

## 6. 实战示例：附近的咖啡店 App

把前面学的知识串起来，做一个完整的小 App！

### 6.1 数据模型

```swift
import CoreLocation

struct CoffeeShop: Identifiable {
    let id = UUID()
    let name: String
    let address: String
    let coordinate: CLLocationCoordinate2D
    let rating: Double

    var distance: Double = 0
}
```

### 6.2 LocationManager

```swift
import CoreLocation

class LocationManager: NSObject, CLLocationManagerDelegate, ObservableObject {
    private let manager = CLLocationManager()
    @Published var userLocation: CLLocation?
    @Published var authorizationStatus: CLAuthorizationStatus = .notDetermined

    override init() {
        super.init()
        manager.delegate = self
        manager.desiredAccuracy = kCLLocationAccuracyHundredMeters
    }

    func requestPermission() {
        manager.requestWhenInUseAuthorization()
    }

    func startUpdating() {
        manager.startUpdatingLocation()
    }

    func locationManager(_ manager: CLLocationManager, didUpdateLocations locations: [CLLocation]) {
        userLocation = locations.last
    }

    func locationManager(_ manager: CLLocationManager, didChangeAuthorization status: CLAuthorizationStatus) {
        authorizationStatus = status
        if status == .authorizedWhenInUse || status == .authorizedAlways {
            manager.startUpdatingLocation()
        }
    }
}
```

### 6.3 主视图

```swift
import SwiftUI
import MapKit

struct CoffeeShopMapView: View {
    @StateObject private var locationManager = LocationManager()

    let shops = [
        CoffeeShop(name: "星巴克·国贸店", address: "建国门外大街1号", coordinate: CLLocationCoordinate2D(latitude: 39.9087, longitude: 116.4605), rating: 4.5),
        CoffeeShop(name: "瑞幸·望京店", address: "望京西路1号", coordinate: CLLocationCoordinate2D(latitude: 39.9942, longitude: 116.4713), rating: 4.2),
        CoffeeShop(name: "Manner·三里屯店", address: "三里屯路19号", coordinate: CLLocationCoordinate2D(latitude: 39.9339, longitude: 116.4539), rating: 4.7),
        CoffeeShop(name: "Tim Hortons·朝阳店", address: "朝阳路100号", coordinate: CLLocationCoordinate2D(latitude: 39.9219, longitude: 116.4435), rating: 4.0)
    ]

    @State private var selectedShop: CoffeeShop?
    @State private var position: MapCameraPosition = .automatic

    var body: some View {
        ZStack(alignment: .bottom) {
            mapView

            if locationManager.authorizationStatus == .notDetermined {
                permissionOverlay
            }
        }
        .onAppear {
            locationManager.requestPermission()
        }
    }

    var mapView: some View {
        Map(position: $position, selection: $selectedShop) {
            UserAnnotation()

            ForEach(shops) { shop in
                Annotation(shop.name, coordinate: shop.coordinate) {
                    CoffeeAnnotationView(shop: shop, isSelected: selectedShop?.id == shop.id)
                        .onTapGesture {
                            selectedShop = shop
                        }
                }
            }
        }
        .mapControls {
            MapUserLocationButton()
            MapCompass()
        }
        .overlay(alignment: .topTrailing) {
            if let shop = selectedShop {
                ShopDetailCard(shop: shop, userLocation: locationManager.userLocation) {
                    selectedShop = nil
                }
                .padding()
                .transition(.move(edge: .top).combined(with: .opacity))
                .animation(.easeInOut, value: selectedShop)
            }
        }
    }

    var permissionOverlay: some View {
        VStack(spacing: 16) {
            Image(systemName: "location.circle")
                .font(.system(size: 60))
                .foregroundColor(.blue)
            Text("需要定位权限来查找附近咖啡店")
                .font(.headline)
            Button("开启定位") {
                locationManager.requestPermission()
            }
            .buttonStyle(.borderedProminent)
        }
        .padding(40)
        .background(.ultraThinMaterial)
        .cornerRadius(20)
        .shadow(radius: 10)
    }
}
```

### 6.5 详情卡片

```swift
struct ShopDetailCard: View {
    let shop: CoffeeShop
    let userLocation: CLLocation?
    let onClose: () -> Void

    var distanceText: String {
        guard let userLocation = userLocation else { return "距离未知" }
        let shopLocation = CLLocation(latitude: shop.coordinate.latitude, longitude: shop.coordinate.longitude)
        let distance = userLocation.distance(from: shopLocation)
        if distance < 1000 {
            return String(format: "距离 %.0f 米", distance)
        } else {
            return String(format: "距离 %.1f 公里", distance / 1000)
        }
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            HStack {
                VStack(alignment: .leading) {
                    Text(shop.name)
                        .font(.headline)
                    Text(shop.address)
                        .font(.caption)
                        .foregroundColor(.secondary)
                }
                Spacer()
                Button(action: onClose) {
                    Image(systemName: "xmark.circle.fill")
                        .foregroundColor(.secondary)
                }
            }

            HStack {
                Label(distanceText, systemImage: "figure.walk")
                    .font(.subheadline)
                    .foregroundColor(.blue)
                Spacer()
                HStack(spacing: 2) {
                    Image(systemName: "star.fill")
                        .foregroundColor(.orange)
                        .font(.caption)
                    Text(String(format: "%.1f", shop.rating))
                        .font(.subheadline)
                }
            }
        }
        .padding()
        .background(.ultraThinMaterial)
        .cornerRadius(16)
        .shadow(radius: 5)
    }
}
```

> 💡 这个实战 App 涵盖了：定位权限请求 → 获取用户位置 → 地图展示 → 标注添加 → 点击交互 → 距离计算，是一个完整的地图+定位功能闭环。

## 7. 隐私与审核

### 7.1 Info.plist 权限描述要求

Apple 对定位权限描述的审核非常严格，以下是常见被拒原因：

| 被拒原因 | 正确做法 |
|----------|----------|
| 描述太笼统，如"需要定位" | 具体说明用途，如"需要您的位置来推荐附近咖啡店" |
| 请求了 Always 权限但只用了 WhenInUse | 只请求实际需要的最低权限 |
| 没有在代码中实际使用定位 | 不要请求不使用的权限 |
| 后台定位没有合理理由 | 只在真正需要时才请求后台定位 |

### 7.2 最小化定位使用原则

```swift
// ✅ 好的做法：按需定位
manager.desiredAccuracy = kCLLocationAccuracyHundredMeters  // 不需要精确到米
manager.startUpdatingLocation()
// 拿到一次位置后停止
func locationManager(_ manager: CLLocationManager, didUpdateLocations locations: [CLLocation]) {
    if let location = locations.last {
        // 处理位置...
        manager.stopUpdatingLocation()  // 用完即停
    }
}

// ❌ 坏的做法：一直高精度定位
manager.desiredAccuracy = kCLLocationAccuracyBestForNavigation  // 太精确了
manager.startUpdatingLocation()
// 从不停止...
```

### 7.3 精度级别选择

| 精度常量 | 精度 | 耗电 | 适用场景 |
|----------|------|------|----------|
| `kCLLocationAccuracyBestForNavigation` | ~5米 | 🔴 极高 | 导航 |
| `kCLLocationAccuracyBest` | ~10米 | 🟠 高 | 精确打卡 |
| `kCLLocationAccuracyNearestTenMeters` | ~10米 | 🟡 中 | 找附近店铺 |
| `kCLLocationAccuracyHundredMeters` | ~100米 | 🟢 低 | 天气查询 |
| `kCLLocationAccuracyKilometer` | ~1公里 | 🟢 很低 | 城市级服务 |
| `kCLLocationAccuracyThreeKilometers` | ~3公里 | 🟢 极低 | 省份级服务 |

> ⚠️ 审核时 Apple 会检查你的 App 是否使用了超出必要范围的定位精度。如果只是查天气却用了导航级精度，很可能被拒。

### 7.4 权限被拒后的引导

当用户拒绝定位权限后，不要什么都不做，应该引导用户去设置中开启：

```swift
if locationManager.authorizationStatus == .denied {
    VStack(spacing: 16) {
        Text("定位权限被关闭")
            .font(.headline)
        Text("请在设置中开启定位权限以使用此功能")
            .multilineTextAlignment(.center)
            .foregroundColor(.secondary)
        Button("前往设置") {
            if let url = URL(string: UIApplication.openSettingsURLString) {
                UIApplication.shared.open(url)
            }
        }
        .buttonStyle(.borderedProminent)
    }
    .padding()
}
```

## 8. 国内地图注意

### 8.1 为什么需要关注国内地图？

Apple 地图在中国使用的是高德数据源，但功能上与高德 App 有差距。如果你的 App 面向国内用户，可能需要考虑使用第三方地图 SDK：

| 对比项 | Apple MapKit | 高德地图 SDK | 百度地图 SDK |
|--------|-------------|-------------|-------------|
| 数据源 | 高德（中国） | 自有 | 自有 |
| 国内 POI 丰富度 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 路线规划 | 基础 | 丰富（驾车/公交/步行） | 丰富 |
| 导航 | 基础 | 专业级 | 专业级 |
| 集成难度 | 原生，最简单 | 中等，需注册 Key | 中等，需注册 Key |
| 费用 | 免费 | 个人免费/商用付费 | 个人免费/商用付费 |
| SwiftUI 支持 | 原生 | 有 SwiftUI 封装 | 有 SwiftUI 封装 |

### 8.2 高德地图 SDK 简介集成步骤

1. 在 [高德开放平台](https://lbs.amap.com/) 注册账号并创建应用
2. 获取 API Key
3. 通过 CocoaPods 或 SPM 集成

```ruby
# Podfile
pod 'AMap3DMap'      # 3D地图
pod 'AMapSearch'     # 搜索服务
pod 'AMapLocation'   # 定位服务
```

4. 在 `AppDelegate` 中配置 Key

```swift
import AMapFoundationKit

func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    AMapServices.shared().apiKey = "你的高德Key"
    return true
}
```

### 8.3 百度地图 SDK 简介集成步骤

1. 在 [百度地图开放平台](https://lbsyun.baidu.com/) 注册并创建应用
2. 获取 AK（Access Key）
3. 通过 CocoaPods 集成

```ruby
# Podfile
pod 'BaiduMapKit'        # 地图
pod 'BMKLocationKit'    # 定位
```

### 8.4 坐标系差异（重要！）

> ⚠️ 这是非常容易踩坑的地方！

| 坐标系 | 名称 | 使用方 | 示例坐标 |
|--------|------|--------|----------|
| WGS-84 | 国际标准坐标 | GPS、Apple 地图 | (39.9042, 116.4074) |
| GCJ-02 | 国测局坐标（"火星坐标"） | 高德地图、腾讯地图 | (39.9052, 116.4089) |
| BD-09 | 百度加密坐标 | 百度地图 | (39.9062, 116.4101) |

**同一个地点在不同坐标系下经纬度不同！** 如果你在 Apple 地图上用高德的坐标，位置会偏移几百米。

```swift
// 坐标转换是必须的！
// 高德/腾讯 GCJ-02 → Apple MapKit WGS-84 需要转换
// 百度 BD-09 → Apple MapKit WGS-84 需要转换
// 高德/腾讯之间不需要转换（都是 GCJ-02）
```

> 💡 生活类比：就像不同国家用不同的度量衡——同样是"1斤"，中国是500克，台湾是600克。坐标也是，同样一组数字，在不同坐标系下指向不同的位置。

### 8.5 选择建议

| 场景 | 推荐 |
|------|------|
| 简单展示位置、不需要复杂路线规划 | Apple MapKit（最省事） |
| 国内 POI 搜索、路线规划 | 高德地图 SDK |
| 需要百度生态（如小程序互通） | 百度地图 SDK |
| 海外用户为主 | Apple MapKit 或 Google Maps |

## 小结

| 知识点 | 核心要点 |
|--------|----------|
| CoreLocation | 通过 `CLLocationManager` 请求权限、获取位置 |
| 权限类型 | WhenInUse（前台）、Always（前后台）、临时精确位置 |
| MapKit + SwiftUI | `Map` 视图 + `Marker`/`Annotation` 标注 |
| 地图交互 | `UserAnnotation` 跟踪、`onMapCameraChange` 监听区域变化 |
| 地理编码 | `CLGeocoder` 实现地址↔坐标互转 |
| 实战 | 附近咖啡店 App = 定位 + 地图 + 标注 + 距离计算 |
| 隐私审核 | 权限描述要具体、精度要最小化、用完即停 |
| 国内地图 | 注意坐标系差异（WGS-84/GCJ-02/BD-09），按需选择第三方 SDK |

> 💡 地图与定位是 iOS 开发中非常实用的能力，但也是隐私敏感区域。记住一个原则：**只请求你需要的，用完就释放，对用户坦诚**。这样既能通过审核，也能赢得用户信任。
