# 34-动画与手势

> 🎯 **本章目标**：掌握 SwiftUI 动画系统的两大核心——隐式动画与显式动画，学会使用各种动画曲线和弹簧动画，熟练运用点击、长按、拖拽、缩放、旋转等手势，理解转场动画和共享元素转场，让你的 App "动"起来。

---

## 隐式动画

💡 **通俗理解**：隐式动画就像"自动挡"——你只需要告诉 SwiftUI"这个属性变化时要加动画"，SwiftUI 会自动帮你处理过渡效果，不需要手动控制动画的开始和结束。

### .animation() 修饰符

`.animation()` 修饰符会让它所监听的属性**在发生变化时自动产生动画**。你只需要改变属性的值，动画就会自动执行。

```swift
struct ImplicitAnimationDemo: View {
    @State private var isExpanded = false

    var body: some View {
        VStack(spacing: 40) {
            Circle()
                .fill(Color.blue.gradient)
                .frame(width: isExpanded ? 200 : 100, height: isExpanded ? 200 : 100)
                .animation(.easeInOut(duration: 0.5), value: isExpanded)

            Button(isExpanded ? "缩小" : "放大") {
                isExpanded.toggle()
            }
            .font(.headline)
        }
    }
}
```

### 自动对属性变化添加动画

`.animation()` 的关键参数是 `value`——只有当这个值变化时，动画才会触发：

| 参数 | 说明 | 示例 |
|------|------|------|
| `animation` | 动画类型 | `.easeInOut`、`.spring()` |
| `value` | 监听的值 | `isExpanded`、`scale` |

⚠️ **警告**：如果不指定 `value`，所有属性变化都会触发动画，可能导致意外的动画效果。**务必指定 `value`！**

```swift
// ❌ 不推荐：所有变化都会动画
Circle()
    .frame(width: size)
    .animation(.default)

// ✅ 推荐：只在 size 变化时动画
Circle()
    .frame(width: size)
    .animation(.default, value: size)
```

### 示例

```swift
import SwiftUI

struct ImplicitAnimationExample: View {
    @State private var isOn = false
    @State private var rotation: Double = 0
    @State private var opacity: Double = 1

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 40) {
                    RoundedRectangle(cornerRadius: isOn ? 40 : 16)
                        .fill(isOn ? Color.green.gradient : Color.red.gradient)
                        .frame(width: isOn ? 200 : 150, height: isOn ? 80 : 150)
                        .animation(.easeInOut(duration: 0.6), value: isOn)

                    Button(isOn ? "关闭" : "打开") {
                        isOn.toggle()
                    }
                    .font(.headline)
                    .buttonStyle(.borderedProminent)

                    Divider()

                    Image(systemName: "arrow.clockwise")
                        .font(.system(size: 50))
                        .rotationEffect(.degrees(rotation))
                        .animation(.easeInOut(duration: 0.5), value: rotation)

                    Button("旋转 90°") {
                        rotation += 90
                    }
                    .font(.headline)
                    .buttonStyle(.borderedProminent)

                    Divider()

                    Text("淡入淡出")
                        .font(.title.bold())
                        .opacity(opacity)
                        .animation(.easeInOut(duration: 0.3), value: opacity)

                    Button(opacity < 1 ? "显示" : "隐藏") {
                        opacity = opacity < 1 ? 1 : 0.2
                    }
                    .font(.headline)
                    .buttonStyle(.borderedProminent)
                }
                .padding()
            }
            .navigationTitle("隐式动画")
        }
    }
}
```

💡 **提示**：隐式动画适合"简单、自动"的场景——只要属性变了就动画。如果需要精确控制动画的时机和范围，请使用显式动画。

## 显式动画

💡 **通俗理解**：显式动画就像"手动挡"——你明确地告诉 SwiftUI"这段代码里的变化要用动画"，只有 `withAnimation { }` 包裹的代码才会产生动画效果。

### withAnimation { ... }

`withAnimation` 让你**精确控制哪些变化需要动画**：

```swift
struct ExplicitAnimationDemo: View {
    @State private var isExpanded = false

    var body: some View {
        VStack(spacing: 40) {
            Circle()
                .fill(Color.blue.gradient)
                .frame(width: isExpanded ? 200 : 100, height: isExpanded ? 200 : 100)

            Button("切换大小") {
                withAnimation(.easeInOut(duration: 0.5)) {
                    isExpanded.toggle()
                }
            }
        }
    }
}
```

### 指定动画范围

`withAnimation` 的最大优势是**只动画包裹内的变化**，外面的代码不受影响：

| 对比 | 隐式动画 `.animation()` | 显式动画 `withAnimation` |
|------|------------------------|-------------------------|
| 控制方式 | 声明式，自动触发 | 命令式，手动触发 |
| 动画范围 | 所有使用该属性的地方 | 只有 `withAnimation { }` 内的代码 |
| 灵活性 | 较低 | 较高 |
| 适用场景 | 简单的属性变化 | 需要精确控制的多属性动画 |

```swift
struct AnimationScopeDemo: View {
    @State private var scale: CGFloat = 1
    @State private var rotation: Double = 0
    @State private var color: Color = .blue

    var body: some View {
        VStack(spacing: 30) {
            Circle()
                .fill(color.gradient)
                .frame(width: 120 * scale, height: 120 * scale)
                .rotationEffect(.degrees(rotation))

            Button("同时动画") {
                withAnimation(.easeInOut(duration: 0.5)) {
                    scale = scale == 1 ? 1.5 : 1
                    rotation += 90
                    color = color == .blue ? .purple : .blue
                }
            }
            .buttonStyle(.borderedProminent)

            Button("只动画缩放") {
                withAnimation(.easeInOut(duration: 0.5)) {
                    scale = scale == 1 ? 1.5 : 1
                }
                rotation += 90
                color = color == .blue ? .purple : .blue
            }
            .buttonStyle(.bordered)
        }
    }
}
```

### 动画回调（completion）

iOS 17+ 提供了 `withAnimation` 的完成回调，让你在动画结束后执行代码：

```swift
struct AnimationCompletionDemo: View {
    @State private var isExpanded = false
    @State private var message = "等待动画..."

    var body: some View {
        VStack(spacing: 30) {
            Text(message)
                .font(.headline)
                .foregroundStyle(.secondary)

            Circle()
                .fill(Color.blue.gradient)
                .frame(width: isExpanded ? 200 : 80, height: isExpanded ? 200 : 80)

            Button("开始动画") {
                message = "动画进行中..."
                withAnimation(.easeInOut(duration: 1.0)) {
                    isExpanded.toggle()
                } completion: {
                    message = isExpanded ? "动画完成：已放大" : "动画完成：已缩小"
                }
            }
            .buttonStyle(.borderedProminent)
        }
    }
}
```

💡 **提示**：`completion` 回调在 iOS 17+ 才可用。如果你需要支持更低版本，可以使用 `DispatchQueue.main.asyncAfter(deadline: .now() + 动画时长)` 来模拟。

### 示例

```swift
import SwiftUI

struct ExplicitAnimationExample: View {
    @State private var cards: [Color] = [.blue, .green, .orange, .purple, .pink]
    @State private var flipped = false

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 30) {
                    Text("点击卡片翻转")
                        .font(.subheadline)
                        .foregroundStyle(.secondary)

                    HStack(spacing: 12) {
                        ForEach(cards, id: \.self) { color in
                            RoundedRectangle(cornerRadius: 12)
                                .fill(flipped ? color.gradient : Color.gray.gradient)
                                .frame(width: 60, height: 90)
                                .rotation3DEffect(.degrees(flipped ? 180 : 0), axis: (x: 0, y: 1, z: 0))
                        }
                    }

                    Button("翻转所有卡片") {
                        withAnimation(.spring(duration: 0.6, bounce: 0.3)) {
                            flipped.toggle()
                        }
                    }
                    .buttonStyle(.borderedProminent)

                    Divider()

                    StaggeredAnimationDemo()
                }
                .padding()
            }
            .navigationTitle("显式动画")
        }
    }
}

struct StaggeredAnimationDemo: View {
    @State private var items: [Bool] = Array(repeating: false, count: 5)

    var body: some View {
        VStack(spacing: 12) {
            Text("交错动画")
                .font(.headline)

            VStack(spacing: 8) {
                ForEach(0..<5, id: \.self) { index in
                    RoundedRectangle(cornerRadius: 8)
                        .fill(Color.blue.gradient)
                        .frame(height: 40)
                        .frame(maxWidth: items[index] ? .infinity : 50)
                        .opacity(items[index] ? 1 : 0.3)
                }
            }

            Button("播放交错动画") {
                for index in 0..<5 {
                    DispatchQueue.main.asyncAfter(deadline: .now() + Double(index) * 0.15) {
                        withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                            items[index].toggle()
                        }
                    }
                }
            }
            .buttonStyle(.bordered)
        }
    }
}
```

## 动画类型详解

### easeIn/easeOut/easeInOut

缓动动画是最基础的动画类型，通过不同的"缓动曲线"控制动画的速度变化。

💡 **通俗理解**：缓动曲线就像开车——`easeIn` 是慢慢起步然后加速，`easeOut` 是快速起步然后慢慢停下，`easeInOut` 是慢慢起步、中间最快、慢慢停下。

| 缓动类型 | 速度变化 | 适用场景 |
|---------|---------|---------|
| `.easeIn` | 慢 → 快 | 物体开始移动（如火箭发射） |
| `.easeOut` | 快 → 慢 | 物体减速停下（如刹车） |
| `.easeInOut` | 慢 → 快 → 慢 | 最常用，自然流畅的移动 |
| `.linear` | 匀速 | 旋转、进度条等匀速变化 |

```swift
import SwiftUI

struct EasingCurveDemo: View {
    @State private var isMoving = false

    var body: some View {
        NavigationStack {
            VStack(spacing: 24) {
                AnimationRow(title: "easeIn", animation: .easeIn(duration: 1.0), isMoving: isMoving)
                AnimationRow(title: "easeOut", animation: .easeOut(duration: 1.0), isMoving: isMoving)
                AnimationRow(title: "easeInOut", animation: .easeInOut(duration: 1.0), isMoving: isMoving)
                AnimationRow(title: "linear", animation: .linear(duration: 1.0), isMoving: isMoving)

                Button(isMoving ? "重置" : "开始") {
                    withAnimation(.easeInOut(duration: 0.3)) {
                        isMoving.toggle()
                    }
                }
                .font(.headline)
                .buttonStyle(.borderedProminent)
                .padding(.top, 20)
            }
            .padding()
            .navigationTitle("缓动曲线对比")
        }
    }
}

struct AnimationRow: View {
    let title: String
    let animation: Animation
    let isMoving: Bool

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            Text(title)
                .font(.caption)
                .foregroundStyle(.secondary)

            HStack {
                Circle()
                    .fill(Color.blue)
                    .frame(width: 24, height: 24)
                    .offset(x: isMoving ? 280 : 0)
                    .animation(animation, value: isMoving)

                Spacer()
            }
            .background(Color.gray.opacity(0.1))
            .clipShape(RoundedRectangle(cornerRadius: 4))
        }
    }
}
```

### spring 弹簧动画

弹簧动画模拟了物理弹簧的效果——物体到达目标位置后会有"回弹"，看起来更自然、更有弹性。

💡 **通俗理解**：弹簧动画就像拉一根橡皮筋——松手后物体会弹到目标位置，还会"抖几下"才停下来。这种效果比缓动动画更生动、更有"物理感"。

#### .spring(duration:bounce:)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `duration` | `Double` | 0.5 | 动画总时长（秒） |
| `bounce` | `Double` | 0.0 | 回弹程度，0 = 无回弹，1 = 最大回弹 |

```swift
// 无回弹（类似 easeInOut）
.animation(.spring(duration: 0.5), value: someValue)

// 轻微回弹（推荐！自然又有弹性）
.animation(.spring(duration: 0.5, bounce: 0.3), value: someValue)

// 明显回弹（活泼、弹跳感强）
.animation(.spring(duration: 0.6, bounce: 0.5), value: someValue)
```

#### 参数说明

| bounce 值 | 效果 | 适用场景 |
|-----------|------|---------|
| `0.0` | 无回弹，平滑到达 | 严肃、正式的 UI |
| `0.1 ~ 0.3` | 轻微回弹，自然舒适 | **大多数场景推荐** |
| `0.4 ~ 0.6` | 明显回弹，活泼有趣 | 游戏、趣味交互 |
| `0.7+` | 强烈弹跳，夸张效果 | 特殊动画、吸引注意 |

⚠️ **警告**：`bounce` 值超过 1.0 会导致动画不稳定，物体可能来回弹跳不停！

#### 示例

```swift
import SwiftUI

struct SpringAnimationDemo: View {
    @State private var isExpanded = false

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 30) {
                    SpringCard(title: "bounce: 0.0", bounce: 0.0, isExpanded: isExpanded)
                    SpringCard(title: "bounce: 0.2", bounce: 0.2, isExpanded: isExpanded)
                    SpringCard(title: "bounce: 0.4", bounce: 0.4, isExpanded: isExpanded)
                    SpringCard(title: "bounce: 0.6", bounce: 0.6, isExpanded: isExpanded)

                    Button(isExpanded ? "重置" : "弹跳！") {
                        isExpanded.toggle()
                    }
                    .font(.headline)
                    .buttonStyle(.borderedProminent)
                }
                .padding()
            }
            .navigationTitle("弹簧动画对比")
        }
    }
}

struct SpringCard: View {
    let title: String
    let bounce: Double
    let isExpanded: Bool

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text(title)
                .font(.caption)
                .foregroundStyle(.secondary)

            RoundedRectangle(cornerRadius: 12)
                .fill(Color.blue.gradient)
                .frame(width: isExpanded ? 300 : 80, height: 40)
                .animation(.spring(duration: 0.6, bounce: bounce), value: isExpanded)
        }
    }
}
```

💡 **提示**：弹簧动画是 iOS 系统动画的"灵魂"——系统自带的开关、弹窗、页面跳转都用了弹簧动画。在大多数场景下，`.spring(duration: 0.4, bounce: 0.2)` 是一个很好的起点。

### 自定义动画曲线

当内置的缓动和弹簧动画不能满足需求时，你可以自定义动画曲线。

#### .timingCurve()

`timingCurve` 使用贝塞尔曲线定义动画速度，类似于 CSS 的 `cubic-bezier()`：

```swift
// 参数：控制点1(x1, y1)，控制点2(x2, y2)，值范围 0~1
Animation.timingCurve(0.4, 0.0, 0.2, 1.0, duration: 0.5)
```

💡 **通俗理解**：贝塞尔曲线就像画一条弯曲的线来描述速度变化——曲线越陡，速度越快；曲线越平，速度越慢。

```swift
import SwiftUI

struct TimingCurveDemo: View {
    @State private var isMoving = false

    var body: some View {
        NavigationStack {
            VStack(spacing: 24) {
                CurveRow(
                    title: "Material Design 标准曲线",
                    animation: .timingCurve(0.4, 0.0, 0.2, 1.0, duration: 1.0),
                    isMoving: isMoving
                )
                CurveRow(
                    title: "快速减速",
                    animation: .timingCurve(0.0, 0.0, 0.2, 1.0, duration: 1.0),
                    isMoving: isMoving
                )
                CurveRow(
                    title: "缓慢加速",
                    animation: .timingCurve(0.4, 0.0, 1.0, 1.0, duration: 1.0),
                    isMoving: isMoving
                )

                Button(isMoving ? "重置" : "开始") {
                    isMoving.toggle()
                }
                .font(.headline)
                .buttonStyle(.borderedProminent)
                .padding(.top, 20)
            }
            .padding()
            .navigationTitle("自定义曲线")
        }
    }
}

struct CurveRow: View {
    let title: String
    let animation: Animation
    let isMoving: Bool

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            Text(title)
                .font(.caption)
                .foregroundStyle(.secondary)

            HStack {
                Circle()
                    .fill(Color.purple)
                    .frame(width: 24, height: 24)
                    .offset(x: isMoving ? 280 : 0)
                    .animation(animation, value: isMoving)
                Spacer()
            }
            .background(Color.gray.opacity(0.1))
            .clipShape(RoundedRectangle(cornerRadius: 4))
        }
    }
}
```

#### .interpolatingSpring()

`interpolatingSpring` 是另一种弹簧动画，参数更偏物理特性：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `mass` | 质量（越大越"重"，回弹越慢） | 1.0 |
| `stiffness` | 刚度（越大弹得越快） | 100 |
| `damping` | 阻尼（越大回弹越少） | 10~20 |

```swift
Animation.interpolatingSpring(mass: 1.0, stiffness: 100, damping: 15)
```

#### 示例

```swift
import SwiftUI

struct InterpolatingSpringDemo: View {
    @State private var isExpanded = false

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 24) {
                    InterpolatingCard(
                        title: "低阻尼（多回弹）",
                        mass: 1.0, stiffness: 100, damping: 8,
                        isExpanded: isExpanded
                    )
                    InterpolatingCard(
                        title: "中阻尼（适中）",
                        mass: 1.0, stiffness: 100, damping: 15,
                        isExpanded: isExpanded
                    )
                    InterpolatingCard(
                        title: "高阻尼（少回弹）",
                        mass: 1.0, stiffness: 100, damping: 30,
                        isExpanded: isExpanded
                    )
                    InterpolatingCard(
                        title: "高刚度（快速弹跳）",
                        mass: 1.0, stiffness: 200, damping: 15,
                        isExpanded: isExpanded
                    )

                    Button(isExpanded ? "重置" : "开始") {
                        isExpanded.toggle()
                    }
                    .font(.headline)
                    .buttonStyle(.borderedProminent)
                }
                .padding()
            }
            .navigationTitle("Interpolating Spring")
        }
    }
}

struct InterpolatingCard: View {
    let title: String
    let mass: Double
    let stiffness: Double
    let damping: Double
    let isExpanded: Bool

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text(title)
                .font(.caption)
                .foregroundStyle(.secondary)

            RoundedRectangle(cornerRadius: 12)
                .fill(Color.orange.gradient)
                .frame(width: isExpanded ? 300 : 80, height: 40)
                .animation(.interpolatingSpring(mass: mass, stiffness: stiffness, damping: damping), value: isExpanded)
        }
    }
}
```

💡 **提示**：日常开发中，`.spring(duration:bounce:)` 更简单易用；`.interpolatingSpring()` 更适合需要精确物理模拟的场景。

## 手势

SwiftUI 提供了丰富的手势识别器，让用户可以通过触摸与 App 交互。

💡 **通俗理解**：手势就是用户在屏幕上的"动作"——点击、长按、拖拽、缩放、旋转。SwiftUI 帮你识别这些动作，你只需要写"识别到动作后做什么"。

### TapGesture 点击

#### .onTapGesture

最常用的手势，点击视图时触发：

```swift
Text("点我")
    .onTapGesture {
        print("被点击了！")
    }
```

#### 双击

通过 `count` 参数指定点击次数，实现双击：

```swift
Image(systemName: "heart")
    .font(.system(size: 60))
    .onTapGesture(count: 2) {
        print("双击了！")
    }
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `count` | 点击次数（1 = 单击，2 = 双击） | 1 |
| `perform` | 点击后执行的闭包 | — |

#### 示例

```swift
import SwiftUI

struct TapGestureDemo: View {
    @State private var tapCount = 0
    @State private var doubleTapScale: CGFloat = 1.0
    @State private var isLiked = false

    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 40) {
                    VStack(spacing: 12) {
                        Text("单击计数：\(tapCount)")
                            .font(.title2.bold())

                        Text("点我试试")
                            .font(.headline)
                            .foregroundStyle(.white)
                            .padding(.horizontal, 30)
                            .padding(.vertical, 12)
                            .background(Color.blue)
                            .clipShape(Capsule())
                            .onTapGesture {
                                tapCount += 1
                            }
                    }

                    Divider()

                    VStack(spacing: 12) {
                        Text("双击放大/缩小")
                            .font(.subheadline)
                            .foregroundStyle(.secondary)

                        Image(systemName: "star.fill")
                            .font(.system(size: 60))
                            .foregroundStyle(.yellow)
                            .scaleEffect(doubleTapScale)
                            .onTapGesture(count: 2) {
                                withAnimation(.spring(duration: 0.4, bounce: 0.3)) {
                                    doubleTapScale = doubleTapScale == 1.0 ? 1.5 : 1.0
                                }
                            }
                    }

                    Divider()

                    VStack(spacing: 12) {
                        Text("单击切换收藏")
                            .font(.subheadline)
                            .foregroundStyle(.secondary)

                        Image(systemName: isLiked ? "heart.fill" : "heart")
                            .font(.system(size: 60))
                            .foregroundStyle(isLiked ? .red : .gray)
                            .contentTransition(.symbolEffect(.replace.byLayer))
                            .onTapGesture {
                                withAnimation(.spring(duration: 0.4, bounce: 0.4)) {
                                    isLiked.toggle()
                                }
                            }
                    }
                }
                .padding()
            }
            .navigationTitle("点击手势")
        }
    }
}
```

⚠️ **警告**：设置 `count: 2`（双击）后，单击不会有任何响应。如果需要同时支持单击和双击，需要使用组合手势。

### LongPressGesture 长按

#### .onLongPressGesture

长按视图时触发，可以设置最短按压时间：

```swift
Text("长按我")
    .onTapGesture { }
    .onLongPressGesture {
        print("长按触发！")
    }
```

### DragGesture 拖拽

#### .gesture(DragGesture())

拖拽手势让用户可以用手指拖动视图：

```swift
Circle()
    .frame(width: 80, height: 80)
    .gesture(
        DragGesture()
            .onChanged { value in
                // 拖拽中
            }
            .onEnded { value in
                // 拖拽结束
            }
    )
```

#### 获取拖拽偏移

`DragGesture.Value` 提供了拖拽的详细信息：

| 属性 | 说明 |
|------|------|
| `translation` | 相对于起始位置的偏移量（CGSize） |
| `location` | 当前触摸点位置 |
| `startLocation` | 起始触摸点位置 |
| `predictedTranslation` | 预测的最终偏移（惯性） |

#### 示例：可拖拽卡片

```swift
import SwiftUI

struct DragGestureDemo: View {
    @State private var offset = CGSize.zero
    @State private var lastOffset = CGSize.zero
    @State private var cardColor: Color = .blue

    var body: some View {
        NavigationStack {
            VStack(spacing: 30) {
                Text("拖拽下方卡片")
                    .font(.subheadline)
                    .foregroundStyle(.secondary)

                RoundedRectangle(cornerRadius: 20)
                    .fill(cardColor.gradient)
                    .frame(width: 200, height: 280)
                    .overlay {
                        VStack(spacing: 12) {
                            Image(systemName: "hand.draw")
                                .font(.system(size: 40))
                                .foregroundStyle(.white)
                            Text("拖我移动")
                                .font(.headline)
                                .foregroundStyle(.white)
                            Text("偏移: (\(Int(offset.width)), \(Int(offset.height)))")
                                .font(.caption)
                                .foregroundStyle(.white.opacity(0.8))
                        }
                    }
                    .offset(offset)
                    .gesture(
                        DragGesture()
                            .onChanged { value in
                                offset = CGSize(
                                    width: lastOffset.width + value.translation.width,
                                    height: lastOffset.height + value.translation.height
                                )
                            }
                            .onEnded { value in
                                lastOffset = offset
                                if abs(offset.width) > 100 {
                                    withAnimation(.spring(duration: 0.5, bounce: 0.4)) {
                                        offset = CGSize(width: offset.width > 0 ? 200 : -200, height: offset.height)
                                        lastOffset = offset
                                        cardColor = [.green, .orange, .purple, .pink].randomElement() ?? .blue
                                    }
                                    DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) {
                                        withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                                            offset = .zero
                                            lastOffset = .zero
                                        }
                                    }
                                }
                            }
                    )
                    .animation(.spring(duration: 0.3), value: offset)

                Text("向左或向右拖拽超过 100 点，卡片会飞走！")
                    .font(.caption)
                    .foregroundStyle(.secondary)

                Button("重置位置") {
                    withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                        offset = .zero
                        lastOffset = .zero
                    }
                }
                .buttonStyle(.bordered)
            }
            .navigationTitle("拖拽手势")
        }
    }
}
```

💡 **提示**：拖拽时需要同时记录 `offset` 和 `lastOffset`，否则每次拖拽都会从原点开始，而不是从上次结束的位置开始。

### 组合手势

当需要多个手势协同工作时，就需要组合手势。

| 组合方式 | 说明 | 示例场景 |
|---------|------|---------|
| **Sequenced** | 顺序识别，第一个完成后才识别第二个 | 先长按再拖拽 |
| **Simultaneous** | 同时识别多个手势 | 缩放的同时旋转 |
| **Exclusive** | 互斥，只识别其中一个 | 单击或双击（不同时触发） |

#### Sequenced / Simultaneous / Exclusive

```swift
// 顺序：先长按，再拖拽
.gesture(
    LongPressGesture(minimumDuration: 0.5)
        .sequenced(before: DragGesture())
        .onChanged { value in
            switch value {
            case .first(true):
                print("长按成功")
            case .second(true, let drag):
                print("拖拽中: \(drag?.translation ?? .zero)")
            default:
                break
            }
        }
)

// 同时：缩放 + 旋转
.gesture(
    SimultaneousGesture(
        MagnificationGesture().onChanged { ... },
        RotationGesture().onChanged { ... }
    )
)

// 互斥：单击或长按
.gesture(
    TapGesture().exclusively(before: LongPressGesture())
)
```

#### 示例


## 转场动画

转场动画（Transition）控制视图**出现和消失**时的动画效果。

💡 **通俗理解**：转场动画就像舞台上的"出场"和"退场"——角色上场时怎么亮相，退场时怎么消失。普通的动画只改变属性（大小、颜色），转场动画控制的是"从无到有"和"从有到无"。

### 基本转场

#### .transition(.slide)

视图出现时从左侧滑入，消失时向右侧滑出：

```swift
if showView {
    Text("你好！")
        .transition(.slide)
}
```

#### .transition(.opacity)

视图出现时淡入，消失时淡出：

```swift
if showView {
    Text("你好！")
        .transition(.opacity)
}
```

#### .transition(.scale)

视图出现时从小变大，消失时从大变小：

```swift
if showView {
    Text("你好！")
        .transition(.scale)
}
```

#### 内置转场列表

| 转场 | 效果 | 适用场景 |
|------|------|---------|
| `.slide` | 从左滑入/向右滑出 | 列表项出现 |
| `.opacity` | 淡入/淡出 | 通用，最自然 |
| `.scale` | 缩放出现/消失 | 弹窗、提示 |
| `.move(edge: .bottom)` | 从指定边缘滑入 | 底部弹窗 |
| `.move(edge: .top)` | 从顶部滑入 | 顶部通知 |
| `.asymmetric` | 出现和消失使用不同转场 | 精细控制 |

```swift
// 从底部滑入
.transition(.move(edge: .bottom))

// 出现和消失使用不同效果
.transition(.asymmetric(
    insertion: .scale.combined(with: .opacity),
    removal: .move(edge: .trailing)
))
```

⚠️ **警告**：转场动画必须配合 `withAnimation` 使用！如果没有动画包裹，视图会直接出现/消失，没有任何过渡效果。

```swift
// ❌ 没有动画，直接出现/消失
showView.toggle()

// ✅ 配合动画，有转场效果
withAnimation(.spring(duration: 0.4)) {
    showView.toggle()
}
```


### 自定义转场

#### AnyTransition.modifier()

当内置转场不能满足需求时，可以用 `AnyTransition.modifier()` 创建自定义转场：

```swift
struct FadeScaleModifier: ViewModifier {
    let isActive: Bool

    func body(content: Content) -> some View {
        content
            .scaleEffect(isActive ? 1 : 0.5)
            .opacity(isActive ? 1 : 0)
    }
}

extension AnyTransition {
    static var fadeScale: AnyTransition {
        .modifier(
            active: FadeScaleModifier(isActive: false),
            identity: FadeScaleModifier(isActive: true)
        )
    }
}
```

💡 **通俗理解**：`active` 是"动画开始前/结束后"的状态，`identity` 是"动画完成后"的状态。SwiftUI 会在两者之间自动插值。

```swift
}

                            if showSlideBlur {
                                RoundedRectangle(cornerRadius: 16)
                                    .fill(Color.orange.gradient)
                                    .frame(width: 120, height: 80)
                                    .overlay {
                                        Text("模糊出现")
                                            .foregroundStyle(.white)
                                            .font(.headline)
                                    }
                                    .transition(.slideBlur)
                            }
                            Spacer()
                        }
                        .frame(height: 100)
                        .background(Color.gray.opacity(0.06))
                        .clipShape(RoundedRectangle(cornerRadius: 8))

                        Button(showSlideBlur ? "隐藏" : "显示") {
                            withAnimation(.easeInOut(duration: 0.5)) {
                                showSlideBlur.toggle()
                            }
                        }
                        .buttonStyle(.bordered)
                    }
                }
                .padding()
            }
            .navigationTitle("自定义转场")
        }
    }
}
```

💡 **提示**：自定义转场可以像内置转场一样使用 `.combined(with:)` 组合，例如 `.rotateIn.combined(with: .opacity)`。

### matchedGeometryEffect

`matchedGeometryEffect` 是 SwiftUI 最炫酷的转场效果——让同一个元素在两个位置之间"飞过去"，实现共享元素动画。

💡 **通俗理解**：就像魔术师的"大变活人"——同一个人从舞台左边瞬间"飞"到右边，中间有流畅的过渡动画。这在 App 中常用于：图片点击放大、列表项展开详情等。

#### 共享元素转场

核心概念：
1. 两个视图使用**相同的 namespace** 和 **相同的 id**
2. 当一个视图消失、另一个出现时，SwiftUI 自动在两者之间创建过渡动画

#### @Namespace

`@Namespace` 是一个自动生成的唯一标识，用于关联两个视图：

```swift
@Namespace private var ns

// 视图 A
if !isExpanded {
    Image("photo")
        .matchedGeometryEffect(id: "photo", in: ns)
}

// 视图 B
if isExpanded {
    Image("photo")
        .matchedGeometryEffect(id: "photo", in: ns)
}
```

#### 示例：图片点击放大

```swift
import SwiftUI

struct MatchedGeometryDemo: View {
    @Namespace private var ns
    @State private var selectedItem: String? = nil

    let items = ["sun.max.fill", "cloud.rain.fill", "snowflake", "wind", "cloud.bolt.fill"]

    var body: some View {
        NavigationStack {
            ZStack {
                if let selectedItem {
                    Color.black.opacity(0.4)
                        .ignoresSafeArea()
                        .onTapGesture {
                            withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                                self.selectedItem = nil
                            }
                        }

                    VStack(spacing: 20) {
                        Image(systemName: selectedItem)
                            .font(.system(size: 100))
                            .foregroundStyle(.white)
                            .frame(width: 250, height: 250)
                            .background(
                                RoundedRectangle(cornerRadius: 24)
                                    .fill(Color.blue.gradient)
                            )
                            .matchedGeometryEffect(id: selectedItem, in: ns)

                        Text(selectedItem.replacingOccurrences(of: ".fill", with: "").replacingOccurrences(of: ".", with: " "))
                            .font(.title2.bold())
                            .foregroundStyle(.white)
                    }
                    .onTapGesture {
                        withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                            self.selectedItem = nil
                        }
                    }
                } else {
                    ScrollView {
                        LazyVGrid(columns: [
                            GridItem(.flexible()),
                            GridItem(.flexible()),
                            GridItem(.flexible())
                        ], spacing: 16) {
                            ForEach(items, id: \.self) { item in
                                VStack(spacing: 8) {
                                    Image(systemName: item)
                                        .font(.system(size: 36))
                                        .foregroundStyle(.white)
                                        .frame(width: 90, height: 90)
                                        .background(
                                            RoundedRectangle(cornerRadius: 16)
                                                .fill(Color.blue.gradient)
                                        )
                                        .matchedGeometryEffect(id: item, in: ns)

                                    Text(item.replacingOccurrences(of: ".fill", with: "").replacingOccurrences(of: ".", with: " "))
                                        .font(.caption2)
                                        .foregroundStyle(.secondary)
                                        .lineLimit(1)
                                }
                                .onTapGesture {
                                    withAnimation(.spring(duration: 0.5, bounce: 0.3)) {
                                        selectedItem = item
                                    }
                                }
                            }
                        }
                        .padding()
                    }
                }
            }
            .navigationTitle("共享元素转场")
        }
    }
}
```

⚠️ **警告**：`matchedGeometryEffect` 有几个重要限制：
1. 两个视图**不能同时存在**——必须一个消失、另一个出现
2. `id` 和 `namespace` 必须完全匹配
3. 动画必须用 `withAnimation` 包裹，否则没有过渡效果

💡 **提示**：`matchedGeometryEffect` 是打造"丝滑"用户体验的利器。很多主流 App（如 Apple Photos、App Store）都使用了类似的共享元素转场效果。

## 小结

本章我们学习了 SwiftUI 动画与手势的完整知识体系：

| 知识点 | 核心内容 |
|--------|---------|
| **隐式动画** | `.animation()` 自动触发，适合简单场景 |
| **显式动画** | `withAnimation { }` 精确控制，适合复杂场景 |
| **缓动动画** | easeIn/easeOut/easeInOut/linear，控制速度曲线 |
| **弹簧动画** | `.spring(duration:bounce:)`，自然有弹性的动画 |
| **自定义曲线** | `.timingCurve()` 贝塞尔曲线，`.interpolatingSpring()` 物理弹簧 |
| **点击手势** | `.onTapGesture`，支持单击/双击 |
| **长按手势** | `.onLongPressGesture`，支持最短按压时间 |
| **拖拽手势** | `DragGesture()`，获取偏移量实现拖动 |
| **缩放手势** | `MagnificationGesture()`，双指缩放 |
| **旋转手势** | `RotationGesture()`，双指旋转 |
| **组合手势** | Sequenced/Simultaneous/Exclusive |
| **基本转场** | slide/opacity/scale/move/asymmetric |
| **自定义转场** | `AnyTransition.modifier()` |
| **共享元素** | `matchedGeometryEffect` + `@Namespace` |

🔑 **核心记忆点**：
1. 隐式动画用 `.animation(_:value:)`，显式动画用 `withAnimation { }`
2. 弹簧动画 `.spring(duration: 0.4, bounce: 0.2)` 是最常用的动画类型
3. 拖拽手势需要记录 `lastOffset`，否则每次从原点开始
4. 缩放和旋转手势需要真机测试
5. 转场动画必须配合 `withAnimation` 使用
6. `matchedGeometryEffect` 实现共享元素转场，打造丝滑体验
