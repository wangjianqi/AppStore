## 1. AVFoundation 框架概述

### 1.1 框架架构

AVFoundation 是 Apple 提供的用于处理音视频媒体的"瑞士军刀"。它就像一个完整的影视工作室——从拍摄、录制、剪辑到播放、导出，全流程都能覆盖。

> 💡 **生活类比**：如果把 iOS 音视频开发比作拍电影，那么 AVFoundation 就是你的整个剧组——导演、摄像师、录音师、剪辑师、放映员一应俱全。

```
┌─────────────────────────────────────────────┐
│                 AVFoundation                │
├──────────┬──────────┬──────────┬────────────┤
│ 播放子系统 │ 录制子系统 │ 编辑子系统 │ 处理子系统   │
│          │          │          │            │
│AVPlayer  │AVCapture │AVAsset   │AVAudio     │
│AVPlayerL │ Session  │Export    │Engine      │
│ayer      │AVAudioR  │Session   │AVVideo      │
│AVQueueP  │ecorder   │AVComposi │Compositor  │
│layer     │          │tion      │            │
├──────────┴──────────┴──────────┴────────────┤
│              Core Media / Core Audio         │
└─────────────────────────────────────────────┘
```

### 1.2 能力全景表

| 子系统 | 核心类 | 能力描述 |
|--------|--------|----------|
| **音频播放** | `AVAudioPlayer` | 本地音频文件播放，支持循环、音量、进度控制 |
| **流媒体播放** | `AVPlayer` / `AVPlayerItem` | 本地/网络音视频播放，支持 HLS/DASH |
| **视频渲染** | `AVPlayerLayer` | 将视频画面渲染到 CALayer 上 |
| **音频录制** | `AVAudioRecorder` | 麦克风录音，支持多种编码格式 |
| **相机录制** | `AVCaptureSession` | 前后摄像头录制，支持照片/视频/深度数据 |
| **资源编辑** | `AVComposition` | 多轨道拼接、裁剪、叠加等非线性编辑 |
| **导出转码** | `AVAssetExportSession` | 格式转换、分辨率调整、导出最终文件 |
| **音频处理** | `AVAudioEngine` | 实时音频处理链（混响、均衡器等） |
| **元数据读取** | `AVAsset` / `AVMetadataItem` | 读取媒体文件的时长、尺寸、元信息 |

> ⚠️ **注意**：AVFoundation 同时支持 Objective-C 和 Swift，但在 SwiftUI 项目中通常需要通过 `UIViewRepresentable` 或 `UIViewControllerRepresentable` 来桥接 UIKit 组件。

## 2. 音频播放

### 2.1 AVAudioPlayer — 本地音频播放

`AVAudioPlayer` 就像一个简单的 MP3 播放器——给它一个本地文件路径，它就能播放。适合播放短音频、提示音、背景音乐等场景。

#### 基本用法

```swift
import AVFoundation

class AudioManager: ObservableObject {
    private var audioPlayer: AVAudioPlayer?
    @Published var isPlaying = false
    @Published var progress: Double = 0
    @Published var duration: Double = 0

    func loadAudio(from url: URL) {
        do {
            audioPlayer = try AVAudioPlayer(contentsOf: url)
            audioPlayer?.delegate = self
            audioPlayer?.prepareToPlay()
            duration = audioPlayer?.duration ?? 0
        } catch {
            print("加载音频失败: \(error.localizedDescription)")
        }
    }

    func play() {
        audioPlayer?.play()
        isPlaying = true
        startProgressTimer()
    }

    func pause() {
        audioPlayer?.pause()
        isPlaying = false
    }

    func stop() {
        audioPlayer?.stop()
        audioPlayer?.currentTime = 0
        isPlaying = false
    }

    func seek(to time: TimeInterval) {
        audioPlayer?.currentTime = time
    }

    func setVolume(_ volume: Float) {
        audioPlayer?.volume = min(max(volume, 0), 1)
    }

    private var progressTimer: Timer?

    private func startProgressTimer() {
        progressTimer?.invalidate()
        progressTimer = Timer.scheduledTimer(withTimeInterval: 0.1, repeats: true) { [weak self] _ in
            guard let player = self?.audioPlayer else { return }
            if player.duration > 0 {
                self?.progress = player.currentTime / player.duration
            }
        }
    }
}

extension AudioManager: AVAudioPlayerDelegate {
    func audioPlayerDidFinishPlaying(_ player: AVAudioPlayer, successfully flag: Bool) {
        isPlaying = false
        progress = 0
    }
}
```

#### 支持的音频格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| MP3 | `.mp3` | 最通用，压缩率高 |
| AAC | `.m4a`, `.aac` | Apple 推荐格式，质量好 |
| WAV | `.wav` | 无损，体积大 |
| AIFF | `.aiff`, `.aif` | Apple 原生无损格式 |
| CAF | `.caf` | Core Audio Format，适合长时间录音 |

> 💡 **技巧**：对于 App 内置的音频资源，建议使用 AAC (`.m4a`) 格式——它在体积和质量的平衡上表现最佳。

### 2.2 AVPlayer — 流媒体播放

当需要播放网络音频或需要更强大的控制能力时，`AVPlayer` 是更好的选择。它像一台专业播放设备——支持流媒体、缓冲管理、多队列播放等高级特性。

> 💡 **生活类比**：AVAudioPlayer 像随身听，只能放已经下载好的磁带；AVPlayer 像智能音箱，既能放本地音乐也能在线点播。

```swift
import AVFoundation

class StreamAudioPlayer: ObservableObject {
    private let player = AVPlayer()
    private var timeObserver: Any?
    @Published var isPlaying = false
    @Published var currentTime: CMTime = .zero
    @Published var totalTime: CMTime = .zero
    @Published var bufferedProgress: Double = 0

    init() {
        setupTimeObserver()
        addPeriodicTimeObserver()
    }

    func load(url: URL) {
        let item = AVPlayerItem(url: url)
        player.replaceCurrentItem(with: item)
        observeItemStatus(item)
    }

    func play() { player.play(); isPlaying = true }
    func pause() { player.pause(); isPlaying = false }

    func seek(to time: CMTime) {
        player.seek(to: time, toleranceBefore: .zero, toleranceAfter: .zero)
    }

    func setRate(_ rate: Float) {
        player.rate = rate * (isPlaying ? 1 : 0)
    }

    private func addPeriodicTimeObserver() {
        let interval = CMTime(value: 1, timescale: 10)
        timeObserver = player.addPeriodicTimeObserver(forInterval: interval, queue: .main) { [weak self] time in
            self?.currentTime = time
        }
    }

    private func observeItemStatus(_ item: AVPlayerItem) {
        item.addObserver(self, forKeyPath: "status", options: [.new], context: nil)
        item.addObserver(self, forKeyPath: "loadedTimeRanges", options: [.new], context: nil)
    }

    override func observeValue(forKeyPath keyPath: String?, of object: Any?,
                               change: [NSKeyValueChangeKey : Any]?, context: UnsafeMutableRawPointer?) {
        if keyPath == "status", let item = object as? AVPlayerItem {
            if item.status == .readyToPlay {
                totalTime = item.duration
            } else if item.status == .failed {
                print("加载失败: \(item.error?.localizedDescription ?? "未知错误")")
            }
        }
        if keyPath == "loadedTimeRanges", let item = object as? AVPlayerItem {
            let ranges = item.loadedTimeRanges
            let buffer = ranges.first?.timeRangeValue.end.seconds ?? 0
            let total = item.duration.seconds
            bufferedProgress = total > 0 ? buffer / total : 0
        }
    }

    deinit {
        if let observer = timeObserver {
            player.removeTimeObserver(observer)
        }
    }
}
```

### 2.3 音频会话配置（AVAudioSession）

在播放音频之前，必须告诉系统"我要用声音了"。这就像在图书馆里要小声说话一样——你需要先声明自己的意图。

```swift
import AVFoundation

class AudioSessionManager {
    static let shared = AudioSessionManager()

    func configureForPlayback() {
        let session = AVAudioSession.sharedInstance()

        do {
            try session.setCategory(
                .playback,
                mode: .default,
                options: [.mixWithOthers]
            )
            try session.setActive(true)
        } catch {
            print("音频会话配置失败: \(error)")
        }
    }

    func configureForRecording() {
        let session = AVAudioSession.sharedInstance()

        do {
            try session.setCategory(
                .playAndRecord,
                mode: .default,
                options: [.defaultToSpeaker, .allowBluetooth]
            )
            try session.setActive(true)
        } catch {
            print("录音会话配置失败: \(error)")
        }
    }

    func deactivate() {
        try? AVAudioSession.sharedInstance().setActive(false, options: .notifyOthersOnDeactivation)
    }
}
```

> ⚠️ **重要**：每次 App 启动或进入前台时都应重新激活音频会话，因为系统可能在后台将其重置。

## 3. 音频录制

### 3.1 AVAudioRecorder 基础

`AVAudioRecorder` 就像一台数字录音笔——你按下录音键就开始录，按停止就保存文件。

```swift
import AVFoundation

class AudioRecorderManager: NSObject, ObservableObject, AVAudioRecorderDelegate {
    private var recorder: AVAudioRecorder?
    @Published var isRecording = false
    @Published var recordingTime: TimeInterval = 0
    @Published var audioLevel: Float = 0

    private var timer: Timer?

    override init() {
        super.init()
        AudioSessionManager.shared.configureForRecording()
    }

    func requestPermission() async -> Bool {
        await withCheckedContinuation { continuation in
            AVAudioApplication.requestRecordPermission { granted in
                continuation.resume(returning: granted)
            }
        }
    }

    func startRecording() async throws -> URL {
        let documentsPath = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
        let fileName = "recording_\(Int(Date().timeIntervalSince1970)).m4a"
        let url = documentsPath.appendingPathComponent(fileName)

        let settings: [String: Any] = [
            AVFormatIDKey: kAudioFormatMPEG4AAC,
            AVSampleRateKey: 44100.0,
            AVNumberOfChannelsKey: 1,
            AVEncoderBitRateKey: 64000,
            AVEncoderAudioQualityKey: AVAudioQuality.high.rawValue
        ]

        recorder = try AVAudioRecorder(url: url, settings: settings)
        recorder?.delegate = self
        recorder?.isMeteringEnabled = true
        recorder?.record()
        isRecording = true
        startMonitoring()

        return url
    }

    func stopRecording() {
        recorder?.stop()
        isRecording = false
        stopMonitoring()
    }

    private func startMonitoring() {
        timer = Timer.scheduledTimer(withTimeInterval: 0.05, repeats: true) { [weak self] _ in
            guard let self = self, let recorder = self.recorder else { return }
            recorder.updateMeters()
            self.audioLevel = recorder.averagePower(forChannel: 0)
            self.recordingTime = recorder.currentTime
        }
    }

    private func stopMonitoring() {
        timer?.invalidate()
        timer = nil
    }

    func audioRecorderDidFinishRecording(_ recorder: AVAudioRecorder, successfully flag: Bool) {
        if !flag {
            print("录音未成功完成")
        }
    }
}
```

### 3.2 录音格式选择指南

| 场景 | 推荐格式 | 编码参数 | 适用说明 |
|------|----------|----------|----------|
| 语音备忘 | AAC (.m4a) | 44.1kHz, 单声道, 64kbps | 体积小，质量够用 |
| 高品质录音 | Apple Lossless (.caf) | 48kHz, 立体声 | 无损压缩 |
| 即时通讯语音 | Opus/AAC | 16kHz, 单声道, 32kbps | 极低延迟需求 |
| 音乐采样 | PCM/WAV (.wav) | 48kHz, 立体声, 16bit | 后期处理需要原始数据 |

> ⚠️ **权限提醒**：录音需要在 Info.plist 中添加 `NSMicrophoneUsageDescription`，且首次调用时会弹出系统权限对话框。App Store 审核要求权限描述必须清晰说明用途。

## 4. 视频播放

### 4.1 AVPlayer + AVPlayerLayer

视频播放比音频复杂一步——除了声音还需要画面。`AVPlayerLayer` 负责将视频画面渲染出来，就像把胶片投影到屏幕上。

```swift
import AVFoundation
import UIKit

class VideoPlayerView: UIView {
    private let playerLayer = AVPlayerLayer()
    var player: AVPlayer? {
        get { playerLayer.player }
        set { playerLayer.player = newValue }
    }

    override init(frame: CGRect) {
        super.init(frame: frame)
        commonInit()
    }

    required init?(coder: NSCoder) {
        super.init(coder: coder)
        commonInit()
    }

    private func commonInit() {
        layer.addSublayer(playerLayer)
        playerLayer.videoGravity = .resizeAspect
    }

    override func layoutSubviews() {
        super.layoutSubviews()
        playerLayer.frame = bounds
    }
}
```

```swift
    @Published var isPlaying = false
    @Published var currentTime: Double = 0
    @Published var totalTime: Double = 0
    private var timeObserver: Any?

    func loadVideo(url: URL) {
        let item = AVPlayerItem(url: url)
        player = AVPlayer(playerItem: item)
        addTimeObserver()
    }

    func togglePlayPause() {
        if isPlaying {
            player?.pause()
        } else {
            player?.play()
        }
        isPlaying.toggle()
    }

    func seek(to progress: Double) {
        guard let duration = player?.currentItem?.duration.seconds,
              duration.isFinite else { return }
        let targetTime = CMTime(seconds: progress * duration, preferredTimescale: 600)
        player?.seek(to: targetTime, toleranceBefore: .zero, toleranceAfter: .zero)
    }

    private func addTimeObserver() {
        let interval = CMTime(value: 1, timescale: 30)
        timeObserver = player?.addPeriodicTimeObserver(forInterval: interval, queue: .main) { [weak self] time in
            self?.currentTime = time.seconds
            self?.totalTime = time.duration.seconds
        }
    }

    deinit {
        if let obs = timeObserver { player?.removeTimeObserver(obs) }
    }
}
```

## 5. 视频录制与编辑

### 5.1 AVCaptureSession — 相机录制

`AVCaptureSession` 是整个录制流程的"指挥中心"，协调摄像头、麦克风和输出目标之间的配合。

> 💡 **生活类比**：AVCaptureSession 就像电视台的导播室——导演（Session）指挥摄像机（Input）拍摄画面，同时安排录音师（Audio Input）收音，最后信号送到录像机（Output）保存下来。

```swift
import AVFoundation
import SwiftUI

class CameraViewModel: NSObject, ObservableObject, AVCapturePhotoCaptureDelegate {
    private let captureSession = AVCaptureSession()
    private var videoOutput: AVCaptureMovieFileOutput?
    private var previewLayer: AVCaptureVideoPreviewLayer?

    @Published var isRecording = false
    @Published var permissionGranted = false
    @Published var recordingURL: URL?

    override init() {
        super.init()
        checkPermissionAndSetup()
    }

    private func checkPermissionAndSetup() {
        switch AVCaptureDevice.authorizationStatus(for: .video) {
        case .authorized:
            setupCaptureSession()
        case .notDetermined:
            AVCaptureDevice.requestAccess(for: .video) { [weak self] granted in
                if granted { DispatchQueue.main.async { self?.setupCaptureSession() } }
            }
        default:
            permissionGranted = false
        }
    }

    private func setupCaptureSession() {
        captureSession.sessionPreset = .high

        guard let camera = AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: .back),
              let input = try? AVCaptureDeviceInput(device: camera) else { return }

        if captureSession.canAddInput(input) {
            captureSession.addInput(input)
        }

        let audioDevice = AVCaptureDevice.default(for: .audio)
        if let audioDevice, let audioInput = try? AVCaptureDeviceInput(device: audioDevice),
           captureSession.canAddInput(audioInput) {
            captureSession.addInput(audioInput)
        }

        let movieOutput = AVCaptureMovieFileOutput()
        if captureSession.canAddOutput(movieOutput) {
            captureSession.addOutput(movieOutput)
            videoOutput = movieOutput
        }

        DispatchQueue.global(qos: .userInitiated).async {
            self.captureSession.startRunning()
            DispatchQueue.main.async { self.permissionGranted = true }
        }
    }

    func getPreviewLayer() -> AVCaptureVideoPreviewLayer {
        let layer = AVCaptureVideoPreviewLayer(session: captureSession)
        layer.videoGravity = .resizeAspectFill
        return layer
    }

    func toggleRecording() {
        guard let output = videoOutput else { return }

        if isRecording {
            output.stopRecording()
        } else {
            let tempURL = FileManager.default.temporaryDirectory
                .appendingPathComponent("video_\(Date().timeIntervalSince1970).mov")
            output.startRecording(to: tempURL, recordingDelegate: self)
            isRecording = true
        }
    }

    func fileOutput(_ output: AVCaptureFileOutput,
                    didFinishRecordingTo outputFileURL: URL,
                    from connections: [AVCaptureConnection],
                    error: Error?) {
        isRecording = false
        if error == nil {
            recordingURL = outputFileURL
        }
    }

    func switchCamera() {
        guard let currentInput = captureSession.inputs.first as? AVCaptureDeviceInput else { return }
        let newPosition: AVCaptureDevice.Position = currentInput.device.position == .back ? .front : .back

        captureSession.beginConfiguration()
        captureSession.removeInput(currentInput)

        if let newCamera = AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: newPosition),
           let newInput = try? AVCaptureDeviceInput(device: newCamera),
           captureSession.canAddInput(newInput) {
            captureSession.addInput(newInput)
        }

        captureSession.commitConfiguration()
    }
}
```

### 5.2 AVAssetExportSession — 视频导出与转码

录制完成后，经常需要对视频进行格式转换或压缩：

```swift
import AVFoundation

class VideoExporter {
    static func exportVideo(sourceURL: URL,
                            destinationURL: URL,
                            presetName: AVAssetExportPresetName = .highestQuality,
                            completion: @escaping (Result<URL, Error>) -> Void) {
        let asset = AVAsset(url: sourceURL)

        guard let exportSession = AVAssetExportSession(asset: asset, presetName: presetName) else {
            completion(.failure(ExporterError.exportSessionFailed))
            return
        }

        exportSession.outputURL = destinationURL
        exportSession.outputFileType = .mp4
        exportSession.shouldOptimizeForNetworkUse = true

        exportSession.exportAsynchronously {
            DispatchQueue.main.async {
                switch exportSession.status {
                case .completed:
                    completion(.success(destinationURL))
                case .failed:
                    completion(.failure(exportSession.error ?? ExporterError.unknown))
                case .cancelled:
                    completion(.failure(ExporterError.cancelled))
                default:
                    completion(.failure(ExporterError.unknown))
                }
            }
        }
    }
}
```

### 5.3 AVComposition — 简单视频剪辑

`AVComposition` 允许你在代码中像剪片子一样拼接、裁剪视频片段：

```swift
import AVFoundation
import CoreMedia

class SimpleVideoEditor {
    /// 将两个视频首尾拼接
    static func concatenateVideos(videoURLs: [URL], outputURL: URL,
                                  completion: @escaping (Result<URL, Error>) -> Void) {
        let composition = AVMutableComposition()
        guard let videoTrack = composition.addMutableTrack(withMediaType: .video, preferredTrackID: kCMPersistentTrackID_Invalid),
              let audioTrack = composition.addMutableTrack(withMediaType: .audio, preferredTrackID: kCMPersistentTrackID_Invalid) else {
            completion(.failure(EditorError.trackCreationFailed))
            return
        }

        var insertTime = CMTime.zero

        for url in videoURLs {
            let asset = AVAsset(url: url)
            guard let assetVideoTrack = asset.tracks(withMediaType: .video).first,
                  let assetAudioTrack = asset.tracks(withMediaType: .audio).first else { continue }

            do {
                try videoTrack.insertTimeRange(CMTimeRange(start: .zero, duration: asset.duration),
                                                of: assetVideoTrack, at: insertTime)
                try audioTrack.insertTimeRange(CMTimeRange(start: .zero, duration: asset.duration),
                                                of: assetAudioTrack, at: insertTime)
            } catch {
                completion(.failure(error))
                return
            }

            insertTime = CMTimeAdd(insertTime, asset.duration)
        }

        guard let exportSession = AVAssetExportSession(asset: composition, presetName: .highestQuality) else {
            completion(.failure(ExporterError.exportSessionFailed))
            return
        }

        exportSession.outputURL = outputURL
        exportSession.outputFileType = .mp4
        exportSession.shouldOptimizeForNetworkUse = true

        exportSession.exportAsynchronously {
            DispatchQueue.main.async {
                if exportSession.status == .completed {
                    completion(.success(outputURL))
                } else {
                    completion(.failure(exportSession.error ?? ExporterError.unknown))
                }
            }
        }
    }

    /// 裁剪视频指定时间段
    static func trimVideo(sourceURL: URL, startTime: TimeInterval, endTime: TimeInterval,
                           outputURL: URL, completion: @escaping (Result<URL, Error>) -> Void) {
        let asset = AVAsset(url: sourceURL)
        let composition = AVMutableComposition()

        guard let videoTrack = composition.addMutableTrack(withMediaType: .video, preferredTrackID: kCMPersistentTrackID_Invalid) else {
            completion(.failure(EditorError.trackCreationFailed))
            return
        }

        let timeRange = CMTimeRange(
            start: CMTime(seconds: startTime, preferredTimescale: 600),
            duration: CMTime(seconds: endTime - startTime, preferredTimescale: 600)
        )

        guard let sourceTrack = asset.tracks(withMediaType: .video).first else {
            completion(.failure(EditorError.noVideoTrack))
            return
        }

        do {
            try videoTrack.insertTimeRange(timeRange, of: sourceTrack, at: .zero)
        } catch {
            completion(.failure(error))
            return
        }

        guard let exportSession = AVAssetExportSession(asset: composition, presetName: .highestQuality) else { return }
        exportSession.outputURL = outputURL
        exportSession.outputFileType = .mp4
        exportSession.timeRange = timeRange
        exportSession.exportAsynchronously {
            DispatchQueue.main.async {
                completion(exportSession.status == .completed ? .success(outputURL) : .failure(exportSession.error ?? ExporterError.unknown))
            }
        }
    }
}

enum EditorError: LocalizedError {
    case trackCreationFailed
    case noVideoTrack
    var errorDescription: String? {
        switch self {
        case .trackCreationFailed: return "创建轨道失败"
        case .noVideoTrack: return "源文件中没有视频轨道"
        }
    }
}
```

## 6. SwiftUI 完整集成方案

### 6.1 封装可复用的视频播放组件

将前面学到的知识整合为一个生产级的 SwiftUI 视频播放器：

```swift
import SwiftUI
import AVFoundation
import AVKit

struct MediaVideoPlayer: View {
    let url: URL
    @State private var player: AVPlayer?
    @State private var isPlaying = false
    @State private var progress: Double = 0
    @State private var showsControls = true
    @State private var controlsOpacity: Double = 1.0
    @State private var hideTask: Task<Void, Never>?

    var body: some View {
        GeometryReader { geometry in
            ZStack {
                if let player {
                    VideoPlayer(player: player)
                        .disabled(true)

                    Color.black.opacity(showsControls ? 0.0001 : 0)
                        .onTapGesture { toggleControls() }

                    if showsControls {
                        VStack {
                            Spacer()
                            playerControls
                                .padding(.horizontal)
                                .padding(.bottom, geometry.safeAreaInsets.bottom + 8)
                                .opacity(controlsOpacity)
                        }
                        .animation(.easeInOut(duration: 0.25), value: showsControls)
                    }
                } else {
                    ProgressView()
                        .progressViewStyle(.circular)
                        .tint(.white)
                }
            }
        }
        .background(Color.black)
        .onAppear { setupPlayer() }
        .onDisappear { cleanup() }
    }

    private var playerControls: some View {
        VStack(spacing: 8) {
            Slider(value: $progress, in: 0...1) { editing in
                if !editing { seekToProgress(progress) }
            }
            .tint(.white)

            HStack(spacing: 20) {
                Button { skip(by: -10) } label: {
                    Image(systemName: "backward.fill").font(.body)
                }

                Button { togglePlayPause() } label: {
                    Image(systemName: isPlaying ? "pause.fill" : "play.fill")
                        .font(.title)
                        .frame(width: 50, height: 50)
                        .background(Circle().fill(.white.opacity(0.2)))
                }

                Button { skip(by: 10) } label: {
                    Image(systemName: "forward.fill").font(.body)
                }

                Spacer()

                Text(formatTime(currentTime) + " / " + formatTime(totalTime))
                    .font(.system(.caption, design: .monospaced))
                    .foregroundColor(.white.secondary)
            }
            .foregroundColor(.white)
        }
    }

    private var currentTime: TimeInterval { player?.currentTime().seconds ?? 0 }
    private var totalTime: TimeInterval { player?.currentItem?.duration.seconds ?? 0 }

    private func setupPlayer() {
        let p = AVPlayer()
        p.replaceCurrentItem(with: AVPlayerItem(url: url))
        player = p
        addTimeObserver(to: p)
    }

    private func togglePlayPause() {
        if isPlaying { player?.pause() } else { player?.play() }
        withAnimation(.spring(response: 0.3)) { isPlaying.toggle() }
    }

    private func toggleControls() {
        withAnimation(.easeInOut(duration: 0.25)) { showsControls.toggle() }
        resetHideTimer()
    }

    private func resetHideTimer() {
        hideTask?.cancel()
        hideTask = Task {
            try? await Task.sleep(nanoseconds: 3_000_000_000)
            if !Task.isCancelled { withAnimation { showsControls = false } }
        }
    }

    private func addTimeObserver(to p: AVPlayer) {
        let interval = CMTime(value: 1, timescale: 30)
        p.addPeriodicTimeObserver(forInterval: interval, queue: .main) { [weak self] time in
            guard let self, let total = p.currentItem?.duration.seconds, total > 0 else { return }
            self.progress = time.seconds / total
        }
    }

    private func seekToProgress(_ value: Double) {
        guard let total = player?.currentItem?.duration.seconds, total > 0 else { return }
        player?.seek(to: CMTime(seconds: value * total, preferredTimescale: 600))
    }

    private func skip(by seconds: TimeInterval) {
        guard let p = player else { return }
        let newTime = max(0, min(p.currentTime().seconds + seconds, p.currentItem?.duration.seconds ?? 0))
        p.seek(to: CMTime(seconds: newTime, preferredTimescale: 600))
    }

    private func formatTime(_ time: TimeInterval) -> String {
        let m = Int(time) / 60
        let s = Int(time) % 60
        return String(format: "%d:%02d", m, s)
    }

    private func cleanup() {
        hideTask?.cancel()
        player?.pause()
        player = nil
    }
}
```

## 7. 后台音频与会话管理

### 7.1 AVAudioSession Category 详解

音频会话的 Category 决定了你的 App 如何与系统的其他音频交互。选对 Category 就像选对场合穿衣服——正式场合不能穿拖鞋，休闲聚会不用打领带。

| Category | 行为特征 | 典型场景 |
|----------|----------|----------|
| `.ambient` | 静音键生效，与其他音频混合 | 游戏背景音、电子书朗读 |
| `.soloAmbient` | 静音键生效，**中断**其他音频 | 默认 category |
| `.playback` | 忽略静音键，支持后台播放 | 音乐播放器、播客 App |
| `.playAndRecord` | 同时支持播放和录音 | 通话类 App、K歌 App |
| `.multiRoute` | 多路输出同时发声 | 专业音频工具 |

### 7.2 AVAudioSession Mode 详解

Mode 是在 Category 基础上的进一步细化，告诉系统更具体的使用意图：

| Mode | 适用 Category | 效果 |
|------|---------------|------|
| `.default` | 所有 | 默认行为 |
| `.voiceChat` | playAndRecord | 优化语音通话，降低回声和噪声 |
| `.videoRecording` | playback/playAndRecord | 录像优化，禁用系统铃声 |
| `.measurement` | playback | 最小化信号处理，精确测量 |
| `.moviePlayback` | playback | 电影播放优化 |
| `.spokenAudio` | ambient/playback | 语音内容（Siri、有声书），暂停其他非语音 |

### 7.3 Options 组合选项

| Option | 效果 |
|--------|------|
| `.mixWithOthers` | 不打断其他 App 的音频 |
| `.duckOthers` | 将其他 App 音量压低（而非静音） |
| `.allowBluetooth` | 允许蓝牙耳机输入/输出 |
| `.defaultToSpeaker` | 录音默认使用扬声器（非听筒） |
| `.interruptSpokenAudioAndMixWithOthers` | 打断其他语音但混合非语音 |

### 7.4 后台播放完整配置

要实现真正的后台音频播放（锁屏也能继续听），需要三步配置：

**第一步：Info.plist 配置**

```xml
<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>
```

**第二步：音频会话配置**

```swift
func configureForBackgroundPlayback() {
    let session = AVAudioSession.sharedInstance()
    do {
        try session.setCategory(.playback, mode: .default)
        try session.setActive(true)
    } catch {
        print("后台播放配置失败: \(error)")
    }

    // 设置 Now Playing 信息（锁屏显示）
    var nowPlayingInfo = [String: Any]()
    nowPlayingInfo[MPMediaItemPropertyTitle] = "歌曲名称"
    nowPlayingInfo[MPMediaItemPropertyArtist] = "歌手名"
    nowPlayingInfo[MPMediaItemPropertyArtwork] = MPMediaItemArtwork(boundsSize: CGSize(width: 512, height: 512)) { _ in
        UIImage(named: "album_art") ?? UIImage()
    }
    nowPlayingInfo[MPNowPlayingInfoPropertyElapsedPlaybackTime] = player?.currentTime.seconds ?? 0
    nowPlayingInfo[MPNowPlayingInfoPropertyPlaybackRate] = player?.rate ?? 0
    nowPlayingInfo[MPMediaItemPropertyPlaybackDuration] = player?.currentItem?.duration.seconds ?? 0

    MPNowPlayingInfoCenter.default().nowPlayingInfo = nowPlayingInfo

    // 注册远程控制事件（锁屏/耳机的播放暂停按钮）
    let commandCenter = MPRemoteCommandCenter.shared()
    commandCenter.playCommand.addTarget { event -> MRPremoteCommandHandlerStatus in
        self.play()
        return .success
    }
    commandCenter.pauseCommand.addTarget { event -> MRPremoteCommandHandlerStatus in
        self.pause()
        return .success
    }
}
```

> 💡 **提示**：别忘了 import `MediaPlayer` 框架才能使用 `MPNowPlayingInfoCenter` 和 `MPRemoteCommandCenter`。

## 8. 常见问题与最佳实践

### 8.1 格式兼容性问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 播放无声 | 未配置 AVAudioSession | 在播放前调用 `setCategory(_:mode:options:)` |
| 视频黑屏 | 视频编解码器不支持 | 使用 `AVAssetExportSession` 转换为 H.264 |
| 录音文件为空 | 权限被拒绝 | 先请求 `NSMicrophoneUsageDescription` 权限 |
| HLS 无法播放 | 缺少 `App Transport Security` 设置 | Info.plist 中添加域名例外或全局关闭 ATS |
| 某些设备无法播放 HEVC | 设备不支持硬解 | 降级为 H.264 或检测 `supportsVideoCodec` |

### 8.2 内存管理注意事项

```swift
// ❌ 错误做法：强引用导致内存泄漏
class BadPlayerHolder {
    let player = AVPlayer()
    // 如果不手动清理，player 会一直持有 AVPlayerItem 和缓存数据
}

// ✅ 正确做法：及时释放资源
class GoodPlayerHolder {
    var player: AVPlayer?

    deinit {
        // 移除所有 KVO 和 Time Observer
        player?.removeAllObservers()
        player?.replaceCurrentItem(with: nil)
        player = nil
    }
}

// ✅ 更好的做法：使用 @StateObject + 清理逻辑
@MainActor
class PlayerViewModel: ObservableObject {
    private var player: AVPlayer?
    private var timeObserver: Any?

    func load(_ url: URL) {
        cleanup()
        player = AVPlayer(url: url)
        // ... setup code ...
    }

    func cleanup() {
        if let obs = timeObserver {
            player?.removeTimeObserver(obs)
            timeObserver = nil
        }
        player?.pause()
        player?.replaceCurrentItem(with: nil)
        player = nil
    }
}
```

### 8.3 App Store 审核要点

| 审核项 | 要求 | 注意事项 |
|--------|------|----------|
| **隐私政策** | 必须说明音频/视频的使用目的 | 包括是否上传服务器、存储位置 |
| **权限描述** | `NSMicrophoneUsageDescription` 必须清晰 | 不能写"需要麦克风权限"，要写"用于录制语音消息" |
| **相册权限** | `NSPhotoLibraryUsageDescription` | 选择图片/视频时才请求，不要一启动就弹 |
| **相机权限** | `NSCameraUsageDescription` | 同上，按需请求 |
| **后台音频** | 必须确实有后台播放功能 | 不能声明 audio background mode 却不做音频播放 |
| **儿童隐私** | COPPA 合规 | 如果涉及儿童用户，需额外注意 |
| **HEIC/HEVC** | 导出的图片/视频需兼容 | 考虑提供兼容性选项 |

> ⚠️ **审核高频拒绝原因**：最常见的问题是**权限描述不够具体**。审核团队明确要求描述必须让用户清楚知道为什么需要这个权限。"App 需要访问您的麦克风"会被拒，改为"录制语音笔记以便稍后回放"才能通过。

### 8.4 性能优化清单

- [ ] 使用 `prepareToPlay()` 预加载音频，减少播放延迟
- [ ] 视频 PlayerItem 使用 `automaticallyLoadedAssetKeys` 异步加载元数据
- [ ] 大量视频列表中使用懒加载，只在可见时创建 AVPlayer
- [ ] 录音完成后立即将临时文件移至持久目录
- [ ] 导出大视频时显示进度，避免用户以为 App 卡死
- [ ] 使用 `AVAssetImageGenerator` 生成缩略图而非截取全帧
- [ ] 在 `sceneDidEnterBackground` 时暂停非必要的播放器以节省电量

## 本章小结

| 主题 | 核心要点 | 关键 API |
|------|----------|----------|
| **框架概述** | AVFoundation 是音视频处理的统一框架，覆盖播放/录制/编辑/处理全链路 | `AVFoundation` 全家桶 |
| **音频播放** | 本地用 AVAudioPlayer，网络/高级用 AVPlayer；务必先配置 AVAudioSession | `AVAudioPlayer`, `AVPlayer` |
| **音频录制** | AVAudioRecorder 支持多种格式，记得请求麦克风权限并设置合理编码参数 | `AVAudioRecorder`, `requestRecordPermission` |
| **视频播放** | AVPlayerLayer 渲染画面，UIViewRepresentable 桥接到 SwiftUI，PiP 需开启 Background Mode | `AVPlayerLayer`, `UIViewRepresentable`, `AVPlayerViewController` |
| **视频录制** | AVCaptureSession 协调输入输出，支持前后摄像头切换 | `AVCaptureSession`, `AVCaptureMovieFileOutput` |
| **视频编辑** | AVComposition 用于拼接裁剪，AVAssetExportSession 用于格式转换和导出 | `AVMutableComposition`, `AVAssetExportSession` |
| **SwiftUI 集成** | 通过 UIViewRepresentable 包装 UIKit 组件，结合 @StateObject 管理播放状态 | `UIViewRepresentable`, `@ObservedObject` |
| **后台与会话** | Category 决定音频行为，Mode 细化场景，后台播放需配 Info.plist + Remote Command | `AVAudioSession`, `MPNowPlayingInfoCenter` |
| **最佳实践** | 及时移除 Observer、按需请求权限、权限描述具体化、注意内存释放 | KVO 清理, 权限时机, 审核合规 |

> 🎯 **一句话总结**：AVFoundation 是 iOS 音视频开发的基石——理解其分层架构（播放层→录制层→编辑层），掌握 AVAudioSession 的 Category/Mode 配置规则，并通过 UIViewRepresentable 将 UIKit 能力桥接到 SwiftUI，就能构建出专业的多媒体应用。
