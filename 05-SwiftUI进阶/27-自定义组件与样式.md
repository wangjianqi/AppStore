## 提取子视图

当你的视图代码越来越长，或者发现同样的 UI 片段在多处重复出现时，就该**提取子视图**了。

💡 **通俗理解**：提取子视图就像"整理衣柜"——把衣服按类别分到不同的抽屉里，而不是全部堆在一起。找起来方便，看起来也清爽。

### 识别可提取组件

#### 重复代码识别

当你在多个地方写了几乎相同的 UI 代码，这就是一个信号——该提取了：

```swift
struct ContentView: View {
    var body: some View {
        VStack {
            HStack {
                Image(systemName: "star.fill")
                    .foregroundStyle(.yellow)
                Text("评分：4.8")
                    .font(.headline)
            }
            .padding()
            .background(RoundedRectangle(cornerRadius: 10).fill(.yellow.opacity(0.1)))

            HStack {
                Image(systemName: "star.fill")
                    .foregroundStyle(.yellow)
                Text("评分：4.5")
                    .font(.headline)
            }
            .padding()
            .background(RoundedRectangle(cornerRadius: 10).fill(.yellow.opacity(0.1)))
        }
    }
}
```

上面两段 `HStack` 代码几乎一样，只是文字不同——典型的重复代码！

#### 独立功能模块识别

即使不重复，如果一个视图的 `body` 超过 30~50 行，也应该考虑拆分。每个视图应该只负责一件事。

| 信号 | 说明 |
|------|------|
| 代码重复 | 同样的 UI 出现 2 次以上 |
| body 过长 | 超过 30 行就该拆分 |
| 独立功能块 | 一个 Section、一个卡片、一个列表项 |
| 需要复用 | 这个 UI 片段其他页面也要用 |

### 提取方法

#### 创建新的 View struct

提取子视图只需要三步：
1. 创建一个新的 `View` struct
2. 把重复的 UI 代码移到新视图的 `body` 中
3. 把变化的部分作为参数传入

#### 传入参数

```swift
struct RatingBadge: View {
    let rating: String

    var body: some View {
        HStack {
            Image(systemName: "star.fill")
                .foregroundStyle(.yellow)
            Text("评分：\(rating)")
                .font(.headline)
        }
        .padding()
        .background(RoundedRectangle(cornerRadius: 10).fill(.yellow.opacity(0.1)))
    }
}
```

使用时：

```swift
VStack {
    RatingBadge(rating: "4.8")
    RatingBadge(rating: "4.5")
    RatingBadge(rating: "3.9")
}
```

💡 **提示**：参数越少越好！只传入变化的部分，不变的部分留在子视图内部。

#### 示例

```swift
import SwiftUI
```

### 组件化思维

#### 每个组件只做一件事

就像乐高积木一样，每个组件应该有**单一职责**：

| 组件 | 职责 | 不应该做的 |
|------|------|-----------|
| `UserAvatar` | 显示用户头像 | 不负责网络请求 |
| `InfoCard` | 显示信息卡片 | 不负责数据存储 |
| `RatingBadge` | 显示评分 | 不负责评分逻辑 |

#### 组件可复用

好的组件应该**不依赖特定的上下文**，可以在任何地方使用：

```swift
struct TagView: View {
    let text: String
    let color: Color

    var body: some View {
        Text(text)
            .font(.caption)
            .padding(.horizontal, 10)
            .padding(.vertical, 4)
            .background(color.opacity(0.15))
            .foregroundStyle(color)
            .clipShape(Capsule())
    }
}
```

这个 `TagView` 可以用在任何需要标签的地方：商品分类、文章标签、用户角色……

#### 组件可组合

小组件可以组合成大组件：

```swift
struct ProductCard: View {
    let name: String
    let price: Double
    let rating: String
    let tags: [(text: String, color: Color)]

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text(name)
                .font(.headline)
            HStack {
                RatingBadge(rating: rating)
                Spacer()
                Text("¥\(String(format: "%.0f", price))")
                    .font(.title3.bold())
                    .foregroundStyle(.red)
            }
            HStack {
                ForEach(tags, id: \.text) { tag in
                    TagView(text: tag.text, color: tag.color)
                }
            }
        }
        .padding()
        .background(RoundedRectangle(cornerRadius: 12).fill(.gray.opacity(0.06)))
    }
}
```

💡 **提示**：组件化思维的核心是"搭积木"——先造好小积木（TagView、RatingBadge），再用小积木搭大结构（ProductCard）。

## 自定义 ViewModifier

ViewModifier 是 SwiftUI 的"样式封装器"——把一组修饰符打包成一个整体，方便复用。

💡 **通俗理解**：ViewModifier 就像"一键美颜滤镜"——你不需要每次手动调亮度、对比度、饱和度，一键应用就行。而普通的 `.padding().background()` 就像手动调参数，每次都要重复操作。

### 创建 ViewModifier

#### ViewModifier 协议

遵循 `ViewModifier` 协议，实现 `body(content:)` 方法：

```swift
struct CardModifier: ViewModifier {
    func body(content: Content) -> some View {
        content
            .padding()
            .background(RoundedRectangle(cornerRadius: 12).fill(.white))
            .shadow(color: .black.opacity(0.1), radius: 8, y: 4)
    }
}
```

- `content` 参数：被修饰的原始视图
- 返回值：修饰后的视图

#### body(content:) 方法

在 `body(content:)` 中，你可以对 `content` 添加任意修饰符：

```swift
struct HighlightModifier: ViewModifier {
    let color: Color

    func body(content: Content) -> some View {
        content
            .padding(.horizontal, 12)
            .padding(.vertical, 6)
            .background(color.opacity(0.15))
            .foregroundStyle(color)
            .clipShape(Capsule())
    }
}
```

#### 示例

```swift
import SwiftUI

struct CardModifier: ViewModifier {
    var cornerRadius: CGFloat = 12
    var shadowRadius: CGFloat = 8
    var backgroundColor: Color = .white

    func body(content: Content) -> some View {
        content
            .padding()
            .background(RoundedRectangle(cornerRadius: cornerRadius).fill(backgroundColor))
            .shadow(color: .black.opacity(0.08), radius: shadowRadius, y: 4)
    }
}

struct GlowModifier: ViewModifier {
    let color: Color
    let radius: CGFloat

    func body(content: Content) -> some View {
        content
            .shadow(color: color, radius: radius)
            .shadow(color: color, radius: radius * 0.5)
    }
}

struct ViewModifierDemo: View {
    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 20) {
                    Text("默认卡片样式")
                        .modifier(CardModifier())

                    Text("圆角更大的卡片")
                        .modifier(CardModifier(cornerRadius: 24))

                    Text("带颜色的卡片")
                        .modifier(CardModifier(backgroundColor: .blue.opacity(0.08)))

                    Text("发光文字")
                        .font(.title.bold())
                        .modifier(GlowModifier(color: .blue, radius: 10))

                    Text("红色发光")
                        .font(.title2.bold())
                        .foregroundStyle(.red)
                        .modifier(GlowModifier(color: .red, radius: 8))
                }
                .padding()
            }
            .navigationTitle("ViewModifier 示例")
        }
    }
}
```

💡 **提示**：使用 `.modifier()` 应用自定义修饰符。但更优雅的方式是扩展 View，下面会介绍。

### 复用样式

#### 将常用样式封装为 Modifier

为了让修饰符用起来像原生的一样，可以给 `View` 写扩展：

```swift
extension View {
    func cardStyle(cornerRadius: CGFloat = 12, backgroundColor: Color = .white) -> some View {
        modifier(CardModifier(cornerRadius: cornerRadius, backgroundColor: backgroundColor))
    }
}
```

使用时就像原生修饰符一样：

```swift
Text("卡片内容")
    .cardStyle()

Text("大圆角卡片")
    .cardStyle(cornerRadius: 24)
```

#### 示例

```swift
import SwiftUI

struct BorderedButtonModifier: ViewModifier {
    let color: Color
    let isFilled: Bool

    func body(content: Content) -> some View {
        content
            .font(.headline)
            .padding(.horizontal, 20)
            .padding(.vertical, 12)
            .foregroundStyle(isFilled ? .white : color)
            .background(isFilled ? color : .clear)
            .overlay(
                RoundedRectangle(cornerRadius: 10)
                    .stroke(color, lineWidth: isFilled ? 0 : 2)
            )
            .clipShape(RoundedRectangle(cornerRadius: 10))
    }
}

extension View {
    func borderedButton(color: Color = .blue, isFilled: Bool = true) -> some View {
        modifier(BorderedButtonModifier(color: color, isFilled: isFilled))
    }
}

struct ReusableStyleDemo: View {
    var body: some View {
        NavigationStack {
            VStack(spacing: 20) {
                Button("主要按钮") {}
                    .borderedButton(color: .blue, isFilled: true)

                Button("危险按钮") {}
                    .borderedButton(color: .red, isFilled: true)

                Button("成功按钮") {}
                    .borderedButton(color: .green, isFilled: true)

                Button("描边按钮") {}
                    .borderedButton(color: .blue, isFilled: false)

                Button("橙色描边") {}
                    .borderedButton(color: .orange, isFilled: false)
            }
            .navigationTitle("复用样式示例")
        }
    }
}
```

💡 **提示**：通过 `extension View` 封装修饰符，使用体验和原生 `.buttonStyle()` 一样自然！

### 组合 Modifier

#### 多个 Modifier 组合

ViewModifier 可以嵌套组合，实现更复杂的样式：

```swift
struct GradientBackgroundModifier: ViewModifier {
    let colors: [Color]
    let cornerRadius: CGFloat

    func body(content: Content) -> some View {
        content
            .padding()
            .background(
                LinearGradient(colors: colors, startPoint: .topLeading, endPoint: .bottomTrailing)
            )
            .clipShape(RoundedRectangle(cornerRadius: cornerRadius))
            .shadow(color: colors.first?.opacity(0.3) ?? .clear, radius: 10, y: 5)
    }
}

extension View {
    func gradientBackground(colors: [Color], cornerRadius: CGFloat = 16) -> some View {
        modifier(GradientBackgroundModifier(colors: colors, cornerRadius: cornerRadius))
    }
}
```

#### 示例

```swift
import SwiftUI

struct ShadowModifier: ViewModifier {
    let color: Color
    let radius: CGFloat
    let y: CGFloat

    func body(content: Content) -> some View {
        content.shadow(color: color.opacity(0.2), radius: radius, x: 0, y: y)
    }
}

struct GradientBackgroundModifier: ViewModifier {
    let colors: [Color]
    let cornerRadius: CGFloat

    func body(content: Content) -> some View {
        content
            .padding()
            .background(
                LinearGradient(colors: colors, startPoint: .topLeading, endPoint: .bottomTrailing)
            )
            .clipShape(RoundedRectangle(cornerRadius: cornerRadius))
    }
}

extension View {
    func cardShadow(color: Color = .blue, radius: CGFloat = 8, y: CGFloat = 4) -> some View {
        modifier(ShadowModifier(color: color, radius: radius, y: y))
    }

    func gradientBackground(colors: [Color], cornerRadius: CGFloat = 16) -> some View {
        modifier(GradientBackgroundModifier(colors: colors, cornerRadius: cornerRadius))
    }
}

struct CompositeModifierDemo: View {
    var body: some View {
        NavigationStack {
            ScrollView {
                VStack(spacing: 24) {
                    Text("渐变卡片")
                        .foregroundStyle(.white)
                        .font(.title2.bold())
                        .gradientBackground(colors: [.blue, .purple])
                        .cardShadow(color: .blue)

                    Text("日落卡片")
                        .foregroundStyle(.white)
                        .font(.title2.bold())
                        .gradientBackground(colors: [.orange, .pink])
                        .cardShadow(color: .orange)

                    Text("森林卡片")
                        .foregroundStyle(.white)
                        .font(.title2.bold())
                        .gradientBackground(colors: [.green, .teal])
                        .cardShadow(color: .green)

                    HStack(spacing: 12) {
                        Text("组合")
                            .foregroundStyle(.white)
                            .font(.headline)
                            .gradientBackground(colors: [.indigo, .blue], cornerRadius: 12)
                        Text("效果")
                            .foregroundStyle(.white)
                            .font(.headline)
                            .gradientBackground(colors: [.pink, .red], cornerRadius: 12)
                    }
                }
                .padding()
            }
            .navigationTitle("组合 Modifier 示例")
        }
    }
}
```

💡 **提示**：组合 Modifier 的核心思想是"小而美"——每个 Modifier 只做一件事，通过组合实现复杂效果。

## 主题色系统

一个 App 应该有统一的配色方案，而不是到处硬编码颜色值。主题色系统让你的 App 风格统一，改色时一处修改、全局生效。

### 定义主题色

#### 扩展 Color

通过扩展 `Color`，定义 App 的专属颜色：

```swift
extension Color {
    static let appPrimary = Color(red: 0.25, green: 0.47, blue: 0.85)
    static let appSecondary = Color(red: 0.98, green: 0.55, blue: 0.24)
    static let appBackground = Color(red: 0.97, green: 0.97, blue: 0.98)
    static let appCardBackground = Color.white
    static let appTextPrimary = Color(red: 0.13, green: 0.13, blue: 0.15)
    static let appTextSecondary = Color(red: 0.55, green: 0.55, blue: 0.58)
    static let appSuccess = Color.green
    static let appWarning = Color.orange
    static let appError = Color.red
}
```

💡 **提示**：用 `app` 前缀命名，避免和系统颜色冲突（如 `Color.red`）。

#### 定义主色/辅色/背景色等

| 颜色角色 | 用途 | 示例 |
|---------|------|------|
| **主色（Primary）** | 按钮、Tab 高亮、关键元素 | 导航栏颜色、CTA 按钮 |
| **辅色（Secondary）** | 次要操作、标签 | 描边按钮、标签背景 |
| **背景色（Background）** | 页面背景 | 整体背景色 |
| **卡片背景色** | 卡片、Cell 背景 | 列表项背景 |
| **文字主色** | 标题、正文 | 主要文字颜色 |
| **文字辅色** | 副标题、说明 | 次要文字颜色 |
| **功能色** | 成功/警告/错误 | 状态提示 |

#### 示例

```swift
    static let appCardBackground = Color.white
    static let appTextPrimary = Color(red: 0.13, green: 0.13, blue: 0.15)
    static let appTextSecondary = Color(red: 0.55, green: 0.55, blue: 0.58)

                            .padding()

                    }

                    VStack(spacing: 8) {
                        HStack {
                            Circle().fill(Color.appPrimary).frame(width: 32, height: 32)
                            Text("主色 Primary").foregroundStyle(Color.appTextPrimary)

                        }

                            Circle().fill(Color.appSecondary).frame(width: 32, height: 32)

                    .shadow(color: .black.opacity(0.05), radius: 8, y: 4)

                    .frame(maxWidth: .infinity, alignment: .leading)
                    .background(Color.appCardBackground)
                    .clipShape(RoundedRectangle(cornerRadius: 12))
```

### 动态主题切换

#### 使用 @AppStorage 保存主题选择

`@AppStorage` 可以把用户选择的主题保存到 UserDefaults，下次打开 App 自动恢复。

#### 切换主题色

定义多个主题，用户选择后全局切换：

```swift
enum AppTheme: String, CaseIterable {
    case ocean = "海洋"
    case sunset = "日落"
    case forest = "森林"
    case lavender = "薰衣草"

    var primary: Color {
        switch self {
        case .ocean: return Color(red: 0.25, green: 0.47, blue: 0.85)
        case .sunset: return Color(red: 0.98, green: 0.55, blue: 0.24)
        case .forest: return Color(red: 0.20, green: 0.70, blue: 0.40)
        case .lavender: return Color(red: 0.58, green: 0.40, blue: 0.82)
        }

    }

    var secondary: Color {
        switch self {
        case .ocean: return Color(red: 0.40, green: 0.70, blue: 0.95)
        case .sunset: return Color(red: 1.00, green: 0.75, blue: 0.40)
        case .forest: return Color(red: 0.55, green: 0.85, blue: 0.55)
        case .lavender: return Color(red: 0.75, green: 0.60, blue: 0.90)
        }
    }

    var gradient: [Color] {
        [primary, secondary]
    }
}
```

#### 示例

## 暗黑模式适配

iOS 支持浅色和深色两种外观模式。适配暗黑模式可以让你的 App 在两种模式下都有良好的视觉体验。

### 颜色适配

#### Asset Catalog 定义颜色（Light/Dark）

最推荐的方式是在 Asset Catalog 中定义颜色，分别设置浅色和深色模式的值：

1. 打开 `Assets.xcassets`
2. 右键 → New Color Set
3. 在 Attributes Inspector 中，将 Appearances 设为 "Any, Dark"
4. 分别设置浅色和深色模式的颜色值

```
颜色名          浅色模式        深色模式
─────────────────────────────────────────
cardBackground  #FFFFFF        #1C1C1E
textPrimary     #1C1C1E        #F2F2F7
textSecondary   #8E8E93        #A1A1A6
separator       #C6C6C8        #38383A
```

#### 代码中适配

在代码中使用 Asset Catalog 定义的颜色，系统会自动根据当前模式选择：

```swift
// 使用 Asset Catalog 中定义的颜色
Text("自动适配")
    .foregroundStyle(Color("textPrimary"))
    .background(Color("cardBackground"))
```

也可以用 `Color` 的 `init(light:dark:)` 在代码中定义适配色：

```swift
extension Color {
    static let adaptiveCard = Color(light: Color(red: 1, green: 1, blue: 1), dark: Color(red: 0.11, green: 0.11, blue: 0.12))
    static let adaptiveText = Color(light: Color(red: 0.07, green: 0.07, blue: 0.09), dark: Color(red: 0.95, green: 0.95, blue: 0.97))
}

extension Color {
    init(light: Color, dark: Color) {
        self.init(uiColor: UIColor { traitCollection in
            traitCollection.userInterfaceStyle == .dark
                ? UIColor(dark)
                : UIColor(light)
        })
    }
}
```

#### 示例

```swift
import SwiftUI

extension Color {
    init(light: Color, dark: Color) {
        self.init(uiColor: UIColor { traitCollection in
            traitCollection.userInterfaceStyle == .dark
                ? UIColor(dark)

        })
    }

    static let adaptiveCard = Color(light: .white, dark: Color(red: 0.11, green: 0.11, blue: 0.12))
    static let adaptiveText = Color(light: Color(red: 0.07, green: 0.07, blue: 0.09), dark: Color(red: 0.95, green: 0.95, blue: 0.97))
    static let adaptiveSecondary = Color(light: .gray, dark: .gray.opacity(0.6))
    static let adaptiveSeparator = Color(light: Color(red: 0.78, green: 0.78, blue: 0.80), dark: Color(red: 0.22, green: 0.22, blue: 0.23))
}

struct DarkModeColorDemo: View {
    var body: some View {
        NavigationStack {
            ScrollView {

                            .font(.title2.bold())
                            .foregroundStyle(Color.adaptiveText)
                        Text("正文内容，自动适配深色模式")
                            .foregroundStyle(Color.adaptiveSecondary)
                        Divider().background(Color.adaptiveSeparator)
                        Text("更多内容...")
                            .foregroundStyle(Color.adaptiveText)
                    }
                    .padding()
                    .background(Color.adaptiveCard)
                    .clipShape(RoundedRectangle(cornerRadius: 12))

                    HStack(spacing: 12) {
                        VStack {
                            Image(systemName: "sun.max.fill")
                                .font(.title)
                                .foregroundStyle(.orange)
                            Text("浅色")
                                .font(.caption)
                                .foregroundStyle(Color.adaptiveSecondary)
                        }
                        .frame(maxWidth: .infinity)
                        .padding()
                        .background(Color.adaptiveCard)
                        .clipShape(RoundedRectangle(cornerRadius: 12))

                        VStack {
                            Image(systemName: "moon.fill")
                                .font(.title)
                                .foregroundStyle(.indigo)
                            Text("深色")
                                .font(.caption)
                                .foregroundStyle(Color.adaptiveSecondary)
                        }
                        .frame(maxWidth: .infinity)
                        .padding()
                        .background(Color.adaptiveCard)
                        .clipShape(RoundedRectangle(cornerRadius: 12))
                    }

                    Text("💡 系统颜色（如 .blue、.red）会自动适配深色模式，不需要手动处理")
                        .font(.caption)
                        .foregroundStyle(Color.adaptiveSecondary)
                        .padding()
                }
                .padding()
            }
            .navigationTitle("暗黑模式颜色适配")
        }
    }
}
```

💡 **提示**：SwiftUI 的系统颜色（`.primary`、`.secondary`、`.blue` 等）已经自动适配了深色模式！只有自定义颜色才需要手动适配。

### 图片适配

#### Asset Catalog 定义图片（Light/Dark）

和颜色一样，图片也可以在 Asset Catalog 中分别设置浅色和深色版本：

1. 打开 `Assets.xcassets`
2. 选择一个 Image Set
3. 在 Attributes Inspector 中，将 Appearances 设为 "Any, Dark"
4. 分别拖入浅色和深色模式的图片

适用场景：

| 场景 | 浅色模式图片 | 深色模式图片 |

| Logo | 深色 Logo | 浅色 Logo |
| 图标背景 | 浅色背景 | 深色背景 |
| 装饰图 | 适合浅底的图 | 适合深底的图 |

#### 示例

```swift
                    }
```

### 渲染模式

SF Symbols 支持 4 种渲染模式，决定了图标的着色方式。

#### .renderingMode(.monochrome)

单色模式：整个图标使用一种颜色，最常用的模式。

```swift
Image(systemName: "heart.fill")
    .renderingMode(.monochrome)
    .foregroundStyle(.red)
    .font(.title)
```

#### .renderingMode(.multicolor)

多色模式：图标的各部分使用系统预设的颜色。

```swift
Image(systemName: "externaldrive.badge.wifi")
    .renderingMode(.multicolor)
    .font(.title)
```

#### .renderingMode(.hierarchical)

层级模式：根据图标层次自动调整透明度，主层最亮，次层渐淡。

```swift
Image(systemName: "square.stack.3d.up.fill")
    .renderingMode(.hierarchical)
    .foregroundStyle(.blue)
    .font(.title)
```

#### .renderingMode(.palette)

调色板模式：用多个颜色分别着色图标的不同层。

```swift
Image(systemName: "person.crop.circle.badge.checkmark")
    .renderingMode(.palette)
    .foregroundStyle(.blue, .green)
    .font(.title)
```

#### 对比表

| 渲染模式 | 着色方式 | 适用场景 | 需要指定颜色 |
|---------|---------|---------|:----------:|
| **monochrome** | 单一颜色 | 通用图标、Tab 图标 | ✅ 1 个颜色 |
| **multicolor** | 系统预设多色 | 天气、设备等自带颜色的图标 | ❌ |
| **hierarchical** | 层级渐变 | 多层图标，需要层次感 | ✅ 1 个颜色 |
| **palette** | 多色分别着色 | 需要精确控制每层颜色 | ✅ 多个颜色 |

#### 示例

```swift
import SwiftUI

struct RenderingModeDemo: View {
    var body: some View {
        NavigationStack {
            List {
                Section("单色 Monochrome") {
```

### 自定义颜色与大小

#### .symbolRenderingMode()

`.symbolRenderingMode()` 是 `.renderingMode()` 的新版本（iOS 17+），专门用于 SF Symbols：

```swift
Image(systemName: "heart.fill")
    .symbolRenderingMode(.monochrome)
    .foregroundStyle(.red)
```

#### .font() 控制大小

SF Symbols 的大小跟随字体大小，用 `.font()` 控制：

```swift
HStack(spacing: 16) {
    Image(systemName: "star.fill")
        .font(.caption)
    Image(systemName: "star.fill")
        .font(.body)
    Image(systemName: "star.fill")
        .font(.title)
    Image(systemName: "star.fill")
        .font(.system(size: 48))
}
.foregroundStyle(.yellow)
```

| 方式 | 示例 | 说明 |
|------|------|------|
| 语义字体 | `.font(.title)` | 跟随系统缩放 |
| 固定大小 | `.font(.system(size: 36))` | 精确控制大小 |
| 粗细 | `.font(.title.bold())` | 控制线条粗细 |

#### .foregroundStyle() 控制颜色

```swift
Image(systemName: "heart.fill")
    .foregroundStyle(.red)

Image(systemName: "star.fill")
    .foregroundStyle(.yellow)

Image(systemName: "checkmark.circle.fill")
    .foregroundStyle(.green)
```

⚠️ **注意**：优先使用 `.foregroundStyle()` 而不是 `.foregroundColor()`，前者支持多色渲染，后者只支持单色。

### 动画图标

iOS 17 引入了 SF Symbols 动画，让图标"活"起来！

#### .symbolEffect()

```swift
Image(systemName: "heart.fill")
    .symbolEffect(.pulse)

Image(systemName: "gearshape.fill")
    .symbolEffect(.rotate)

Image(systemName: "bell.fill")
    .symbolEffect(.bounce)
```

#### 可动画图标列表

| 动画效果 | 修饰符 | 适用图标 | 效果描述 |
|---------|--------|---------|---------|
| **脉冲** | `.symbolEffect(.pulse)` | 可变颜色图标 | 部分区域闪烁 |
| **弹跳** | `.symbolEffect(.bounce)` | 任意图标 | 图标弹跳一下 |
| **旋转** | `.symbolEffect(.rotate)` | 齿轮、箭头等 | 持续旋转 |
| **缩放** | `.symbolEffect(.scale.up)` | 任意图标 | 放大效果 |
| **替换** | `.contentTransition(.symbolEffect)` | 切换图标时 | 平滑过渡 |

💡 **提示**：`.pulse` 效果最适合"可变颜色"图标（图标名含 `.fill` 的变体），比如 `heart.fill`、`bell.fill`、`wifi`。

#### 示例

```swift
import SwiftUI

struct AnimatedSymbolsDemo: View {
    @State private var isLiked = false
    @State private var notificationCount = 0

    var body: some View {
        NavigationStack {
            List {
                Section("脉冲动画 Pulse") {
                    HStack {
                        Image(systemName: "heart.fill")
                            .symbolEffect(.pulse)
                            .foregroundStyle(.red)
                            .font(.title2)
                        Text("爱心脉冲")
                    }
                    HStack {
                        Image(systemName: "bell.fill")
                            .symbolEffect(.pulse)
                            .foregroundStyle(.orange)
                            .font(.title2)
                        Text("通知脉冲")
                    }
                    HStack {
                        Image(systemName: "wifi")
                            .symbolEffect(.pulse)
                            .foregroundStyle(.blue)
                            .font(.title2)
                        Text("WiFi 脉冲")
                    }
                }

                Section("弹跳动画 Bounce") {
                    HStack {
                        Image(systemName: "star.fill")
                            .symbolEffect(.bounce)
                            .foregroundStyle(.yellow)
                            .font(.title2)
                        Text("星星弹跳")
                    }
                    HStack {
                        Image(systemName: "hand.thumbsup.fill")
                            .symbolEffect(.bounce)
                            .foregroundStyle(.blue)
                            .font(.title2)
                        Text("点赞弹跳")
                    }
                }

                Section("旋转动画 Rotate") {
                    HStack {
                        Image(systemName: "gearshape.fill")
                            .symbolEffect(.rotate)
                            .foregroundStyle(.gray)
                            .font(.title2)
                        Text("齿轮旋转")
                    }
                    HStack {
                        Image(systemName: "arrow.triangle.2.circlepath")
                            .symbolEffect(.rotate)
                            .foregroundStyle(.blue)
                            .font(.title2)
                        Text("刷新旋转")
                    }
                }

                Section("交互式动画") {
                    Button {
                        isLiked.toggle()
                    } label: {
                        HStack {
                            Image(systemName: isLiked ? "heart.fill" : "heart")
                                .contentTransition(.symbolEffect(.replace.byLayer.downUp))
                                .foregroundStyle(isLiked ? .red : .gray)
                                .font(.title2)
                            Text(isLiked ? "已收藏" : "收藏")
                        }
                    }

                    Button {
                        notificationCount += 1
                    } label: {
                        HStack {
                            Image(systemName: "bell.badge.fill")
                                .symbolEffect(.bounce, value: notificationCount)
                                .foregroundStyle(.orange)
                                .font(.title2)
                            Text("发送通知（\(notificationCount)）")
                        }
                    }
                }
            }
            .navigationTitle("SF Symbols 动画")
        }
    }
}
```

⚠️ **警告**：SF Symbols 动画需要 iOS 17+。在 iOS 16 及以下，`.symbolEffect()` 会被忽略，图标仍然正常显示，只是没有动画。

💡 **提示**：`.contentTransition(.symbolEffect(.replace))` 可以让图标切换时有平滑的过渡动画，比如空心变实心、一个图标变另一个图标。

## 小结

本章我们学习了 SwiftUI 中自定义组件与样式系统的完整知识：

| 知识点 | 核心内容 |
|--------|---------|
| **提取子视图** | 识别重复代码、创建独立组件、组件化思维 |
| **ViewModifier** | 封装样式、复用修饰符、组合效果 |
| **主题色系统** | 扩展 Color、定义配色方案、动态切换主题 |
| **暗黑模式** | 颜色适配、图片适配、测试方法 |
| **SF Symbols** | 渲染模式、自定义颜色大小、动画图标 |

🔑 **核心记忆点**：
1. 重复代码超过 2 次就该提取为子视图
2. ViewModifier 封装样式，通过 `extension View` 让调用更自然
3. 主题色统一管理，改色一处修改、全局生效
4. 暗黑模式优先用 Asset Catalog 和系统颜色，减少手动判断
