# 30-网络请求：获取真实数据

> 🎯 **本章目标**：理解网络请求的基本原理，掌握 URLSession 发起 GET/POST 请求，学会 async/await 异步编程，熟练使用 Codable 解析 JSON，并能在 SwiftUI 中优雅地处理加载状态和错误。

## 网络请求基础概念

### 什么是 API

API（Application Programming Interface，应用程序编程接口）可以理解为**餐厅的菜单**——你不需要知道厨房怎么做菜，只需要告诉服务员你要什么，厨房就会把菜端给你。

在移动开发中，API 通常指**网络 API**：你的 App 向服务器发送请求，服务器返回你需要的数据。

```
┌──────────┐    请求："给我天气数据"    ┌──────────┐
│  你的 App  │ ──────────────────────► │  服务器    │
│  (客户端)  │ ◄────────────────────── │  (API)    │
└──────────┘    响应：{"temp": 25°C}   └──────────┘
```

💡 **通俗理解**：API 就是一个"数据窗口"，你往窗口递一张纸条（请求），窗口就给你返回一袋数据（响应）。

### HTTP 请求方法

HTTP 请求方法告诉服务器你想要做什么操作，最常用的有 4 种：

| 方法 | 用途 | 类比 | 是否有请求体 |
|------|------|------|:----------:|
| **GET** | 获取数据 | 在图书馆查书 | ❌ |
| **POST** | 创建新数据 | 往信箱投信 | ✅ |
| **PUT** | 更新数据（整体替换） | 替换整篇文章 | ✅ |
| **DELETE** | 删除数据 | 撕掉一页纸 | ❌ |

⚠️ **注意**：在实际开发中，GET 请求最常用，其次是 POST。PUT 和 DELETE 在 RESTful API 中才会频繁用到。

### JSON 数据格式

JSON（JavaScript Object Notation）是 API 返回数据最常用的格式，本质上就是**键值对**。

```json
{
  "name": "张三",
  "age": 25,
  "isStudent": false,
  "hobbies": ["编程", "游戏"],
  "address": {
    "city": "北京",
    "street": "朝阳路"
  }
}
```

| JSON 类型 | 写法示例 | 对应 Swift 类型 |
|-----------|---------|----------------|
| 字符串 | `"hello"` | `String` |
| 数字 | `42` / `3.14` | `Int` / `Double` |
| 布尔值 | `true` / `false` | `Bool` |
| 数组 | `[1, 2, 3]` | `[Int]` |
| 对象 | `{"key": "value"}` | `struct` / `class` |
| 空值 | `null` | `Optional` |

💡 **提示**：JSON 的键（key）必须用**双引号**包裹，值是字符串也要双引号，数字和布尔值不需要。

### RESTful API 简介

RESTful 是一种 API 设计风格，核心思想是**用 URL 表示资源，用 HTTP 方法表示操作**：

| 操作 | HTTP 方法 | URL 示例 | 说明 |
|------|----------|---------|------|
| 获取所有用户 | GET | `/users` | 返回用户列表 |
| 获取某个用户 | GET | `/users/1` | 返回 ID 为 1 的用户 |
| 创建用户 | POST | `/users` | 提交新用户数据 |
| 更新用户 | PUT | `/users/1` | 更新 ID 为 1 的用户 |
| 删除用户 | DELETE | `/users/1` | 删除 ID 为 1 的用户 |

⚠️ **注意**：RESTful 只是一种设计规范，不是强制标准。实际项目中你可能会遇到各种风格的 API。

## URLSession 基础

URLSession 是 Apple 提供的网络请求工具，就像一个"网络快递员"，帮你把请求发出去，把响应带回来。

### GET 请求

GET 请求是最简单的网络请求——你给一个网址，服务器返回数据。

#### URLSession.shared.data(from: url)

最基础的 GET 请求只需要两步：
1. 创建一个 URL
2. 用 `URLSession.shared.data(from:)` 获取数据

```swift
let url = URL(string: "https://api.example.com/users")!
let (data, response) = try await URLSession.shared.data(from: url)
```

返回值是一个元组：
- `data`：服务器返回的原始数据（`Data` 类型）
- `response`：服务器的响应信息（状态码、头信息等）

#### async/await 方式

Swift 5.5 引入了 `async/await`，让异步代码写起来像同步代码一样直观：

```swift
// 旧方式（回调地狱）👇
URLSession.shared.dataTask(with: url) { data, response, error in
    if let error = error {
        print(error)
        return
    }
    guard let data = data else { return }
    // 处理数据...
}.resume()

// 新方式（async/await）👇
do {
    let (data, response) = try await URLSession.shared.data(from: url)
    // 处理数据...
} catch {
    print(error)
}
```

💡 **提示**：`async/await` 是现代 Swift 的推荐写法，代码更简洁、更易读。本书所有示例都使用 `async/await`。

#### 完整示例

下面是一个完整可运行的 GET 请求示例，使用免费的 JSONPlaceholder 测试 API：

```swift
import SwiftUI

struct User: Codable {
    let id: Int
    let name: String
    let email: String
    let phone: String
}

struct GETRequestView: View {
    @State private var users: [User] = []
    @State private var errorMessage: String?

    var body: some View {
        List(users) { user in
            VStack(alignment: .leading, spacing: 4) {
                Text(user.name)
                    .font(.headline)
                Text(user.email)
                    .font(.subheadline)
                    .foregroundStyle(.secondary)
                Text(user.phone)
                    .font(.caption)
                    .foregroundStyle(.tertiary)
            }
            .padding(.vertical, 4)
        }
        .overlay {
            if let errorMessage = errorMessage {
                ContentUnavailableView("加载失败", systemImage: "wifi.exclamationmark", description: Text(errorMessage))
            }
        }
        .task {
            await fetchUsers()
        }
    }

    func fetchUsers() async {
        guard let url = URL(string: "https://jsonplaceholder.typicode.com/users") else {
            errorMessage = "URL 无效"
            return
        }

        do {
            let (data, response) = try await URLSession.shared.data(from: url)

            guard let httpResponse = response as? HTTPURLResponse,
                  (200...299).contains(httpResponse.statusCode) else {
                errorMessage = "服务器错误"
                return
            }

            users = try JSONDecoder().decode([User].self, from: data)
        } catch {
            errorMessage = error.localizedDescription
        }
    }
}
```

💡 **提示**：`.task { }` 是 SwiftUI 提供的修饰符，视图出现时自动执行异步任务，视图消失时自动取消。

### POST 请求

POST 请求用于向服务器**提交数据**，比如登录、注册、发帖等。

#### URLRequest 配置

POST 请求需要创建 `URLRequest`，因为默认的请求方式是 GET，我们需要手动修改：

```swift
var request = URLRequest(url: url)
request.httpMethod = "POST"
```

#### 设置 HTTP 方法

```swift
request.httpMethod = "POST"   // 创建
request.httpMethod = "PUT"    // 更新
request.httpMethod = "DELETE" // 删除
```

#### 设置请求体

POST 请求通常需要在请求体中发送 JSON 数据：

```swift
let body: [String: Any] = [
    "title": "我的帖子",
    "body": "这是内容",
    "userId": 1
]
request.httpBody = try JSONSerialization.data(withJSONObject: body)
```

💡 **更优雅的方式**：用 `JSONEncoder` 编码 `Codable` 对象：

```swift
let post = NewPost(title: "我的帖子", body: "这是内容", userId: 1)
request.httpBody = try JSONEncoder().encode(post)
```

#### 完整示例

```swift
import SwiftUI

struct NewPost: Codable {
    let title: String
    let body: String
    let userId: Int
}

struct PostResponse: Codable {
    let id: Int
    let title: String
    let body: String
    let userId: Int
}

struct POSTRequestView: View {
    @State private var responseText: String = "等待发送..."
    @State private var isSending = false

    var body: some View {
        VStack(spacing: 20) {
            Text("POST 请求示例")
                .font(.title2.bold())

            Text(responseText)
                .font(.body)
                .foregroundStyle(.secondary)
                .multilineTextAlignment(.center)
                .padding()

            Button(action: sendPost) {
                HStack {
                    if isSending {
                        ProgressView()
                            .tint(.white)
                    }
                    Text(isSending ? "发送中..." : "发送 POST 请求")
                }
                .frame(maxWidth: .infinity)
                .padding()
                .background(Color.blue)
                .foregroundStyle(.white)
                .clipShape(RoundedRectangle(cornerRadius: 12))
            }
            .disabled(isSending)
            .padding(.horizontal)
        }
        .padding()
    }

    func sendPost() {
        isSending = true
        Task {
            guard let url = URL(string: "https://jsonplaceholder.typicode.com/posts") else {
                responseText = "URL 无效"
                isSending = false
                return
            }

            var request = URLRequest(url: url)
            request.httpMethod = "POST"
            request.setValue("application/json", forHTTPHeaderField: "Content-Type")

            let newPost = NewPost(title: "SwiftUI 学习", body: "今天学了网络请求！", userId: 1)
            request.httpBody = try? JSONEncoder().encode(newPost)

            do {
                let (data, response) = try await URLSession.shared.data(for: request)

                guard let httpResponse = response as? HTTPURLResponse,
                      (200...299).contains(httpResponse.statusCode) else {
                    responseText = "服务器返回错误"
                    isSending = false
                    return
                }

                let result = try JSONDecoder().decode(PostResponse.self, from: data)
                responseText = "✅ 成功！\nID: \(result.id)\n标题: \(result.title)\n内容: \(result.body)"
            } catch {
                responseText = "❌ 错误：\(error.localizedDescription)"
            }

            isSending = false
        }
    }
}
```

⚠️ **注意**：JSONPlaceholder 是测试 API，POST 请求并不会真正创建数据，但会返回一个模拟的响应。

### 请求头配置

请求头（HTTP Headers）是附加在请求中的元信息，告诉服务器关于请求的额外细节。

#### 常用请求头

| 请求头 | 用途 | 示例值 |
|--------|------|--------|
| `Content-Type` | 告诉服务器请求体的格式 | `application/json` |
| `Authorization` | 身份验证凭证 | `Bearer abc123token` |
| `Accept` | 期望的响应格式 | `application/json` |
| `User-Agent` | 客户端标识 | `MyApp/1.0` |

#### Content-Type

发送 JSON 数据时，必须设置 `Content-Type`：

```swift
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
```

⚠️ **警告**：如果发送 JSON 数据但忘记设置 `Content-Type`，很多服务器会拒绝请求或无法正确解析！

#### Authorization

很多 API 需要身份验证，最常见的两种方式：

```swift
// 方式1：Bearer Token（最常用）
request.setValue("Bearer your_token_here", forHTTPHeaderField: "Authorization")

// 方式2：API Key
request.setValue("your_api_key_here", forHTTPHeaderField: "X-API-Key")
```

#### 完整示例

```swift
import SwiftUI

struct AuthRequestView: View {
    @State private var resultText: String = "点击按钮发送带请求头的请求"

    var body: some View {
        VStack(spacing: 20) {
            Text(resultText)
                .font(.body)
                .foregroundStyle(.secondary)
                .padding()

            Button("发送带请求头的 GET 请求") {
                Task {
                    await fetchWithHeaders()
                }
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }

    func fetchWithHeaders() async {
        guard let url = URL(string: "https://jsonplaceholder.typicode.com/posts/1") else {
            resultText = "URL 无效"
            return
        }

        var request = URLRequest(url: url)
        request.httpMethod = "GET"
        request.setValue("application/json", forHTTPHeaderField: "Accept")
        request.setValue("MyApp/1.0", forHTTPHeaderField: "User-Agent")
        request.setValue("Bearer demo_token_123", forHTTPHeaderField: "Authorization")

        do {
            let (data, response) = try await URLSession.shared.data(for: request)

            if let httpResponse = response as? HTTPURLResponse {
                resultText = "状态码：\(httpResponse.statusCode)\n响应头：\(httpResponse.allHeaderFields)"
            }
        } catch {
            resultText = "错误：\(error.localizedDescription)"
        }
    }
}
```

## async/await 异步编程

网络请求需要时间——你的 App 不会"卡住"等待，而是先去做别的事，等数据回来了再处理。这就是**异步编程**。

### 异步函数定义

#### func fetchData() async throws -> Data

在函数签名中加 `async` 表示这是一个异步函数，加 `throws` 表示可能抛出错误：

```swift
func fetchUser(id: Int) async throws -> User {
    let url = URL(string: "https://api.example.com/users/\(id)")!
    let (data, _) = try await URLSession.shared.data(from: url)
    return try JSONDecoder().decode(User.self, from: data)
}
```

| 关键字 | 含义 | 类比 |
|--------|------|------|
| `async` | 这个函数需要等待（不会阻塞主线程） | "我去取快递，你先忙" |
| `await` | 在这里等待异步操作完成 | "等快递到了再继续" |
| `throws` | 这个函数可能出错 | "取快递可能找不到" |
| `try` | 调用可能出错的函数 | "试试看能不能取到" |

#### async 关键字

`async` 标记函数为异步函数，只能在异步上下文中调用：

```swift
// ✅ 正确：async 函数
func loadProfile() async throws -> Profile {
    let data = try await fetchData()
    return try parse(data)
}

// ❌ 错误：普通函数不能直接调用 async 函数
func loadProfile() -> Profile {
    let data = try await fetchData() // 编译错误！
}

// ✅ 正确：在 Task 中调用
func loadProfile() {
    Task {
        let data = try await fetchData()
    }
}
```

#### Task 调用异步函数

`Task` 创建一个异步执行环境，让你可以在普通函数中调用 `async` 函数：

```swift
// 在 SwiftUI 视图中
Button("加载数据") {
    Task {
        do {
            let users = try await fetchUsers()
            self.userList = users
        } catch {
            self.errorMessage = error.localizedDescription
        }
    }
}
```

💡 **提示**：SwiftUI 的 `.task { }` 修饰符已经自带了 `Task` 环境，不需要再手动创建。

### Task 与 TaskGroup

#### Task { await ... }

`Task` 可以创建一个异步任务，适合简单的并发场景：

```swift
Task {
    async let users = fetchUsers()
    async let posts = fetchPosts()

    let allUsers = try await users
    let allPosts = try await posts

    self.users = allUsers
    self.posts = allPosts
}
```

💡 **提示**：`async let` 可以让多个请求**同时**发起，而不是一个接一个，大大提升速度！

#### 并发多个请求

`TaskGroup` 适合需要动态数量并发任务的场景：

```swift
func fetchAllPosts() async throws -> [Post] {
    let postIds = Array(1...10)

    return try await withThrowingTaskGroup(of: Post.self) { group in
        for id in postIds {
            group.addTask {
                try await self.fetchPost(id: id)
            }
        }

        var posts: [Post] = []
        for try await post in group {
            posts.append(post)
        }
        return posts
    }
}

func fetchPost(id: Int) async throws -> Post {
    let url = URL(string: "https://jsonplaceholder.typicode.com/posts/\(id)")!
    let (data, _) = try await URLSession.shared.data(from: url)
    return try JSONDecoder().decode(Post.self, from: data)
}
```

| 方式 | 适用场景 | 特点 |
|------|---------|------|
| `async let` | 固定数量的并发请求 | 简单直观 |
| `TaskGroup` | 动态数量的并发请求 | 灵活强大 |

### 错误处理

#### try / catch

网络请求随时可能失败，必须做好错误处理：

```swift
do {
    let users = try await fetchUsers()
    self.users = users
} catch {
    // error 是 Error 类型，包含错误信息
    print("请求失败：\(error)")
}
```

#### 自定义错误类型

为了更精确地处理不同错误，可以定义自己的错误类型：

```swift
enum NetworkError: LocalizedError {
    case invalidURL
    case serverError(statusCode: Int)
    case decodingFailed
    case networkUnavailable
    case timeout

    var errorDescription: String? {
        switch self {
        case .invalidURL:
            return "URL 格式无效"
        case .serverError(let code):
            return "服务器错误（状态码：\(code)）"
        case .decodingFailed:
            return "数据解析失败"
        case .networkUnavailable:
            return "网络不可用，请检查网络连接"
        case .timeout:
            return "请求超时，请稍后重试"
        }
    }
}
```

#### 示例

将自定义错误与网络请求结合：

```swift
func fetchUsers() async throws -> [User] {
    guard let url = URL(string: "https://jsonplaceholder.typicode.com/users") else {
        throw NetworkError.invalidURL
    }

    let (data, response): (Data, URLResponse)

    do {
        (data, response) = try await URLSession.shared.data(from: url)
    } catch {
        throw NetworkError.networkUnavailable
    }

    guard let httpResponse = response as? HTTPURLResponse else {
        throw NetworkError.serverError(statusCode: 0)
    }

    guard (200...299).contains(httpResponse.statusCode) else {
        throw NetworkError.serverError(statusCode: httpResponse.statusCode)
    }

    do {
        return try JSONDecoder().decode([User].self, from: data)
    } catch {
        throw NetworkError.decodingFailed
    }
}
```

## JSON 解析（Codable）

服务器返回的是原始的 `Data`（二进制数据），我们需要把它转换成 Swift 对象，这个过程叫**解码（Decoding）**。

### Codable 协议

#### 编码（Encodable）和解码（Decodable）

`Codable` 是 `Encodable` 和 `Decodable` 的组合：

| 协议 | 作用 | 方向 |
|------|------|------|
| `Decodable` | JSON → Swift 对象 | 服务器 → App |
| `Encodable` | Swift 对象 → JSON | App → 服务器 |
| `Codable` | 两者都支持 | 双向 |

#### 自动合成

只要你的类型属性都是基本类型，Swift 会自动帮你实现编解码：

```swift
struct User: Codable {
    let id: Int
    let name: String
    let email: String
}

// 自动支持：
// let user = try JSONDecoder().decode(User.self, from: data)
// let jsonData = try JSONEncoder().encode(user)
```

💡 **提示**：几乎所有基础类型都支持 Codable：`String`、`Int`、`Double`、`Bool`、`Date`、`URL`、`Array`、`Dictionary` 等。

### 解码 JSON

#### JSONDecoder()

`JSONDecoder` 把 JSON 数据转成 Swift 对象：

```swift
let json = """
{
    "id": 1,
    "name": "张三",
    "email": "zhangsan@example.com"
}
""".data(using: .utf8)!

let user = try JSONDecoder().decode(User.self, from: json)
print(user.name) // "张三"
```

⚠️ **注意**：`decode` 的第一个参数是 `User.self`（类型本身），不是 `User()`（实例）。

#### 日期策略

JSON 中的日期格式五花八门，`JSONDecoder` 提供了多种策略：

```swift
let decoder = JSONDecoder()

// 策略1：ISO 8601 格式（如 "2024-01-15T10:30:00Z"）
decoder.dateDecodingStrategy = .iso8601

// 策略2：时间戳（秒数，如 1705312200）
decoder.dateDecodingStrategy = .secondsSince1970

// 策略3：时间戳（毫秒数）
decoder.dateDecodingStrategy = .millisecondsSince1970

// 策略4：自定义格式
let formatter = DateFormatter()
formatter.dateFormat = "yyyy-MM-dd"
decoder.dateDecodingStrategy = .formatted(formatter)
```

| 策略 | JSON 中的样子 | 适用场景 |
|------|-------------|---------|
| `.iso8601` | `"2024-01-15T10:30:00Z"` | 标准格式，最常用 |
| `.secondsSince1970` | `1705312200` | Unix 时间戳 |
| `.millisecondsSince1970` | `1705312200000` | Java 后端常用 |
| `.formatted(formatter)` | `"2024-01-15"` | 自定义格式 |

#### 键策略（CodingKeys）

当 JSON 的键名和 Swift 属性名不一致时，用 `CodingKeys` 做映射：

```swift
// JSON: { "user_name": "张三", "user_age": 25 }
struct User: Codable {
    let name: String
    let age: Int

    enum CodingKeys: String, CodingKey {
        case name = "user_name"
        case age = "user_age"
    }
}
```

💡 **提示**：这在与后端对接时非常常见，因为后端可能用 `snake_case`（下划线命名），而 Swift 用 `camelCase`（驼峰命名）。

更方便的方式——批量转换命名风格：

```swift
let decoder = JSONDecoder()
decoder.keyDecodingStrategy = .convertFromSnakeCase
// user_name → userName 自动转换！
```

### 编码 JSON

#### JSONEncoder()

`JSONEncoder` 把 Swift 对象转成 JSON 数据，用于 POST 请求的请求体：

```swift
let encoder = JSONEncoder()

// 设置输出格式（调试时用 .prettyPrinted 更易读）
encoder.outputFormatting = [.prettyPrinted, .sortedKeys]

let user = User(id: 1, name: "张三", email: "zhangsan@example.com")
let jsonData = try encoder.encode(user)

// 查看生成的 JSON 字符串
if let jsonString = String(data: jsonData, encoding: .utf8) {
    print(jsonString)
}
```

输出：

```json
{
  "email" : "zhangsan@example.com",
  "id" : 1,
  "name" : "张三"
}
```

| `outputFormatting` 选项 | 效果 |
|------------------------|------|
| `.prettyPrinted` | 格式化输出（有缩进换行） |
| `.sortedKeys` | 按键名字母排序 |
| `.withoutEscapingSlashes` | 斜杠不转义 |

struct Post: Codable {
    let id: Int
    let title: String
    let body: String
    let userId: Int
}

    let id: Int
    let postId: Int

struct JSONParsingView: View {

    @State private var isLoading = false

                Text(post.title)
                    .font(.headline)
                Text(post.body)
                    .font(.subheadline)
                    .foregroundStyle(.secondary)

                Text("用户 ID: \(post.userId)")
                    .font(.caption)
                    .foregroundStyle(.tertiary)

        }

## 错误处理与加载状态

### 网络错误处理

#### 常见网络错误

| 错误类型 | 原因 | 解决方案 |
|---------|------|---------|
| `URLError.notConnectedToInternet` | 没有网络 | 提示用户检查网络 |
| `URLError.timedOut` | 请求超时 | 增加超时时间或重试 |
| `URLError.cannotFindHost` | 服务器找不到 | 检查 URL |
| `URLError.badServerResponse` | 服务器返回错误 | 检查服务器状态 |
| `DecodingError` | JSON 解析失败 | 检查数据模型 |

#### 超时处理

```swift
func fetchWithTimeout() async throws -> Data {
    guard let url = URL(string: "https://api.example.com/data") else {
        throw NetworkError.invalidURL
    }

    var request = URLRequest(url: url)
    request.timeoutInterval = 15 // 15 秒超时

    let (data, response) = try await URLSession.shared.data(for: request)

    guard let httpResponse = response as? HTTPURLResponse,
          (200...299).contains(httpResponse.statusCode) else {
        let statusCode = (response as? HTTPURLResponse)?.statusCode ?? 0
        throw NetworkError.serverError(statusCode: statusCode)
    }

    return data
}
```

💡 **提示**：默认超时时间是 60 秒，对于移动端来说太长了，建议设置 10~30 秒。

#### 重试机制

简单的重试实现：

```swift
func fetchWithRetry(url: URL, maxRetries: Int = 3) async throws -> Data {
    var lastError: Error?

    for attempt in 1...maxRetries {
        do {
            let (data, response) = try await URLSession.shared.data(from: url)

            guard let httpResponse = response as? HTTPURLResponse,
                  (200...299).contains(httpResponse.statusCode) else {
                throw NetworkError.serverError(statusCode: (response as? HTTPURLResponse)?.statusCode ?? 0)
            }

            return data
        } catch {
            lastError = error
            print("第 \(attempt) 次请求失败：\(error.localizedDescription)")

            if attempt < maxRetries {
                try await Task.sleep(for: .seconds(Double(attempt)))
            }
        }
    }

    throw lastError!
}
```

⚠️ **注意**：重试时建议加上递增的等待时间（指数退避），避免短时间内大量重试给服务器造成压力。

### 加载状态管理

#### 枚举定义状态

用一个枚举来管理加载的 4 种状态：

```swift
enum LoadState<T> {
    case idle           // 还没开始
    case loading        // 加载中
    case loaded(T)      // 加载成功，携带数据
    case error(String)  // 加载失败，携带错误信息
}
```

#### 根据状态显示不同 UI

```swift
import SwiftUI

struct User: Codable {
    let id: Int
    let name: String
    let email: String
}

enum LoadState<T> {
    case idle
    case loading
    case loaded(T)
    case error(String)
}

struct StateManagementView: View {
    @State private var state: LoadState<[User]> = .idle

    var body: some View {
        NavigationStack {
            Group {
                switch state {
                case .idle:
                    ContentUnavailableView("点击加载", systemImage: "arrow.down.circle", description: Text("点击下方按钮加载数据"))

                case .loading:
                    VStack(spacing: 16) {
                        ProgressView()
                            .scaleEffect(1.5)
                        Text("正在加载...")
                            .foregroundStyle(.secondary)
                    }

                case .loaded(let users):
                    List(users) { user in
                        HStack {
                            Image(systemName: "person.circle.fill")
                                .font(.title2)
                                .foregroundStyle(.blue)
                            VStack(alignment: .leading, spacing: 2) {
                                Text(user.name)
                                    .font(.headline)
                                Text(user.email)
                                    .font(.subheadline)
                                    .foregroundStyle(.secondary)
                            }
                        }
                        .padding(.vertical, 4)
                    }

                case .error(let message):
                    VStack(spacing: 16) {
                        Image(systemName: "wifi.exclamationmark")
                            .font(.system(size: 50))
                            .foregroundStyle(.red)
                        Text("加载失败")
                            .font(.title3.bold())
                        Text(message)
                            .font(.subheadline)
                            .foregroundStyle(.secondary)
                            .multilineTextAlignment(.center)
                        Button("重试") {
                            Task { await loadUsers() }
                        }
                        .buttonStyle(.borderedProminent)
                    }
                    .padding()
                }
            }
            .navigationTitle("用户列表")
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Button(action: { Task { await loadUsers() } }) {
                        Image(systemName: "arrow.clockwise")
                    }
                    .disabled(state == .loading)
                }
            }
        }
    }

    func loadUsers() async {
        state = .loading

        guard let url = URL(string: "https://jsonplaceholder.typicode.com/users") else {
            state = .error("URL 无效")
            return
        }

        do {
            let (data, response) = try await URLSession.shared.data(from: url)

            guard let httpResponse = response as? HTTPURLResponse,
                  (200...299).contains(httpResponse.statusCode) else {
                state = .error("服务器错误")
                return
            }

            let users = try JSONDecoder().decode([User].self, from: data)
            state = .loaded(users)
        } catch {
            state = .error(error.localizedDescription)
        }
    }
}
```

💡 **提示**：使用泛型 `LoadState<T>` 可以让这个枚举复用于任何数据类型，不仅限于 `[User]`。

### 重试机制

#### 自动重试

在网络波动时自动重试，用户无感知：

```swift
func loadWithAutoRetry() async {
    state = .loading

    let maxRetries = 3
    var attempt = 0

    while attempt < maxRetries {
        do {
            let users = try await fetchUsers()
            state = .loaded(users)
            return
        } catch {
            attempt += 1
            if attempt < maxRetries {
                try? await Task.sleep(for: .seconds(Double(attempt) * 2))
            } else {
                state = .error("请求失败，已重试 \(maxRetries) 次：\(error.localizedDescription)")
            }
        }
    }
}
```
