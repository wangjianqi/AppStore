## 1. PhotosUI 框架：PhotosPicker 选择图片/视频

### 1.1 什么是 PhotosUI？

PhotosUI 是 Apple 提供的专门用于访问相册的框架。其中最核心的组件就是 `PhotosPicker`——你可以把它想象成一个"相册入口"，用户点击后弹出系统相册选择器，选完图片后自动返回你的 App。

> 💡 生活类比：PhotosPicker 就像餐厅里的菜单，你不需要亲自去厨房（相册）翻找，服务员（系统）会把菜单拿给你，你点完菜（选完图），菜就端上来了。

### 1.2 基本用法

#### 第一步：导入框架

```swift
import PhotosUI
```

#### 第二步：创建 PhotosPicker

```swift
struct PhotoPickerView: View {
    @State private var selectedItem: PhotosPickerItem?
    @State private var selectedImage: Image?

    var body: some View {
        VStack(spacing: 20) {
            if let selectedImage {
                selectedImage
                    .resizable()
                    .scaledToFit()
                    .frame(width: 300, height: 300)
            } else {
                Rectangle()
                    .fill(Color.gray.opacity(0.3))
                    .frame(width: 300, height: 300)
                    .overlay(Text("暂无图片").foregroundColor(.gray))
            }

            PhotosPicker("选择图片", selection: $selectedItem, matching: .images)
        }
        .onChange(of: selectedItem) { _, newItem in
            Task {
                if let data = try? await newItem?.loadTransferable(type: Data.self),
                   let uiImage = UIImage(data: data) {
                    selectedImage = Image(uiImage: uiImage)
                }
            }
        }
    }
}
```

> ⚠️ 注意：`loadTransferable` 是异步方法，必须在 `Task` 中调用。`onChange` 在 iOS 17+ 使用新旧值双参数格式。

### 1.3 PhotosPicker 参数详解

| 参数 | 类型 | 说明 |
|------|------|------|
| `selection` | `Binding<PhotosPickerItem?>` | 绑定选中的项目，单选模式 |
| `matching` | `PHPickerFilter` | 过滤类型，如 `.images`、`.videos`、`.livePhotos` |
| `maxItemCount` | `Int` | 最大选择数量，默认 1 |
| `photoLibrary` | `PHPhotoLibrary` | 指定相册，默认 `.shared()` |

### 1.4 多选模式

```swift
struct MultiPhotoPickerView: View {
    @State private var selectedItems: [PhotosPickerItem] = []
    @State private var images: [Image] = []

    var body: some View {
        VStack {
            ScrollView(.horizontal) {
                HStack {
                    ForEach(0..<images.count, id: \.self) { index in
                        images[index]
                            .resizable()
                            .scaledToFit()
                            .frame(width: 100, height: 100)
                            .clipShape(RoundedRectangle(cornerRadius: 8))
                    }
                }
            }

            PhotosPicker(
                "选择多张图片",
                selection: $selectedItems,
                maxItemCount: 5,
                matching: .images
            )
        }
        .onChange(of: selectedItems) { _, newItems in
            Task {
                var loadedImages: [Image] = []
                for item in newItems {
                    if let data = try? await item.loadTransferable(type: Data.self),
                       let uiImage = UIImage(data: data) {
                        loadedImages.append(Image(uiImage: uiImage))
                    }
                }
                images = loadedImages
            }
        }
    }
}
```

### 1.5 过滤类型一览

| 过滤器 | 说明 |
|--------|------|
| `.images` | 仅图片 |
| `.videos` | 仅视频 |
| `.livePhotos` | 仅 Live Photo |
| `.screenshots` | 仅截图 |
| `.depthEffectPhotos` | 仅人像模式照片 |
| `.not(.screenshots)` | 排除截图 |

> 💡 提示：`PhotosPicker` 使用系统自带的选择器界面，**不需要请求相册权限**就能工作！系统会以只读方式帮你拿到用户选中的内容。这是最推荐的相册访问方式。

## 2. 相机调用

### 2.1 方式一：UIImagePickerController（简单快捷）

`UIImagePickerController` 是系统提供的现成相机界面，就像"速食面"——开袋即食，简单但定制性有限。

```swift
struct CameraView: UIViewControllerRepresentable {
    @Binding var image: UIImage?
    @Environment(\.dismiss) private var dismiss

    func makeUIViewController(context: Context) -> UIImagePickerController {
        let picker = UIImagePickerController()
        picker.sourceType = .camera
        picker.delegate = context.coordinator
        return picker
    }

    func updateUIViewController(_ uiViewController: UIImagePickerController, context: Context) {}

    func makeCoordinator() -> Coordinator {
        Coordinator(self)
    }

    class Coordinator: NSObject, UIImagePickerControllerDelegate, UINavigationControllerDelegate {
        let parent: CameraView

        init(_ parent: CameraView) {
            self.parent = parent
        }

        func imagePickerController(_ picker: UIImagePickerController, didFinishPickingMediaWithInfo info: [UIImagePickerController.InfoKey: Any]) {
            parent.image = info[.originalImage] as? UIImage
            parent.dismiss()
        }

        func imagePickerControllerDidCancel(_ picker: UIImagePickerController) {
            parent.dismiss()
        }
    }
}
```

使用时：

```swift
struct CameraDemoView: View {
    @State private var image: UIImage?
    @State private var showCamera = false

    var body: some View {
        VStack {
            if let image {
                Image(uiImage: image)
                    .resizable()
                    .scaledToFit()
                    .frame(width: 300, height: 300)
            }

            Button("拍照") {
                showCamera = true
            }
        }
        .sheet(isPresented: $showCamera) {
            CameraView(image: $image)
        }
    }
}
```

> ⚠️ 注意：相机必须在真机上测试，模拟器没有摄像头会直接崩溃！记得先检查设备是否支持相机。

检查相机是否可用：

```swift
if UIImagePickerController.isSourceTypeAvailable(.camera) {
    showCamera = true
} else {
    print("当前设备不支持相机")
}
```

### 2.2 UIImagePickerController 参数一览

| 属性 | 说明 |
|------|------|
| `sourceType` | `.camera`（拍照）、`.photoLibrary`（相册）、`.savedPhotosAlbum`（相机胶卷） |
| `mediaTypes` | 支持的媒体类型，如 `["public.image", "public.movie"]` |
| `cameraCaptureMode` | `.photo`（拍照）、`.video`（录像） |
| `cameraDevice` | `.rear`（后置）、`.front`（前置） |
| `allowsEditing` | 是否允许编辑（裁剪） |

### 2.3 方式二：AVFoundation 自定义相机（灵活强大）

AVFoundation 就像"自己做饭"——食材（API）都给你了，想做什么菜（界面）完全由你决定，但需要更多代码。

#### 基本架构

```swift
import AVFoundation

class CameraManager: NSObject, ObservableObject {
    let session = AVCaptureSession()
    @Published var previewLayer: AVCaptureVideoPreviewLayer?
    @Published var capturedImage: UIImage?

    func setupCamera() {
        session.beginConfiguration()

        guard let device = AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: .back),
              let input = try? AVCaptureDeviceInput(device: device) else {
            session.commitConfiguration()
            return
        }

        if session.canAddInput(input) {
            session.addInput(input)
        }

        let output = AVCapturePhotoOutput()
        if session.canAddOutput(output) {
            session.addOutput(output)
        }

        session.commitConfiguration()

        let previewLayer = AVCaptureVideoPreviewLayer(session: session)
        previewLayer.videoGravity = .resizeAspectFill
        self.previewLayer = previewLayer

        DispatchQueue.global(qos: .userInitiated).async {
            self.session.startRunning()
        }
    }

    func capturePhoto(with output: AVCapturePhotoOutput) {
        let settings = AVCapturePhotoSettings()
        output.capturePhoto(with: settings, delegate: self)
    }

    func stopCamera() {
        session.stopRunning()
    }
}

extension CameraManager: AVCapturePhotoCaptureDelegate {
    func photoOutput(_ output: AVCapturePhotoOutput, didFinishProcessingPhoto photo: AVCapturePhoto, error: Error?) {
        guard let data = photo.fileDataRepresentation(),
              let image = UIImage(data: data) else { return }
        DispatchQueue.main.async {
            self.capturedImage = image
        }
    }
}
```

#### 自定义相机界面

```swift
struct CustomCameraView: View {
    @StateObject private var cameraManager = CameraManager()
    @Environment(\.dismiss) private var dismiss

        ZStack {

                            cameraManager.capturePhoto(with: output)
                        }
                    }) {
                        Circle()
                            .fill(Color.white)
                            .frame(width: 70, height: 70)
                            .overlay(
                                Circle()
                                    .stroke(Color.white, lineWidth: 3)
                                    .frame(width: 58, height: 58)
                            )
                    }

                    Spacer()
                }
                .padding(.bottom, 50)
            }
        }
        .onAppear {
            cameraManager.setupCamera()
        }
        .onDisappear {
            cameraManager.stopCamera()
        }

}

struct CameraPreviewView: UIViewRepresentable {
    let session: AVCaptureSession

    func makeUIView(context: Context) -> UIView {
        let view = UIView()
        let previewLayer = AVCaptureVideoPreviewLayer(session: session)
        previewLayer.videoGravity = .resizeAspectFill
        view.layer.addSublayer(previewLayer)
        return view
    }

    func updateUIView(_ uiView: UIView, context: Context) {
        if let previewLayer = uiView.layer.sublayers?.first as? AVCaptureVideoPreviewLayer {
            DispatchQueue.main.async {
                previewLayer.frame = uiView.bounds
            }
        }
    }
}
```

### 2.4 两种方式对比

| 对比项 | UIImagePickerController | AVFoundation |
|--------|------------------------|--------------|
| 代码量 | 少（约 30 行） | 多（约 100+ 行） |
| 自定义程度 | 低 | 高 |
| 界面风格 | 系统默认 | 完全自定义 |
| 学习曲线 | 平缓 | 陡峭 |
| 适用场景 | 快速集成 | 需要自定义 UI |

> 💡 建议：如果只是简单拍照，用 `UIImagePickerController` 就够了。只有当你需要自定义拍照界面（比如加滤镜预览、贴纸等）时，才需要用 AVFoundation。

## 3. 图片处理：缩放、裁剪、滤镜

### 3.1 图片缩放

```swift
extension UIImage {
    func scaled(to size: CGSize) -> UIImage? {
        let renderer = UIGraphicsImageRenderer(size: size)
        return renderer.image { _ in
            self.draw(in: CGRect(origin: .zero, size: size))
        }
    }

    func scaledToFit(maxDimension: CGFloat) -> UIImage? {
        let scale = min(maxDimension / size.width, maxDimension / size.height)
        let newSize = CGSize(width: size.width * scale, height: size.height * scale)
        return scaled(to: newSize)
    }
}
```

使用示例：

```swift
let thumbnail = originalImage.scaledToFit(maxDimension: 200)
```

### 3.2 图片裁剪

```swift
extension UIImage {
    func cropped(to rect: CGRect) -> UIImage? {
        guard let cgImage = cgImage?.cropping(to: rect) else { return nil }
        return UIImage(cgImage: cgImage, scale: scale, orientation: imageOrientation)
    }

    func croppedToSquare() -> UIImage? {
        let minLength = min(size.width, size.height)
        let xOffset = (size.width - minLength) / 2
        let yOffset = (size.height - minLength) / 2
        let cropRect = CGRect(x: xOffset, y: yOffset, width: minLength, height: minLength)
        return cropped(to: cropRect)
    }
}
```

> 💡 生活类比：裁剪图片就像用剪刀剪纸——你画一个矩形框，框住你想要的部分，然后"咔嚓"一下剪下来。

### 3.3 CoreImage 滤镜

CoreImage 是 Apple 的图像处理框架，内置了上百种滤镜，就像手机修图 App 里的"一键滤镜"。

```swift
import CoreImage

class ImageFilterManager {
    let context = CIContext()

    func applyFilter(to image: UIImage, filterName: String) -> UIImage? {
        guard let ciImage = CIImage(image: image) else { return nil }
        guard let filter = CIFilter(name: filterName) else { return nil }

        filter.setValue(ciImage, forKey: kCIInputImageKey)

        guard let outputImage = filter.outputImage,
              let cgImage = context.createCGImage(outputImage, from: outputImage.extent) else {
            return nil
        }

        return UIImage(cgImage: cgImage, scale: image.scale, orientation: image.imageOrientation)
    }
}
```

#### 常用滤镜一览

| 滤镜名称 | 效果 | 关键参数 |
|----------|------|----------|
| `CISepiaTone` | 怀旧/棕褐色 | `inputIntensity`（0~1） |
| `CIGaussianBlur` | 高斯模糊 | `inputRadius`（像素值） |
| `CIVignette` | 暗角效果 | `inputIntensity`、`inputRadius` |
| `CIColorControls` | 亮度/对比度/饱和度 | `inputBrightness`、`inputContrast`、`inputSaturation` |
| `CIPhotoEffectMono` | 黑白 | 无 |
| `CIPhotoEffectChrome` | 鲜艳 | 无 |
| `CIPhotoEffectFade` | 褪色 | 无 |
| `CIPhotoEffectNoir` | 黑白（高对比） | 无 |
| `CIUnsharpMask` | 锐化 | `inputRadius`、`inputIntensity` |

#### 滤镜应用示例

```swift
let filterManager = ImageFilterManager()

let vintage = filterManager.applyFilter(to: originalImage, filterName: "CISepiaTone")

let blurred = filterManager.applyFilter(to: originalImage, filterName: "CIGaussianBlur")

let mono = filterManager.applyFilter(to: originalImage, filterName: "CIPhotoEffectMono")
```

#### 带参数的滤镜

```swift
func applyBlur(to image: UIImage, radius: Double) -> UIImage? {
    guard let ciImage = CIImage(image: image),
          let filter = CIFilter(name: "CIGaussianBlur") else { return nil }

    filter.setValue(ciImage, forKey: kCIInputImageKey)
    filter.setValue(radius, forKey: kCIInputRadiusKey)

    guard let outputImage = filter.outputImage,
          let cgImage = CIContext().createCGImage(outputImage, from: ciImage.extent) else {
        return nil
    }

    return UIImage(cgImage: cgImage)
}
```

> ⚠️ 注意：`createCGImage` 的 `from` 参数建议使用**原始图片的 extent**，而不是 outputImage 的 extent，因为模糊滤镜会扩展图片边界，导致输出图片变大。

## 4. 保存到相册：PHPhotoLibrary 权限与保存

### 4.1 保存图片到相册

```swift
import Photos

func saveToPhotoLibrary(image: UIImage) {
    PHPhotoLibrary.requestAuthorization(for: .addOnly) { status in
        guard status == .authorized || status == .limited else {
            print("相册权限未授权")
            return
        }

        PHPhotoLibrary.shared().performChanges {
            PHAssetChangeRequest.creationRequestForAsset(from: image)
        } completionHandler: { success, error in
            if success {
                print("保存成功")
            } else {
                print("保存失败: \(error?.localizedDescription ?? "")")
            }
        }
    }
}
```

### 4.2 保存视频到相册

```swift
func saveVideoToPhotoLibrary(url: URL) {
    PHPhotoLibrary.requestAuthorization(for: .addOnly) { status in
        guard status == .authorized || status == .limited else { return }

        PHPhotoLibrary.shared().performChanges {
            PHAssetChangeRequest.creationRequestForAssetFromVideo(atFileURL: url)
        } completionHandler: { success, error in
            if success {
                print("视频保存成功")
            }
        }
    }
}
```

### 4.3 iOS 14+ 有限相册访问

iOS 14 引入了"选择部分照片"的功能，用户可以只授权部分照片给 App。

```swift
func checkPhotoLibraryStatus() {
    let status = PHPhotoLibrary.authorizationStatus(for: .addOnly)
    switch status {
    case .notDetermined:
        PHPhotoLibrary.requestAuthorization(for: .addOnly) { newStatus in
            DispatchQueue.main.async {
                handleAuthorizationStatus(newStatus)
            }
        }
    case .restricted, .denied:
        print("相册权限被拒绝或受限")
    case .authorized:
        print("完全访问相册")
    case .limited:
        print("部分访问相册")
    default:
        break
    }
}
```

> 💡 提示：如果用户选择了"选择照片…"，状态会返回 `.limited`。你可以通过 `PHAsset.fetchAssets` 获取用户授权的那部分照片。

## 5. 相册权限管理

### 5.1 权限级别详解

| 权限级别 | 状态值 | 说明 |
|----------|--------|------|
| 未决定 | `.notDetermined` | 用户还没做过选择 |
| 已授权 | `.authorized` | 完全访问相册 |
| 有限授权 | `.limited` | 仅访问选中的照片（iOS 14+） |
| 已拒绝 | `.denied` | 用户明确拒绝 |
| 受限 | `.restricted` | 家长控制等限制 |

### 5.2 请求权限的完整流程

```swift
func requestPhotoPermission() async -> Bool {
    let status = PHPhotoLibrary.authorizationStatus(for: .readWrite)

    switch status {
    case .notDetermined:
        let newStatus = await PHPhotoLibrary.requestAuthorization(for: .readWrite)
        return newStatus == .authorized || newStatus == .limited

    case .authorized, .limited:
        return true

    case .denied, .restricted:
        return false

    default:
        return false
    }
}
```

### 5.3 两种访问级别

| 访问级别 | 说明 | 适用场景 |
|----------|------|----------|
| `.addOnly` | 只能保存，不能读取 | 只需要保存图片到相册 |
| `.readWrite` | 可读可写 | 需要浏览/读取相册内容 |

> 💡 建议：遵循**最小权限原则**，如果只需要保存图片，就只请求 `.addOnly`，这样用户看到的权限弹窗描述会更友好，审核也更容易通过。

### 5.4 引导用户开启权限

当用户拒绝权限后，应该引导用户去设置中手动开启：

```swift
struct PermissionDeniedView: View {
    var body: some View {
        VStack(spacing: 20) {
            Image(systemName: "photo.on.rectangle.angled")
                .font(.system(size: 60))
                .foregroundColor(.gray)

            Text("需要相册权限才能使用此功能")
                .font(.headline)

            Text("请在设置中开启相册访问权限")
                .font(.subheadline)
                .foregroundColor(.gray)

            Button("前往设置") {
                if let url = URL(string: UIApplication.openSettingsURLString) {
                    UIApplication.shared.open(url)
                }
            }
            .buttonStyle(.borderedProminent)
        }
    }
}
```

### 5.5 Info.plist 权限描述

在 `Info.plist` 中必须添加对应的权限描述，否则 App 会崩溃：

| Key | 说明 | 示例描述 |
|-----|------|----------|
| `NSPhotoLibraryUsageDescription` | 读取相册权限 | "需要访问您的相册以选择头像" |
| `NSPhotoLibraryAddUsageDescription` | 保存到相册权限 | "需要保存编辑后的图片到相册" |
| `NSCameraUsageDescription` | 相机权限 | "需要使用相机进行拍照" |

> ⚠️ 重要：这些描述**必须具体说明用途**，写"需要权限"这种模糊描述会被 App Store 审核拒绝！

## 6. 实战示例：头像选择与裁剪功能

### 6.1 功能需求

- 从相册选择或拍照获取图片
- 支持手势缩放和拖动
- 圆形裁剪框
- 保存裁剪后的头像

### 6.2 完整实现

```swift
import SwiftUI
import PhotosUI

struct AvatarPickerView: View {
    @State private var selectedItem: PhotosPickerItem?
    @State private var originalImage: UIImage?
    @State private var croppedImage: UIImage?
    @State private var showPicker = false
    @State private var scale: CGFloat = 1.0
    @State private var offset: CGSize = .zero
    @State private var lastScale: CGFloat = 1.0
    @State private var lastOffset: CGSize = .zero

    var body: some View {
        NavigationStack {
            VStack(spacing: 30) {
                if let croppedImage {
                    Image(uiImage: croppedImage)
                        .resizable()
                        .scaledToFit()
                        .frame(width: 150, height: 150)
                        .clipShape(Circle())
                        .overlay(Circle().stroke(Color.blue, lineWidth: 3))
                } else {
                    Circle()
                        .fill(Color.gray.opacity(0.2))
                        .frame(width: 150, height: 150)
                        .overlay(
                            Image(systemName: "person.fill")
                                .font(.system(size: 50))
                                .foregroundColor(.gray)
                        )
                }

                if let originalImage {
                    AvatarCropView(
                        image: originalImage,
                        scale: $scale,
                        offset: $offset,
                        lastScale: $lastScale,
                        lastOffset: $lastOffset
                    )
                    .frame(width: 300, height: 300)
                    .clipShape(Circle())
                    .overlay(Circle().stroke(Color.white, lineWidth: 2))
                    .shadow(radius: 5)

                    Button("确认裁剪") {
                        cropImage()
                    }
                    .buttonStyle(.borderedProminent)
                }

                Spacer()

                HStack(spacing: 20) {
                    PhotosPicker("从相册选择", selection: $selectedItem, matching: .images)
                        .buttonStyle(.bordered)

                    Button("拍照") {
                        showPicker = true
                    }
                    .buttonStyle(.bordered)
                }
            }
            .padding()
            .navigationTitle("设置头像")
            .onChange(of: selectedItem) { _, newItem in
                Task {
                    if let data = try? await newItem?.loadTransferable(type: Data.self),
                       let uiImage = UIImage(data: data) {
                        originalImage = uiImage
                        resetCropState()
                    }
                }
            }
            .sheet(isPresented: $showPicker) {
                CameraView(image: $originalImage)
            }
        }
    }

    private func resetCropState() {
        scale = 1.0
        offset = .zero
        lastScale = 1.0
        lastOffset = .zero
    }

    private func cropImage() {
        guard let originalImage else { return }

        let cropSize = CGSize(width: 300, height: 300)
        let renderer = UIGraphicsImageRenderer(size: cropSize)

        let cropped = renderer.image { context in
            let cgContext = context.cgContext
            cgContext.concatenate(CGAffineTransform(
                scaleX: 1.0 / scale,
                y: 1.0 / scale
            ))
            cgContext.translateBy(
                x: -offset.width * scale,
                y: -offset.height * scale
            )

            let imageSize = originalImage.size
            let drawRect = CGRect(
                x: (cropSize.width - imageSize.width * scale) / 2,
                y: (cropSize.height - imageSize.height * scale) / 2,
                width: imageSize.width * scale,
                height: imageSize.height * scale
            )
            originalImage.draw(in: drawRect)
        }

        croppedImage = cropped
    }
}

struct AvatarCropView: View {
    let image: UIImage
    @Binding var scale: CGFloat
    @Binding var offset: CGSize
    @Binding var lastScale: CGFloat
    @Binding var lastOffset: CGSize

    var body: some View {
        Image(uiImage: image)
            .resizable()
            .scaledToFit()
            .scaleEffect(scale)
            .offset(offset)
            .gesture(
                MagnifyGesture()
                    .onChanged { value in
                        scale = lastScale * value.magnification
                    }
                    .onEnded { _ in
                        lastScale = scale
                        scale = min(max(scale, 1), 5)
                        lastScale = scale
                    }
            )
            .simultaneousGesture(
                DragGesture()
                    .onChanged { value in
                        offset = CGSize(
                            width: lastOffset.width + value.translation.width,
                            height: lastOffset.height + value.translation.height
                        )
                    }
                    .onEnded { _ in
                        lastOffset = offset
                    }
            )
    }
}
```

### 6.3 实现要点总结

| 步骤 | 说明 |
|------|------|
| 1. 选择/拍照 | PhotosPicker 或 UIImagePickerController |
| 2. 手势操作 | MagnifyGesture 缩放 + DragGesture 拖动 |
| 3. 圆形遮罩 | `.clipShape(Circle())` |
| 4. 裁剪渲染 | UIGraphicsImageRenderer 重新绘制 |
| 5. 结果展示 | 裁剪后显示为圆形头像 |

> 💡 提示：实际项目中，建议使用更成熟的裁剪库（如 [Mantis](https://github.com/guoyingtao/Mantis) 或 [TOCropViewController](https://github.com/TimOliver/TOCropViewController)），它们处理了更多边界情况。

## 7. 隐私与审核

### 7.1 权限描述最佳实践

App Store 审核对隐私权限描述要求非常严格，以下是需要遵守的规则：

| 规则 | 说明 | ✅ 正确示例 | ❌ 错误示例 |
|------|------|------------|------------|
| 具体说明用途 | 必须告诉用户为什么需要这个权限 | "需要访问相册以选择头像" | "需要访问相册" |
| 与功能对应 | 描述必须和实际使用场景一致 | "需要使用相机扫描二维码" | "需要使用相机" |
| 不可夸大 | 不能申请超过实际需要的权限 | 只读场景请求 `.addOnly` | 所有场景都请求 `.readWrite` |

### 7.2 最小化访问原则

```swift
// ✅ 只需要保存图片 —— 请求 addOnly
PHPhotoLibrary.requestAuthorization(for: .addOnly)

// ✅ 需要读取相册内容 —— 请求 readWrite
PHPhotoLibrary.requestAuthorization(for: .readWrite)

// ❌ 不管什么场景都请求 readWrite
PHPhotoLibrary.requestAuthorization(for: .readWrite)
```

### 7.3 PhotosPicker vs 直接访问相册

| 对比项 | PhotosPicker | PHAsset 直接访问 |
|--------|-------------|-----------------|
| 需要权限 | ❌ 不需要 | ✅ 需要 |
| 用户感知 | ✅ 用户主动选择 | ⚠️ 后台静默读取 |
| 审核友好度 | ✅ 高 | ⚠️ 需要充分理由 |
| 功能灵活度 | ⚠️ 有限 | ✅ 完全控制 |

> 💡 审核建议：**优先使用 PhotosPicker**。只有当你需要自动读取相册内容（比如相册管理 App、照片备份 App）时，才使用 PHAsset 直接访问。

### 7.4 常见审核被拒原因

| 被拒原因 | 解决方案 |
|----------|----------|
| 权限描述太模糊 | 写明具体用途，如"用于更换头像" |
| 请求了不需要的权限 | 只请求实际需要的权限级别 |
| 后台访问相册无说明 | 在描述中说明为什么需要后台访问 |
| 相机权限描述与功能不符 | 确保描述和实际使用场景一致 |
| 没有处理"拒绝"状态 | 提供友好的降级体验，不要弹窗强制要求 |

### 7.5 完整的权限处理模板

```swift
enum PhotoPermissionStatus {
    case granted
    case limited
    case denied
    case notDetermined
}

func checkAndRequestPermission(for level: PHAccessLevel = .readWrite) async -> PhotoPermissionStatus {
    let currentStatus = PHPhotoLibrary.authorizationStatus(for: level)

    switch currentStatus {
    case .authorized:
        return .granted
    case .limited:
        return .limited
    case .denied, .restricted:
        return .denied
    case .notDetermined:
        let newStatus = await PHPhotoLibrary.requestAuthorization(for: level)
        switch newStatus {
        case .authorized:
            return .granted
        case .limited:
            return .limited
        default:
            return .denied
        }
    default:
        return .denied
    }
}
```

## 小结

本章我们学习了 iOS 开发中相册与相机相关的完整知识体系：

| 知识点 | 核心内容 |
|--------|----------|
| **PhotosPicker** | 系统相册选择器，无需权限，支持单选/多选/过滤 |
| **UIImagePickerController** | 简单快捷的相机调用方式，适合快速集成 |
| **AVFoundation** | 自定义相机，灵活但代码量大，适合需要自定义 UI 的场景 |
| **图片处理** | 缩放用 UIGraphicsImageRenderer，裁剪用 CGImage.cropping，滤镜用 CoreImage |
| **保存到相册** | PHPhotoLibrary + PHAssetChangeRequest，注意请求 addOnly 权限 |
| **权限管理** | 五种状态、两种级别、引导用户去设置开启 |
| **隐私审核** | 权限描述要具体、最小化访问、优先使用 PhotosPicker |

> 💡 核心原则：**能用 PhotosPicker 就不用 PHAsset，能用 addOnly 就不用 readWrite，权限描述必须具体说明用途。** 这三条原则能帮你避免 90% 的审核问题。
