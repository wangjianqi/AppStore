# 国内第三方登录集成

> 🎯 **本章目标**：掌握国内主流第三方登录（微信、支付宝）的完整集成流程，建立多登录方式统一管理架构，了解国内登录的特殊合规要求，规避 App Store 审核中与登录相关的常见被拒原因。

---

## 1. 国内登录生态概述

### 1.1 国内主流登录方式一览

国内移动应用的登录生态与海外市场差异显著。在国内，用户对第三方社交登录的依赖程度远高于海外，尤其是微信登录几乎成为"标配"。

| 登录方式 | 典型使用场景 | 用户接受度 | 集成复杂度 |
|----------|------------|-----------|-----------|
| 微信登录 | 几乎所有面向 C 端的 App | ⭐⭐⭐⭐⭐ | 中高 |
| 支付宝登录 | 金融、电商、生活服务类 App | ⭐⭐⭐⭐ | 中 |
| 手机号验证码 | 所有 App（合规必备） | ⭐⭐⭐⭐⭐ | 中 |
| 邮箱密码 | 工具类、跨境 App | ⭐⭐ | 低 |
| Sign in with Apple | 上架 App Store 必须提供 | ⭐⭐⭐ | 低 |
| QQ 登录 | 游戏、社交类 App | ⭐⭐⭐ | 中 |
| 抖音登录 | 短视频、内容类 App | ⭐⭐ | 中 |

### 1.2 各平台市场份额与用户习惯

国内移动互联网用户约 10 亿，其中微信月活超过 13 亿，支付宝月活超过 8 亿。这意味着：

- **微信登录覆盖率最高**：几乎所有国内用户都有微信账号，一次授权即可登录，转化率远高于手机号验证码
- **支付宝登录在特定领域强势**：金融、电商场景下用户信任度高，且与支付环节无缝衔接
- **手机号验证码是合规底线**：工信部要求 App 必须支持手机号注册/登录，且需完成实名认证

> 💡 **提示**：国内用户普遍反感填写长表单，"一键登录"的转化率比邮箱注册高出 3-5 倍。优先提供微信登录入口可以显著降低注册流失率。

### 1.3 为什么国内 App 几乎必须支持微信登录

1. **用户基数决定**：微信是国内最大的超级 App，渗透率接近 100%
2. **转化率优势**：微信一键授权 vs 手机号验证码，转化率差距可达 40% 以上
3. **社交裂变需要**：微信分享、小程序跳转都依赖微信生态，登录是前提
4. **用户预期**：国内用户打开新 App 的第一反应是找微信登录按钮

### 1.4 国内登录 vs 海外登录的差异

| 对比维度 | 国内登录 | 海外登录 |
|---------|---------|---------|
| 主流方式 | 微信、支付宝、手机号 | Google、Facebook、Apple |
| 实名要求 | 必须实名（手机号绑定） | 大多无需实名 |
| 合规框架 | 个人信息保护法、网络安全法 | GDPR、CCPA |
| 审核要求 | 工信部备案 + App Store 双重审核 | 主要看 App Store 审核 |
| 登录回调 | Universal Link + URL Scheme 并用 | Universal Link 为主 |
| SDK 来源 | 国内厂商 SDK，需翻墙下载 | CocoaPods 直接集成 |
| 隐私政策 | 必须在首次启动时弹窗同意 | App Store Connect 填写即可 |
| 账号体系 | OpenID + UnionID 体系 | OAuth 2.0 标准流程 |

> ⚠️ **警告**：国内第三方登录 SDK 通常体积较大（微信 SDK 约 5MB+），且部分 SDK 仍依赖 UIKit 而非 SwiftUI，需要在桥接层做适配。

## 2. 微信登录集成

### 2.1 微信开放平台注册与 App 创建

集成微信登录的第一步是在微信开放平台完成注册和配置：

1. 访问 [微信开放平台](https://open.weixin.qq.com/)，使用企业资质注册账号
2. 完成开发者资质认证（需营业执照，认证费 300 元/年）
3. 在"管理中心"→"移动应用"中创建应用
4. 填写应用信息：Bundle ID、应用名称、图标、简介
5. 提交审核，通常 1-3 个工作日通过
6. 审核通过后获取 **AppID** 和 **AppSecret**

> ⚠️ **警告**：微信开放平台要求使用企业资质，个人开发者无法申请。如果尚未注册公司，可以考虑使用手机号验证码登录作为替代方案。

### 2.2 Universal Link 配置

微信从 SDK 1.8.6 版本开始强制要求使用 Universal Link 方式回调，不再支持单纯的 URL Scheme 回调。

**服务端配置步骤：**

1. 在你的域名根目录创建 `.well-known/apple-app-site-association` 文件（无后缀名）
2. 文件内容示例：

```json
{
    "applinks": {
        "apps": [],
        "details": [
            {
                "appID": "TEAMID.com.example.myapp",
                "paths": [
                    "/wechat/callback/*"
                ]
            }
        ]
    }
}
```

3. 确保该文件通过 HTTPS 访问，且无重定向
4. 服务器返回的 Content-Type 为 `application/json`

**Xcode 配置步骤：**

1. 打开 Target → Signing & Capabilities
2. 点击 "+" 添加 "Associated Domains"
3. 添加条目：`applinks:yourdomain.com`
4. 在微信开放平台填写 Universal Link：`https://yourdomain.com/wechat/callback/`

> 💡 **提示**：Universal Link 的域名必须与微信开放平台填写的完全一致，包括是否包含 www 前缀。建议统一使用不带 www 的裸域名。

### 2.3 iOS 端集成 WXApi SDK

**方式一：CocoaPods 集成（推荐）**

```ruby
pod 'WXApi', '~> 2.0'
```

**方式二：手动集成**

从微信开放平台下载 SDK，将 `WXApi.framework` 拖入项目。

**初始化配置：**

```swift
import WXApi

final class WeChatSDKManager: NSObject, WXApiDelegate {
    static let shared = WeChatSDKManager()
    private let appId = "YOUR_WECHAT_APPID"
    private let universalLink = "https://yourdomain.com/wechat/callback/"

    func register() {
        WXApi.registerApp(appId, universalLink: universalLink)
    }

    func isInstalled() -> Bool {
        WXApi.isWXAppInstalled()
    }
}
```

在 App 启动时调用注册：

```swift
@main
struct MyApp: App {
    init() {
        WeChatSDKManager.shared.register()
    }

    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}
```

### 2.4 SwiftUI 中封装微信登录按钮

```swift
import SwiftUI
import WXApi

struct WeChatLoginButton: View {
    let onSuccess: (String) -> Void
    let onFailure: (Error) -> Void

    var body: some View {
        Button {
            performLogin()
        } label: {
            HStack(spacing: 8) {
                Image("wechat_icon")
                    .resizable()
                    .frame(width: 24, height: 24)
                Text("微信登录")
                    .font(.body.bold())
                    .foregroundStyle(.white)
            }
            .frame(maxWidth: .infinity)
            .padding(.vertical, 14)
            .background(Color(red: 0.07, green: 0.60, blue: 0.24))
            .clipShape(RoundedRectangle(cornerRadius: 10))
        }
    }

    private func performLogin() {
        guard WeChatSDKManager.shared.isInstalled() else {
            onFailure(WeChatError.notInstalled)
            return
        }

        let req = SendAuthReq()
        req.scope = "snsapi_userinfo"
        req.state = UUID().uuidString

        WXApi.send(req) { success in
            if !success {
                onFailure(WeChatError.sendFailed)
            }
        }
    }
}

    case sendFailed
    case authDenied
    case tokenExchangeFailed

        switch self {
        case .notInstalled: "未安装微信"
        case .sendFailed: "拉起微信失败"
        case .authDenied: "用户拒绝授权"
        case .tokenExchangeFailed: "Token 换取失败"
        }
    }
}
```

### 2.5 授权流程详解

微信登录的完整授权流程分为四个阶段：

```
┌──────────┐    ①拉起微信     ┌──────────┐
│  你的App  │ ──────────────→ │   微信    │
│          │                  │          │
│          │ ←────────────── │          │
│          │    ②用户授权      │          │
│          │                  └──────────┘
│          │
│          │    ③回调code     ┌──────────┐
│          │ ──────────────→ │ 你的服务器 │
│          │                  │          │
│          │ ←────────────── │          │
│          │    ④返回token    │          │
└──────────┘                  └──────────┘
```

**① 拉起微信**：调用 `WXApi.send(SendAuthReq)` 拉起微信客户端

**② 用户授权**：用户在微信中确认授权，微信通过 Universal Link 回调你的 App，携带 `code`

**③ 回调获取 code → 换取 access_token**：这一步必须在你的服务器端完成，不要在客户端直接调用微信接口

```swift
struct WeChatAuthResponse {
    let code: String
    let state: String
    let lang: String
    let country: String
}

struct WeChatTokenResponse: Decodable {
    let accessToken: String
    let expiresIn: Int
    let refreshToken: String
    let openid: String
    let scope: String
    let unionid: String

    enum CodingKeys: String, CodingKey {
        case accessToken = "access_token"
        case expiresIn = "expires_in"
        case refreshToken = "refresh_token"
        case openid
        case scope
        case unionid
    }
}
```

**④ 服务器换取 token**：你的服务器使用 code 向微信服务器换取 access_token 和 openid

> ⚠️ **警告**：AppSecret 绝对不能存储在客户端代码中。换取 access_token 的操作必须在服务器端完成，否则 AppSecret 泄露会导致严重安全问题。

### 2.6 处理微信回调

微信回调通过 Universal Link 传递到 App，需要在 SceneDelegate 或 AppDelegate 中处理：

**iOS 16+ SwiftUI 方式（推荐）：**

```swift
@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
                .onOpenURL { url in
                    WeChatSDKManager.shared.handleOpenURL(url)
                }
        }
    }
}
```

**WXApiDelegate 回调处理：**

```swift
final class WeChatSDKManager: NSObject, WXApiDelegate {
    var loginCompletion: ((Result<WeChatAuthResponse, Error>) -> Void)?

    func onReq(_ req: BaseReq) {}

    func onResp(_ resp: BaseResp) {
        guard resp.isKind(of: SendAuthResp.self) else { return }
        let authResp = resp as! SendAuthResp

        switch resp.errCode {
        case 0:
            let response = WeChatAuthResponse(
                code: authResp.code ?? "",
                state: authResp.state ?? "",
                lang: authResp.lang ?? "",
                country: authResp.country ?? ""
            )
            loginCompletion?(.success(response))
        case -2:
            loginCompletion?(.failure(WeChatError.authDenied))
        default:
            loginCompletion?(.failure(WeChatError.sendFailed))
        }
    }

    func handleOpenURL(_ url: URL) {
        WXApi.handleOpen(url, delegate: self)
    }
}
```

### 2.7 Token 存储与刷新

```swift
import Security

final class WeChatTokenStore {
    static let shared = WeChatTokenStore()
    private let service = "com.myapp.wechat-token"

    func save(token: WeChatTokenResponse) {
        let data = try? JSONEncoder().encode(token)
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: "wechat_access_token"
        ]
        SecItemDelete(query as CFDictionary)
        var addQuery = query
        addQuery[kSecValueData as String] = data
        SecItemAdd(addQuery as CFDictionary, nil)
    }

    func load() -> WeChatTokenResponse? {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: "wechat_access_token",
            kSecReturnData as String: true
        ]
        var result: AnyObject?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        guard status == errSecSuccess, let data = result as? Data else { return nil }
        return try? JSONDecoder().decode(WeChatTokenResponse.self, from: data)
    }

    func clear() {
        let query: [String: Any] = [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service
        ]
        SecItemDelete(query as CFDictionary)
    }
}
```

> 💡 **提示**：微信 access_token 有效期为 2 小时，refresh_token 有效期为 30 天。建议在每次启动 App 时检查 token 是否过期，过期则使用 refresh_token 刷新。

### 2.8 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 拉不起微信 | 未安装微信或 Bundle ID 不匹配 | 检查 `isWXAppInstalled()` 和开放平台配置 |
| 回调不走 Universal Link | 服务器 AASA 文件配置错误 | 用 Apple 验证工具检查 AASA 文件 |
| 回调后 code 为空 | scope 参数错误 | 确保使用 `snsapi_userinfo` |
| 服务器换 token 失败 | AppSecret 错误或 code 已过期 | code 只能使用一次，5 分钟内有效 |
| Universal Link 偶尔失效 | iOS 缓存 AASA 文件 | 卸载重装 App 触发重新拉取 |
| 微信白屏 | SDK 版本与微信版本不兼容 | 更新到最新 SDK 版本 |

## 3. 支付宝登录集成

### 3.1 支付宝开放平台注册与配置

1. 访问 [支付宝开放平台](https://open.alipay.com/)，使用企业支付宝账号登录
2. 创建应用，选择"移动应用"类型
3. 在"功能列表"中添加"获取会员信息"能力
4. 配置应用信息：Bundle ID、应用名称、图标
5. 设置授权回调地址（与微信不同，支付宝使用 URL Scheme 回调）
6. 提交审核，获取 **AppID**

> 💡 **提示**：支付宝开放平台的审核速度通常比微信快，一般 1 个工作日内完成。但需要企业支付宝账号，个人账号无法申请。

### 3.2 SDK 集成步骤

**CocoaPods 集成：**

```ruby
pod 'AlipaySDK-iOS', '~> 15.8'
```

**手动集成：**

从支付宝开放平台下载 SDK，将 `AlipaySDK.framework` 和 `AlipaySDK.bundle` 拖入项目。

**URL Scheme 注册：**

在 `Info.plist` 中注册 URL Scheme：

```xml
<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleURLName</key>
        <string>com.example.myapp.alipay</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>alipay1234567890</string>
        </array>
    </dict>
</array>
```

**初始化：**

```swift
import AlipaySDK

final class AlipaySDKManager {
    static let shared = AlipaySDKManager()

    func register() {
        AlipaySDK.defaultService()
    }
}
```

### 3.3 授权流程与微信的异同

| 对比项 | 微信登录 | 支付宝登录 |
|--------|---------|-----------|
| 回调方式 | Universal Link | URL Scheme |
| 授权参数 | scope + state | authInfo 字符串 |
| 授权结果 | 返回 code | 返回 authCode |
| Token 换取 | 服务器端用 code 换 | 服务器端用 authCode 换 |
| 用户信息 | 需额外请求 | 换 token 时可同时获取 |
| 安装检测 | `WXApi.isWXAppInstalled()` | `AlipaySDK.defaultService().isAlipayInstalled()` |
| 审核周期 | 1-3 工作日 | 1 工作日内 |

**支付宝授权流程：**

```swift
final class AlipaySDKManager: NSObject {
    static let shared = AlipaySDKManager()
    var loginCompletion: ((Result<String, Error>) -> Void)?

    func performLogin() {
        guard let sdk = AlipaySDK.defaultService() else { return }
        guard sdk.isAlipayInstalled() else {
            loginCompletion?(.failure(AlipayError.notInstalled))
            return
        }

        let authInfo = buildAuthInfo()
        sdk.auth_V2(withInfo: authInfo, fromScheme: "alipay1234567890") { result in
            self.handleAuthResult(result)
        }
    }

    private func buildAuthInfo() -> String {
        let appId = "2021001234567890"
        let pid = "2088001234567890"
        let targetId = UUID().uuidString
        return "apiname=com.alipay.account.auth&app_id=\(appId)&pid=\(pid)&target_id=\(targetId)&auth_type=AUTHACCOUNT&scope=kuaijie"
    }

    private func handleAuthResult(_ result: [AnyHashable: Any]?) {
        guard let result = result,
              let resultStatus = result["resultStatus"] as? String,
              resultStatus == "9000",
              let resultString = result["result"] as? String else {
            loginCompletion?(.failure(AlipayError.authFailed))
            return
        }

        let authCode = extractAuthCode(from: resultString)
        loginCompletion?(.success(authCode))
    }

    private func extractAuthCode(from result: String) -> String {
        let pairs = result.split(separator: "&")
        for pair in pairs {
            let kv = pair.split(separator: "=", maxSplits: 1)
            if kv.count == 2 && kv[0] == "auth_code" {
                return String(kv[1])
            }
        }
        return ""
    }
}
```

## 4. 多登录方式统一架构

### 4.1 设计统一的 AuthService 协议

当 App 支持多种登录方式时，需要一个统一的协议层来抽象登录行为，避免业务代码与具体 SDK 耦合：

```swift
import AuthenticationServices

enum AuthProvider: String, CaseIterable {
    case apple = "apple"
    case wechat = "wechat"
    case alipay = "alipay"
    case phone = "phone"

    var displayName: String {
        switch self {
        case .apple: "通过 Apple 登录"
        case .wechat: "微信登录"
        case .alipay: "支付宝登录"
        case .phone: "手机号登录"
        }
    }

    var iconName: String {
        switch self {
        case .apple: "apple.logo"
        case .wechat: "wechat_icon"
        case .alipay: "alipay_icon"
        case .phone: "phone.fill"
        }
    }
}

struct AuthUser {
    let provider: AuthProvider
    let providerUserId: String
    let accessToken: String
    let refreshToken: String?
    let nickname: String?
    let avatarURL: URL?
    let unionId: String?
}

enum AuthError: LocalizedError {
    case userCancelled
    case networkError
    case invalidCredential
    case tokenExpired
    case bindingFailed

    var errorDescription: String? {
        switch self {
        case .userCancelled: "用户取消登录"
        case .networkError: "网络错误，请稍后重试"
        case .invalidCredential: "登录凭据无效"
        case .tokenExpired: "登录已过期，请重新登录"
        case .bindingFailed: "账号绑定失败"
        }
    }
}

protocol AuthServiceProtocol {
    var provider: AuthProvider { get }
    var isAvailable: Bool { get async }
    func login() async throws -> AuthUser
    func logout() async throws
    func refreshToken() async throws -> AuthUser
}
```

### 4.2 各登录方式实现协议

```swift
final class AppleAuthService: AuthServiceProtocol {
    let provider: AuthProvider = .apple
    var isAvailable: Bool { true }

    func login() async throws -> AuthUser {
        try await withCheckedThrowingContinuation { continuation in
            let provider = ASAuthorizationAppleIDProvider()
            let request = provider.createRequest()
            request.requestedScopes = [.fullName, .email]

            let controller = ASAuthorizationController(authorizationRequests: [request])
            let delegate = AppleAuthDelegate(continuation: continuation)
            controller.delegate = delegate
            controller.performRequests()

            ObjC.associate(delegate, to: controller)
        }
    }

    func logout() async throws {}

    func refreshToken() async throws -> AuthUser {
        throw AuthError.tokenExpired
    }

private final class AppleAuthDelegate: NSObject, ASAuthorizationControllerDelegate {
    let continuation: CheckedContinuation<AuthUser, Error>

    init(continuation: CheckedContinuation<AuthUser, Error>) {
        self.continuation = continuation
    }

    func authorizationController(controller: ASAuthorizationController, didCompleteWithAuthorization authorization: ASAuthorization) {
        guard let credential = authorization.credential as? ASAuthorizationAppleIDCredential else {
            continuation.resume(throwing: AuthError.invalidCredential)
            return
        }

        let user = AuthUser(
            provider: .apple,
            providerUserId: credential.user,
            accessToken: credential.identityToken.flatMap { String(data: $0, encoding: .utf8) } ?? "",
            refreshToken: nil,
            nickname: [credential.fullName?.givenName, credential.fullName?.familyName].compactMap { $0 }.joined(),
            avatarURL: nil,
            unionId: nil
        )
        continuation.resume(returning: user)
    }

    func authorizationController(controller: ASAuthorizationController, didCompleteWithError error: Error) {
        if let error = error as? ASAuthorizationError, error.code == .canceled {
            continuation.resume(throwing: AuthError.userCancelled)
        } else {
            continuation.resume(throwing: AuthError.invalidCredential)
        }
    }
}
```

```swift
final class WeChatAuthService: AuthServiceProtocol {
    let provider: AuthProvider = .wechat
    var isAvailable: Bool { WeChatSDKManager.shared.isInstalled() }

    func login() async throws -> AuthUser {
        guard isAvailable else {
            throw WeChatError.notInstalled
        }

        return try await withCheckedThrowingContinuation { continuation in
            WeChatSDKManager.shared.loginCompletion = { result in
                switch result {
                case .success(let response):
                    Task {
                        do {
                            let user = try await self.exchangeToken(code: response.code)
                            continuation.resume(returning: user)
                        } catch {
                            continuation.resume(throwing: error)
                        }
                    }
                case .failure(let error):
                    continuation.resume(throwing: error)
                }
            }

            let req = SendAuthReq()
            req.scope = "snsapi_userinfo"
            req.state = UUID().uuidString
            WXApi.send(req) { success in
                if !success {
                    continuation.resume(throwing: WeChatError.sendFailed)
                }
            }
        }
    }

    private func exchangeToken(code: String) async throws -> AuthUser {
        let url = URL(string: "https://api.yourserver.com/auth/wechat/token")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        let body = ["code": code]
        request.httpBody = try JSONEncoder().encode(body)

        let (data, _) = try await URLSession.shared.data(for: request)
        let tokenResp = try JSONDecoder().decode(WeChatTokenResponse.self, from: data)

        return AuthUser(
            provider: .wechat,
            providerUserId: tokenResp.openid,
            accessToken: tokenResp.accessToken,
            refreshToken: tokenResp.refreshToken,
            nickname: nil,
            avatarURL: nil,
            unionId: tokenResp.unionid
        )
    }

    func logout() async throws {
        WeChatTokenStore.shared.clear()
    }

    func refreshToken() async throws -> AuthUser {
        guard let token = WeChatTokenStore.shared.load() else {
            throw AuthError.tokenExpired
        }
        let url = URL(string: "https://api.yourserver.com/auth/wechat/refresh")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        let body = ["refresh_token": token.refreshToken]
        request.httpBody = try JSONEncoder().encode(body)

        let (data, _) = try await URLSession.shared.data(for: request)
        let newToken = try JSONDecoder().decode(WeChatTokenResponse.self, from: data)
        WeChatTokenStore.shared.save(token: newToken)

        return AuthUser(
            provider: .wechat,
            providerUserId: newToken.openid,
            accessToken: newToken.accessToken,
            refreshToken: newToken.refreshToken,
            nickname: nil,
            avatarURL: nil,
            unionId: newToken.unionid
        )
    }
}
```

### 4.3 登录状态管理

```swift
import Observation

@Observable
final class AuthManager {
    var currentUser: AuthUser?
    var isAuthenticated: Bool { currentUser != nil }
    var isLoading = false
    var error: AuthError?

    private let services: [AuthProvider: AuthServiceProtocol]

    init() {
        services = [
            .apple: AppleAuthService(),
            .wechat: WeChatAuthService(),
            .alipay: AlipayAuthService()
        ]
    }

    func login(with provider: AuthProvider) async {
        guard let service = services[provider] else {
            error = .invalidCredential
            return
        }

        guard await service.isAvailable else {
            error = .invalidCredential
            return
        }

        isLoading = true
        error = nil
        defer { isLoading = false }

        do {
            let user = try await service.login()
            currentUser = user
            saveUserLocally(user)
        } catch let error as AuthError {
            self.error = error
        } catch {
            self.error = .networkError
        }
    }

    func logout() async {
        guard let user = currentUser else { return }
        if let service = services[user.provider] {
            try? await service.logout()
        }
        currentUser = nil
        clearLocalUser()
    }

    private func saveUserLocally(_ user: AuthUser) {
        if let data = try? JSONEncoder().encode(user) {
            UserDefaults.standard.set(data, forKey: "current_auth_user")
        }
    }

    private func clearLocalUser() {
        UserDefaults.standard.removeObject(forKey: "current_auth_user")
    }

    func restoreSession() {
        guard let data = UserDefaults.standard.data(forKey: "current_auth_user"),
              let user = try? JSONDecoder().decode(AuthUser.self, from: data) else {
            return
        }
        currentUser = user
    }
}
```

### 4.5 绑定与解绑逻辑

用户可能需要将多个第三方账号绑定到同一个内部账号上，例如先用手机号注册，再绑定微信以便快捷登录：

```swift
@Observable
final class AccountBindingManager {
    var bindings: [AuthProvider: String] = [:]
    var isLoading = false

    func bind(provider: AuthProvider, userId: String) async throws {
        isLoading = true
        defer { isLoading = false }

        let url = URL(string: "https://api.yourserver.com/user/bind")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        let body: [String: String] = [
            "provider": provider.rawValue,
            "provider_user_id": userId
        ]
        request.httpBody = try JSONEncoder().encode(body)

        let (_, response) = try await URLSession.shared.data(for: request)
        guard let httpResponse = response as? HTTPURLResponse, httpResponse.statusCode == 200 else {
            throw AuthError.bindingFailed
        }
        bindings[provider] = userId
    }

    func unbind(provider: AuthProvider) async throws {
        isLoading = true
        defer { isLoading = false }

        let url = URL(string: "https://api.yourserver.com/user/unbind")!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        let body: [String: String] = ["provider": provider.rawValue]
        request.httpBody = try JSONEncoder().encode(body)

        let (_, response) = try await URLSession.shared.data(for: request)
        guard let httpResponse = response as? HTTPURLResponse, httpResponse.statusCode == 200 else {
            throw AuthError.bindingFailed
        }
        bindings.removeValue(forKey: provider)
    }
}
```

> ⚠️ **警告**：解绑操作必须保留至少一种登录方式。如果用户只绑定了微信一个第三方登录，不允许直接解绑，否则用户将无法登录。建议在 UI 层判断：当绑定数量 ≤ 1 时，隐藏解绑按钮。

## 5. 合规与审核要点

### 5.1 Apple 审核规则：有第三方登录必须同时提供 Sign in with Apple

Apple 审核指南 4.8 节明确规定：如果你的 App 支持任何第三方社交登录服务，就必须同时提供 Sign in with Apple。

| 情况 | 是否需要 Sign in with Apple |
|------|---------------------------|
| 只支持微信登录 | ✅ 必须 |
| 微信 + 支付宝 | ✅ 必须 |
| 只有手机号验证码 | ❌ 不需要 |
| 只有 Sign in with Apple | ❌ 不需要（已满足） |
| 微信 + 手机号 | ✅ 必须（微信属于第三方社交登录） |
| 企业内部分发 | ❌ 不需要 |

**合规实现要点：**

1. Sign in with Apple 按钮必须与其他第三方登录按钮同等醒目
2. 不能将 Apple 登录按钮放在折叠区域或二级页面
3. Apple 登录的体验不能劣于其他登录方式（如不能要求额外填表）

### 5.2 国内个人信息保护法对登录的要求

《个人信息保护法》（2021 年 11 月施行）对登录流程有直接影响：

| 要求 | 具体内容 | 对登录的影响 |
|------|---------|------------|
| 最小必要原则 | 只收集实现功能所必需的个人信息 | 登录时只请求必要的 scope |
| 知情同意 | 收集前必须告知并取得同意 | 首次登录前弹出隐私政策 |
| 单独同意 | 敏感个人信息需单独同意 | 人脸、位置等需额外授权弹窗 |
| 撤回同意权 | 用户可随时撤回授权 | 提供注销账号和解绑功能 |
| 数据本地化 | 关键信息基础设施运营者在境内存储 | 登录数据优先存储在国内服务器 |

### 5.3 用户数据收集最小化原则

在登录流程中，应遵循"用多少收多少"的原则：

```swift
enum AuthScope: String {
    case base = "snsapi_base"
    case userInfo = "snsapi_userinfo"
}

func determineScope(for purpose: LoginPurpose) -> AuthScope {
    switch purpose {
    case .quickAccess:
        return .base
    case .fullFeatures:
        return .userInfo
    }
}

enum LoginPurpose {
    case quickAccess
    case fullFeatures
}
```

> 💡 **提示**：如果 App 的核心功能不需要用户头像和昵称，使用 `snsapi_base` 只获取 openid 即可，无需请求用户信息。这既符合最小必要原则，也能提升授权转化率（用户看到请求权限少，更愿意授权）。

### 5.4 隐私政策中登录相关条款

隐私政策必须包含以下与登录相关的内容：

1. **收集的个人信息类型**：明确列出登录时收集的信息（openid、昵称、头像等）
2. **第三方 SDK 信息**：列出微信 SDK、支付宝 SDK 的名称、用途和隐私政策链接
3. **数据传输说明**：说明登录数据如何传输到你的服务器
4. **账号注销机制**：提供明确的账号注销入口和流程
5. **数据保留期限**：说明登录数据的保留时长和删除规则

> ⚠️ **警告**：国内工信部在 2021 年起要求所有 App 必须在隐私政策中列明第三方 SDK 信息。未列明的 SDK 可能导致 App 被通报下架。

### 5.5 常见被拒原因与应对

| 被拒原因 | 具体表现 | 应对方案 |
|---------|---------|---------|
| 缺少 Sign in with Apple | 有微信登录但无 Apple 登录 | 添加 SignInWithAppleButton |
| 强制登录 | 不登录无法使用任何功能 | 允许游客模式浏览部分内容 |
| 隐私政策缺失 | 首次启动无隐私政策弹窗 | 添加隐私政策同意弹窗 |
| 登录按钮不醒目 | Apple 登录被折叠或字号更小 | 所有登录方式同等展示 |
| 账号注销不可用 | 无法注销账号或流程复杂 | 提供一键注销功能 |
| 过度收集信息 | 登录时请求不必要的权限 | 只请求核心 scope |
| SDK 未声明 | 隐私政策中未列出第三方 SDK | 补充 SDK 信息和隐私链接 |
| Universal Link 失效 | 微信回调无法正常工作 | 检查 AASA 文件和域名配置 |

> 💡 **提示**：提交审核前，建议用测试账号走一遍完整的登录→使用→注销流程，确保所有路径畅通。审核人员会实际测试登录功能，如果微信/支付宝登录因沙盒环境无法使用，需在审核备注中说明并提供测试账号。
