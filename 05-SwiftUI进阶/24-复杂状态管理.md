# 24-更复杂的状态管理

> 🎯 **本章目标**：掌握 SwiftUI 中 @StateObject、@ObservedObject、@EnvironmentObject 三种状态管理方式，了解 iOS 17+ 的 @Observable 宏，学会根据场景选择合适的状态管理方案，并遵循状态管理最佳实践。

---

## @StateObject 与 @ObservedObject

在之前的章节中，我们用 `@State` 管理简单值类型（String、Int、Bool 等）。但当状态变得复杂——比如一个包含多个属性的「用户资料」对象，或者一个「购物车」对象——就需要用**引用类型（class）**来管理，这时候就要用到 `@StateObject` 和 `@ObservedObject`。

💡 **通俗理解**：`@State` 是"小本子"，记简单的东西；`@StateObject` / `@ObservedObject` 是"档案柜"，管理复杂的对象数据。

### ObservableObject 协议

要让一个 class 能被 SwiftUI 监听变化，它必须遵循 `ObservableObject` 协议。

#### class 遵循 ObservableObject

```swift
class UserProfile: ObservableObject {
    @Published var username: String = ""
    @Published var avatar: String = "😀"
    @Published var loginCount: Int = 0
}
```

- `ObservableObject` 是 SwiftUI 提供的协议，告诉 SwiftUI："这个对象的变化，你需要关注"
- `@Published` 是属性包装器，标记的属性一变化，就会通知 SwiftUI 刷新界面

#### @Published 属性

`@Published` 就像给属性装了一个"广播器"——属性值一改变，所有监听这个对象的视图都会自动刷新。

```swift
class ShoppingCart: ObservableObject {
    @Published var items: [String] = []
    @Published var totalPrice: Double = 0

    func addItem(_ name: String, price: Double) {
        items.append(name)
        totalPrice += price
    }

    func clearCart() {
        items.removeAll()
        totalPrice = 0
    }
}
```

⚠️ **警告**：只有标记了 `@Published` 的属性变化才会触发视图刷新！忘记加 `@Published`，视图就不会更新。

#### 示例

```swift
import SwiftUI

class Counter: ObservableObject {
    @Published var count: Int = 0

    func increment() { count += 1 }
    func decrement() { count -= 1 }
    func reset() { count = 0 }
}

struct ObservableObjectView: View {
    @StateObject private var counter = Counter()

    var body: some View {
        VStack(spacing: 20) {
            Text("\(counter.count)")
                .font(.system(size: 72, weight: .bold, design: .rounded))
                .foregroundStyle(counter.count > 0 ? .green : counter.count < 0 ? .red : .primary)

            HStack(spacing: 20) {
                Button(action: counter.decrement) {
                    Image(systemName: "minus.circle.fill")
                        .font(.title)
                }
                Button(action: counter.reset) {
                    Image(systemName: "arrow.counterclockwise.circle.fill")
                        .font(.title)
                }
                Button(action: counter.increment) {
                    Image(systemName: "plus.circle.fill")
                        .font(.title)
                }
            }

            Text("计数器由 ObservableObject 管理")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
        .navigationTitle("ObservableObject 示例")
    }
}
```

### @StateObject 生命周期

`@StateObject` 是视图**自己创建并拥有**的对象。

#### @StateObject 由视图创建和拥有

```swift
struct CartView: View {
    @StateObject private var cart = ShoppingCart()

    var body: some View {
        List {
            ForEach(cart.items, id: \.self) { item in
                Text(item)
            }
        }
    }
}
```

💡 **通俗理解**：`@StateObject` 就像你"自己买的手机"——你负责购买、你负责持有、你负责管理。

#### 视图重建时不会重新创建

这是 `@StateObject` 最关键的特点：当视图因为父组件状态变化而**重新渲染**时，`@StateObject` 标记的对象**不会被重新创建**，之前的数据会保留。

```swift
struct ParentView: View {
    @State var colorIndex = 0
    let colors: [Color] = [.blue, .green, .orange]

    var body: some View {
        VStack {
            ChildView()

            Button("切换颜色") {
                colorIndex = (colorIndex + 1) % colors.count
            }
            .buttonStyle(.borderedProminent)
        }
        .background(colors[colorIndex].opacity(0.1))
    }
}

struct ChildView: View {
    @StateObject private var counter = Counter()

    var body: some View {
        VStack {
            Text("计数：\(counter.count)")
                .font(.title)
            Button("增加") { counter.increment() }
        }
    }
}
```

在上面的例子中，点击"切换颜色"会让 `ParentView` 重新渲染，`ChildView` 也会重新渲染，但 `counter` 的值**不会重置**——这就是 `@StateObject` 的威力。

#### 使用场景

| 场景 | 是否适合 @StateObject |
|------|:---:|
| 视图自己创建的数据对象 | ✅ |
| 视图需要拥有并管理生命周期的对象 | ✅ |
| 对象只在当前视图中使用 | ✅ |
| 对象从外部传入 | ❌ 用 @ObservedObject |

### @ObservedObject 使用场景

`@ObservedObject` 用于接收**从外部传入**的已创建对象，视图不负责创建。

#### 从外部传入的已创建对象

```swift
struct CartItemRow: View {
    @ObservedObject var cart: ShoppingCart
    let itemName: String

    var body: some View {
        HStack {
            Text(itemName)
            Spacer()
            Button("加入购物车") {
                cart.addItem(itemName, price: 9.9)
            }
        }
    }
}
```

💡 **通俗理解**：`@ObservedObject` 就像你"借朋友的手机"——你只负责使用，不负责购买和管理。

#### 视图不负责创建

⚠️ **关键区别**：`@ObservedObject` 不会帮你创建对象！它只负责"监听"一个已经存在的对象。

```swift
struct OrderView: View {
    @ObservedObject var cart: ShoppingCart

    var body: some View {
        VStack {
            Text("商品数：\(cart.items.count)")
            Text("总价：¥\(String(format: "%.2f", cart.totalPrice))")
        }
    }
}

struct ShopView: View {
    @StateObject private var cart = ShoppingCart()

    var body: some View {
        VStack {
            CartItemRow(cart: cart, itemName: "苹果")
            CartItemRow(cart: cart, itemName: "香蕉")
            OrderView(cart: cart)
        }
    }
}
```

在上面的例子中：
- `ShopView` 用 `@StateObject` 创建并拥有 `cart`
- `CartItemRow` 和 `OrderView` 用 `@ObservedObject` 接收并监听同一个 `cart`

#### 使用场景

| 场景 | 是否适合 @ObservedObject |
|------|:---:|
| 从父视图传入的共享对象 | ✅ |
| 子视图只需要监听，不需要创建 | ✅ |
| 视图自己创建对象 | ❌ 用 @StateObject |

---

### 两者区别与选择

#### 详细对比表

| 对比项 | @StateObject | @ObservedObject |
|--------|:---:|:---:|
| **谁创建对象** | 当前视图自己创建 | 外部传入（别人创建） |
| **谁拥有对象** | 当前视图拥有 | 不拥有，只是引用 |
| **视图重建时** | 对象不会被重新创建 ✅ | 对象不会被重新创建 ✅ |
| **视图重新初始化时** | 对象不会被重新创建 ✅ | ⚠️ 可能丢失引用 |
| **初始化方式** | `@StateObject var obj = MyClass()` | `@ObservedObject var obj: MyClass` |
| **内存管理** | 视图销毁时对象释放 | 依赖外部持有者 |
| **适用角色** | 对象的"主人" | 对象的"使用者" |

#### 何时用 @StateObject

```swift
struct TodoListView: View {
    @StateObject private var viewModel = TodoViewModel()

    var body: some View {
        List(viewModel.todos) { todo in
            Text(todo.title)
        }
        .task {
            await viewModel.loadTodos()
        }
    }
}
```

**判断标准**：如果这个视图是对象的**第一个使用者**，并且需要**负责创建**它，就用 `@StateObject`。

#### 何时用 @ObservedObject

```swift
struct TodoRowView: View {
    @ObservedObject var todo: TodoItem

    var body: some View {
        HStack {
            Image(systemName: todo.isDone ? "checkmark.circle.fill" : "circle")
            Text(todo.title)
        }
    }
}
```

**判断标准**：如果对象是**别人创建好传给你的**，你只是使用它，就用 `@ObservedObject`。

⚠️ **警告**：不要在 `@ObservedObject` 中创建新对象！下面的写法是**错误**的：

```swift
struct BadView: View {
    @ObservedObject var cart = ShoppingCart()
}
```

这会导致视图重新渲染时对象被重新创建，数据丢失！应该用 `@StateObject` 代替。

#### 完整示例

```swift
import SwiftUI

class TaskStore: ObservableObject {
    @Published var tasks: [String] = []

    func addTask(_ name: String) {
        tasks.append(name)
    }

    func removeTask(at offsets: IndexSet) {
        tasks.remove(atOffsets: offsets)
    }
}

struct TaskManagerView: View {
    @StateObject private var store = TaskStore()
    @State private var newTask = ""

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                HStack {
                    TextField("新任务...", text: $newTask)
                        .textFieldStyle(.roundedBorder)
                    Button("添加") {
                        guard !newTask.isEmpty else { return }
                        store.addTask(newTask)
                        newTask = ""
                    }
                    .buttonStyle(.borderedProminent)
                }
                .padding(.horizontal)

                TaskListView(store: store)
            }
            .navigationTitle("任务管理")
        }
    }
}

struct TaskListView: View {
    @ObservedObject var store: TaskStore

    var body: some View {
        if store.tasks.isEmpty {
            ContentUnavailableView("暂无任务", systemImage: "checkmark.circle", description: Text("添加你的第一个任务"))
        } else {
            List {
                ForEach(store.tasks, id: \.self) { task in
                    HStack {
                        Image(systemName: "circle.fill")
                            .font(.caption)
                            .foregroundStyle(.blue)
                        Text(task)
                    }
                }
                .onDelete { offsets in
                    store.removeTask(at: offsets)
                }
            }
        }
    }
}
```

💡 **提示**：`TaskManagerView` 用 `@StateObject` 创建 `store`，`TaskListView` 用 `@ObservedObject` 接收 `store`——这就是最经典的搭配模式！

## @EnvironmentObject 全局状态

当多个视图需要共享同一个对象时，一层一层地传递很麻烦。`@EnvironmentObject` 可以把对象注入到环境中，任何子视图都能直接获取，不需要手动传递。

💡 **通俗理解**：`@EnvironmentObject` 就像"中央空调"——你不需要在每个房间装空调，只要接通了管道，每个房间都能用。而 `@ObservedObject` 就像"电风扇"——你得从上一个房间搬过来才能用。

### 创建环境对象

#### 定义 ObservableObject 类

首先，定义一个遵循 `ObservableObject` 的类：

```swift
class AppSettings: ObservableObject {
    @Published var isDarkMode: Bool = false
    @Published var username: String = "用户"
    @Published var fontSize: Double = 16
}
```

#### 在根视图注入

在 App 的最顶层视图注入环境对象：

```swift
@main
struct MyApp: App {
    @StateObject private var settings = AppSettings()

    var body: some Scene {
        WindowGroup {
            ContentView()
                .environmentObject(settings)
        }
    }
}
```

💡 **提示**：在根视图用 `@StateObject` 创建对象，再用 `.environmentObject()` 注入，这是最标准的做法。

---

### 注入环境

#### .environmentObject()

`.environmentObject()` 把对象放入 SwiftUI 的环境中，所有子视图都能访问：

```swift
ContentView()
    .environmentObject(settings)
```

⚠️ **警告**：必须在视图使用 `@EnvironmentObject` **之前**注入！如果忘记注入，App 运行时会直接崩溃，报错：`No ObservableObject of type … found.`

#### 在子视图中使用 @EnvironmentObject

子视图不需要通过参数接收，直接声明即可：

```swift
struct ProfileView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        VStack {
            Text("你好，\(settings.username)！")
            Toggle("深色模式", isOn: $settings.isDarkMode)
        }
    }
}
```

💡 **提示**：注意 `@EnvironmentObject` 声明时**不需要默认值**（不像 `@StateObject` 要写 `= AppSettings()`），因为它会自动从环境中获取。

### 订阅环境对象

#### @EnvironmentObject var store: Store

声明了 `@EnvironmentObject` 后，当对象的 `@Published` 属性变化时，视图会自动刷新：

```swift
struct SettingsDetailView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        Form {
            Section("用户信息") {
                TextField("用户名", text: $settings.username)
            }
            Section("显示设置") {
                Toggle("深色模式", isOn: $settings.isDarkMode)
                VStack(alignment: .leading) {
                    Text("字体大小：\(Int(settings.fontSize))")
                    Slider(value: $settings.fontSize, in: 12...24, step: 1)
                }
            }
        }
        .navigationTitle("详细设置")
    }
}
```

#### 自动刷新

当 `settings.isDarkMode` 被切换时，所有使用了 `@EnvironmentObject var settings: AppSettings` 的视图都会自动刷新——不需要手动通知！

#### 完整示例

```swift
import SwiftUI

class AppSettings: ObservableObject {
    @Published var isDarkMode: Bool = false
    @Published var username: String = "用户"
    @Published var fontSize: Double = 16
    @Published var favoriteColor: Color = .blue
}

struct EnvironmentObjectRootView: View {
    @StateObject private var settings = AppSettings()

    var body: some View {
        NavigationStack {
            VStack(spacing: 20) {
                NavigationLink("前往设置页") {
                    SettingsPageView()
                }
                .buttonStyle(.borderedProminent)

                NavigationLink("前往个人页") {
                    ProfilePageView()
                }
                .buttonStyle(.bordered)

                VStack(spacing: 8) {
                    Text("当前状态预览")
                        .font(.headline)
                    Text("用户名：\(settings.username)")
                    Text("深色模式：\(settings.isDarkMode ? "开" : "关")")
                    Text("字体大小：\(Int(settings.fontSize))")
                }
                .font(.subheadline)
                .foregroundStyle(.secondary)
                .padding()
                .background(RoundedRectangle(cornerRadius: 12).fill(.gray.opacity(0.1)))
            }
            .navigationTitle("主页")
        }
        .environmentObject(settings)
    }
}

struct SettingsPageView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        Form {
            Section("用户信息") {
                TextField("用户名", text: $settings.username)
            }
            Section("显示") {
                Toggle("深色模式", isOn: $settings.isDarkMode)
                VStack(alignment: .leading) {
                    Text("字体大小：\(Int(settings.fontSize))")
                    Slider(value: $settings.fontSize, in: 12...24, step: 1)
                }
            }
            Section("颜色") {
                ColorPicker("喜欢的颜色", selection: $settings.favoriteColor)
                RoundedRectangle(cornerRadius: 8)
                    .fill(settings.favoriteColor)
                    .frame(height: 40)
            }
        }
        .navigationTitle("设置")
    }
}

struct ProfilePageView: View {
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        VStack(spacing: 20) {
            Circle()
                .fill(settings.favoriteColor.gradient)
                .frame(width: 80, height: 80)
                .overlay {
                    Text(String(settings.username.prefix(1)))
                        .font(.title.bold())
                        .foregroundStyle(.white)
                }

            Text(settings.username)
                .font(.title2.bold())

            HStack {
                Label(settings.isDarkMode ? "深色模式" : "浅色模式", systemImage: settings.isDarkMode ? "moon.fill" : "sun.max.fill")
                Spacer()
                Text("字体 \(Int(settings.fontSize))pt")
            }
            .font(.subheadline)
            .foregroundStyle(.secondary)
            .padding()
            .background(RoundedRectangle(cornerRadius: 12).fill(.gray.opacity(0.1)))

            Spacer()
        }
        .padding()
        .navigationTitle("个人页")
    }
}
```

💡 **提示**：在 `EnvironmentObjectRootView` 中注入了 `.environmentObject(settings)`，`SettingsPageView` 和 `ProfilePageView` 都能直接用 `@EnvironmentObject` 获取，不需要手动传参！

## @Observable 宏（iOS 17+）

iOS 17 引入了 `@Observable` 宏，这是 Apple 推出的**全新状态管理方式**，比 `ObservableObject` 更简洁、更高效。

### 基本使用

#### @Observable class

用 `@Observable` 宏标记一个类，就**不需要**再遵循 `ObservableObject`，也**不需要**给每个属性加 `@Published`：

```swift
import Observation

@Observable
class UserProfile {
    var username: String = ""
    var avatar: String = "😀"
    var loginCount: Int = 0
}
```

💡 **通俗理解**：`@Observable` 就像"全自动洗衣机"——你只需要把衣服扔进去（定义属性），它自动帮你搞定一切（自动追踪变化）。而 `ObservableObject` + `@Published` 就像"半自动洗衣机"——每个属性你都得手动按按钮（加 `@Published`）。

#### 不需要 ObservableObject 和 @Published

对比一下新旧写法：

```swift
class OldProfile: ObservableObject {
    @Published var username: String = ""
    @Published var avatar: String = "😀"
    @Published var loginCount: Int = 0
}

@Observable
class NewProfile {
    var username: String = ""
    var avatar: String = "😀"
    var loginCount: Int = 0
}
```

`@Observable` 自动追踪所有存储属性的变化，不需要手动标记！

#### 示例

```swift
import SwiftUI
import Observation

@Observable
class ThemeStore {
    var accentColor: Color = .blue
    var isDarkMode: Bool = false
    var cornerRadius: Double = 12
}

struct ObservableMacroView: View {
    @State private var store = ThemeStore()

    var body: some View {
        NavigationStack {
            Form {
                Section("主题色") {
                    ColorPicker("强调色", selection: $store.accentColor)
                    HStack {
                        ForEach([Color.blue, .green, .orange, .pink, .purple], id: \.self) { color in
                            Button {
                                store.accentColor = color
                            } label: {
                                Circle()
                                    .fill(color)
                                    .frame(width: 36, height: 36)
                                    .overlay {
                                        if store.accentColor == color {
                                            Image(systemName: "checkmark")
                                                .foregroundStyle(.white)
                                                .bold()
                                        }
                                    }
                            }
                        }
                    }
                }

                Section("显示") {
                    Toggle("深色模式", isOn: $store.isDarkMode)
                    VStack(alignment: .leading) {
                        Text("圆角大小：\(Int(store.cornerRadius))")
                        Slider(value: $store.cornerRadius, in: 0...30, step: 1)
                    }
                }

                Section("预览") {
                    Button("示例按钮") {}
                        .buttonStyle(.borderedProminent)
                        .tint(store.accentColor)

                    RoundedRectangle(cornerRadius: store.cornerRadius)
                        .fill(store.accentColor.gradient)
                        .frame(height: 60)
                        .overlay {
                            Text("预览卡片")
                                .foregroundStyle(.white)
                                .bold()
                        }
                }
            }
            .navigationTitle("@Observable 示例")
        }
        .preferredColorScheme(store.isDarkMode ? .dark : .light)
    }
}
```

💡 **提示**：使用 `@Observable` 时，属性包装器从 `@StateObject` 变成了 `@State`！因为 `@Observable` 类本身就能被 SwiftUI 追踪，不需要特殊的属性包装器。

---

### 与 ObservableObject 对比

#### 详细对比表

| 对比项 | ObservableObject + @Published | @Observable |
|--------|:---:|:---:|
| **最低系统版本** | iOS 13+ | iOS 17+ |
| **需要遵循协议** | `ObservableObject` | 无需协议 |
| **属性标记** | 每个属性加 `@Published` | 无需标记，自动追踪 |
| **视图中的属性包装器** | `@StateObject` / `@ObservedObject` | `@State` |
| **环境注入** | `@EnvironmentObject` | `@Environment` |
| **性能** | 所有 @Published 变化都触发刷新 | 只刷新实际使用该属性的视图 |
| **代码量** | 较多 | 较少 |
| **非 @Published 属性** | 变化不触发刷新 | 变化也会触发刷新（如果视图使用了它） |

#### 代码量对比

```swift
class CartOld: ObservableObject {
    @Published var items: [String] = []
    @Published var totalPrice: Double = 0
    @Published var discount: Double = 0
    @Published var couponCode: String = ""
}

@Observable
class CartNew {
    var items: [String] = []
    var totalPrice: Double = 0
    var discount: Double = 0
    var couponCode: String = ""
}
```

少了 4 个 `@Published`，少了 `: ObservableObject`——代码更简洁！

#### 性能优势

`@Observable` 有一个重要优势：**精确刷新**。

```swift
@Observable
class UserStore {
    var name: String = ""
    var age: Int = 0
    var avatar: String = ""
}

struct UserNameView: View {
    @State var store = UserStore()

    var body: some View {
        Text(store.name)
    }
}
```

使用 `@Observable` 时，只有 `store.name` 变化时 `UserNameView` 才会刷新；而 `ObservableObject` 中任何 `@Published` 属性变化都会刷新。

### 迁移指南

#### 从 ObservableObject 迁移到 @Observable

迁移只需三步：

**第一步：修改类定义**

```swift
class Cart: ObservableObject {
    @Published var items: [String] = []
    @Published var totalPrice: Double = 0
}

@Observable
class Cart {
    var items: [String] = []
    var totalPrice: Double = 0
}
```

**第二步：修改属性包装器**

| 旧写法 | 新写法 |
|--------|--------|
| `@StateObject var cart = Cart()` | `@State var cart = Cart()` |
| `@ObservedObject var cart: Cart` | `@Bindable var cart: Cart` 或直接用 `cart` |
| `@EnvironmentObject var cart: Cart` | `@Environment var cart: Cart` |

**第三步：修改环境注入**

| 旧写法 | 新写法 |
|--------|--------|
| `.environmentObject(cart)` | `.environment(cart)` |

#### 属性包装器变化

```swift
struct OldWayView: View {
    @StateObject private var cart = Cart()
    @EnvironmentObject var settings: AppSettings

    var body: some View {
        CartDetailView(cart: cart)
            .environmentObject(settings)
    }
}

struct NewWayView: View {
    @State private var cart = Cart()
    @Environment var settings: AppSettings

    var body: some View {
        CartDetailView(cart: cart)
            .environment(settings)
    }
}
```

#### 示例：完整迁移

```swift
import SwiftUI
import Observation

@Observable
class TodoStore {
    var todos: [String] = []
    var filterText: String = ""

    var filteredTodos: [String] {
        if filterText.isEmpty {
            return todos
        }
        return todos.filter { $0.localizedCaseInsensitiveContains(filterText) }
    }

    func addTodo(_ name: String) {
        guard !name.isEmpty else { return }
        todos.append(name)
    }

    func removeTodo(at offsets: IndexSet) {
        todos.remove(atOffsets: offsets)
    }
}

struct ObservableMigrationView: View {
    @State private var store = TodoStore()
    @State private var newTodo = ""

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                HStack {
                    TextField("新任务...", text: $newTodo)
                        .textFieldStyle(.roundedBorder)
                    Button("添加") {
                        store.addTodo(newTodo)
                        newTodo = ""
                    }
                    .buttonStyle(.borderedProminent)
                }
                .padding(.horizontal)

                TextField("搜索过滤...", text: Binding(
                    get: { store.filterText },
                    set: { store.filterText = $0 }
                ))
                .textFieldStyle(.roundedBorder)
                .padding(.horizontal)

                if store.filteredTodos.isEmpty {
                    ContentUnavailableView("暂无任务", systemImage: "checkmark.circle", description: Text("添加你的第一个任务"))
                } else {
                    List {
                        ForEach(store.filteredTodos, id: \.self) { todo in
                            HStack {
                                Image(systemName: "circle.fill")
                                    .font(.caption)
                                    .foregroundStyle(.blue)
                                Text(todo)
                            }
                        }
                        .onDelete { offsets in
                            store.removeTodo(at: offsets)
                        }
                    }
                }
            }
            .navigationTitle("待办事项")
        }
    }
}
```

⚠️ **警告**：`@Observable` 要求 iOS 17+。如果你的 App 需要支持 iOS 16 及以下，暂时不能使用 `@Observable`，继续使用 `ObservableObject`。

💡 **提示**：如果你需要给 `@Observable` 对象的属性创建 `$` 绑定（如 TextField 的 `text:` 参数），需要使用 `@Bindable` 属性包装器：

```swift
struct BindableExampleView: View {
    @Bindable var store: TodoStore

    var body: some View {
        TextField("过滤", text: $store.filterText)
    }
}
```

## 状态管理最佳实践

### 状态提升

当多个兄弟视图需要共享同一个状态时，应该把状态**提升到它们的共同父视图**中。

💡 **通俗理解**：就像两个部门需要共享一份文件，最好的做法是把文件放在"公共文件柜"（父视图）里，而不是在两个部门之间来回传。

#### 将状态提升到共同父视图

```swift
struct BadExample: View {
    @State private var selectedTab = 0

    var body: some View {
        TabView(selection: $selectedTab) {
            TabViewA(count: ???)
            TabViewB(count: ???)
        }
    }
}
```

如果 `TabViewA` 和 `TabViewB` 需要共享一个 `count`，应该把 `count` 提升到父视图：

#### 示例

```swift
import SwiftUI

struct StateHoistingView: View {
    @State private var sharedCount = 0

    var body: some View {
        VStack(spacing: 20) {
            Text("共享计数：\(sharedCount)")
                .font(.title.bold())

            HStack(spacing: 20) {
                CounterPanelA(count: $sharedCount)
                CounterPanelB(count: $sharedCount)
            }
        }
        .padding()
        .navigationTitle("状态提升示例")
    }
}

struct CounterPanelA: View {
    @Binding var count: Int

    var body: some View {
        VStack(spacing: 12) {
            Text("面板 A")
                .font(.headline)
            Text("\(count)")
                .font(.system(size: 40, weight: .bold, design: .rounded))
            Button("A 增加") { count += 1 }
                .buttonStyle(.borderedProminent)
                .tint(.blue)
        }
        .padding()
        .background(RoundedRectangle(cornerRadius: 12).fill(.blue.opacity(0.1)))
    }
}

struct CounterPanelB: View {
    @Binding var count: Int

    var body: some View {
        VStack(spacing: 12) {
            Text("面板 B")
                .font(.headline)
            Text("\(count)")
                .font(.system(size: 40, weight: .bold, design: .rounded))
            Button("B 减少") { count -= 1 }
                .buttonStyle(.borderedProminent)
                .tint(.orange)
        }
        .padding()
        .background(RoundedRectangle(cornerRadius: 12).fill(.orange.opacity(0.1)))
    }
}
```

💡 **提示**：通过 `@Binding` 把 `sharedCount` 的引用传递给子视图，两个面板操作的是同一个数据源。

### 单一数据源

**同一个数据只应该存在于一个地方**，避免多个状态表示同一数据。

#### 避免多个状态表示同一数据

```swift
struct BadDesign: View {
    @State private var price: Double = 100
    @State private var discountPrice: Double = 80
    @State private var discountText: String = "8折"

    var body: some View {
        VStack {
            Text("原价：\(price)")
            Text("折后：\(discountPrice)")
            Text(discountText)
        }
    }
}
```

问题：修改 `price` 时，必须同时手动更新 `discountPrice` 和 `discountText`，很容易遗漏导致数据不一致。

#### 示例

```swift
import SwiftUI

struct SingleSourceView: View {
    @State private var price: Double = 100
    @State private var discount: Double = 0.8

    var discountPrice: Double {
        price * discount
    }

    var discountText: String {
        "\(Int(discount * 100))折"
    }

    var body: some View {
        Form {
            Section("价格设置") {
                VStack(alignment: .leading) {
                    Text("原价：¥\(Int(price))")
                    Slider(value: $price, in: 10...500, step: 10)
                }
                VStack(alignment: .leading) {
                    Text("折扣：\(discountText)")
                    Slider(value: $discount, in: 0.1...1.0, step: 0.05)
                }
            }

            Section("计算结果") {
                HStack {
                    Text("原价")
                    Spacer()
                    Text("¥\(Int(price))")
                        .foregroundStyle(.secondary)
                }
                HStack {
                    Text("折扣")
                    Spacer()
                    Text(discountText)
                        .foregroundStyle(.secondary)
                }
                HStack {
                    Text("折后价")
                    Spacer()
                    Text("¥\(Int(discountPrice))")
                        .foregroundStyle(.red)
                        .bold()
                }
            }
        }
        .navigationTitle("单一数据源示例")
    }
}
```

💡 **提示**：`discountPrice` 和 `discountText` 是计算属性，由 `price` 和 `discount` 自动推导，不需要单独存储。修改 `price` 或 `discount` 时，它们会自动更新，永远不会不一致。

### 避免状态冗余

**可以通过计算得出的数据，不要用状态存储**。

#### 可以计算得出的不要存储

```swift
struct BadCart: View {
    @State private var items: [(name: String, price: Double)] = []
    @State private var totalPrice: Double = 0
    @State private var itemCount: Int = 0

    func addItem(_ name: String, price: Double) {
        items.append((name, price))
        totalPrice += price
        itemCount += 1
    }
}
```

问题：`totalPrice` 和 `itemCount` 可以从 `items` 计算得出，不需要单独存储。手动维护容易出错。

#### 示例

```swift
import SwiftUI

struct CartItem: Identifiable {
    let id = UUID()
    let name: String
    let price: Double
}

struct NoRedundancyView: View {
    @State private var items: [CartItem] = []
    @State private var newItemName = ""
    @State private var newItemPrice = ""

    var totalPrice: Double {
        items.reduce(0) { $0 + $1.price }
    }

    var itemCount: Int {
        items.count
    }

    var body: some View {
        NavigationStack {
            VStack(spacing: 16) {
                VStack(spacing: 8) {
                    HStack {
                        TextField("商品名", text: $newItemName)
                        TextField("价格", text: $newItemPrice)
                            .keyboardType(.decimalPad)
                            .frame(width: 80)
                    }
                    Button("添加商品") {
                        addItem()
                    }
                    .buttonStyle(.borderedProminent)
                }
                .padding(.horizontal)

                if items.isEmpty {
                    ContentUnavailableView("购物车为空", systemImage: "cart", description: Text("添加一些商品吧"))
                } else {
                    List {
                        ForEach(items) { item in
                            HStack {
                                Text(item.name)
                                Spacer()
                                Text("¥\(String(format: "%.2", item.price))")
                                    .foregroundStyle(.secondary)
                            }
                        }
                        .onDelete { offsets in
                            items.remove(atOffsets: offsets)
                        }

                        Section("汇总") {
                            HStack {
                                Text("商品数")
                                Spacer()
                                Text("\(itemCount) 件")
                                    .foregroundStyle(.secondary)
                            }
                            HStack {
                                Text("总价")
                                Spacer()
                                Text("¥\(String(format: "%.2", totalPrice))")
                                    .foregroundStyle(.red)
                                    .bold()
                            }
                        }
                    }
                }
            }
            .navigationTitle("购物车")
        }
    }

    func addItem() {
        guard !newItemName.isEmpty, let price = Double(newItemPrice), price > 0 else { return }
        items.append(CartItem(name: newItemName, price: price))
        newItemName = ""
        newItemPrice = ""
    }
}
```

💡 **提示**：`totalPrice` 和 `itemCount` 是计算属性，由 `items` 自动推导。删除一个商品时，总价和数量自动更新，不需要手动维护。

## 小结

本章我们学习了 SwiftUI 中更复杂的状态管理方式：

| 方式 | 用途 | 适用场景 |
|------|------|---------|
| **@StateObject** | 视图创建并拥有对象 | 对象的第一个使用者 |
| **@ObservedObject** | 接收外部传入的对象 | 对象的使用者（非创建者） |
| **@EnvironmentObject** | 从环境中获取共享对象 | 多个视图共享同一对象 |
| **@Observable** | iOS 17+ 的新方式 | 新项目首选（更简洁高效） |

🔑 **核心记忆点**：
1. `@StateObject` = 自己创建的对象；`@ObservedObject` = 别人传来的对象
2. `@EnvironmentObject` 适合跨多层视图共享数据，避免层层传递
3. `@Observable`（iOS 17+）比 `ObservableObject` 更简洁，新项目优先使用
4. 状态提升：共享状态放在共同父视图中
5. 单一数据源：同一数据只存一份，其他通过计算得出
6. 避免冗余：能计算出的不要存储
