# 15-初识 Swift：你的第一行代码

> 🎯 **本章目标**：了解 Swift 语言的基本面貌，学会使用 Playground 编写和运行代码，掌握变量、常量、基本数据类型以及字符串插值的用法。

## Swift 是什么？

Swift 是 Apple（苹果公司）在 **2014 年**推出的一门全新编程语言，专门用来开发 iOS、iPadOS、macOS、watchOS 和 tvOS 上的 App。

你可以把它理解为：**给 Apple 设备写程序的"官方语言"**。

### Swift 的三大特点

| 特点 | 说明 | 通俗理解 |
|------|------|----------|
| **安全** | Swift 在编译时就能发现很多常见错误，比如使用了空值、数组越界等 | 就像一辆自带安全气囊和防撞系统的车，出错时会及时提醒你 |
| **快速** | Swift 的运行速度接近 C/C++，远超很多脚本语言 | 同样的任务，Swift 跑得更快，App 用起来更流畅 |
| **现代** | 语法简洁优雅，支持很多新语言才有的特性 | 写起来像在说"人话"，不像老语言那么啰嗦 |

💡 **提示**：在 Apple 生态中，Swift 已经完全取代了之前的 Objective-C 语言，是现在开发 Apple App 的首选。

## Playgrounds 介绍与使用

Playground 是 Xcode 内置的一个**交互式编程环境**，你可以把它理解为一个"代码沙盒"——写一行代码，立刻就能看到结果，非常适合学习和实验。

### 创建 Playground

1. 打开 **Xcode**（如果还没安装，请先从 Mac App Store 免费下载）
2. 点击菜单栏：**File → New → Playground…**
3. 在弹出的模板选择窗口中，选择 **Blank**（空白模板），点击 Next
4. 选择保存位置，给文件起个名字（比如 `MyFirstPlayground`），点击 Create

⚠️ **警告**：如果你看不到 Playground 选项，请确认 Xcode 版本是否为最新版。旧版 Xcode 的菜单位置可能略有不同。

### Playground 基本操作

打开 Playground 后，你会看到这样的界面：

```
┌──────────────────────────────────────────────┐
│  编辑区（写代码的地方）    │  结果区（看结果的地方）  │
│                            │                        │
│  var greeting = "Hello"    │  "Hello"               │
│  print(greeting)           │  Hello                 │
│                            │                        │
└──────────────────────────────────────────────┘
```

| 区域 | 作用 |
|------|------|
| **编辑区** | 你在这里编写 Swift 代码 |
| **结果区** | 每行代码的右侧会实时显示运行结果 |
| **调试区** | 底部区域，`print()` 的输出会显示在这里 |

**运行代码的方式**：
- Playground 默认**自动运行**，你修改代码后结果会自动更新
- 也可以手动点击左上角的 ▶️（运行按钮）来执行

### 实时预览

Playground 最大的魅力就是**实时执行**——你不需要像传统开发那样"编译→运行→看结果"，而是：

- 输入代码 → **立刻**看到结果
- 修改代码 → **立刻**看到变化
- 侧边栏会显示每一行的值

💡 **提示**：点击结果区中的"眼睛"图标 👁，可以展开查看更详细的结果，比如图片、视图等。

## 变量与常量

程序的核心就是**处理数据**。在 Swift 中，数据存放在"变量"和"常量"里，你可以把它们想象成**贴了标签的盒子**。

### let 声明常量

常量就像一个**上了锁的盒子**——一旦放进去东西，就不能再换了。

```swift
let pi = 3.14159
let appName = "我的App"
let maxUsers = 100

// ❌ 下面这行会报错！常量不能修改
// pi = 3.14
```

⚠️ **警告**：尝试修改常量的值会导致编译错误。Swift 这样设计是为了防止你意外修改不该变的数据。

### var 声明变量

变量就像一个**可以换东西的盒子**——随时可以放新东西进去。

```swift
var score = 0
score = 10      // ✅ 变量可以修改
score = 100     // ✅ 再次修改也没问题

var userName = "小明"
userName = "小红"  // ✅ 变量可以重新赋值
```

### let vs var：什么时候用哪个？

| 场景 | 用 let 还是 var | 原因 |
|------|----------------|------|
| 圆周率 π | `let` | 永远不会变 |
| App 名称 | `let` | 发布后不会变 |
| 用户分数 | `var` | 会随游戏进行而变化 |
| 当前页面编号 | `var` | 用户翻页时会变化 |

💡 **提示**：Swift 社区有一个好习惯——**优先使用 `let`**。只有确定需要修改的值才用 `var`。这样可以让代码更安全，也能帮助编译器优化性能。

### 类型推断

Swift 很聪明，它能根据你赋的值**自动推断**出数据类型，不需要你手动声明：

```swift
let age = 25              // Swift 自动推断为 Int（整数）
let price = 9.99          // Swift 自动推断为 Double（浮点数）
let name = "张三"          // Swift 自动推断为 String（字符串）
let isStudent = true      // Swift 自动推断为 Bool（布尔值）
```

当然，你也可以**显式声明类型**（在变量名后面加冒号和类型名）：

```swift
let age: Int = 25
let price: Double = 9.99
let name: String = "张三"
let isStudent: Bool = true
```

💡 **提示**：大多数情况下用类型推断就够了，代码更简洁。但在某些场景（比如初始值不够明确时），显式声明类型可以让代码更清晰。

## 基本数据类型

Swift 提供了几种最基础的数据类型，就像不同形状的盒子，用来装不同种类的数据：

| 类型 | 说明 | 示例 |
|------|------|------|
| `Int` | 整数 | `42`, `-7`, `0` |
| `Double` | 双精度浮点数（小数） | `3.14`, `-0.5` |
| `Float` | 单精度浮点数 | `3.14`（精度比 Double 低） |
| `String` | 字符串（文本） | `"Hello"`, `"你好"` |
| `Bool` | 布尔值（真/假） | `true`, `false` |

### Int 整数

整数就是**没有小数点的数**，包括正数、负数和零。

```swift
let population = 8000000       // 城市人口
let temperature = -5           // 零下5度
let zero = 0                   // 零

// 大整数可以用下划线分隔，方便阅读
let bigNumber = 1_000_000      // 等于 1000000
```

⚠️ **警告**：整数除以整数，结果还是整数（小数部分会被直接丢掉）：

```swift
let result = 7 / 2    // 结果是 3，不是 3.5！
```

### Double / Float 浮点数

浮点数就是**带小数点的数**，用来表示更精确的值。

```swift
let pi = 3.1415926535       // Double（默认），精度约15位小数
let weight: Float = 65.5    // Float，精度约6位小数
```

| 对比项 | Double | Float |
|--------|--------|-------|
| 精度 | 约 15 位小数 | 约 6 位小数 |
| 占用内存 | 8 字节 | 4 字节 |
| 默认类型 | ✅ Swift 默认 | 需要显式声明 |
| 使用场景 | 绝大多数情况 | 对性能/内存要求极高的场景 |

💡 **提示**：日常开发中，**默认用 `Double` 就好**，不需要纠结。只有在你明确知道需要节省内存时才考虑 `Float`。

### String 字符串

字符串就是**一段文本**，用双引号 `""` 包裹。

```swift
let greeting = "你好，世界！"
let emptyString = ""                    // 空字符串
let multiLine = """
    这是第一行
    这是第二行
    这是第三行
    """                                 // 多行字符串（三个双引号）

// 字符串拼接
let hello = "你好"
let name = "小明"
let message = hello + "，" + name + "！"   // "你好，小明！"

// 字符串长度
print(greeting.count)                    // 输出：6
```

⚠️ **警告**：Swift 的字符串是用**双引号** `""`，不是单引号 `''`。单引号在 Swift 中没有意义，会导致错误。

### Bool 布尔值

布尔值只有两个值：`true`（真）和 `false`（假），就像开关的"开"和"关"。

```swift
let isLoggedIn = true          // 用户已登录
let hasPermission = false      // 没有权限

// 布尔值常用于条件判断
if isLoggedIn {
    print("欢迎回来！")
} else {
    print("请先登录")
}
```

⚠️ **警告**：Swift 中的布尔值只能是 `true` 或 `false`，不能用 `0` 和 `1` 代替，这与某些其他语言（如 C、Python）不同。

## print 与字符串插值

### print() 函数

`print()` 是 Swift 中最基础的输出函数，它会把内容打印到调试区（控制台）。

```swift
print("Hello, World!")        // 输出：Hello, World!
print(42)                     // 输出：42
print(3.14)                   // 输出：3.14
```

### 字符串插值

字符串插值是 Swift 中非常方便的功能——**在字符串中嵌入变量或表达式的值**，语法是 `\(变量名)`。

```swift
let name = "小明"
let age = 18

print("我叫\(name)，今年\(age)岁。")
// 输出：我叫小明，今年18岁。

// 也可以嵌入表达式
let price = 29.9
let count = 3
print("总价：\(Double(count) * price) 元")
// 输出：总价：89.7 元
```

| 写法 | 说明 | 示例 |
|------|------|------|
| `"文字"` | 普通字符串 | `"Hello"` |
| `"\(变量)"` | 插入变量值 | `"\(name)"` → `"小明"` |
| `"\(表达式)"` | 插入表达式结果 | `"\(1 + 2)"` → `"3"` |

💡 **提示**：字符串插值比用 `+` 拼接字符串更方便、更易读，推荐优先使用。

## 用 AI 辅助理解代码

学习编程的过程中，遇到看不懂的代码是非常正常的。这时候可以让 AI 来帮你！

### 1. 让 AI 逐行解释代码

把不理解的代码发给 AI，加上这样的提示词：

```
请逐行解释以下 Swift 代码的含义：

var total = 0
for i in 1...10 {
    total += i
}
print("总和是\(total)")
```

### 2. 让 AI 对比概念

当你分不清两个概念时：

```
Swift 中 let 和 var 有什么区别？请用通俗的语言解释，并各举一个例子。
```

### 3. 让 AI 生成练习题

学完一个知识点后：

```
我刚学完 Swift 的变量和常量，请给我出 5 道练习题，从简单到困难，并附上答案。
```

### 4. 让 AI 帮你找错

代码报错看不懂时：

```
我的 Swift 代码报了这个错误：Cannot assign to value: 'age' is a 'let' constant
请帮我解释原因，并告诉我怎么修改。
```

💡 **提示**：AI 是你的"24 小时私人老师"，遇到任何问题都可以问。但也要注意自己先思考，不要完全依赖 AI，理解原理才是最重要的。
