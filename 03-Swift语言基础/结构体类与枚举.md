# 结构体、类与枚举

> 🎯 **本章目标**：掌握 struct、class、enum 三大自定义类型的定义与使用，理解值类型与引用类型的本质区别，为 SwiftUI 开发打下坚实基础。

---

## struct 结构体

结构体是 Swift 中最常用的自定义类型，用来把**多个相关的数据**打包在一起。你可以把它想象成一个表格模板——定义好有哪些字段，然后填入不同的数据。

### 定义与使用

```swift
struct Student {
    var name: String
    var age: Int
    var grade: String
}

let student1 = Student(name: "小明", age: 18, grade: "高三")
let student2 = Student(name: "小红", age: 17, grade: "高二")

print("\(student1.name)，\(student1.age)岁，\(student1.grade)")
```

💡 **提示**：SwiftUI 中几乎所有的视图都是 struct！比如 `struct ContentView: View`，所以 struct 是你用得最多的类型。

### 属性与方法

#### 存储属性

存储属性就是**存数据的变量/常量**，每个实例都有一份自己的值。

```swift
struct Rectangle {
    var width: Double
    var height: Double
}
```

#### 计算属性

计算属性**不存储数据**，而是根据其他属性计算出一个值。就像 Excel 里的公式单元格。

```swift
struct Rectangle {
    var width: Double
    var height: Double

    var area: Double {
        return width * height
    }

    var perimeter: Double {
        return 2 * (width + height)
    }
}

let rect = Rectangle(width: 5, height: 3)
print("面积：\(rect.area)")
print("周长：\(rect.perimeter)")
```

| 属性类型 | 关键特征 | 类比 |
|----------|----------|------|
| 存储属性 | 直接存值，占用内存 | 表格里的数据单元格 |
| 计算属性 | 每次访问时计算，不占额外内存 | Excel 里的公式单元格 |

💡 **提示**：计算属性用 `get` 和 `set` 可以实现可读可写：

```swift
struct Circle {
    var radius: Double

    var diameter: Double {
        get {
            return radius * 2
        }
        set {
            radius = newValue / 2
        }
    }
}

var c = Circle(radius: 5)
print(c.diameter)
c.diameter = 20
print(c.radius)
```

#### 方法

方法就是**写在类型里面的函数**，分为实例方法和类型方法。

```swift
struct Calculator {
    var value: Double

    mutating func add(_ n: Double) -> Double {
        value += n
        return value
    }

    mutating func reset() {
        value = 0
    }

    static func description() -> String {
        return "这是一个计算器"
    }
}

var calc = Calculator(value: 10)
print(calc.add(5))
calc.reset()
print(Calculator.description())
```

| 方法类型 | 关键字 | 调用方式 | 说明 |
|----------|--------|----------|------|
| 实例方法 | `func` | `实例.方法()` | 操作实例的数据 |
| 可变实例方法 | `mutating func` | `实例.方法()` | 修改实例的属性 |
| 类型方法 | `static func` | `类型名.方法()` | 不依赖实例，类似工具函数 |

⚠️ **警告**：struct 的方法默认**不能修改属性**！如果需要修改，必须加 `mutating` 关键字。这是 struct 作为值类型的安全保障。

### 初始化器

#### 自动生成 memberwise init

Swift 会自动为 struct 生成一个**逐一初始化器**（memberwise initializer），按属性顺序传入所有值：

```swift
struct Book {
    var title: String
    var author: String
    var pages: Int
}

let book = Book(title: "Swift入门", author: "张三", pages: 300)
```

💡 **提示**：你不需要手写 init，Swift 已经帮你做好了！

#### 自定义 init

当你需要**默认值**或**额外逻辑**时，可以自定义初始化器：

```swift
struct User {
    var name: String
    var age: Int
    var isAdmin: Bool

    init(name: String, age: Int) {
        self.name = name
        self.age = age
        self.isAdmin = false
    }
}

let user = User(name: "小明", age: 20)
print("\(user.name)，管理员：\(user.isAdmin)")
```

⚠️ **警告**：一旦你自定义了 init，Swift 就**不再自动生成** memberwise init。如果你还需要默认的，必须自己写一个。

## class 类

类和结构体很像，都可以有属性和方法，但有几个关键区别——最核心的是：**类是引用类型**。

### 定义与使用

```swift
class Person {
    var name: String
    var age: Int

    init(name: String, age: Int) {
        self.name = name
        self.age = age
    }

    func introduce() -> String {
        return "我叫\(name)，今年\(age)岁"
    }
}

let person = Person(name: "小明", age: 25)
print(person.introduce())
```

💡 **提示**：class 的属性如果不在声明时给默认值，就必须在 `init` 中初始化，否则编译报错。

### 属性与方法

类的属性和方法与 struct 基本一致，但有一个重要区别：**class 的方法默认就可以修改属性**，不需要 `mutating`。

```swift
class BankAccount {
    var owner: String
    var balance: Double

    init(owner: String, balance: Double) {
        self.owner = owner
        self.balance = balance
    }

    func deposit(_ amount: Double) {
        balance += amount
    }

    func withdraw(_ amount: Double) -> Bool {
        if balance >= amount {
            balance -= amount
            return true
        }
        return false
    }
}

let account = BankAccount(owner: "小明", balance: 1000)
account.deposit(500)
print("余额：\(account.balance)")
```

### 初始化器

#### 必须显式定义 init

与 struct 不同，class **不会自动生成** memberwise init，你必须自己写：

```swift
class Dog {
    var name: String
    var breed: String

    init(name: String, breed: String) {
        self.name = name
        self.breed = breed
    }
}

let dog = Dog(name: "旺财", breed: "金毛")
```

⚠️ **警告**：如果 class 有属性没有默认值，又没写 init，编译器会直接报错！

#### 便利初始化器 convenience init

`convenience init` 是**辅助初始化器**，它必须调用同一个类中的**指定初始化器**（designated init）：

```swift
class Product {
    var name: String
    var price: Double

    init(name: String, price: Double) {
        self.name = name
        self.price = price
    }

    convenience init(name: String) {
        self.init(name: name, price: 0.0)
    }
}

let p1 = Product(name: "手机", price: 5999)
let p2 = Product(name: "赠品")
print("\(p2.name)，价格：\(p2.price)")
```

| 初始化器类型 | 关键字 | 规则 |
|-------------|--------|------|
| 指定初始化器 | `init` | 必须初始化所有属性，是主要的初始化入口 |
| 便利初始化器 | `convenience init` | 必须调用指定初始化器，提供默认参数等便捷方式 |

💡 **提示**：`convenience init` 的典型用法是提供带默认值的简化版初始化，让调用方少写参数。

### 继承

继承是 class 独有的特性，struct **不支持**继承。子类可以继承父类的属性和方法，还可以重写（override）或新增功能。

```swift
class Animal {
    var name: String

    init(name: String) {
        self.name = name
    }

    func speak() -> String {
        return "..."
    }
}

class Dog: Animal {
    var breed: String

    init(name: String, breed: String) {
        self.breed = breed
        super.init(name: name)
    }

    override func speak() -> String {
        return "汪汪！"
    }
}

class Cat: Animal {
    override func speak() -> String {
        return "喵喵～"
    }
}

let dog = Dog(name: "旺财", breed: "金毛")
let cat = Cat(name: "小花")

print("\(dog.name)：\(dog.speak())，品种：\(dog.breed)")
print("\(cat.name)：\(cat.speak())")
```

| 概念 | 说明 |
|------|------|
| 父类 | 被继承的类，提供基础功能 |
| 子类 | 继承父类的类，用 `:` 连接 |
| `override` | 子类重写父类方法时**必须**加的关键字 |
| `super` | 在子类中引用父类，如 `super.init()` |

⚠️ **警告**：重写父类方法时**必须**加 `override` 关键字，否则编译器会报错。这是 Swift 的安全机制，防止你意外覆盖了父类方法。

## struct vs class：值类型 vs 引用类型

这是 Swift 中**最核心**的概念之一，理解它才能写出正确的代码。

### 详细对比表

| 对比维度 | struct（值类型） | class（引用类型） |
|----------|------------------|-------------------|
| 类型性质 | 值类型 | 引用类型 |
| 赋值行为 | 复制一份，互不影响 | 共享同一份数据 |
| 传参行为 | 传入副本 | 传入引用（指向同一对象） |
| 修改方法 | 需加 `mutating` | 直接修改 |
| 继承 | ❌ 不支持 | ✅ 支持 |
| 初始化器 | 自动生成 memberwise init | 必须手动写 |
| 析构器 | ❌ 没有 | ✅ 有 `deinit` |
| 内存管理 | 栈（Stack），自动释放 | 堆（Heap），ARC 管理 |
| 比较方式 | `==` 比较内容（需遵循 Equatable） | `===` 比较是否同一对象 |
| 线程安全 | ✅ 天然安全（各自独立副本） | ⚠️ 需要注意（共享可变状态） |
| SwiftUI 适用性 | ✅ 视图必须是 struct | ❌ 视图不能是 class |

### 值类型：复制时独立

```swift
struct Point {
    var x: Int
    var y: Int
}

var p1 = Point(x: 1, y: 2)
var p2 = p1

p2.x = 100

print("p1: (\(p1.x), \(p1.y))")
print("p2: (\(p2.x), \(p2.y))")
```

输出：
```
p1: (1, 2)
p2: (100, 2)
```

修改 p2 不影响 p1，因为赋值时**复制了一份全新的数据**。

### 引用类型：复制时共享

```swift
class Person {
    var name: String
    init(name: String) {
        self.name = name
    }
}

let person1 = Person(name: "小明")
let person2 = person1

person2.name = "小红"

print("person1: \(person1.name)")
print("person2: \(person2.name)")
```

输出：
```
person1: 小红
person2: 小红
```

修改 person2 后 person1 也变了！因为它们**指向同一个对象**，就像两个人拿着同一张银行卡，一个人取了钱，另一个人的余额也变了。

💡 **理解技巧**：
- **值类型** = 复印文件，改复印件不影响原件
- **引用类型** = 共享文档链接，任何人改了大家都看得到

### SwiftUI 中为什么优先用 struct

SwiftUI 的所有视图都是 struct，原因有三：

1. **性能更好**：struct 在栈上分配内存，比堆上的 class 快得多
2. **安全无副作用**：值类型各自独立，不会出现"改了 A 视图，B 视图也变了"的 bug
3. **框架设计**：SwiftUI 通过对比新旧 struct 值来决定是否刷新界面，值类型让这个过程简单高效

⚠️ **警告**：在 SwiftUI 中，视图**必须**是 struct，写成 class 会导致界面无法正确刷新！

## enum 枚举

枚举用来定义一组**固定的可选值**，就像多选题——答案只能是 A、B、C、D 中的一个。

### 基本枚举

```swift
enum Direction {
    case north
    case south
    case east
    case west
}

var currentDirection = Direction.north
currentDirection = .south

switch currentDirection {
case .north:
    print("向北走")
case .south:
    print("向南走")
case .east:
    print("向东走")
case .west:
    print("向西走")
}
```

💡 **提示**：一旦变量的类型确定为某个枚举，后续赋值可以省略枚举名，直接用 `.值`。

⚠️ **警告**：`switch` 枚举时**必须覆盖所有 case**，否则编译报错。如果不想全部处理，可以用 `default` 兜底。

### 关联值

关联值让每个 case 可以**携带不同类型的数据**，这是 Swift 枚举最强大的特性之一。

```swift
enum NetworkResult {
    case success(data: String)
    case failure(error: String)
    case loading(progress: Double)
}

let result = NetworkResult.success(data: "获取到 100 条数据")

switch result {
case .success(let data):
    print("成功：\(data)")
case .failure(let error):
    print("失败：\(error)")
case .loading(let progress):
    print("加载中：\(progress * 100)%")
}
```

**经典应用——网络请求结果**：

```swift
enum APIResponse<T> {
    case success(T)
    case failure(String)
}

func fetchUser() -> APIResponse<String> {
    return .success("用户数据")
}

let response = fetchUser()
switch response {
case .success(let data):
    print("数据：\(data)")
case .failure(let error):
    print("错误：\(error)")
}
```

💡 **提示**：关联值让枚举变成了一个"智能容器"，不同状态可以带不同数据，比简单的常量枚举强大得多。

### 原始值

原始值是枚举 case 自带的**预设值**，所有 case 的原始值类型必须相同。

#### Int 原始值（自动递增）

```swift
enum Planet: Int {
    case mercury = 1
    case venus
    case earth
    case mars
}

print(Planet.earth.rawValue)
print(Planet.mars.rawValue)

if let planet = Planet(rawValue: 2) {
    print("第2颗行星：\(planet)")
}
```

#### String 原始值

```swift
enum Season: String {
    case spring = "春"
    case summer = "夏"
    case autumn = "秋"
    case winter = "冬"
}

print(Season.summer.rawValue)
```

| 特性 | 关联值 | 原始值 |
|------|--------|--------|
| 数据类型 | 每个 case 可以不同 | 所有 case 必须相同 |
| 何时赋值 | 创建实例时赋值 | 定义枚举时就确定 |
| 用途 | 携带动态数据 | 提供固定标识 |
| 访问方式 | `switch` 提取 | `.rawValue` 属性 |

💡 **提示**：Int 原始值从指定的数开始自动递增（默认从 0 开始），String 原始值如果不指定则默认等于 case 名。

### 枚举的方法

枚举也可以定义方法，用来处理与自身相关的逻辑：

```swift
enum Beverage: String {
    case coffee = "咖啡"
    case tea = "茶"
    case juice = "果汁"
    case water = "水"

    func describe() -> String {
        switch self {
        case .coffee:
            return "☕️ \(self.rawValue)——提神醒脑"
        case .tea:
            return "🍵 \(self.rawValue)——清淡养生"
        case .juice:
            return "🧃 \(self.rawValue)——酸甜可口"
        case .water:
            return "💧 \(self.rawValue)——生命之源"
        }
    }

    var isCaffeinated: Bool {
        return self == .coffee || self == .tea
    }
}

let drink = Beverage.coffee
print(drink.describe())
print("含咖啡因：\(drink.isCaffeinated)")
```

输出：
```
☕️ 咖啡——提神醒脑
含咖啡因：true
```

💡 **提示**：在枚举方法中，`self` 代表当前实例，可以用 `switch self` 来针对不同 case 做不同处理。

## 小结

| 类型 | 关键字 | 核心特点 | 典型用途 |
|------|--------|----------|----------|
| 结构体 | `struct` | 值类型，复制独立，自动 init | 数据模型、SwiftUI 视图 |
| 类 | `class` | 引用类型，共享数据，支持继承 | 需要共享状态的对象、视图模型 |
| 枚举 | `enum` | 有限选项，关联值，原始值 | 状态管理、选项定义、结果类型 |

⚠️ **重点记忆**：
1. **struct 是值类型**，赋值和传参时复制；**class 是引用类型**，赋值和传参时共享
2. SwiftUI 视图**必须用 struct**
3. struct 修改属性的方法要加 `mutating`，class 不需要
4. 枚举的 `switch` 必须覆盖所有 case
5. 关联值让枚举可以携带数据，是 Swift 的杀手级特性
