## 📖 简介

**AppStore-Guide** 是一份面向零基础小白的 iOS 开发完整教程，手把手带你从"不知道 Xcode 是什么"到"成功上架 App Store"。整个教程涵盖 **9 大篇 54 章 + 7 个附录**，从环境搭建、语言学习、UI 开发到上架审核、增长变现，形成一条完整的闭环路径。

这不是一份枯燥的技术文档堆砌。本教程全程采用 **AI 驱动开发** 模式——你将学会如何借助 Claude Code、Cursor、Trae 等 AI 工具大幅提升开发效率，用 **Spec 驱动开发** 方法论让 AI 真正成为你的编程搭档，而不是简单的代码补全工具。

同时，本教程特别关注 **国内开发者** 的实际需求，详细讲解 ICP 备案流程、审核被拒应对策略、ASO 优化等实战内容，帮你少走弯路，早日上架。

根据你的背景，选择最适合的阅读路径：

> 第一篇 → 第二篇 → 第三篇（速览）→ 第四篇 → 第五篇 → 第六篇 → 第七篇 → 第八篇 → 第九篇

**🔴 已有 iOS 经验，关注上架与增长**

> 第二篇 → 第七篇 → 第八篇 → 第九篇

直接跳到 AI 驱动开发、上架准备和增长变现部分，解决你的核心痛点。
