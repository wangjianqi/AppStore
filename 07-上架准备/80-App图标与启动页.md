# 80-App 图标与启动页

> 🎯 **本章目标**：学会设计符合 Apple 规范的 App 图标，掌握在 Xcode 中配置 App Icon 和 Launch Screen 的完整流程，让你的 App 拥有专业的"门面"。

---

## App Icon 设计规范

### 尺寸要求（1024x1024）

App Store 对图标尺寸有严格要求，下面是核心规则：

| 要求项 | 说明 |
|--------|------|
| **主图标尺寸** | 1024 × 1024 像素（px） |
| **格式** | PNG，无透明通道（不要用透明背景） |
| **色彩空间** | sRGB 或 P3 |
| **圆角** | ❌ 不要自己画圆角！系统会自动添加 |
| **其他尺寸** | Xcode 自动从 1024x1024 生成，无需手动准备 |

💡 **小知识**：你只需要准备一张 1024×1024 的高质量 PNG 图片，Xcode 会自动帮你缩放到所有需要的尺寸（如 180x180、120x120、60x60 等），大大减少了工作量。

⚠️ **警告**：图标千万不要使用透明背景！如果使用了透明区域，上传到 App Store Connect 时会被拒绝。请确保背景是完全不透明的。

### 设计原则

好的图标能让用户一眼记住你的 App。以下是核心设计原则：

| 原则 | 说明 | ✅ 正确做法 | ❌ 错误做法 |
|------|------|------------|------------|
| **简洁明了** | 图标元素不宜过多，2-3 个视觉焦点最佳 | 一个大字母 + 纯色背景 | 塞满各种小图标和装饰 |
| **识别度高** | 在手机桌面上一眼就能认出来 | 独特的形状和配色 | 和其他 App 图标长得像 |
| **避免文字** | 文字在小尺寸下看不清 | 用 1-2 个字母或首字母缩写 | 写一整行 App 名称 |
| **颜色鲜明** | 使用饱和度高的颜色，在桌面更醒目 | 大面积纯色或渐变 | 灰暗、低对比度的配色 |
| **适配暗色** | 确保在浅色和深色壁纸下都清晰 | 中等亮度 + 鲜明色彩 | 纯黑图标（深色壁纸下消失） |

#### 示例分析

让我们看看几个经典 App 的图标设计思路：

| App | 设计特点 | 为什么好 |
|-----|---------|---------|
| **微信** | 绿色背景 + 两个白色对话气泡 | 颜色独特，一眼识别，含义明确 |
| **Instagram** | 渐变背景 + 相机轮廓 | 渐变色极具辨识度，相机暗示功能 |
| **支付宝** | 蓝色背景 + "支"字 | 蓝色代表信任，单字清晰可读 |
| **抖音** | 黑色背景 + 音符 + 故障风 | 风格独特，年轻化，暗色壁纸也醒目 |

💡 **提示**：你可以打开手机，看看第一屏的 App 图标，哪些一眼就能认出来？它们的共同点就是——**简洁 + 独特配色**。

### 圆角与安全区

iOS 系统会自动为你的图标添加圆角（Super Ellipse 超椭圆），你不需要自己画。

```
┌─────────────────────────┐
│  ⚠️ 圆角区域（会被裁切）  │
│  ┌───────────────────┐  │
│  │                   │  │
│  │   ✅ 安全区       │  │
│  │   重要内容放这里   │  │
│  │                   │  │
│  └───────────────────┘  │
│  ⚠️ 圆角区域（会被裁切）  │
└─────────────────────────┘
```

| 区域 | 说明 |
|------|------|
| **中心安全区** | 约为图标面积的 80%，重要内容放在这里 |
| **边缘区域** | 可能被圆角裁切，不要放重要文字或图形 |
| **四角** | 一定会被裁掉，绝对不要放内容 |

⚠️ **警告**：如果你在图标四角放了重要内容（比如文字），在手机桌面上会被圆角切掉，看起来非常不专业！

### 在线生成工具

如果你已经有一张图片，只是想快速生成符合规范的 App Icon，可以用在线工具：

| 工具 | 网址 | 特点 |
|------|------|------|
| **App Icon Generator** | appicon.co | 一键生成所有尺寸，免费 |
| **MakeAppIcon** | makeappicon.com | AI 辅助，支持从文字生成 |
| **Icon Kitchen** | icon.kitchen | 在线设计 + 生成，免费 |

#### 使用方法（以 App Icon Generator 为例）

1. 打开 [appicon.co](https://appicon.co)
2. 点击「Select Image」上传你的 1024×1024 图片
3. 勾选需要的平台（iOS）
4. 点击「Generate」下载生成的图标包
5. 解压后会得到一个 `AppIcon.appiconset` 文件夹

💡 **提示**：如果你只用 Xcode 的 Asset Catalog 方式，其实只需要 1024×1024 一张图就够了，在线工具主要是帮你生成所有尺寸的备选方案。

### 导出各尺寸

从 Xcode 13 开始，Apple 简化了图标配置流程：

| 方式 | 说明 |
|------|------|
| **新方式（推荐）** | 只提供 1024×1024 一张图，Xcode 自动缩放 |
| **旧方式** | 手动提供每个尺寸的图片（20x20@2x、20x20@3x 等） |

⚠️ **警告**：如果你使用旧方式手动提供各尺寸图标，请确保每个尺寸都提供了，否则 Xcode 会报警告，App Store 审核也可能被拒。

## Xcode 中配置 App Icon

### Asset Catalog 配置

这是最常用的配置方式，跟着步骤操作即可：

**步骤 1：打开 Asset Catalog**

1. 在 Xcode 左侧项目导航器中，找到 `Assets.xcassets`
2. 点击打开

**步骤 2：选择 AppIcon**

1. 在 Asset Catalog 左侧列表中，点击 `AppIcon`
2. 你会看到一个网格，显示各种尺寸的图标槽位

**步骤 3：拖入 1024x1024 图片**

1. 找到标注为「App Store iOS 1024pt」的大槽位
2. 将你的 1024×1024 PNG 图片直接拖入
3. Xcode 会自动填充其他尺寸（如果开启了自动缩放）

```
Assets.xcassets
  └── AppIcon
       ├── App Store iOS    → 1024x1024 ✅（你只需要拖这张）
       ├── iPhone App       → 自动生成
       ├── iPad App         → 自动生成
       └── ...
```

💡 **提示**：拖入图片后，如果看到黄色警告说某些尺寸缺失，不用慌——只要 1024x1024 那张填好了，Xcode 会自动处理。

### 多尺寸适配

| 平台 | 需要的尺寸 | 是否需要手动提供 |
|------|-----------|----------------|
| iPhone | 60x60@2x (120), 60x60@3x (180) | ❌ 自动生成 |
| iPad | 76x76 (76), 76x76@2x (152) | ❌ 自动生成 |
| App Store | 1024x1024 | ✅ 需要手动提供 |
| Spotlight | 40x40@2x, 40x40@3x | ❌ 自动生成 |
| Settings | 29x29@2x, 29x29@3x | ❌ 自动生成 |

💡 **结论**：你只需要关心那张 1024×1024 的主图标，其他交给 Xcode 就好！

## Launch Screen 配置

### Launch Screen Storyboard

#### 什么是启动页？

启动页（Launch Screen）是用户点击 App 图标后，App 加载时显示的第一个界面。它不是广告页，也不是闪屏，而是一个**让用户感觉 App 启动很快**的过渡界面。

| 概念 | 说明 |
|------|------|
| **Launch Screen** | App 加载时显示的界面，系统级，必须提供 |
| **闪屏/广告页** | App 自己实现的广告展示页，可选，不等于 Launch Screen |

#### 为什么需要启动页？

- **系统要求**：iOS 强制要求每个 App 必须提供 Launch Screen
- **用户体验**：没有启动页的话，App 加载时会显示黑屏，非常糟糕
- **启动速度感知**：好的启动页让用户觉得 App "秒开"

⚠️ **警告**：如果不配置 Launch Screen，App 在启动时会显示黑屏，而且 App Store 审核会拒绝！

#### 配置方法

**方法一：使用 Launch Screen Storyboard（推荐）**

Xcode 创建项目时会自动生成 `LaunchScreen.storyboard`，你只需要编辑它即可：

1. 在 Xcode 项目导航器中找到 `LaunchScreen.storyboard`
2. 点击打开 Interface Builder
3. 拖入一个 `UIImageView` 设置背景图或 Logo
4. 拖入一个 `UILabel` 设置 App 名称

**方法二：纯代码配置（通过 Info.plist）**

如果你不想用 Storyboard，也可以通过配置实现：

```xml
<!-- Info.plist 中配置 Launch Screen -->
<key>UILaunchStoryboardName</key>
<string>LaunchScreen</string>
```

💡 **提示**：推荐使用方法一，Xcode 自动生成的 `LaunchScreen.storyboard` 已经帮你搭好了框架，直接修改即可。

### 启动页设计建议

| 建议 | 说明 | ✅ 好的做法 | ❌ 差的做法 |
|------|------|------------|------------|
| **简洁** | 只放 Logo 和背景色 | 居中 Logo + 品牌色背景 | 塞满文字和图片 |
| **与首屏衔接** | 启动页和 App 首屏风格一致 | 启动页是首页的"骨架" | 启动页和首页完全不同 |
| **避免广告感** | 不要放广告、促销信息 | 只展示品牌元素 | "限时优惠！立即购买！" |
| **不要放加载进度条** | 系统不支持动态内容 | 静态界面 | 动画、进度条、倒计时 |

#### 示例对比

```
✅ 好的启动页：
┌─────────────────┐
│                  │
│                  │
│      📱          │  ← 居中的 Logo
│    MyApp         │  ← App 名称
│                  │
│                  │
└─────────────────┘
背景色 = App 主题色

❌ 差的启动页：
┌─────────────────┐
│ 🔥限时特惠！     │
│ 立即下载享8折！   │
│                  │
│    [广告图片]    │
│                  │
│ 跳过 3s >>>     │
│ v2.0.1 | 2026   │
└─────────────────┘
```

⚠️ **重要**：Launch Screen 只支持**静态内容**，不能添加动画、视频或交互元素。如果你想要闪屏广告页，需要在 App 内部自己实现一个 ViewController。

### 暗黑模式适配

启动页也需要适配暗黑模式，否则在深色模式下会显得很突兀。

#### 提供浅色/深色版本

在 `LaunchScreen.storyboard` 中，你可以为浅色和深色模式分别设置颜色和图片：

**颜色适配**：使用 Asset Catalog 中的动态颜色

1. 打开 `Assets.xcassets`
2. 右键 → New Color Set
3. 在 Attributes Inspector 中将 Appearance 设为「Any, Dark」
4. 分别设置浅色和深色模式的颜色值

**图片适配**：使用 Asset Catalog 中的动态图片

1. 打开 `Assets.xcassets`
2. 右键 → New Image Set
3. 在 Attributes Inspector 中将 Appearance 设为「Any, Dark」
4. 分别拖入浅色和深色版本的图片

#### Asset Catalog 配置

```
Assets.xcassets
  └── LaunchBackground（Color Set）
       ├── Any     → #FFFFFF（浅色模式：白色）
       └── Dark    → #1C1C1E（深色模式：深灰）
```

💡 **提示**：最简单的暗黑模式适配方式——启动页背景使用系统语义颜色 `systemBackground`，它会自动在浅色/深色模式下切换。
