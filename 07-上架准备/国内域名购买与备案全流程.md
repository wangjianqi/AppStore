# 国内域名购买与备案全流程

## 本章目标

读完本章，你将能够：

- 理解国内 App 上架为什么必须要有域名和备案
- 独立完成域名购买、实名认证、ICP 备案全流程
- 配置域名解析和 HTTPS 证书
- 掌握各环节的耗时和注意事项，合理规划上架时间

---

## 1. 为什么国内 App 上架需要域名和备案

### 1.1 工信部的要求

2023 年 8 月，工信部发布《工业和信息化部关于开展移动互联网应用程序备案工作的通知》，要求：

> ⚠️ **所有在中国境内运营的 App 必须完成备案，未备案的 App 不得上架、不得提供服务。**

这就像开实体店必须办营业执照一样——你的 App 就是一家"线上店铺"，备案就是你的"营业执照"。

### 1.2 App 备案需要域名

App 备案的核心流程中，**域名是必备条件**，原因如下：

| 备案环节 | 为什么需要域名 |
|---------|-------------|
| App 备案申请 | 需要填写 App 关联的域名信息 |
| ICP 备案 | 域名是 ICP 备案的主体标识 |
| 服务器接入 | 域名需指向已备案的服务器 |
| App Store 审核 | 国内上架需提供备案号，备案号与域名绑定 |

> 💡 简单理解：域名 = 你 App 的"门牌号"，备案 = 给这个门牌号"上户口"。没有门牌号，就没法上户口；没上户口，就不让营业。

### 1.3 整体流程概览

```
域名购买 → 域名实名认证 → ICP 备案 → 域名解析 → HTTPS 证书 → App 备案
 (0.5天)    (1-3工作日)    (5-20工作日)   (几分钟)    (1-7天)     (5-20工作日)
```

> ⚠️ 从零开始到备案完成，**最快也要 1-2 周，慢的话可能 1 个月**。请务必提前规划！

### 2.2 域名选择建议

**后缀优先级**：

| 优先级 | 后缀 | 说明 | 参考价格/年 |
|-------|------|------|------------|
| 🥇 首选 | `.com` | 全球通用、用户信任度最高 | ¥55-75 |
| 🥈 次选 | `.cn` | 中国国家域名、备案友好 | ¥29-50 |
| 🥉 可选 | `.net` | 老牌后缀、认知度尚可 | ¥60-80 |
| ⚠️ 谨慎 | `.com.cn` | 国内企业常用、稍显冗长 | ¥30-50 |
| ❌ 不推荐 | `.xyz`/`.top`/`.vip` 等 | 备案可能受限、用户信任度低 | ¥1-30 |

**域名命名技巧**：

- ✅ 简短易记：`myapp.com` > `my-awesome-ios-application.com`
- ✅ 与 App 名称相关：App 叫"记账本"，域名 `jizhang.com`
- ✅ 避免连字符和数字：`myapp.com` > `my-app123.com`
- ✅ 可以用拼音：`jizhang.com`、`daojia.cn`
- ❌ 避免商标冲突：不要用 `apple`、`wechat` 等词

## 3. 域名实名认证

### 3.1 为什么需要实名认证

根据《中国互联网络域名管理办法》，**所有在中国注册的域名必须完成实名认证**，否则：

- ❌ 域名无法解析（无法指向服务器）
- ❌ 无法进行 ICP 备案
- ❌ 域名可能被注册商暂停或注销

> 💡 类比：域名实名认证就像给域名办"身份证"，没有身份证的域名是"黑户"，什么也干不了。

### 3.2 实名认证流程

#### 个人认证所需材料

| 材料 | 要求 |
|------|------|
| 身份证正面照 | 清晰、完整、无遮挡 |
| 身份证反面照 | 清晰、完整、在有效期内 |
| 手持身份证照片 | 部分注册商要求，五官清晰 |

#### 企业认证所需材料

| 材料 | 要求 |
|------|------|
| 营业执照照片 | 清晰、在有效期内 |
| 法人身份证正反面 | 清晰、完整 |
| 组织机构代码证 | 三证合一时不需要单独提供 |

#### 认证步骤（以阿里云为例）

1. 进入 [域名控制台](https://dc.console.aliyun.com/next/index#/domain-list/all)
2. 找到状态为「未实名认证」的域名，点击「实名认证」
3. 选择认证类型：**个人** 或 **企业**
4. 上传证件照片
5. 填写证件信息（姓名、证件号码等）
6. 提交审核

```
提交认证 → 注册商审核（1个工作日内） → CNNIC审核（1-3个工作日） → 认证通过
```

> ⚠️ 实名认证的姓名/企业名称必须与后续 ICP 备案的**主体名称一致**！否则备案会被驳回。

> ⏱️ **预计时长：1-3 个工作日**

## 4. ICP 备案（网站备案）

### 4.1 什么是 ICP 备案

ICP 备案全称"互联网信息服务备案"，是中国大陆对提供互联网信息服务的网站/App 实行的备案制度。

> 💡 类比：ICP 备案就像给网站/App 办"营业执照"。没有备案号，你的网站/App 在国内就是"非法经营"。

**备案号长这样**：

- 网站备案号：`京ICP备2023123456号`
- App 备案号：`京ICP备2023123456号A`

其中"京"代表北京，"2023123456"是编号。

### 4.2 哪些情况需要 ICP 备案

| 情况 | 是否需要备案 |
|------|------------|
| 服务器在中国大陆 | ✅ **必须备案** |
| App 在国内应用商店上架 | ✅ **必须备案** |
| 服务器在中国香港/海外 | ❌ 不需要（但 App 上架仍需备案） |
| 仅做域名投资，不建站 | ❌ 不需要 |

> ⚠️ **重点**：即使你的服务器在海外，只要 App 要在国内应用商店上架，就需要备案！备案时需要有国内服务器。

### 4.3 备案前置条件

在开始备案之前，你需要准备：

| 前置条件 | 说明 |
|---------|------|
| ✅ 已购买域名 | 且已完成实名认证 |
| ✅ 已购买国内服务器 | 需要有公网 IP，云服务器/轻量服务器均可 |
| ✅ 主体资料 | 个人：身份证；企业：营业执照+法人身份证 |
| ✅ 服务器在备案平台 | 服务器需在备案的云服务商处购买 |

> 💡 域名和服务器的**购买平台最好一致**。比如域名在阿里云买，服务器也在阿里云买，备案就在阿里云做。跨平台备案需要额外的"接入备案"，更麻烦。

### 4.4 备案所需材料清单

#### 个人备案

| 材料 | 格式 | 备注 |
|------|------|------|
| 身份证正反面 | 彩色照片/扫描件 | 在有效期内 |
| 个人近期照片 | 电子版 | 部分省份需要 |
| 域名证书 | 电子版 | 在域名控制台下载 |
| 网站备案真实性核验单 | 签字扫描件 | 平台提供模板 |
| 幕布照片 | 电子版 | 部分平台支持人脸识别替代 |

#### 企业备案

| 材料 | 格式 | 备注 |
|------|------|------|
| 营业执照 | 彩色照片/扫描件 | 在有效期内 |
| 法人身份证正反面 | 彩色照片/扫描件 | 在有效期内 |
| 网站负责人身份证正反面 | 彩色照片/扫描件 | 可以和法人不同 |
| 域名证书 | 电子版 | 在域名控制台下载 |
| 网站备案真实性核验单 | 盖章扫描件 | 公章+签字 |
| 幕布照片 | 电子版 | 网站负责人拍照 |

> ⚠️ 个人备案的网站名称**不能包含企业性质词汇**，如"公司""集团""工作室"等。

### 4.5 备案完整流程（以阿里云为例）

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1.填写信息 │───▶│ 2.上传资料 │───▶│ 3.阿里云  │───▶│ 4.管局审核 │───▶│ 5.备案成功 │
│           │    │           │    │   初审    │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
   30分钟          30分钟        1-2个工作日      5-20个工作日      即时
```

#### 第 1 步：填写信息

1. 登录 [阿里云 ICP 备案系统](https://beian.aliyun.com/)
2. 点击「开始备案」
3. 填写主体信息：

```
主体类型：个人 / 企业
主体名称：张三 / 某某科技有限公司
证件号码：身份证号 / 统一社会信用代码
通讯地址：详细地址（精确到门牌号）
手机号码：负责人手机号
应急联系电话：另一个手机号（不能和上面相同）
```

4. 填写网站/App 信息：

```
网站名称：xxx的个人网站 / 某某App官网
域名：myawesomeapp.com
服务内容：博客/App官网/其他
服务器 IP：xxx.xxx.xxx.xxx（从阿里云服务器列表选择）
```

#### 第 2 步：上传资料

按照系统提示上传所有需要的材料照片。注意：

- 📸 照片要清晰、不反光、不遮挡
- 📸 身份证四个角要完整露出
- 📸 幕布照片要站在指定幕布前拍摄（或使用人脸识别）

#### 第 3 步：阿里云初审

阿里云会在 **1-2 个工作日** 内完成初审。初审可能的问题：

- 信息填写不完整
- 照片不清晰
- 网站名称不符合规范
- 主体信息与证件不一致

> 💡 初审期间，阿里云客服可能会打电话核实信息，请保持手机畅通！

#### 第 4 步：管局审核

初审通过后，阿里云会将备案信息提交到**所在省通信管理局**进行最终审核。

- 审核期间管局可能会电话核实，请保持电话畅通
- 审核期间网站**不能访问**（首次备案）

#### 第 5 步：备案成功

审核通过后，你会收到短信和邮件通知，备案号生效。

- 可以在 [工信部备案查询系统](https://beian.miit.gov.cn/) 查询备案信息
- 备案号需要展示在网站/App 底部

## 5. 备案常见问题

### 5.1 备案被驳回的常见原因

| 驳回原因 | 解决方法 |
|---------|---------|
| 网站名称含企业词汇（个人备案） | 改为个人性质的名称，如"张三的博客" |
| 身份证照片不清晰 | 重新拍摄，确保四角完整、文字清晰 |
| 主体信息与证件不一致 | 核对姓名、证件号是否完全一致 |
| 域名实名认证未通过 | 先完成域名实名认证再提交备案 |
| 通讯地址不详细 | 填写到门牌号级别 |
| 应急电话与主电话相同 | 提供另一个不同的手机号 |
| 网站内容与备案信息不符 | 确保网站实际内容与备案描述一致 |
| 营业执照过期 | 更新营业执照后重新提交 |
| 前置审批未通过 | 涉及新闻、出版、教育等需前置审批 |

> 💡 驳回后可以修改重新提交，不会额外收费。但每次驳回都会重新排队审核，所以**第一次尽量填对**！

### 5.2 备案期间网站能否访问

| 备案类型 | 备案期间网站状态 |
|---------|---------------|
| **首次备案** | ❌ 不能访问，否则会被驳回 |
| **新增网站** | 已有备案的网站可访问，新增的网站不能访问 |
| **接入备案** | ✅ 可以访问（已有备案号） |

> ⚠️ 首次备案期间，如果管局发现你的域名已经可以访问，会直接驳回！

### 5.3 备案号如何展示

备案成功后，需要在网站/App 中展示备案号：

**网站展示要求**：

```html
<!-- 网站底部添加 -->
<footer>
  <p>京ICP备2023123456号</p>
  <!-- 部分省份还要求展示公安备案号 -->
  <p>京公网安备 11010502012345号</p>
</footer>
```

**App 展示要求**：

- 在 App 的「关于」页面或「设置」页面展示备案号
- 备案号需可点击跳转至工信部查询页面

```swift
// iOS 示例：在关于页面展示备案号
Text("京ICP备2023123456号")
    .foregroundColor(.blue)
    .onTapGesture {
        if let url = URL(string: "https://beian.miit.gov.cn/") {
            UIApplication.shared.open(url)
        }
    }
```

## 6. 域名解析配置

### 6.1 什么是域名解析

域名解析就是把域名指向服务器 IP 地址的过程。

> 💡 类比：域名解析就像在通讯录里把"张三"关联到他的手机号。别人拨打"张三"时，系统自动找到对应的手机号。

### 6.2 常见解析记录类型

| 记录类型 | 用途 | 示例 |
|---------|------|------|
| **A 记录** | 将域名指向 IPv4 地址 | `myawesomeapp.com` → `123.45.67.89` |
| **CNAME 记录** | 将域名指向另一个域名 | `www.myawesomeapp.com` → `myawesomeapp.com` |
| **AAAA 记录** | 将域名指向 IPv6 地址 | 较少使用 |
| **MX 记录** | 邮件服务器指向 | 用于企业邮箱 |
| **TXT 记录** | 域名验证、SPF 等 | 用于 SSL 证书验证 |

### 6.3 将域名指向服务器（以阿里云为例）

#### 步骤 1：获取服务器 IP

在阿里云控制台 → 云服务器 ECS → 实例列表中，找到你的服务器公网 IP。

```
服务器公网 IP: 123.45.67.89
```

#### 步骤 2：添加解析记录

1. 进入 [阿里云域名解析控制台](https://dns.console.aliyun.com/)
2. 点击你的域名 → 「解析设置」
3. 添加以下记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| A 记录 | `@` | `123.45.67.89` | 10分钟 |
| A 记录 | `www` | `123.45.67.89` | 10分钟 |

> 💡 `@` 代表根域名（`myawesomeapp.com`），`www` 代表子域名（`www.myawesomeapp.com`）。两条记录都加上，用户无论输入哪个都能访问。

#### 步骤 3：验证解析是否生效

```bash
# 在终端中使用 dig 命令验证
dig myawesomeapp.com

# 或使用 ping 命令
ping myawesomeapp.com
```

预期输出：

```
$ ping myawesomeapp.com
PING myawesomeapp.com (123.45.67.89): 56 data bytes
64 bytes from 123.45.67.89: icmp_seq=0 ttl=50 time=15.3 ms
```

> 💡 解析生效时间通常为 **10 分钟到 2 小时**，全球 DNS 刷新最长可能需要 48 小时。

## 7. HTTPS 证书

### 7.1 为什么需要 HTTPS

| 原因 | 说明 |
|------|------|
| Apple 要求 | iOS App 的网络请求必须使用 HTTPS（ATS 策略） |
| 安全性 | 加密传输数据，防止被窃听和篡改 |
| SEO 优先 | 搜索引擎优先展示 HTTPS 网站 |
| 浏览器要求 | Chrome 对 HTTP 网站标记"不安全" |
| 备案要求 | 部分省份要求网站必须启用 HTTPS |

### 7.2 免费 SSL 证书申请

#### 方案一：阿里云免费证书

1. 进入 [阿里云 SSL 证书控制台](https://yundun.console.aliyun.com/?p=cas)
2. 点击「免费证书」→「创建证书」
3. 填写域名信息
4. 选择验证方式（DNS 验证推荐）

```
证书品牌：DigiCert（免费版）
证书类型：DV（域名验证）
有效期：3个月（免费版）
保护域名：myawesomeapp.com
```

5. 按提示添加 DNS TXT 记录完成域名验证
6. 等待签发（通常几分钟到几小时）

> ⚠️ 阿里云免费证书有效期仅 **3 个月**，到期需重新申请。每个账号每年有 20 个免费证书额度。

#### 方案二：Let's Encrypt（推荐长期使用）

Let's Encrypt 是免费、自动化的证书颁发机构，适合有服务器操作能力的开发者。

**使用 Certbot 自动申请和续期**：

```bash
# 安装 Certbot（Ubuntu/Debian）
sudo apt update
sudo apt install certbot python3-certbot-nginx

# 申请证书（Nginx）
sudo certbot --nginx -d myawesomeapp.com -d www.myawesomeapp.com

# 申请证书（独立模式，无 Web 服务器时）
sudo certbot certonly --standalone -d myawesomeapp.com -d www.myawesomeapp.com

# 设置自动续期（Certbot 会自动添加 cron）
sudo certbot renew --dry-run
```

证书文件位置：

```
/etc/letsencrypt/live/myawesomeapp.com/fullchain.pem   # 证书链
/etc/letsencrypt/live/myawesomeapp.com/privkey.pem     # 私钥
```

> 💡 Let's Encrypt 证书有效期 **90 天**，但 Certbot 会自动续期，实际使用中无需手动操作。

### 7.3 证书部署

#### Nginx 部署示例

```nginx
server {
    listen 443 ssl http2;
    server_name myawesomeapp.com www.myawesomeapp.com;

    # Let's Encrypt 证书路径
    ssl_certificate /etc/letsencrypt/live/myawesomeapp.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/myawesomeapp.com/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # 网站根目录
    root /var/www/html;
    index index.html;
}

# HTTP 自动跳转 HTTPS
server {
    listen 80;
    server_name myawesomeapp.com www.myawesomeapp.com;
    return 301 https://$host$request_uri;
}
```

部署后重启 Nginx：

```bash
sudo nginx -t          # 检查配置语法
sudo systemctl reload nginx  # 重新加载配置
```

#### 验证 HTTPS 是否生效

在浏览器中访问 `https://myawesomeapp.com`，地址栏出现 🔒 锁图标即表示成功。

```bash
# 命令行验证
curl -I https://myawesomeapp.com

# 预期输出包含：
# HTTP/2 200
# server: nginx
```

## 8. 完整时间线总结表

| 阶段 | 具体事项 | 预计时长 | 累计时间 | 注意事项 |
|------|---------|---------|---------|---------|
| 第 1 步 | 域名购买 | 0.5-1 天 | 0.5-1 天 | 选 `.com` 或 `.cn`，在阿里云购买 |
| 第 2 步 | 域名实名认证 | 1-3 个工作日 | 1.5-4 天 | 姓名需与备案主体一致 |
| 第 3 步 | 购买国内服务器 | 0.5 天 | 2-4.5 天 | 与域名同平台购买更方便 |
| 第 4 步 | ICP 备案（初审+管局） | 5-20 个工作日 | 7-24.5 天 | 保持电话畅通 |
| 第 5 步 | 域名解析配置 | 10 分钟-2 小时 | 7-25 天 | A 记录指向服务器 IP |
| 第 6 步 | HTTPS 证书申请 | 1 小时-1 天 | 7-26 天 | Let's Encrypt 免费 |
| 第 7 步 | App 备案 | 5-20 个工作日 | 12-46 天 | 需先完成 ICP 备案 |

### 最快/最慢时间线

```
🚀 最快路径（一切顺利）：
   域名购买(0.5天) → 实名认证(1天) → ICP备案(5天) → 解析+证书(1天) → App备案(5天)
   = 约 12.5 天

🐢 最慢路径（各种延迟）：
   域名购买(1天) → 实名认证(3天) → ICP备案(20天) → 解析+证书(1天) → App备案(20天)
   = 约 45 天
```

> ⚠️ **强烈建议**：在 App 开发阶段就同步进行域名购买和备案，不要等 App 开发完了才开始，否则会白白等待几周！

## 小结

本章我们学习了国内 App 上架所需的域名购买与备案全流程：

1. **域名购买**：在阿里云/腾讯云等国内注册商购买 `.com` 或 `.cn` 域名，耗时约 0.5-1 天
2. **域名实名认证**：上传身份证或营业执照，耗时 1-3 个工作日
3. **ICP 备案**：最耗时的环节，需要 5-20 个工作日，各省时长不同
4. **域名解析**：添加 A 记录将域名指向服务器 IP，几分钟即可完成
5. **HTTPS 证书**：使用 Let's Encrypt 免费证书，配合 Certbot 自动续期
6. **时间规划**：全流程最快约 12 天，最慢约 45 天，务必提前启动

> 💡 记住这个核心原则：**域名和备案是 App 上架的"入场券"，越早准备越好！**
