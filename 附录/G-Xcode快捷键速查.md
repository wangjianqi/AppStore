# G-Xcode 快捷键速查

> Xcode 是 iOS 开发的核心工具，熟练使用快捷键能大幅提升开发效率。本附录按使用频率分类整理了最常用的快捷键，建议先记住高频操作，再逐步扩展。

---

## 1. 文件操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| ⌘ N | 新建文件 | 在当前项目中创建新文件 |
| ⌘ O | 打开项目 | 打开已有的项目或文件 |
| ⌘ S | 保存文件 | 保存当前编辑的文件 |
| ⌘ ⇧ S | 另存为 | 将当前文件另存为新文件 |
| ⌘ W | 关闭当前窗口 | 关闭当前编辑的文件标签页 |
| ⌘ ⇧ W | 关闭项目 | 关闭当前整个项目窗口 |
| ⌘ ⌥ W | 关闭其他标签页 | 只保留当前标签页，关闭其余 |

## 5. 调试操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| ⌘ \\ | 添加/删除断点 | 在当前行添加或移除断点 |
| ⌘ Y | 启用/禁用断点 | 全局启用或禁用所有断点 |
| F6 | 步过（Step Over） | 执行当前行，不进入函数内部 |
| F7 | 步入（Step Into） | 进入函数内部逐步调试 |
| F8 | 步出（Step Out） | 执行完当前函数，返回调用处 |
| ⌃ ⌘ Y | 继续运行 | 从当前断点继续执行程序 |
| ⌘ ⇧ C | 查看变量值 | 在调试时查看光标处变量的值 |
| ⌘ ⇧ Y | 显示/隐藏调试区 | 切换底部调试区域的显示 |
| ⌘ 6 | 打开断点导航器 | 查看和管理所有断点 |

> 💡 **提示**：如果你的 Mac 使用 Touch Bar 或键盘 F 键有特殊功能，步过/步入/步出可能需要按 `fn + F6/F7/F8`。

| 快捷键 | 功能 | 说明 |
|--------|------|------|

| ⌘ → | 向右旋转 | 将模拟器屏幕向右旋转 90° |

| ⌘ L | 锁屏 | 模拟锁屏操作 |
| ⌘ ⇧ M | 切换深色/浅色模式 | 切换模拟器的外观模式 |

## 8. 自定义快捷键

Xcode 允许你修改快捷键绑定，以适应个人习惯。

### 修改方法

1. 打开 Xcode 菜单栏，选择 **Xcode → Settings（设置）**（或按 `⌘ ,`）
2. 点击 **Key Bindings（快捷键绑定）** 选项卡
3. 在搜索框中输入你想修改的功能名称
4. 双击对应功能的快捷键列，按下你想要的新快捷键组合
5. 按 **Enter** 确认

### 注意事项

- ⚠️ 修改前建议先截图记录默认快捷键，方便恢复
- 如果新快捷键与已有绑定冲突，Xcode 会显示警告提示
- 点击右下角的 **Restore Defaults（恢复默认）** 可以重置所有快捷键
- 快捷键配置文件位于：`~/Library/Developer/Xcode/UserData/KeyBindings/`

### 导入/导出配置

- 你可以将自定义的快捷键配置导出为 `.idekeybindings` 文件
- 在 Key Bindings 页面底部点击 ⚙️ 图标，选择 **Export** 或 **Import**
- 这在多台设备间同步快捷键配置时非常有用
