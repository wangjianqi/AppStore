## Figma 基础使用

### 注册与安装

#### 注册 Figma 账号

1. 打开 [figma.com](https://www.figma.com)
2. 点击 **"Get started for free"**
3. 用邮箱或 Google 账号注册
4. 免费版已经足够个人开发者使用

> 💡 **提示**：Figma 免费版支持 3 个项目、每个项目无限页面，对个人开发者完全够用。

#### 下载桌面版 / 使用网页版

| 版本 | 优点 | 缺点 |
|------|------|------|
| 网页版 | 无需安装，打开即用 | 依赖网络，离线不可用 |
| 桌面版 | 更流畅，支持离线 | 需要下载安装 |

下载地址：[figma.com/downloads](https://www.figma.com/downloads/)

> 💡 **提示**：两个版本功能完全一致，数据实时同步。建议桌面版为主，网页版备用。

### 基本操作

#### 创建项目

1. 打开 Figma，点击左侧 **"+"** → **"New design file"**
2. 左上角点击 "Untitled" 重命名为你的 App 名称
3. 一个设计文件 = 一个 App 的所有页面

#### 创建画板（Frame）

画板就是你的"画布"，每个画板代表一个屏幕。

1. 左侧工具栏选择 **Frame 工具**（快捷键 `F`）
2. 右侧面板选择 **Phone** → **iPhone 14/15 Pro**（390×844）
3. 画板上会出现一个手机尺寸的框

> ⚠️ **警告**：一定要用 Frame 而不是直接在空白处画！Frame 可以设置自动布局和约束。

#### 添加形状和文字

| 操作 | 方法 | 快捷键 |
|------|------|--------|
| 添加矩形 | 工具栏 → Rectangle | `R` |
| 添加圆形 | 工具栏 → Ellipse | `O` |
| 添加文字 | 工具栏 → Text | `T` |
| 添加线条 | 工具栏 → Line | `L` |

#### 对齐和分布

选中多个元素后，右侧面板会出现对齐选项：

| 对齐方式 | 图标 | 快捷操作 |
|---------|------|---------|
| 左对齐 | ← | Align left |
| 水平居中 | ↔ | Align horizontal center |
| 右对齐 | → | Align right |
| 顶部对齐 | ↑ | Align top |
| 垂直居中 | ↕ | Align vertical center |
| 底部对齐 | ↓ | Align bottom |
| 水平均匀分布 | ⫶ | Horizontal spacing |
| 垂直均匀分布 | ⋮ | Vertical spacing |

> 💡 **提示**：对齐时以最外层 Frame 为参照。如果要对齐到特定元素，先选中参照元素，再按住 `Shift` 选其他元素。

### 组件与样式

#### 创建组件（Component）

组件就像"模板"，改一处，所有引用处同步更新。

1. 选中要变成组件的元素
2. 右键 → **"Create Component"**（快捷键 `⌥⌘K`）
3. 组件会出现在左侧的 **Assets** 面板中

**示例**：创建一个按钮组件

```
1. 画一个圆角矩形（按钮背景）
2. 在上面添加文字（按钮标题）
3. 全选 → 右键 → Create Component
4. 命名为 "Button/Primary"
```

#### 使用组件实例

1. 从左侧 **Assets** 面板拖拽组件到画板
2. 实例会跟随主组件自动更新
3. 可以在实例上修改文字内容，但样式跟随主组件

> 💡 **提示**：修改主组件的样式，所有实例会自动同步。这就是组件的威力——改一处，全局生效。

#### 定义颜色/字体样式

**颜色样式**：

1. 选中一个元素
2. 右侧面板 → Fill → 点击四个点图标
3. 点击 **"+"** 创建新样式
4. 命名规范：`Primary/Blue`、`Background/Light`、`Text/Secondary`

**字体样式**：

1. 选中文字元素
2. 右侧面板 → 点击字体旁边的四个点图标
3. 点击 **"+"** 创建新样式
4. 命名规范：`Heading/Large`、`Body/Regular`、`Caption/Small`

> ⚠️ **警告**：一定要先定义样式再开始设计！否则后期改颜色/字体要一个个手动改，非常痛苦。

## Apple Human Interface Guidelines 核心规范

Apple HIG（人机交互指南）是 iOS App 设计的"宪法"，遵循它能让你的 App 看起来更"原生"。

> 💡 **提示**：完整 HIG 文档地址：[https://developer.apple.com/design/human-interface-guidelines/](https://developer.apple.com/design/human-interface-guidelines/)

### 设计原则

#### 一致性（Consistency）

- 相同的操作在 App 内应该有相同的结果
- 使用系统标准控件，用户不需要重新学习
- 图标风格、颜色、字体保持统一

#### 直观性（Direct Manipulation）

- 用户直接操作屏幕上的内容，而不是通过抽象的按钮
- 手势操作（滑动、捏合、拖拽）让交互更自然
- 结果立即可见，不需要额外确认

#### 反馈性（Feedback）

- 每个操作都应该有视觉或触觉反馈
- 按钮点击有高亮效果
- 加载中有进度指示
- 操作成功/失败有提示

#### 用户控制（User Control）

- 用户可以随时取消操作
- 返回导航始终可用
- 危险操作需要二次确认
- 用户可以自定义设置

| 原则 | 好的设计 | 差的设计 |
|------|---------|---------|
| 一致性 | 所有页面用同样的返回按钮 | 每个页面的返回按钮位置不同 |
| 直观性 | 拖拽排序列表 | 点击"上移""下移"按钮排序 |
| 反馈性 | 删除后显示"已删除"+ 撤销按钮 | 删除后没有任何提示 |
| 用户控制 | 删除前弹出确认框 | 点击直接删除，无法恢复 |

### 导航模式

iOS 有 3 种主要导航模式，选择合适的导航是设计的第一步。

#### Tab Bar（底部标签栏）

- 适合：3-5 个并列的主要功能模块
- 位置：屏幕底部
- 示例：微信、支付宝、淘宝

#### Side Bar（侧边栏）

- 适合：iPad 上功能较多的 App
- 位置：屏幕左侧
- 示例：iPad 版备忘录、邮件

#### Navigation Bar（导航栏）

- 适合：层级式页面导航（列表 → 详情）
- 位置：屏幕顶部
- 示例：设置、通讯录

#### 对比表

| 导航模式 | 适合场景 | 适合设备 | 功能数量 | 示例 App |
|---------|---------|---------|---------|---------|
| Tab Bar | 并列功能 | iPhone/iPad | 3-5 个 | 微信、音乐 |
| Side Bar | 多功能/层级 | iPad 为主 | 5+ 个 | 备忘录、文件 |
| Navigation Bar | 层级导航 | iPhone/iPad | 不限 | 设置、通讯录 |

> 💡 **提示**：大多数 iPhone App 使用 **Tab Bar + Navigation Bar** 的组合。Tab Bar 管大模块切换，Navigation Bar 管页面层级跳转。

### 常用控件规范

#### 按钮（Button）

| 类型 | 说明 | 最小点击区域 |
|------|------|-------------|
| 主要按钮（Filled） | 最重要操作，实心填充 | 44×44 pt |
| 次要按钮（Tinted） | 次要操作，浅色填充 | 44×44 pt |
| 文字按钮（Plain） | 辅助操作，只有文字 | 44×44 pt |
| 灰色按钮（Gray） | 禁用状态 | 44×44 pt |

> ⚠️ **警告**：iOS 规定最小点击区域为 **44×44 pt**。小于这个尺寸，用户很难准确点击。

#### 列表（List）

| 样式 | 说明 | 适用场景 |
|------|------|---------|
| Plain | 无分组背景 | 简单列表 |
| Grouped | 带圆角分组背景 | 设置页、表单 |
| Inset Grouped | 分组带内边距 | iOS 15+ 默认样式 |

#### 搜索栏（Search Bar）

- 高度：36 pt
- 圆角样式
- 放在 Navigation Bar 下方或列表顶部
- 支持取消按钮

#### 尺寸和间距建议

| 元素 | 推荐值 |
|------|--------|
| 页面左右边距 | 16-20 pt |
| 元素之间间距 | 8-16 pt |
| 分组之间间距 | 24-35 pt |
| 导航栏高度 | 44 pt（+ 状态栏 47/54 pt） |
| Tab Bar 高度 | 49 pt（+ 安全区域 34 pt） |
| 列表行高 | 44-60 pt |
| 按钮圆角 | 8-12 pt |
| 卡片圆角 | 12-16 pt |

## 配色与字体选择

### 配色方案

#### 主色选择

主色决定了 App 的整体调性，选择时考虑：

| 调性 | 推荐色系 | 示例 App |
|------|---------|---------|
| 专业可信 | 蓝色系 | 支付宝、钉钉 |
| 活力热情 | 橙/红色系 | 淘宝、B站 |
| 自然清新 | 绿色系 | 微信、支付宝蚂蚁森林 |
| 高端简约 | 黑/灰色系 | Apple、Notion |
| 温暖友好 | 黄/粉色系 | 美团、小红书 |

#### 辅色搭配

一个 App 的配色通常包含：

| 角色 | 说明 | 数量 |
|------|------|------|
| 主色（Primary） | 品牌色，用于按钮、强调 | 1 个 |
| 辅色（Secondary） | 辅助强调 | 1-2 个 |
| 背景色（Background） | 页面底色 | 1-2 个（亮/暗模式） |
| 文字色（Text） | 主要/次要/占位文字 | 3-4 个 |
| 分隔线/边框 | 细线、卡片边框 | 1-2 个 |

> ⚠️ **警告**：不要用太多颜色！一个 App 的配色最好不超过 5 种主色调。颜色越多越难统一。

#### 配色工具推荐

| 工具 | 网址 | 特点 |
|------|------|------|
| Coolors | coolors.co | 快速生成配色方案，空格键换一套 |
| Adobe Color | color.adobe.com | 专业配色，支持色轮和规则 |
| Happy Hues | happyhues.co | 现成配色方案+实际效果预览 |
| iOS System Colors | — | 直接用 Apple 系统色，最安全 |

#### 配色示例

以"记账 App"为例：

```
主色：     #007AFF（iOS 蓝）— 按钮、选中态
辅色：     #34C759（iOS 绿）— 收入标识
警告色：   #FF3B30（iOS 红）— 支出标识
背景色：   #F2F2F7（iOS 浅灰）— 页面底色
卡片色：   #FFFFFF — 卡片背景
主文字：   #000000 — 标题和正文
次文字：   #8E8E93 — 副标题和说明
占位文字： #C7C7CC — 输入框提示
```

> 💡 **提示**：最省心的做法是直接使用 **iOS 系统色**，这样你的 App 会自动适配亮/暗模式，而且和系统风格一致。

### iOS 系统字体

#### SF Pro 字体族

Apple 的系统字体叫 **SF Pro**，它有以下特点：

- 在所有 Apple 设备上预装，无需额外引入
- 针对屏幕显示优化，小字号也很清晰
- 自动适配动态字体大小

| 字体变体 | 用途 |
|---------|------|
| SF Pro Text | 小字号（≤20pt），字间距更宽 |
| SF Pro Display | 大字号（>20pt），字间距更紧凑 |
| SF Pro Rounded | 圆角版本，用于儿童类 App 或轻松场景 |

> 💡 **提示**：在 SwiftUI 中，你不需要手动指定 SF Pro。使用系统字体 API（如 `.title`、`.body`）会自动使用 SF Pro。

#### 字体层级（大标题/标题/正文/说明）

#### 推荐字号表

| 层级 | SwiftUI 样式 | 字号 | 字重 | 用途 |
|------|-------------|------|------|------|
| 大标题 | `.largeTitle` | 34 pt | Bold | 页面主标题 |
| 标题 1 | `.title` | 28 pt | Bold | 区块标题 |
| 标题 2 | `.title2` | 22 pt | Bold | 子区块标题 |
| 标题 3 | `.title3` | 20 pt | Semibold | 小标题 |
| 标题 | `.headline` | 17 pt | Semibold | 列表项标题 |
| 正文 | `.body` | 17 pt | Regular | 主要内容文字 |
| 说明 | `.callout` | 16 pt | Regular | 次要内容 |
| 小字 | `.subheadline` | 15 pt | Regular | 辅助说明 |
| 脚注 | `.footnote` | 13 pt | Regular | 注释、时间戳 |
| 标注 | `.caption` | 12 pt | Regular | 标签、徽章 |
| 极小 | `.caption2` | 11 pt | Regular | 最小文字 |

### 字体层级

#### 动态字体大小

iOS 支持**动态字体（Dynamic Type）**，用户可以在"设置 → 显示与亮度 → 文字大小"中调整字体大小。

使用 SwiftUI 的语义化字体样式（如 `.body`、`.headline`），会自动支持动态字体。

```swift
Text("你好世界")
    .font(.body) 
```

而使用固定字号则不会：

```swift
Text("你好世界")
    .font(.system(size: 17))
```

> ⚠️ **警告**：尽量使用语义化字体样式（`.body`、`.headline` 等），而不是固定字号。这样你的 App 会自动支持无障碍字体大小。

#### 推荐层级表

| 层级 | 样式 | 颜色 | 示例 |
|------|------|------|------|
| 页面标题 | `.largeTitle` | 主文字色 | "我的账本" |
| 区块标题 | `.title3` | 主文字色 | "本月支出" |
| 列表标题 | `.headline` | 主文字色 | "餐饮" |
| 列表副标题 | `.subheadline` | 次文字色 | "今天 12:30" |
| 正文 | `.body` | 主文字色 | "消费详情说明" |
| 辅助说明 | `.caption` | 占位文字色 | "上次更新：2分钟前" |

## 从设计稿到 SwiftUI 代码

### 布局还原

#### Frame → VStack/HStack

Figma 中的 Frame 对应 SwiftUI 中的 `VStack`（垂直）或 `HStack`（水平）。

| Figma 布局 | SwiftUI 对应 |
|-----------|-------------|
| 垂直排列的 Frame | `VStack` |
| 水平排列的 Frame | `HStack` |
| 重叠的元素 | `ZStack` |

**示例**：

Figma 中一个垂直排列的卡片：

```
┌─────────────────┐
│   📊 本月支出     │  ← 标题
│   ¥ 3,280.00    │  ← 金额
│   比上月少 12%    │  ← 说明
└─────────────────┘
```

对应的 SwiftUI 代码：

```swift
VStack(alignment: .leading, spacing: 4) {
    Text("本月支出")
        .font(.subheadline)
        .foregroundColor(.secondary)
    Text("¥ 3,280.00")
        .font(.title)
        .fontWeight(.bold)
    Text("比上月少 12%")
        .font(.caption)
        .foregroundColor(.secondary)
}
.padding()
.background(Color.white)
.cornerRadius(12)
```

#### Auto Layout → Spacer/frame

Figma 的 Auto Layout 对应 SwiftUI 的布局系统：

| Figma Auto Layout | SwiftUI 对应 |
|-------------------|-------------|
| Fill container | `.frame(maxWidth: .infinity)` |
| Fixed | `.frame(width: 200)` |
| Hug content | 默认行为（不设 frame） |
| Gap（间距） | `spacing:` 参数 |
| Padding | `.padding()` |
| Space between | `Spacer()` |

**示例**：

Figma 中一个"标题 + 右侧箭头"的行：

```
┌──────────────────────────┐
│  设置              >     │
└──────────────────────────┘
```

对应的 SwiftUI 代码：

```swift
HStack {
    Text("设置")
        .font(.headline)
    Spacer()
    Image(systemName: "chevron.right")
        .foregroundColor(.secondary)
}
.padding(.horizontal, 16)
.padding(.vertical, 12)
```

### 颜色还原

#### 十六进制颜色 → Color

SwiftUI 的 `Color` 不直接支持十六进制，需要写一个扩展：

```swift
extension Color {
    init(hex: String) {
        let hex = hex.trimmingCharacters(in: CharacterSet.alphanumerics.inverted)
        var int: UInt64 = 0
        Scanner(string: hex).scanHexInt64(&int)
        let a, r, g, b: UInt64
        switch hex.count {
        case 6:
            (a, r, g, b) = (255, int >> 16, int >> 8 & 0xFF, int & 0xFF)
        case 8:
            (a, r, g, b) = (int >> 24, int >> 16 & 0xFF, int >> 8 & 0xFF, int & 0xFF)
        default:
            (a, r, g, b) = (255, 0, 0, 0)
        }
        self.init(
            .sRGB,
            red: Double(r) / 255,
            green: Double(g) / 255,
            blue: Double(b) / 255,
            opacity: Double(a) / 255
        )
    }
}
```

#### 扩展 Color

定义项目级的颜色常量，方便全局使用和修改：

```swift
extension Color {
    static let appPrimary = Color(hex: "007AFF")
    static let appBackground = Color(hex: "F2F2F7")
    static let appCard = Color.white
    static let appIncome = Color(hex: "34C759")
    static let appExpense = Color(hex: "FF3B30")
    static let appTextPrimary = Color(hex: "000000")
    static let appTextSecondary = Color(hex: "8E8E93")
}
```

**使用**：

```swift
Text("¥ 3,280.00")
    .foregroundColor(.appExpense)

Button("保存") {
}
    .background(Color.appPrimary)
```

> 💡 **提示**：把所有颜色定义在一个地方，以后要改主题色只需要改一处。

### 间距与尺寸

#### 设计稿标注 → SwiftUI 代码

| 设计稿标注 | SwiftUI 代码 |
|-----------|-------------|
| 左右边距 16pt | `.padding(.horizontal, 16)` |
| 上下边距 12pt | `.padding(.vertical, 12)` |
| 四周边距 16pt | `.padding(16)` |
| 元素间距 8pt | `VStack(spacing: 8)` |
| 固定宽度 200pt | `.frame(width: 200)` |
| 固定高度 44pt | `.frame(height: 44)` |
| 撑满宽度 | `.frame(maxWidth: .infinity)` |

#### 常用间距规范

| 场景 | 推荐间距 |
|------|---------|
| 页面左右边距 | 16-20 pt |
| 卡片内部边距 | 12-16 pt |
| 列表项之间 | 0 pt（用分隔线） |
| 区块之间 | 24-35 pt |
| 按钮内边距 | 水平 16 pt，垂直 12 pt |
| 图标与文字间距 | 8 pt |

**示例**：一个完整的卡片组件

```swift
VStack(alignment: .leading, spacing: 16) {
    Text("本月支出")
        .font(.subheadline)
        .foregroundColor(.appTextSecondary)

    Text("¥ 3,280.00")
        .font(.largeTitle)
        .fontWeight(.bold)
        .foregroundColor(.appTextPrimary)

    HStack(spacing: 8) {
        Circle()
            .fill(Color.appIncome)
            .frame(width: 8, height: 8)
        Text("比上月少 12%")
            .font(.caption)
            .foregroundColor(.appTextSecondary)
    }
}
.padding(16)
.frame(maxWidth: .infinity, alignment: .leading)
.background(Color.appCard)
.cornerRadius(12)
.shadow(color: .black.opacity(0.05), radius: 8, y: 2)
```

## 用 AI 辅助 UI 设计与代码转换

AI 可以帮你快速从"想法"到"代码"，但你需要学会正确地描述需求。

### 让 AI 根据描述生成 SwiftUI 代码

#### Prompt 模板

```
请用 SwiftUI 生成一个 [页面类型] 页面，要求如下：

- 布局：[描述布局结构]
- 颜色：[描述配色方案]
- 字体：[描述字体层级]
- 间距：[描述间距要求]
- 交互：[描述交互行为]

请使用 iOS 原生控件和设计规范，代码要清晰易读。
```

#### 实际示例

**输入**：

```
请用 SwiftUI 生成一个记账 App 的首页，要求如下：

- 布局：顶部显示本月支出总额卡片，下方是最近账单列表
- 颜色：主色 #007AFF，支出用 #FF3B30，收入用 #34C759
```
