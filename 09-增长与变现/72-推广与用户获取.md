## 社交媒体推广

> 🎯 **本节目标**：了解各社交媒体平台的特点和推广策略，选择适合你 App 的平台，制定高效的内容推广方案。

### 小红书推广

小红书是国内最适合 App 推广的平台之一，用户以年轻女性为主，种草文化浓厚，非常适合生活类、工具类、效率类 App。

#### 平台特点

| 特点 | 说明 |
|------|------|
| **用户画像** | 18-35 岁女性为主，消费意愿强 |
| **内容形式** | 图文笔记 + 短视频 |
| **核心机制** | 种草 → 搜索 → 购买/下载 |
| **流量来源** | 搜索流量 + 推荐流量 |
| **适合 App 类型** | 生活、美妆、穿搭、美食、效率、学习、健身 |

#### 内容策略

| 策略 | 说明 | 示例 |
|------|------|------|
| **痛点切入** | 从用户痛点出发，展示 App 如何解决 | "总是忘记记账？这个 App 帮我解决了" |
| **场景化展示** | 在真实生活场景中使用 App | "上班族的一天，全靠这个 App 续命" |
| **对比种草** | 与其他方式对比，突出优势 | "从纸质手帐到电子手帐，回不去了" |
| **教程分享** | 教用户如何用 App 达成目标 | "3 步搞定月度预算，超简单" |
| **数据展示** | 用数据证明效果 | "用了 30 天，存下了 2000 块" |

#### 发布技巧

```text
1. 标题：用数字 + 痛点 + 好奇心
   ✅ "3个App让我从月光族到存钱达人"
   ❌ "推荐一款记账App"

2. 封面图：高颜值 + 大字标题
   → 小红书是视觉平台，封面决定了点击率
   → 用 App 截图 + 精美排版 + 醒目标题

3. 正文：口语化 + emoji + 分段
   → 像跟朋友聊天一样写
   → 多用 🌟💡✅ 等emoji增加可读性

4. 标签：5-10 个相关标签
   #记账App #存钱 #理财 #效率工具 #自律

5. 发布时间：晚上 8-10 点（用户活跃高峰）
```

> 💡 **提示**：小红书的搜索流量非常可观。在笔记标题和正文中自然地包含关键词（如"记账App"、"效率工具"），能让你在用户搜索时被更多发现。

### 抖音/视频号推广

短视频是目前流量最大的内容形式，抖音和视频号是必争之地。

#### 短视频内容策略

| 策略 | 说明 | 适合 App 类型 |
|------|------|-------------|
| **功能演示** | 直接展示 App 核心功能 | 工具类、效率类 |
| **前后对比** | 展示使用 App 前后的变化 | 健身、学习、理财类 |
| **挑战/打卡** | 发起使用 App 的挑战活动 | 习惯养成、健身类 |
| **教程/技巧** | 教用户用 App 完成某个任务 | 所有类型 |
| **搞笑/剧情** | 用搞笑方式植入 App | 所有类型 |

#### App 演示视频

```text
一条高转化 App 演示视频的结构：

0-3秒：抛出痛点/悬念（"你还在用Excel记账？"）
3-10秒：展示 App 核心功能（录屏 + 旁白解说）
10-20秒：展示效果/结果（"一个月后，我存下了..."）
20-30秒：引导下载（"链接在评论区"或"搜索xxx下载"）

关键：
- 前3秒必须抓住注意力，否则用户划走
- 录屏画面要清晰，操作要流畅
- 旁白语速稍快，信息密度高
- 加字幕！很多用户静音刷视频
```

#### 发布技巧

| 平台 | 技巧 |
|------|------|
| **抖音** | 用热门BGM、参与挑战赛、评论区互动、固定更新频率（日更或隔日更） |
| **视频号** | 借助微信社交关系链、引导朋友圈转发、与公众号联动 |

```text
抖音发布 Checklist：
☐ 视频时长 15-60 秒（短于 15 秒不够完整，长于 60 秒完播率低）
☐ 添加 3-5 个话题标签
☐ 写好视频描述（包含关键词）
☐ 选择合适的封面帧
☐ 发布后 30 分钟内积极回复评论
☐ 同一内容可隔 1-2 周重新发布（换标题/封面）
```

> 💡 **提示**：抖音的算法推荐机制意味着即使 0 粉丝也有机会出爆款。关键是视频的前 3 秒完播率和整体完播率。多做测试，找到最吸引你目标用户的开头方式。

### Twitter/X 推广

如果你的 App 面向海外市场，Twitter/X 是最核心的推广平台。

#### 平台特点

| 特点 | 说明 |
|------|------|
| **用户画像** | 科技爱好者、开发者、创业者为主 |
| **内容形式** | 短文本 + 图片/视频 + 长推文（Thread） |
| **核心机制** | 转发 → 讨论 → 关注 |
| **适合 App 类型** | 开发者工具、效率工具、AI 产品、SaaS |

#### 内容策略

| 内容类型 | 说明 | 示例 |
|----------|------|------|
| **Build in Public** | 公开分享开发过程 | "Day 15: Just shipped the dark mode 🌙" |
| **功能展示** | 用短视频/GIF 展示功能 | "Watch how easy it is to..." |
| **用户反馈** | 分享用户好评截图 | "User said: 'This changed my workflow'" |
| **数据/里程碑** | 分享增长数据 | "Just hit 10K downloads! 🎉" |
| **Thread 教程** | 用长推文教用户使用 | "🧵 How I built an app in 30 days..." |

#### 社区互动

```text
Twitter 推广的核心不是发推，而是互动：

1. 找到你的目标社区
   → 搜索 #indiehacker #buildinpublic #iosdev 等标签
   → 关注和互动同领域的开发者

2. 真诚互动
   → 回复别人的推文，提供建设性意见
   → 转发并评论别人的内容
   → 不要只发广告，80% 互动 + 20% 推广

3. 参与话题
   → #IndieHackers、#BuildInPublic、#100DaysOfCode
   → 参与讨论，分享你的经验和见解

4. 发布节奏
   → 每天 3-5 条推文
   → 混合内容：开发进展、功能展示、行业观点、个人故事
```

> 💡 **提示**：Twitter 上 "Build in Public"（公开构建）文化非常流行。分享你的开发过程、遇到的困难、学到的经验，比直接推销 App 更容易获得关注和支持。

### 微博推广

微博是国内老牌社交媒体平台，适合话题营销和事件传播。

#### 平台特点

| 特点 | 说明 |
|------|------|
| **用户画像** | 年龄层较广，新闻和话题驱动 |
| **内容形式** | 图文 + 长文 + 视频 |

| **适合场景** | 话题营销、事件传播、KOL 合作 |

#### 话题营销

```text
微博推广的核心是"话题"：

1. 创建品牌话题
   → #极简记账App# #3秒记账挑战#

2. 借势热门话题
   → #存钱大作战# #自律给我自由# #效率提升#

3. 发起互动活动
```

> 💡 **提示**：微博的传播力来自转发。制作容易引发共鸣的内容（如省钱技巧、效率提升），比直接推销 App 更容易被转发。

## 内容营销

> 🎯 **本节目标**：学会通过技术博客、视频教程和播客等内容形式，持续吸引目标用户，建立专业影响力。

### 技术博客

写技术博客是开发者最自然的推广方式——你本来就在写代码，把开发经验分享出来就能吸引同频用户。

#### 掘金/CSDN/知乎

| 平台 | 特点 | 适合内容 | 用户画像 |
|------|------|---------|---------|
| **掘金** | 技术社区，推荐算法好 | Swift/SwiftUI 技术文章、开发经验 | 开发者 |
| **CSDN** | 老牌技术社区，SEO 好 | 技术教程、问题解决方案 | 开发者 |
| **知乎** | 问答社区，搜索流量大 | "如何xxx"类回答、经验分享 | 泛互联网用户 |

#### 分享开发经验

```text
适合写的技术博客主题：

1. 开发过程分享
   → "我是如何用 SwiftUI 开发一款记账 App 的"
   → "从 0 到 1：独立开发者上架 App Store 全记录"

2. 技术解决方案
   → "SwiftUI 实现自定义日历组件"
   → "iOS 本地数据持久化最佳实践"

3. 经验教训
   → "App 被拒 3 次后，我总结的审核避坑指南"
   → "独立开发者第一个月，我赚了多少钱"

4. 行业观点
   → "2025 年独立开发者还有机会吗？"
   → "为什么我选择 SwiftUI 而不是 UIKit"
```

#### 吸引开发者用户

```text
博客中自然植入 App 的方式：

❌ 硬广："快下载我的 App！"
✅ 软植入："在开发这个功能时，我遇到了 xxx 问题..."

文章结尾加一段：
"如果你对这款 App 感兴趣，可以在 App Store 搜索「xxx」下载体验。
有任何建议欢迎在评论区留言！"

→ 提供价值在前，推广在后
→ 读者因为你的技术分享关注你，进而关注你的产品
```

> 💡 **提示**：技术博客的长期价值远超社交媒体。一篇好的技术文章可以在搜索引擎上持续带来流量数年。建议每周写 1-2 篇，坚持 3 个月就能看到明显效果。

> 💡 **提示**：视频的封面和标题决定了 80% 的点击率。花时间设计一个吸引人的封面，写一个让人想点的标题，比视频内容本身更重要。

### 播客

播客是一个被低估的推广渠道，听众忠诚度高，适合深度内容。

#### 播客平台

| 平台 | 特点 | 适合人群 |
|------|------|---------|
| **小宇宙** | 国内最火的播客平台 | 国内用户 |
| **Apple Podcasts** | iOS 内置播客 | 海外用户 |
| **Spotify** | 全球最大音频平台 | 海外用户 |
| **喜马拉雅** | 国内老牌音频平台 | 国内泛用户 |

#### 话题选择

```text
适合播客的话题：

1. 独立开发者故事
   → "从大厂离职做独立开发，第一年赚了多少"
   → 个人故事最容易引起共鸣

2. 行业观察
   → "2025 年 iOS 独立开发还有机会吗"
   → 分享你的独特见解

3. 技术讨论
   → "SwiftUI vs UIKit，我选了哪个"
   → 有观点的讨论比中立的介绍更吸引人

4. 嘉宾访谈
   → 邀请其他独立开发者分享经验
   → 互相推广，扩大受众
```

> 💡 **提示**：播客的转化路径较长（听播客 → 产生兴趣 → 搜索下载），但听众质量最高、忠诚度最强。适合作为长期品牌建设渠道，不适合追求短期下载量。

## Product Hunt 发布

> 🎯 **本节目标**：掌握 Product Hunt 发布的完整流程和策略，在上线当天获得最大曝光。

Product Hunt 是全球最大的新产品发布社区，每天有数十万科技爱好者在上面发现新产品。如果你的 App 在 Product Hunt 上获得好成绩，一天之内就能获得数千次下载。

### 准备工作

Product Hunt 发布需要提前准备大量素材，不要临时抱佛脚。

#### 产品页面准备

| 准备项 | 要求 | 说明 |
|--------|------|------|
| **产品名称** | 简洁有力 | 与 App Store 名称一致 |
| **一句话介绍** | 60 字符以内 | 用一句话说清楚 App 是做什么的 |
| **详细描述** | 无严格限制 | 说清楚 App 解决什么问题、核心功能、定价 |
| **产品链接** | App Store 链接 | 确保链接正确可访问 |
| **定价信息** | 免费/付费/订阅 | 如实填写 |

#### 文案准备

```text
Product Hunt 描述文案模板：

[一句话介绍]
xxx is a [category] app that helps [target user] to [core benefit].

[问题]
Have you ever [痛点描述]?

[解决方案]
xxx makes it easy to [解决方案]. With xxx, you can:
- 核心功能 1
- 核心功能 2
- 核心功能 3

[为什么做这个产品]
We built xxx because [做这个产品的原因/故事].

[特别优惠]
Product Hunt users get [特别优惠，如免费试用期延长].

[联系方式]
Questions? Reach us at [邮箱/Twitter]
```

#### 图片和视频准备

| 素材 | 要求 | 说明 |
|------|------|------|
| **Logo** | 240×240 像素 | App 图标，清晰醒目 |
| **缩略图** | 1270×760 像素 | 产品展示图，出现在列表中 |
| **Gallery 图片** | 最多 8 张 | 展示核心功能的截图，加英文标注 |
| **宣传视频** | YouTube 链接 | 1-2 分钟产品演示视频，强烈推荐 |

> ⚠️ **警告**：Product Hunt 的用户以英文用户为主，所有文案和截图必须是英文！中文内容几乎不会获得关注。

### 发布策略

#### 选择发布时间

Product Hunt 的排名按太平洋时间（PT）计算，每天重置：

```text
最佳发布时间：太平洋时间 00:01（即北京时间 16:01）

为什么？
- 排名从每天 00:01 PT 开始计算
- 越早发布，积累投票的时间越长
- 00:01 发布意味着你有完整的 24 小时来获取投票

时区换算：
太平洋时间 00:01 = 北京时间 16:01（夏令时）
太平洋时间 00:01 = 北京时间 17:01（冬令时）
```

#### 团队成员支持

```text
发布当天的团队作战计划：

1. 提前通知团队成员和支持者
   → 告诉他们具体的发布时间和链接
   → 请他们在发布后第一时间投票和评论

2. 发布后立即行动
   → 团队成员投票（每人一个账号，不要刷票）
   → 每人写一条真实的使用感受评论
   → 分享到自己的社交网络

3. 全天互动
   → 及时回复每一条评论
   → 感谢每一个投票者
   → 在 Twitter 上实时分享进展

⚠️ 不要做的事：
- ❌ 用假账号刷票（会被检测并惩罚）
- ❌ 群发消息求投票（会被举报）
- ❌ 付费买投票（违反社区规则）
```

#### 社区互动

```text
发布当天的互动策略：

1. 回复每一条评论
   → 用真诚、详细的内容回复
   → 不要只说 "Thanks!"，要展开讨论

2. 主动参与社区
   → 在其他产品下留言（真诚地）
   → 回答社区中的问题

3. 实时更新进展
   → 在 Twitter 上分享排名变化
   → "We're #3 on Product Hunt! 🎉"

4. 收集反馈
   → 认真对待每一条建议
   → 记录有价值的反馈用于产品改进
```

> 💡 **提示**：Product Hunt 上获得 #1 的关键不是票数最多，而是综合得分（投票数 + 评论数 + 参与度）。所以鼓励支持者写评论比单纯投票更有价值。

### 发布示例

```text
一个成功的 Product Hunt 发布案例：

产品：FocusTimer（番茄钟 App）

准备阶段（发布前 2 周）：
- 准备了 8 张带英文标注的功能截图
- 录制了 90 秒产品演示视频
- 写了详细的英文产品描述
- 联系了 20 位支持者

发布当天：
- 太平洋时间 00:01 准时发布
- 30 分钟内获得 15 票和 5 条评论
- 全天在 Twitter 和社区互动
- 最终获得 312 票，排名第 4

发布效果：
- 当天下载量：1,200+
- 一周内下载量：3,500+
- 被 3 家科技媒体报道
- Twitter 新增关注 500+
```

## 媒体与 KOL 合作

> 🎯 **本节目标**：学会寻找和评估 KOL，选择合适的合作方式，追踪和评估推广效果。

### 寻找合适的 KOL

KOL（Key Opinion Leader，关键意见领袖）推广是获取精准用户的高效方式，但选错 KOL 就是浪费钱。

#### 目标用户匹配

```text
找 KOL 的第一步：明确你的目标用户是谁

示例：记账 App 的目标用户
- 20-35 岁上班族
- 有理财需求
- 习惯使用手机管理生活

→ 适合的 KOL 类型：
- 理财博主 ✅
- 效率工具博主 ✅
- 生活方式博主 ✅
- 美食博主 ❌（用户不匹配）
- 游戏博主 ❌（用户不匹配）
```

#### 粉丝质量评估

| 评估维度 | 怎么看 | 好的信号 | 差的信号 |
|----------|--------|---------|---------|
| **互动率** | 点赞+评论数/粉丝数 | >3% | <1% |
| **评论质量** | 看评论内容 | 真实讨论 | "加油"、"支持"等水评 |
| **粉丝增长** | 看增长曲线 | 稳步增长 | 突然暴增（可能买粉） |
| **内容质量** | 看近期内容 | 专业、用心 | 低质、广告占比过高 |
| **合作品牌** | 看历史合作 | 有知名品牌 | 全是不知名产品 |

> ⚠️ **警告**：不要只看粉丝数！一个 5 万粉丝、互动率 5% 的 KOL，效果可能比 50 万粉丝、互动率 0.5% 的 KOL 好得多。粉丝质量 > 粉丝数量。

### 合作方式

#### 免费体验

```text
适合：粉丝量较小的 KOL（1万以下）

方式：
1. 给 KOL 免费赠送 App 会员/高级功能
2. KOL 自愿分享使用体验
3. 不强制要求正面评价

优点：成本极低
缺点：KOL 可能不写，内容不可控
```

#### 付费推广

```text
适合：粉丝量中等的 KOL（1-50万）

方式：
1. 与 KOL 协商推广费用和内容形式
2. 约定发布时间、内容要求和修改权限
3. KOL 按约定制作和发布内容

费用参考（小红书）：
| 粉丝量 | 单篇费用参考 |
|--------|------------|
| 1-5万 | 500-3000元 |
| 5-20万 | 3000-10000元 |
| 20-50万 | 10000-30000元 |
| 50万+ | 30000元起 |
```

#### 联名合作

```text
适合：与 App 调性匹配的 KOL

方式：
1. 与 KOL 联合推出特别版功能/主题
2. KOL 参与产品设计的某个环节
3. 双方共同推广

示例：
- 记账 App × 理财博主 → 联名推出"理财达人记账模板"
- 日记 App × 插画师 → 联名推出"限定手帐贴纸包"
```

#### 合作方式对比表

| 对比项 | 免费体验 | 付费推广 | 联名合作 |
|--------|---------|---------|---------|
| **成本** | 极低（免费会员） | 中等（数千到数万） | 中等（分成或固定费） |
| **可控性** | 低 | 中 | 高 |
| **效果** | 不确定 | 较确定 | 最好 |
| **适合阶段** | 早期试水 | 成长期 | 成熟期 |
| **风险** | KOL 可能不写 | 效果可能不达预期 | 需要投入设计资源 |
| **适合 KOL** | 小 KOL | 中等 KOL | 头部 KOL |

### 效果评估

推广不是花了钱就完事，必须追踪效果才能优化投入。

#### 下载量追踪

```text
方法一：专属链接
→ 为每个 KOL 生成专属的 App Store 链接或落地页链接
→ 通过链接参数追踪来源

方法二：优惠码
→ 给每个 KOL 分配专属优惠码
→ 通过优惠码使用次数追踪转化

方法三：时间对比
→ 对比推广前后的下载量变化
→ 简单但不够精确（受其他因素影响）
```

#### 转化率分析

```text
关键指标：

曝光量 → KOL 内容的阅读/播放量
点击量 → 用户点击下载链接的次数
下载量 → 实际完成下载的次数
激活量 → 首次打开 App 的次数

转化漏斗：
曝光 10,000 → 点击 500（5%）→ 下载 100（20%）→ 激活 80（80%）

→ 如果点击率低：内容不够吸引或用户不匹配
→ 如果下载率低：App Store 页面需要优化（ASO）
→ 如果激活率低：App 首次体验需要优化
```

#### ROI 计算

```text
ROI（投资回报率）= （收益 - 成本）/ 成本 × 100%

示例：
KOL 推广费用：5,000 元
带来下载量：300 次
7日留存用户：120 人
付费用户：15 人
付费收入：450 元（15人 × 30元）

短期 ROI = (450 - 5000) / 5000 × 100% = -91%
→ 短期看是亏的

但如果考虑长期价值（LTV）：
假设每个付费用户平均生命周期价值 = 120 元
长期收入 = 15 × 120 = 1,800 元
长期 ROI = (1800 - 5000) / 5000 × 100% = -64%

→ 仍然亏，说明这个 KOL 不划算，需要换人或调整策略
```

> 💡 **提示**：KOL 推广的 ROI 通常需要较长时间才能回正。不要只看短期下载量，要关注用户质量和长期留存。一个带来 100 个高质量用户的 KOL，比带来 1000 个低质量用户的 KOL 更有价值。

## 用户推荐机制设计

> 🎯 **本节目标**：学会设计邀请码、分享奖励和社交分享机制，让现有用户帮你带来新用户。

用户推荐是成本最低、转化率最高的获客方式。被朋友推荐来的用户，留存率和付费率通常比其他渠道高 2-3 倍。

### 邀请码机制

邀请码是最经典的推荐方式——老用户获得邀请码，分享给朋友，朋友用邀请码注册后双方获得奖励。

#### 邀请码设计

```text
邀请码设计要点：

1. 邀请码格式
   → 简短好记：6-8 位字母数字组合
   → 示例：FXT8K2 或 FOCUS-TIMER

2. 邀请码获取
   → 在 App 内"邀请好友"页面生成
   → 每个用户可生成多个邀请码
   → 支持一键复制和分享

3. 邀请码使用
   → 新用户注册时输入邀请码
   → 或通过邀请链接自动填充
```

#### 奖励机制

| 奖励类型 | 邀请人奖励 | 被邀请人奖励 | 说明 |
|----------|-----------|-------------|------|
| **会员时长** | +7 天会员 | +7 天会员 | 最常见，成本可控 |
| **功能解锁** | 解锁高级功能 | 解锁高级功能 | 适合功能驱动的 App |
| **虚拟货币** | +100 金币 | +50 金币 | 适合有虚拟经济体系的 App |
| **去广告** | 7 天无广告 | 7 天无广告 | 适合广告变现的 App |

```text
奖励设计原则：

1. 双方都有奖励 → 被邀请人才有动力使用邀请码
2. 奖励要有价值 → 不要给无感的奖励（如 1 天会员）
3. 奖励成本可控 → 计算好每个新用户的获取成本
4. 防止刷单 → 限制每个用户的邀请次数和奖励上限
```

> ⚠️ **警告**：邀请码机制一定要做好防刷措施！否则可能被薅羊毛——用户用多个假账号互相邀请，消耗你的奖励资源。建议限制同一设备只能注册一个账号。

### 分享奖励

分享奖励比邀请码更轻量——用户只需把 App 分享到社交媒体，就能获得奖励。

#### 分享到社交媒体

```text
分享奖励流程：

1. 用户在 App 内点击"分享"按钮
2. 选择分享到微信/微博/Twitter 等
3. 系统生成带追踪参数的分享链接
4. 用户完成分享后获得奖励
5. 通过分享链接下载的新用户被记录来源

分享内容模板：
"我正在用 xxx 记账，超好用！3秒就能记一笔，还能自动生成月度报表。
下载链接：[链接]"
```

#### 双方奖励

```text
分享奖励 vs 邀请码奖励的区别：

分享奖励：只要分享就给奖励（不管有没有人下载）
→ 门槛低，但可能被滥用（分享到只有自己的小号）

邀请码奖励：只有被邀请人注册后才给奖励
→ 门槛高，但效果更确定

推荐组合使用：
- 分享奖励：小奖励（3天会员），鼓励传播
- 邀请码奖励：大奖励（7天会员），鼓励转化
```

### 社交分享优化

社交分享的每个细节都会影响传播效果，需要精心设计。

#### 分享内容设计

```text
好的分享内容 = 价值 + 好奇心 + 行动指令

❌ 差的分享内容：
"推荐一款记账App [链接]"

✅ 好的分享内容：
"这个月居然存下了3000块！全靠这个记账App，3秒记一笔，月底自动出报表 📊
试试看 → [链接]"

分享内容要素：
1. 个人体验 → "我存下了3000块"（真实感）
2. 核心卖点 → "3秒记一笔"（功能亮点）
3. 视觉元素 → 📊（增加注意力）
4. 行动指令 → "试试看"（引导点击）
5. 下载链接 → [链接]（转化入口）
```

#### 分享落地页

用户点击分享链接后，应该跳转到一个精心设计的落地页，而不是直接跳到 App Store：

```text
落地页设计要点：

1. 首屏：一句话说清楚 App 是什么
   → "3秒记账，轻松理财"

2. 核心功能展示：3-4 个功能亮点
   → 配合截图或 GIF

3. 用户评价：2-3 条真实好评
   → 增加信任感

4. 下载按钮：醒目的 CTA 按钮
   → "立即下载" / "免费体验"
   → 同时提供 App Store 和 Android 下载链接

5. 分享者信息（可选）
   → "你的朋友 xxx 推荐了这个 App"
   → 增加信任感和点击意愿
```

> 💡 **提示**：分享落地页比直接跳 App Store 的转化率高 30%-50%，因为落地页可以更好地展示 App 价值，说服用户下载。推荐使用 Carrd、Framer 等工具快速搭建落地页。

## 小结

本章我们学习了推广与用户获取的核心方法：

| 内容 | 关键要点 |
|------|---------|
| **社交媒体推广** | 小红书种草、抖音短视频、Twitter Build in Public、微博话题营销 |
| **内容营销** | 技术博客长期引流、视频教程高传播、播客深度连接 |
| **Product Hunt** | 提前准备英文素材、太平洋时间 00:01 发布、全天互动 |
| **KOL 合作** | 选对 KOL 比粉丝数重要、追踪 ROI、从免费体验开始 |
| **用户推荐** | 邀请码双方奖励、分享内容精心设计、落地页提高转化 |

> 📌 **关键提醒**：
> - 推广不是花钱越多效果越好，选对渠道和内容才是关键
> - 先做免费推广（ASO + 社交媒体 + 内容营销），再考虑付费推广
> - 每个渠道都要追踪效果，用数据指导决策
> - 用户推荐是成本最低的获客方式，优先设计好推荐机制
> - 推广是持续工作，不是一次性的活动
