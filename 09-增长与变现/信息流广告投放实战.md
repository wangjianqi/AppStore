# 信息流广告投放实战

> 🎯 **本章目标**：从资深投放人员的视角，系统掌握主流信息流广告平台的深度实操方法，理解竞价机制、出价策略、预算管理和放量缩量节奏，学会在不同平台之间做预算分配和效果对比，最终能独立操盘一个日耗千元到万元级别的投放项目。

## 信息流广告投放全景

### 什么是信息流广告

信息流广告是**嵌入在内容流中的原生广告**，用户在刷内容时自然看到，不像传统横幅广告那样突兀。

```text
信息流广告的核心特征：
- 原生：和内容混排，不打断用户浏览
- 算法驱动：平台根据用户兴趣精准推荐
- 竞价机制：广告主实时竞价，价高者得
- 效果可追踪：从展示到安装到付费全链路数据

与 ASA 的关键区别：
ASA：用户主动搜索 → 高意图 → 高转化
信息流：用户被动浏览 → 低意图 → 靠素材吸引 → 量大
```

### 信息流广告生态

```text
广告主（你）→ 广告平台（巨量引擎/Meta/Google）→ 流量方（抖音/微信/YouTube）

三方博弈：
- 广告主：希望用最低成本获取最多高质量用户
- 广告平台：希望最大化广告收入（eCPM = 出价 × CTR × CVR）
- 流量方：希望广告不影响用户体验

你的核心任务：在平台规则下，找到成本和量的最优平衡点
```

## 竞价机制深度解析

### eCPM 竞价公式

所有信息流平台的核心竞价逻辑都是 eCPM 排序：

```text
eCPM = 出价 × 预估CTR × 预估CVR × 1000

示例：
广告主 A：出价 ¥20，预估 CTR 3%，预估 CVR 8%
广告主 B：出价 ¥30，预估 CTR 1.5%，预估 CVR 5%
广告主 C：出价 ¥15，预估 CTR 5%，预估 CVR 12%

eCPM_A = 20 × 0.03 × 0.08 × 1000 = 48
eCPM_B = 30 × 0.015 × 0.05 × 1000 = 22.5
eCPM_C = 15 × 0.05 × 0.12 × 1000 = 90

排名：C > A > B → 广告主 C 赢得展示

关键洞察：出价最高不一定赢！
- 广告主 B 出价最高（¥30）但 eCPM 最低
- 广告主 C 出价最低（¥15）但 eCPM 最高
- 原因：C 的素材好（CTR高）+ 落地页好（CVR高）
```

> 💡 **核心认知**：竞价本质不是"出价竞争"，而是"效率竞争"。提升 CTR 和 CVR 比单纯提高出价更有效。

### 二价拍卖机制

```text
信息流广告采用广义二价拍卖（GSP）：

实际扣费 = 下一名的 eCPM ÷ 你的 eCPM × 你的出价 + ¥0.01

示例：
你的 eCPM：90，出价：¥15
下一名 eCPM：48

实际扣费 = 48 ÷ 90 × 15 + 0.01 = ¥8.01

→ 你出价 ¥15，但实际只扣 ¥8.01
→ 你只需要比下一名多 ¥0.01 就能赢

启示：
1. 出价可以适当高于心理价位，实际扣费通常低于出价
2. CTR/CVR 越高，实际扣费越低（eCPM 差距越大）
3. 不要害怕出高价，关键是素材质量
```

### oCPX 自动出价

现代信息流平台都支持 oCPX（oCPM/oCPC）自动出价：

```text
oCPX 机制：
1. 你设置目标转化成本（如 CPA ¥30）
2. 平台算法自动调整每次展示的出价
3. 高转化概率用户：提高出价抢量
4. 低转化概率用户：降低出价省钱
5. 最终平均 CPA 趋近你的目标

oCPX 的三个阶段：

阶段一：冷启动学习期（0-6个转化）
- 算法在探索什么样的用户会转化
- CPA 可能波动较大（高于或低于目标）
- ⚠️ 不要频繁调整出价/定向，会打断学习

阶段二：稳定投放期（6+个转化/天）
- 算法已找到高转化人群
- CPA 趋于稳定
- 可以开始微调优化

阶段三：衰减期
- 素材疲劳，CTR 下降
- CPA 逐渐升高
- 需要更新素材重新学习
```

> ⚠️ **警告**：冷启动期最忌讳"频繁调整"。每次调整出价、定向或素材，算法都会重新学习。三天两头改设置 = 永远在冷启动 = 永远亏钱。

## 国内信息流平台实操

### 巨量引擎（抖音/头条/西瓜）

巨量引擎是字节跳动旗下的广告投放平台，覆盖抖音、今日头条、西瓜视频等流量。

#### 账户结构

```text
广告主账户
  └── 推广计划（Campaign）
        └── 广告组（Ad Group）
              └── 广告（Ad）
                    └── 创意（Creative）

命名规范：
计划：日期_目标_地区（如 0601_安装_全国）
广告组：计划名_定向_出价（如 0601_安装_全国_兴趣定向_CPA30）
广告：广告组名_素材版本（如 0601_安装_全国_兴趣定向_CPA30_视频A）
```

#### 投放设置要点

| 设置项 | 建议 | 说明 |
|--------|------|------|
| **投放目标** | 激活/注册 | App 投放首选激活，有数据后切注册 |
| **出价方式** | oCPM | 自动出价，设置目标 CPA |
| **日预算** | 目标CPA × 20-30 | 给算法足够的探索空间 |
| **投放时段** | 全天 | 冷启动期不要限制时段 |
| **定向方式** | 先宽后窄 | 先通投跑数据，再根据数据收窄 |
| **创意类型** | 视频为主 | 抖音是视频平台，视频 CTR 远高于图片 |

#### 巨量引擎投放节奏

```text
第 1-3 天：冷启动
- 日预算：目标CPA × 10（如 CPA30 → 日预算300）
- 定向：通投或宽兴趣定向
- 素材：3-5 组不同风格视频
- 不调整出价，让算法学习

第 4-7 天：数据积累
- 日预算：逐步提升到 CPA × 20
- 分析哪些素材/定向效果好
- 关闭 CPA > 目标 × 1.5 的广告组
- 加大效果好的广告组预算

第 8-14 天：放量期
- 日预算：CPA × 30-50
- 复制效果好的广告组，微调定向
- 持续补充新素材（每2天1组新素材）
- 监控 CPA 波动

第 15+ 天：稳定优化
- 维持日预算
- 每周更新 2-3 组素材
- 精细化定向（Lookalike/再营销）
- 定期复盘数据
```

### 聚光平台（小红书）

小红书聚光平台适合女性用户为主的 App 投放。

#### 投放设置要点

| 设置项 | 建议 | 说明 |
|--------|------|------|
| **投放目标** | 表单/关注 | 小红书用户习惯"种草"而非直接下载 |
| **出价方式** | oCPC | 按点击出价，oCPC 自动优化 |
| **创意类型** | 笔记信息流 | 模仿真实笔记风格，不要像广告 |
| **关键词定向** | 核心词 + 场景词 | "记账App" + "攒钱方法" |
| **人群定向** | 女性 + 18-35 | 小红书核心用户群 |

#### 小红书投放的特殊性

```text
小红书 ≠ 传统信息流

1. 内容即广告：素材必须像真实笔记，不能像硬广
   ✅ "我用了这个记账App一个月，省了2000块"
   ❌ "下载XX记账App，功能强大，限时免费"

2. 种草逻辑：先种草，再转化
   用户看到笔记 → 收藏/点赞 → 搜索App名 → 下载
   → 归因链路长，7日ROAS可能很低，30日ROAS才真实

3. 达人合作 > 自投广告
   找小红书达人发笔记 → 用聚光加热 → 效果远好于纯自投

4. 评论区运营
   广告笔记的评论区要有人互动，否则转化率极低
```

## 海外信息流平台实操

### Meta Ads（Facebook + Instagram）

Meta Ads 是海外最大的社交广告平台，覆盖 Facebook 和 Instagram。

#### 账户结构

```text
Business Manager
  └── 广告账户（Ad Account）
        └── 广告系列（Campaign）
              └── 广告组（Ad Set）
                    └── 广告（Ad）

Campaign 目标选择：
- App Installs：以安装为目标（推荐起步用）
- Conversions：以特定事件为目标（有数据后切换）
- Traffic：以点击为目标（不推荐，点击≠安装）
```

#### 投放设置要点

| 设置项 | 建议 | 说明 |
|--------|------|------|
| **Campaign 目标** | App Installs → Conversions | 先跑安装，有数据后切事件优化 |
| **Ad Set 出价** | Lowest Cost → Cost Cap | 先最低成本跑量，再设成本上限 |
| **Ad Set 定向** | Advantage+ Audience | Meta 的 AI 定向通常比手动好 |
| **Ad Set 版位** | 自动版位 | 让算法找到最优版位 |
| **Ad 素材** | 视频 + 静图组合 | 每个Ad Set 至少 3 个素材 |
| **Ad 文案** | 短文案 + 社交证明 | "10万人都在用的记账App" |

#### Meta Ads 竞价策略

```text
三种出价策略对比：

1. 最低成本（Lowest Cost）
   - 不设出价上限，系统自动以最低成本获取最多转化
   - 优点：跑量快，学习期短
   - 缺点：CPA 可能波动大
   - 适用：冷启动期

2. 成本上限（Cost Cap）
   - 设置 CPA 上限，系统在不超过上限的前提下最大化量
   - 优点：CPA 可控
   - 缺点：可能跑不出量
   - 适用：有明确 CPA 目标时

3. 出价上限（Bid Cap）
   - 设置每次竞价的最高出价
   - 优点：最严格的成本控制
   - 缺点：严重限制跑量
   - 适用：预算极紧时

推荐路径：
冷启动（最低成本）→ 稳定期（成本上限）→ 规模期（最低成本+预算控制）
```

```text
文字：

- 可交互的轻量广告
```

## 出价与预算管理

### 出价策略进阶

```text
出价的三个层次：

层次一：基础出价（新手）
- 设置目标 CPA，让平台自动出价
- 不做任何手动调整
- 适合日耗 < ¥1,000

层次二：分时出价（进阶）
- 根据不同时段的转化率调整出价
- 高峰时段（晚 8-11 点）提高出价 10-20%
- 低谷时段（凌晨 2-6 点）降低出价 30-50%
- 适合日耗 ¥1,000-10,000

层次三：分人群出价（高级）
- 不同人群设置不同出价
- 高价值人群（高 LTV）出价 +50%
- 低价值人群出价 -30%
- 需要足够的用户数据支撑
- 适合日耗 > ¥10,000
```

### 预算分配框架

```text
预算分配三原则：

1. 70-20-10 法则
   - 70% 预算给已验证的有效渠道
   - 20% 预算给有潜力的新渠道
   - 10% 预算给实验性渠道

2. 按渠道 CPA 分配
   - CPA < 目标 70%：加大预算（+50%）
   - CPA 在目标 70-100%：维持预算
   - CPA 在目标 100-130%：减少预算（-30%）
   - CPA > 目标 130%：暂停或大幅缩减

3. 按用户价值分配
   - 高 LTV 渠道：允许更高 CPA
   - 低 LTV 渠道：严格控制 CPA
   - LTV/CAC > 3 的渠道优先加预算
```

#### 预算调整节奏

```text
预算调整频率：

日耗 < ¥1,000：
- 每周调整 1 次
- 每次调整幅度 ≤ 30%

日耗 ¥1,000-10,000：
- 每 3 天调整 1 次
- 每次调整幅度 ≤ 20%

日耗 > ¥10,000：
- 每天微调
- 每次调整幅度 ≤ 10%

⚠️ 黄金法则：不要一天内调整预算超过 50%
大幅调整会触发算法重新学习，导致 CPA 飙升
```

## 放量与缩量

### 放量策略

```text
放量的正确姿势：

1. 素材放量（最安全）
   - 增加新素材 → CTR 提升 → eCPM 提升 → 赢得更多展示
   - 不需要提高出价，成本不增
   - 每周新增 2-3 组素材

2. 定向放量
   - 放宽定向条件 → 触达更多人群
   - 从精准定向 → 宽定向 → 通投
   - 注意：CPA 可能上升

3. 出价放量
   - 提高出价 10-20% → 抢到更多展示
   - 最直接的放量方式
   - 注意：CPA 一定上升

4. 预算放量
   - 提高日预算 → 系统有更多探索空间
   - 适合 CPA 已稳定的情况
   - 每次提高 ≤ 30%

放量优先级：素材放量 > 预算放量 > 定向放量 > 出价放量
```

### 缩量策略

```text
什么时候需要缩量：

1. CPA 持续高于目标 30%+ 超过 3 天
2. 整体 ROI < 1（花钱比赚得多）
3. 素材疲劳，CTR 持续下降
4. 渠道质量下降，留存率降低

缩量的正确姿势：

1. 先缩低效广告组
   - 关闭 CPA > 目标 × 1.5 的广告组
   - 保留效果最好的 2-3 个广告组

2. 降低出价 10-15%
   - 不要一次性降太多
   - 每天降 5%，观察 2 天

3. 收窄定向
   - 从通投 → 宽定向 → 精准定向
   - 只保留高转化人群

4. 最后才降预算
   - 降预算是最粗暴的方式
   - 可能导致算法重新学习

⚠️ 缩量禁忌：
- 不要一次性关闭所有广告组
- 不要把出价降到市场均价以下
- 不要在数据波动时做决策（至少观察 3 天）
```

## 多渠道协同投放

### 渠道组合策略

```text
常见渠道组合：

组合一：ASA + 信息流（推荐）
- ASA 覆盖高意图搜索用户
- 信息流覆盖潜在兴趣用户
- ASA 带来的用户 LTV 通常更高
- 信息流带来的用户量更大

预算分配：ASA 30-40% + 信息流 60-70%

组合二：国内 + 海外
- 国内：巨量引擎 + 聚光 + 粉丝通
- 海外：Meta + Google UAC + TikTok
- 先做好一个市场，再扩展

预算分配：核心市场 70% + 新市场 30%

组合三：品牌 + 效果
- 品牌广告：KOL + 内容营销 + 社区
- 效果广告：信息流 + ASA
- 品牌提升认知，效果驱动转化

预算分配：效果 80% + 品牌 20%（独立开发者）
```

### 渠道效果对比模板

```text
| 渠道 | 日耗 | CPA | 7日ROAS | 次日留存 | 7日留存 | 付费率 | LTV/CAC |
|------|------|-----|---------|---------|---------|--------|---------|
| ASA  | ¥500 | ¥12 | 45%     | 42%     | 25%     | 5.2%   | 4.2     |
```

## 投放常见坑

### 坑一：冷启动期频繁调整

```text
错误做法：
Day 1：创建广告，CPA ¥50 → 觉得太高
Day 2：降低出价 20% → 量骤降
Day 3：换定向 → 重新学习
Day 4：换素材 → 又重新学习
Day 5：CPA 还是 ¥50，预算花不出去

正确做法：
Day 1-3：不动，让算法学习
Day 4：如果 CPA > 目标 × 1.5，微调出价 -10%
Day 5-7：观察 CPA 趋势
Day 8：如果仍无改善，关闭重建

核心原则：给算法至少 3 天学习时间，6 个转化后再做判断
```

### 坑二：只看 CPA 不看 LTV

```text
错误做法：
渠道 A：CPA ¥10，LTV ¥15 → LTV/CAC = 1.5
渠道 B：CPA ¥25，LTV ¥100 → LTV/CAC = 4.0

只看 CPA → 选渠道 A → 实际利润低
看 LTV/CAC → 选渠道 B → 实际利润高

→ CPA 只是"入口价格"，LTV 才是"真实价值"
→ 允许高 CPA 渠道存在，只要 LTV/CAC > 3
```

### 坑三：素材疲劳不重视

```text
素材疲劳的表现：
- CTR 从 3% 降到 1.5%（下降 50%）
- CPA 从 ¥20 涨到 ¥35（上涨 75%）
- 展示量不变但点击量减少

素材生命周期：
- 新素材：1-3 天蜜月期，CTR 最高
- 成熟期：4-14 天，CTR 稳定
- 疲劳期：15+ 天，CTR 持续下降

应对策略：
- 每 7 天补充 1-2 组新素材
- 每 14 天淘汰 CTR 最低的素材
- 保持同时在线 3-5 组素材轮换
- 素材库至少储备 10 组以上
```

### 坑四：盲目追求低成本

```text
错误逻辑：CPA 越低越好

实际情况：
CPA ¥5，日新增 10 人 → 月新增 300 人
CPA ¥15，日新增 100 人 → 月新增 3,000 人

→ CPA 低但量少，总增长有限
→ 适当提高 CPA 换取更大规模

正确的思考方式：
1. 先确定目标月新增量
2. 反推需要的日新增量
3. 在日新增量达标的前提下优化 CPA
4. 而不是一味追求最低 CPA
```

## 本章小结

- 信息流广告的竞价本质是 **eCPM 排序**，提升 CTR 和 CVR 比提高出价更有效
- **oCPX 冷启动期**最忌讳频繁调整，给算法至少 3 天学习时间
- 国内三大平台各有特点：巨量引擎量大、聚光种草、粉丝通话题
- 海外三大平台：Meta 定向精准、Google 覆盖广、TikTok 年轻用户
- 放量优先级：素材放量 > 预算放量 > 定向放量 > 出价放量
- 不要只看 CPA，要看 LTV/CAC 比值；不要追求最低成本，要在达标量级下优化成本
- 素材是投放的生命线，7 天补充新素材，14 天淘汰低效素材
