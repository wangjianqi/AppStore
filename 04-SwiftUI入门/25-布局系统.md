# 25-布局系统：VStack/HStack/ZStack

> 🎯 **本章目标**：掌握 SwiftUI 三大核心布局容器（VStack、HStack、ZStack）的用法，学会使用 Spacer、Divider、padding、frame 等修饰符精确控制视图的位置与尺寸，最终能独立构建登录页面和卡片布局。

---

## VStack 垂直布局

VStack 是 SwiftUI 中最常用的布局容器之一，它把子视图**从上到下**垂直排列。

### 基本使用

```swift
struct VStackBasicView: View {
    var body: some View {
        VStack {
            Text("第一行")
            Text("第二行")
            Text("第三行")
        }
    }
}
```

运行效果：三行文字从上到下依次排列，默认居中对齐。

> 💡 **提示**：VStack 中的子视图数量没有硬性上限，但建议保持在 10 个以内。超过 10 个时，需要用 `Group` 包裹，否则编译器会报错。

### 对齐方式

VStack 通过 `alignment` 参数控制子视图的**水平对齐方式**：

| 对齐方式 | 说明 | 效果 |
|---------|------|------|
| `.center`（默认） | 居中对齐 | 子视图在水平方向居中 |
| `.leading` | 左对齐 | 子视图靠左排列 |
| `.trailing` | 右对齐 | 子视图靠右排列 |

```swift
struct VStackAlignmentView: View {
    var body: some View {
        VStack(alignment: .leading) {
            Text("左对齐 - 短文本")
            Text("左对齐 - 这是一段比较长的文本")
            Text("左对齐 - 中")
        }
        .border(Color.red)
    }
}
```

⚠️ **注意**：`alignment` 控制的是**水平方向**的对齐。因为 VStack 是垂直排列的，所以水平方向有对齐的余地，垂直方向则没有。

### 间距控制

`spacing` 参数控制子视图之间的**间距**：

```swift
struct VStackSpacingView: View {
    var body: some View {
        HStack {
            VStack(spacing: 0) {
                Text("间距 0")
                Text("间距 0")
                Text("间距 0")
            }
            .border(Color.red)

            VStack(spacing: 20) {
                Text("间距 20")
                Text("间距 20")
                Text("间距 20")
            }
            .border(Color.blue)
        }
    }
}
```

| spacing 值 | 效果 |
|-----------|------|
| 不传（默认） | 系统自动计算合适间距 |
| `0` | 子视图紧密贴合，无间距 |
| `正数` | 子视图之间固定间距 |

> 💡 **提示**：不传 `spacing` 时，SwiftUI 会根据子视图类型自动选择合适的间距，通常看起来比较协调。如果需要精确控制，再手动指定。

## HStack 水平布局

HStack 和 VStack 用法几乎一样，只是方向不同——它把子视图**从左到右**水平排列。

### 基本使用

```swift
struct HStackBasicView: View {
    var body: some View {
        HStack {
            Text("左边")
            Text("中间")
            Text("右边")
        }
    }
}
```

### 对齐方式

HStack 通过 `alignment` 参数控制子视图的**垂直对齐方式**：

| 对齐方式 | 说明 |
|---------|------|
| `.center`（默认） | 垂直居中 |
| `.top` | 顶部对齐 |
| `.bottom` | 底部对齐 |
| `.firstTextBaseline` | 首行文字基线对齐 |
| `.lastTextBaseline` | 末行文字基线对齐 |

```swift
struct HStackAlignmentView: View {
    var body: some View {
        HStack(alignment: .top) {
            Text("短")
                .font(.title)
            Text("这段文字比较长，会换行显示，可以看到顶部对齐的效果")
                .font(.caption)
            Text("中")
                .font(.title2)
        }
        .border(Color.red)
    }
}
```

⚠️ **注意**：HStack 的 `alignment` 控制的是**垂直方向**的对齐，和 VStack 正好相反。

### 间距控制

和 VStack 一样，使用 `spacing` 参数：

```swift
struct HStackSpacingView: View {
    var body: some View {
        HStack(spacing: 30) {
            Text("项目A")
            Text("项目B")
            Text("项目C")
        }
    }
}
```

## ZStack 层叠布局

ZStack 把子视图**按顺序层叠**在一起，类似 Photoshop 中的图层概念。

### 基本使用

```swift
struct ZStackBasicView: View {
    var body: some View {
        ZStack {
            Color.blue
                .frame(width: 200, height: 200)

            Color.red
                .frame(width: 100, height: 100)

            Text("层叠文字")
                .foregroundColor(.white)
                .font(.title)
        }
    }
}
```

运行效果：蓝色方块在底层，红色方块在中间，白色文字在最上层。

### 层叠顺序

ZStack 中的层叠规则非常简单：

| 代码顺序 | 层级 | 视觉效果 |
|---------|------|---------|
| 第一个子视图 | 最底层 | 被其他视图覆盖 |
| 第二个子视图 | 中间层 | 覆盖前者，被后者覆盖 |
| 最后一个子视图 | 最上层 | 覆盖所有前面的视图 |

```swift
struct ZStackOrderView: View {
    var body: some View {
        ZStack {
            Rectangle()
                .fill(Color.yellow)
                .frame(width: 200, height: 200)

            Rectangle()
                .fill(Color.orange)
                .frame(width: 150, height: 150)

            Rectangle()
                .fill(Color.red)
                .frame(width: 100, height: 100)
        }
    }
}
```

> 💡 **提示**：如果需要动态调整层叠顺序，可以使用 `.zIndex()` 修饰符，值越大的视图越在上层。

```swift
ZStack {
    Text("底层")
        .zIndex(1)
    Text("上层")
        .zIndex(2)
}
```

⚠️ **注意**：ZStack 默认会对齐方式为 `.center`，所有子视图以中心点对齐叠加。可以通过 `ZStack(alignment: .topLeading)` 等方式修改。

## Spacer 与 Divider

### Spacer——占据剩余空间

`Spacer()` 是一个弹性空间，它会**尽可能占据剩余空间**，把其他视图"挤"到一边。

```swift
struct SpacerDemoView: View {
    var body: some View {
        VStack {
            HStack {
                Text("左边")
                Spacer()
                Text("右边")
            }
            .padding()

            HStack {
                Text("左")
                Spacer()
                Text("中")
                Spacer()
                Text("右")
            }
            .padding()
        }
    }
}
```

| 用法 | 效果 |
|------|------|
| 两个视图之间放一个 Spacer | 两端对齐 |
| 多个视图之间各放 Spacer | 等间距分布 |
| VStack 末尾放 Spacer | 内容顶部对齐 |

### Divider——分割线

`Divider()` 绘制一条细细的分割线，用于视觉分隔。

```swift
struct DividerDemoView: View {
    var body: some View {
        VStack {
            Text("第一组")
            Divider()
            Text("第二组")
            Divider()
            Text("第三组")
        }
        .padding()
    }
}
```

> 💡 **提示**：在 HStack 中，Divider 是竖线；在 VStack 中，Divider 是横线。

## padding 与 frame

### padding 内边距

`padding` 为视图添加内边距，是最常用的间距控制修饰符。

| 写法 | 说明 | 效果 |
|------|------|------|
| `.padding()` | 四周默认内边距（约 16pt） | 上下左右都有间距 |
| `.padding(20)` | 四周固定内边距 | 上下左右都是 20pt |
| `.padding(.horizontal)` | 水平方向默认内边距 | 左右有间距 |
| `.padding(.vertical, 10)` | 垂直方向固定内边距 | 上下各 10pt |
| `.padding(.top, 20)` | 单侧内边距 | 只有顶部 20pt |
| `.padding(EdgeInsets(top: 10, leading: 20, bottom: 10, trailing: 20))` | 精确控制四边 | 每边可以不同 |

```swift
struct PaddingDemoView: View {
    var body: some View {
        VStack(spacing: 20) {
            Text("默认 padding")
                .padding()
                .background(Color.yellow)

            Text("自定义 padding")
                .padding(EdgeInsets(top: 10, leading: 30, bottom: 10, trailing: 30))
                .background(Color.green)

            Text("只加水平 padding")
                .padding(.horizontal, 20)
                .background(Color.orange)
        }
    }
}
```

⚠️ **注意**：`.padding()` 要写在 `.background()` **前面**！padding 会撑大视图的尺寸，background 会跟着变大。如果反过来，背景色不会包含 padding 的区域。

### frame 尺寸控制

`frame` 用于指定视图的宽度和高度。

**固定尺寸：**

```swift
Text("固定尺寸")
    .frame(width: 200, height: 100)
    .background(Color.blue.opacity(0.3))
```

**撑满可用空间：**

```swift
Text("撑满宽度")
    .frame(maxWidth: .infinity)
    .background(Color.green.opacity(0.3))
```

**弹性尺寸范围：**

```swift
Text("弹性尺寸")
    .frame(minWidth: 100, maxWidth: 300, minHeight: 50, maxHeight: 200)
    .background(Color.orange.opacity(0.3))
```

| frame 参数 | 说明 |
|-----------|------|
| `width` / `height` | 固定宽高 |
| `minWidth` / `minHeight` | 最小宽高 |
| `maxWidth` / `maxHeight` | 最大宽高 |
| `.infinity` | 无限大（撑满父容器） |
| `alignment` | frame 内部对齐方式（默认 `.center`） |

> 💡 **提示**：`maxWidth: .infinity` 非常常用，可以让按钮或卡片撑满整个屏幕宽度。

### offset 偏移

`offset` 在不改变布局的前提下，让视图在视觉上偏移。

```swift
struct OffsetDemoView: View {
    var body: some View {
        ZStack {
            Circle()
                .fill(Color.blue)
                .frame(width: 100, height: 100)

            Circle()
                .fill(Color.red)
                .frame(width: 100, height: 100)
                .offset(x: 30, y: 30)
        }
    }
}
```

⚠️ **注意**：`offset` 只是视觉偏移，不会影响布局计算。也就是说，其他视图仍然认为这个视图在原来的位置。如果需要真正改变布局位置，应该使用 `padding` 或 `frame`。

## 布局实战练习

### 构建登录页面

下面是一个完整的登录页面示例，综合运用了 VStack、HStack、Spacer、padding、frame 等知识：

```swift
import SwiftUI

struct LoginView: View {
    @State private var username: String = ""
    @State private var password: String = ""
    @State private var rememberMe: Bool = false

    var body: some View {
        VStack(spacing: 30) {
            Spacer()

            VStack(spacing: 8) {
                Text("欢迎回来")
                    .font(.largeTitle)
                    .fontWeight(.bold)
                Text("请登录你的账号")
                    .font(.subheadline)
                    .foregroundColor(.secondary)
            }

            VStack(spacing: 16) {
                TextField("用户名", text: $username)
                    .textFieldStyle(.roundedBorder)
                    .padding(.horizontal)

                SecureField("密码", text: $password)
                    .textFieldStyle(.roundedBorder)
                    .padding(.horizontal)
            }

            HStack {
                Toggle("记住我", isOn: $rememberMe)
                    .font(.subheadline)
                Spacer()
                Button("忘记密码？") {}
                    .font(.subheadline)
                    .foregroundColor(.blue)
            }
            .padding(.horizontal)

            Button {
                print("登录成功")
            } label: {
                Text("登 录")
                    .foregroundColor(.white)
                    .font(.headline)
                    .frame(maxWidth: .infinity)
                    .padding(.vertical, 14)
                    .background(Color.blue)
                    .cornerRadius(10)
            }
            .padding(.horizontal)

            HStack(spacing: 4) {
                Text("还没有账号？")
                    .foregroundColor(.secondary)
                Button("立即注册") {}
                    .foregroundColor(.blue)
            }
            .font(.subheadline)

            Spacer()

            Divider()
                .padding(.horizontal)

            Text("其他登录方式")
                .font(.caption)
                .foregroundColor(.secondary)

            HStack(spacing: 40) {
                Button {} label: {
                    Image(systemName: "phone.fill")
                        .font(.title2)
                        .foregroundColor(.gray)
                }
                Button {} label: {
                    Image(systemName: "message.fill")
                        .font(.title2)
                        .foregroundColor(.gray)
                }
                Button {} label: {
                    Image(systemName: "applelogo")
                        .font(.title2)
                        .foregroundColor(.gray)
                }
            }
            .padding(.bottom, 30)
        }
    }
}

#Preview {
    LoginView()
}
```

### 构建卡片布局

下面是一个信息卡片布局示例，综合运用了 ZStack、HStack、VStack、padding、frame 等：

```swift
import SwiftUI

struct ProfileCard: View {
    let name: String
    let role: String
    let message: String

    var body: some View {
        ZStack(alignment: .topLeading) {
            RoundedRectangle(cornerRadius: 16)
                .fill(
                    LinearGradient(
                        colors: [Color.blue, Color.purple],
                        startPoint: .topLeading,
                        endPoint: .bottomTrailing
                    )
                )
                .frame(height: 200)

            VStack(alignment: .leading, spacing: 12) {
                HStack {
                    Circle()
                        .fill(Color.white.opacity(0.3))
                        .frame(width: 50, height: 50)
                        .overlay(
                            Text(String(name.prefix(1)))
                                .font(.title2)
                                .fontWeight(.bold)
                                .foregroundColor(.white)
                        )

                    VStack(alignment: .leading, spacing: 2) {
                        Text(name)
                            .font(.title3)
                            .fontWeight(.semibold)
                            .foregroundColor(.white)
                        Text(role)
                            .font(.caption)
                            .foregroundColor(.white.opacity(0.8))
                    }

                    Spacer()

                    Image(systemName: "ellipsis")
                        .foregroundColor(.white.opacity(0.8))
                }

                Spacer()

                Text(message)
                    .font(.subheadline)
                    .foregroundColor(.white.opacity(0.9))
                    .lineLimit(2)
            }
            .padding(20)
        }
    }
}

struct CardListView: View {
    let profiles = [
        ProfileData(name: "小明", role: "iOS 开发工程师", message: "热爱 SwiftUI，正在学习布局系统的各种技巧！"),
        ProfileData(name: "小红", role: "UI 设计师", message: "好的设计是让复杂变简单，好的布局是让信息更清晰。"),
        ProfileData(name: "小刚", role: "产品经理", message: "用户体验至上，每一个像素都有它的意义。")
    ]

    var body: some View {
        ScrollView {
            VStack(spacing: 20) {
                ForEach(profiles) { profile in
                    ProfileCard(
                        name: profile.name,
                        role: profile.role,
                        message: profile.message
                    )
                }
            }
            .padding()
        }
    }
}

struct ProfileData: Identifiable {
    let id = UUID()
    let name: String
    let role: String
    let message: String
}

}
```

## 小结

本章我们学习了 SwiftUI 布局系统的核心知识：

| 知识点 | 核心要点 |
|-------|---------|
| **VStack** | 垂直排列子视图，`alignment` 控制水平对齐，`spacing` 控制间距 |
| **HStack** | 水平排列子视图，`alignment` 控制垂直对齐，`spacing` 控制间距 |
| **ZStack** | 层叠排列子视图，后写的在上层，可用 `.zIndex()` 调整 |
| **Spacer** | 占据剩余空间，实现两端对齐或等间距分布 |
| **Divider** | 绘制分割线，VStack 中为横线，HStack 中为竖线 |
| **padding** | 添加内边距，注意写在 `.background()` 前面 |
| **frame** | 控制视图尺寸，`maxWidth: .infinity` 可撑满宽度 |
| **offset** | 视觉偏移，不影响布局计算 |

> 💡 **核心心法**：SwiftUI 布局的核心思路是**嵌套组合**——用 VStack、HStack、ZStack 把小视图组合成大视图，层层嵌套就能构建出任何复杂的界面。
