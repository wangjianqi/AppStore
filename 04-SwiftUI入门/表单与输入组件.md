# 表单与输入组件

> 🎯 **本章目标**：掌握 SwiftUI 中所有常用输入组件的使用方法，学会构建完整的表单界面，处理用户输入验证和表单提交。

---

## Form 容器

`Form` 是 SwiftUI 专门为表单场景设计的容器视图，它会自动适配系统样式，在 iOS 上呈现为分组的列表外观。

### 基础用法

最简单的 Form 只需要把内容放进去：

```swift
struct BasicFormView: View {
    @State private var username = ""
    @State private var notificationsEnabled = true

    var body: some View {
        Form {
            TextField("用户名", text: $username)
            Toggle("启用通知", isOn: $notificationsEnabled)
        }
    }
}
```

💡 **提示**：`Form` 会自动为内部的输入组件添加合适的间距和样式，不需要手动调整。

### Section 分组

当表单内容较多时，使用 `Section` 将相关字段分组：

```swift
struct SectionFormView: View {
    @State private var name = ""
    @State private var email = ""
    @State private var phone = ""
    @State private var notificationsEnabled = true
    @State private var darkMode = false

    var body: some View {
        Form {
            Section("个人信息") {
                TextField("姓名", text: $name)
                TextField("邮箱", text: $email)
                TextField("电话", text: $phone)
            }

            Section("偏好设置") {
                Toggle("启用通知", isOn: $notificationsEnabled)
                Toggle("深色模式", isOn: $darkMode)
            }

            Section {
                Button("保存") {
                    saveSettings()
                }
                .foregroundStyle(.blue)
            }
        }
    }

    func saveSettings() {
        print("保存设置")
    }
}
```

`Section` 的 header 和 footer 都可以自定义：

```swift
Section {
    TextField("用户名", text: $username)
    SecureField("密码", text: $password)
} header: {
    Text("登录信息")
        .font(.headline)
} footer: {
    Text("密码至少需要 8 个字符")
        .font(.caption)
        .foregroundStyle(.secondary)
}
```

### Form 样式

SwiftUI 提供了多种 Form 样式：

```swift
struct FormStyleDemo: View {
    @State private var name = ""

    var body: some View {
        TabView {
            NavigationStack {
                Form {
                    Section("分组样式（默认）") {
                        TextField("姓名", text: $name)
                    }
                }
                .navigationTitle("Grouped")
            }
            .tabItem { Label("Grouped", systemImage: "list.bullet") }

            NavigationStack {
                Form {
                    Section("内联样式") {
                        TextField("姓名", text: $name)
                    }
                }
                .formStyle(.columns)
                .navigationTitle("Columns")
            }
            .tabItem { Label("Columns", systemImage: "square.grid.2x2") }
        }
    }
}
```

| 样式 | 修饰符 | 效果 | 适用场景 |
|------|--------|------|---------|
| `.grouped` | `.formStyle(.grouped)` | 分组圆角卡片 | 设置页面（默认） |
| `.columns` | `.formStyle(.columns)` | 多列布局 | iPad、macOS |
| `.automatic` | `.formStyle(.automatic)` | 平台自适应 | 通用 |

⚠️ **警告**：Form 内部不要嵌套 `ScrollView`，Form 本身已经支持滚动。嵌套会导致滚动冲突和性能问题。

## TextField 文本输入

`TextField` 是最常用的输入组件，用于接收单行文本。

### 基本使用

```swift
struct TextFieldBasicView: View {
    @State private var text = ""

    var body: some View {
        Form {
            TextField("请输入", text: $text)

            Text("你输入了：\(text)")
                .foregroundStyle(.secondary)
        }
    }
}
```

### 键盘类型

通过 `.keyboardType()` 指定不同的键盘类型：

```swift
struct KeyboardTypeView: View {
    @State private var name = ""
    @State private var email = ""
    @State private var phone = ""
    @State private var url = ""
    @State private var number = ""

    var body: some View {
        Form {
            TextField("姓名", text: $name)
                .keyboardType(.default)

            TextField("邮箱", text: $email)
                .keyboardType(.emailAddress)
                .textInputAutocapitalization(.never)
                .autocorrectionDisabled()

            TextField("电话", text: $phone)
                .keyboardType(.phonePad)

            TextField("网址", text: $url)
                .keyboardType(.URL)
                .textInputAutocapitalization(.never)
                .autocorrectionDisabled()

            TextField("数量", text: $number)
                .keyboardType(.numberPad)
        }
    }
}
```

| 键盘类型 | 修饰符值 | 效果 |
|---------|---------|------|
| 默认键盘 | `.default` | 完整 QWERTY 键盘 |
| 邮箱键盘 | `.emailAddress` | 带 @ 和 .com |
| 数字键盘 | `.numberPad` | 只有数字 |
| 电话键盘 | `.phonePad` | 数字 + 拨号符号 |
| URL 键盘 | `.URL` | 带 / 和 .com |
| 小数键盘 | `.decimalPad` | 数字 + 小数点 |
| Twitter 键盘 | `.twitterPad` | 带 @ 和 # |
| 搜索键盘 | `.webSearch` | 带 搜索 按钮 |

💡 **提示**：邮箱和 URL 输入时，记得加上 `.textInputAutocapitalization(.never)` 和 `.autocorrectionDisabled()`，避免自动大写和自动纠错干扰。

### 文本自动大写

```swift
TextField("标题", text: $title)
    .textInputAutocapitalization(.words)

TextField("句子", text: $sentence)
    .textInputAutocapitalization(.sentences)

TextField("全部大写", text: $code)
    .textInputAutocapitalization(.characters)

TextField("不大写", text: $email)
    .textInputAutocapitalization(.never)
```

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `.sentences` | 句首大写 | 正文输入（默认） |
| `.words` | 每个词首大写 | 姓名、标题 |
| `.characters` | 全部大写 | 验证码、编号 |
| `.never` | 不自动大写 | 邮箱、URL、用户名 |

### 提交回调

`.onSubmit` 在用户按下键盘的"回车/完成"键时触发：

```swift
struct OnSubmitView: View {
    @State private var username = ""
    @State private var password = ""
    @State private var message = ""

    var body: some View {
        Form {
            TextField("用户名", text: $username)
                .onSubmit {
                    message = "用户名已确认：\(username)"
                }

            SecureField("密码", text: $password)
                .onSubmit {
                    login()
                }

            Text(message)
                .foregroundStyle(.blue)
        }
    }

    func login() {
        message = "正在登录..."
    }
}
```

也可以为不同的提交动作命名：

```swift
Form {
    TextField("搜索", text: $searchText)
        .submitLabel(.search)
        .onSubmit(of: .search) {
            performSearch()
        }

    TextField("发送消息", text: $messageText)
        .submitLabel(.send)
        .onSubmit(of: .send) {
            sendMessage()
        }

    TextField("下一步", text: $stepText)
        .submitLabel(.next)
        .onSubmit(of: .next) {
            focusField = .password
        }
}
```

| submitLabel | 键盘按钮文字 |
|-------------|------------|
| `.done` | 完成 |
| `.go` | 前往 |
| `.send` | 发送 |
| `.search` | 搜索 |
| `.return` | 换行 |
| `.next` | 下一项 |
| `.continue` | 继续 |
| `.join` | 加入 |

### TextField 样式

```swift
struct TextFieldStyleDemo: View {
    @State private var text1 = ""
    @State private var text2 = ""
    @State private var text3 = ""

    var body: some View {
        VStack(spacing: 20) {
            TextField("默认样式", text: $text1)
                .textFieldStyle(.automatic)

            TextField("圆角样式", text: $text2)
                .textFieldStyle(.roundedBorder)

            TextField("下划线样式", text: $text3)
                .textFieldStyle(.plain)
                .padding(.bottom, 4)
                .overlay(
                    Rectangle()
                        .frame(height: 1)
                        .foregroundStyle(.gray),
                    alignment: .bottom
                )
        }
        .padding()

}
```

| 样式 | 修饰符 | 外观 |
|------|--------|------|
| `.automatic` | `.textFieldStyle(.automatic)` | 跟随容器（Form 中为默认） |
| `.roundedBorder` | `.textFieldStyle(.roundedBorder)` | 灰色圆角边框 |
| `.plain` | `.textFieldStyle(.plain)` | 无边框 |

💡 **提示**：在 `Form` 中使用 `.automatic` 样式即可，系统会自动适配。在非 Form 场景下，推荐使用 `.roundedBorder` 提供视觉边界。

### 自定义 TextField

```swift
struct CustomTextField: View {
    let placeholder: String
    @Binding var text: String
    let icon: String
    var isError: Bool = false

    var body: some View {
        HStack(spacing: 12) {
            Image(systemName: icon)
                .foregroundStyle(isError ? .red : .blue)
                .frame(width: 20)

            TextField(placeholder, text: $text)
        }
        .padding()
        .background(
            RoundedRectangle(cornerRadius: 10)
                .fill(Color(.systemGray6))
        )
        .overlay(
            RoundedRectangle(cornerRadius: 10)
                .stroke(isError ? Color.red : Color.clear, lineWidth: 1)
        )
    }
}

struct CustomTextFieldDemo: View {
    @State private var email = ""
    @State private var password = ""

    var body: some View {
        VStack(spacing: 16) {
            CustomTextField(
                placeholder: "邮箱",
                text: $email,
                icon: "envelope",
                isError: email.isEmpty == false && !email.contains("@")
            )

            CustomTextField(
                placeholder: "密码",
                text: $password,
                icon: "lock",
                isError: password.isEmpty == false && password.count < 8
            )
        }
        .padding()
    }
}
```

## SecureField 密码输入

`SecureField` 和 `TextField` 用法几乎一样，但输入内容会显示为圆点，适合密码输入。

### 基本使用

```swift
struct SecureFieldBasicView: View {
    @State private var password = ""
    @State private var confirmPassword = ""

    var body: some View {
        Form {
            Section("设置密码") {
                SecureField("密码", text: $password)
                SecureField("确认密码", text: $confirmPassword)
            }

            if !password.isEmpty && !confirmPassword.isEmpty {
                if password == confirmPassword {
                    Label("密码一致", systemImage: "checkmark.circle.fill")
                        .foregroundStyle(.green)
                } else {
                    Label("密码不一致", systemImage: "xmark.circle.fill")
                        .foregroundStyle(.red)
                }
            }
        }
    }
}
```

### 密码显示/隐藏切换

SwiftUI 没有内置密码可见性切换，需要自己实现：

```swift
struct PasswordToggleView: View {
    @State private var password = ""
    @State private var showPassword = false

    var body: some View {
        HStack {
            if showPassword {
                TextField("密码", text: $password)
                    .autocorrectionDisabled()
                    .textInputAutocapitalization(.never)
            } else {
                SecureField("密码", text: $password)
            }

            Button {
                showPassword.toggle()
            } label: {
                Image(systemName: showPassword ? "eye.slash" : "eye")
                    .foregroundStyle(.secondary)
            }
        }
        .padding()
        .background(
            RoundedRectangle(cornerRadius: 10)
                .fill(Color(.systemGray6))
        )
    }
}
```

⚠️ **警告**：`SecureField` 不支持 `.keyboardType()` 修饰符，密码键盘始终是默认类型。如果需要自定义键盘类型，可以使用上面的切换方案。

## TextEditor 多行文本

`TextEditor` 用于多行文本输入，适合备注、评论、描述等场景。

### 基本使用

```swift
struct TextEditorBasicView: View {
    @State private var text = "在这里输入多行文本..."

    var body: some View {
        VStack {
            TextEditor(text: $text)
                .frame(height: 200)
                .scrollContentBackground(.hidden)
                .background(Color(.systemGray6))
                .clipShape(RoundedRectangle(cornerRadius: 10))

            Text("已输入 \(text.count) 个字符")
                .font(.caption)
                .foregroundStyle(.secondary)
        }
        .padding()
    }
}
```

💡 **提示**：`.scrollContentBackground(.hidden)` 可以隐藏 TextEditor 默认的白色背景，方便自定义样式。这个修饰符需要 iOS 16+。

### 字符计数与限制

```swift
struct CharacterLimitView: View {
    @State private var bio = ""
    let maxCharacters = 200

    var characterCount: Int {
        bio.count
    }

    var isOverLimit: Bool {
        characterCount > maxCharacters
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text("个人简介")
                .font(.headline)

            ZStack(alignment: .topLeading) {
                RoundedRectangle(cornerRadius: 10)
                    .fill(Color(.systemGray6))
                    .frame(minHeight: 120)

                if bio.isEmpty {
                    Text("介绍一下你自己...")
                        .foregroundStyle(.tertiary)
                        .padding(8)
                }

                TextEditor(text: $bio)
                    .scrollContentBackground(.hidden)
                    .padding(4)
            }

            HStack {
                Spacer()
                Text("\(characterCount)/\(maxCharacters)")
                    .font(.caption)
                    .foregroundStyle(isOverLimit ? .red : .secondary)
            }
        }
        .padding()
    }
}
```

### TextEditor 样式定制

```swift
struct StyledTextEditorView: View {
    @State private var content = ""

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            Text("备注")
                .font(.headline)

            TextEditor(text: $content)
                .scrollContentBackground(.hidden)
                .font(.body)
                .padding(8)
                .background(
                    RoundedRectangle(cornerRadius: 12)
                        .strokeBorder(Color(.systemGray4), lineWidth: 1)
                )
                .frame(minHeight: 150)
        }
        .padding()
    }
}
```

| 特性 | TextField | TextEditor |
|------|-----------|------------|
| 行数 | 单行 | 多行 |
| 滚动 | 不支持 | 自动滚动 |
| Placeholder | 内置支持 | 需手动实现 |
| 键盘类型 | 可自定义 | 默认键盘 |
| Form 中使用 | 自动适配 | 需指定高度 |

## Toggle 开关切换

`Toggle` 是一个开关控件，用于在两个状态之间切换（开/关）。

### 基本使用

```swift
struct ToggleBasicView: View {

    @State private var bluetoothEnabled = false
    @State private var airplaneMode = false

    var body: some View {
        Form {
            Toggle("Wi-Fi", isOn: $wifiEnabled)
            Toggle("蓝牙", isOn: $bluetoothEnabled)
            Toggle("飞行模式", isOn: $airplaneMode)
        }
    }
}
```

### Toggle 样式

```swift
struct ToggleStyleDemo: View {
    @State private var isOn1 = true
    @State private var isOn2 = true
    @State private var isOn3 = true

    var body: some View {
        Form {
            Section("默认样式") {

```

| 样式 | 修饰符 | 外观 |
|------|--------|------|
| `.switch` | `.toggleStyle(.switch)` | iOS 标准开关（默认） |
| `.button` | `.toggleStyle(.button)` | 按钮样式，点击切换 |

## Picker 选择器

`Picker` 用于从一组选项中选择一个值，支持多种展示样式。

### 基本使用

```swift
struct PickerBasicView: View {
    let colors = ["红色", "橙色", "黄色", "绿色", "蓝色"]
    @State private var selectedColor = "红色"

    var body: some View {
        Form {
            Picker("选择颜色", selection: $selectedColor) {
                ForEach(colors, id: \.self) { color in
                    Text(color).tag(color)
                }
            }
        }
    }
}
```

### 使用枚举作为数据源

推荐使用枚举作为 Picker 的数据源，类型更安全：

```swift
enum Difficulty: String, CaseIterable, Identifiable {
    case easy = "简单"
    case medium = "中等"
    case hard = "困难"

    var id: String { rawValue }

    var icon: String {
        switch self {
        case .easy: return "face.smiling"
        case .medium: return "face.dashed"
        case .hard: return "face.dashed.fill"
        }
    }
}

struct EnumPickerView: View {
    @State private var difficulty: Difficulty = .medium

    var body: some View {
        Form {
            Picker("难度", selection: $difficulty) {
                ForEach(Difficulty.allCases) { level in
                    HStack {
                        Image(systemName: level.icon)
                        Text(level.rawValue)
                    }
                    .tag(level)
                }
            }
        }
    }
}
```

### Segmented 样式（分段选择）

```swift
struct SegmentedPickerView: View {
    enum TimeRange: String, CaseIterable {
        case day = "日"
        case week = "周"

```

### 样式对比

| 样式 | 修饰符 | 外观 | 适用场景 |
|------|--------|------|---------|
| `.automatic` | `.pickerStyle(.automatic)` | 跟随容器 | Form 中默认 |
| `.wheel` | `.pickerStyle(.wheel)` | 滚轮选择 | 日期、数量 |
| `.menu` | `.pickerStyle(.menu)` | 下拉菜单 | 选项较多时 |
| `.segmented` | `.pickerStyle(.segmented)` | 分段控件 | 2-5 个选项切换 |
| `.inline` | `.pickerStyle(.inline)` | 展开列表 | 需要看到所有选项 |
| `.navigationLink` | `.pickerStyle(.navigationLink)` | 导航到新页面 | 选项多且需要搜索 |

💡 **提示**：在 Form 中，Picker 默认使用 `.navigationLink` 样式，点击后会跳转到新页面选择。如果选项少于 5 个，考虑使用 `.segmented` 样式更直观。

### 多选 Picker

SwiftUI 原生不支持多选 Picker，但可以自己实现：

```swift
struct MultiPickerView: View {
    let options = ["Swift", "Objective-C", "Python", "JavaScript", "Rust", "Go"]
    @State private var selections: Set<String> = []

    var body: some View {
        Form {
            Section("选择你擅长的语言") {
                ForEach(options, id: \.self) { option in
                    HStack {
                        Text(option)
                        Spacer()
                        if selections.contains(option) {
                            Image(systemName: "checkmark")
                                .foregroundStyle(.blue)
                        }
                    }
                    .contentShape(Rectangle())
                    .onTapGesture {
                        if selections.contains(option) {
                            selections.remove(option)
                        } else {
                            selections.insert(option)
                        }
                    }
                }
            }

            Section("已选择") {
                Text(selections.sorted().joined(separator: "、"))
                    .foregroundStyle(.blue)
            }
        }
    }
}
```

## DatePicker 日期选择器

`DatePicker` 用于选择日期和时间，支持多种样式。

### 基本使用

```swift
struct DatePickerBasicView: View {
    @State private var selectedDate = Date()
```

### 验证状态枚举

更优雅的方式是使用枚举管理验证状态：

```swift
enum ValidationState {
    case unknown
    case valid
    case invalid(String)

    var isValid: Bool {
        if case .valid = self { return true }
        return false
    }

    var message: String? {
        if case .invalid(let msg) = self { return msg }
        return nil
    }
}

struct ValidationStateView: View {
    @State private var password = ""
    @State private var confirmPassword = ""

    var passwordState: ValidationState {
        guard !password.isEmpty else { return .unknown }
        if password.count < 8 { return .invalid("密码至少 8 个字符") }
        if !password.contains(where: { $0.isNumber }) { return .invalid("密码需要包含数字") }
        if !password.contains(where: { $0.isLetter }) { return .invalid("密码需要包含字母") }
        return .valid
    }

    var confirmState: ValidationState {
        guard !confirmPassword.isEmpty else { return .unknown }
        if confirmPassword != password { return .invalid("两次密码不一致") }
        return .valid
    }

    var body: some View {
        Form {
            Section("设置密码") {
                SecureField("密码", text: $password)
                validationLabel(passwordState)

                SecureField("确认密码", text: $confirmPassword)
                validationLabel(confirmState)
            }
        }
    }

    @ViewBuilder
    func validationLabel(_ state: ValidationState) -> some View {
        switch state {
        case .unknown:
            EmptyView()
        case .valid:
            Label("验证通过", systemImage: "checkmark.circle.fill")
                .font(.caption)
                .foregroundStyle(.green)
        case .invalid(let message):
            Label(message, systemImage: "xmark.circle.fill")
                .font(.caption)
                .foregroundStyle(.red)
        }
    }
}
```

⚠️ **警告**：避免在验证逻辑中使用过于复杂的正则表达式，简单的条件判断通常就够用了。复杂的正则难以维护，且容易出错。

### @FocusState 焦点控制

`@FocusState` 可以编程式控制哪个输入框获得焦点：

```swift
enum FocusField: Hashable {
    case username
    case email

    @State private var password = ""

}
```

## 实战：构建完整的注册表单

综合运用本章所有知识，构建一个完整的注册表单：

```swift
import SwiftUI

enum RegistrationField: Hashable {
    case username
    case email
    case password
    case confirmPassword
    case phone
    case verificationCode
}

enum Gender: String, CaseIterable, Identifiable {
    case male = "男"
    case female = "女"
    case other = "其他"

    var id: String { rawValue }
}

class RegistrationViewModel: ObservableObject {
    @Published var username = ""
    @Published var email = ""
    @Published var password = ""
    @Published var confirmPassword = ""
    @Published var phone = ""
    @Published var verificationCode = ""
    @Published var gender: Gender = .male
    @Published var birthday = Date()
    @Published var agreeToTerms = false
    @Published var subscribeNewsletter = true

    @Published var showSuccessAlert = false
    @Published var errorMessage: String?

    var usernameState: ValidationState {
        guard !username.isEmpty else { return .unknown }
        if username.count < 3 { return .invalid("用户名至少 3 个字符") }
        if username.count > 20 { return .invalid("用户名最多 20 个字符") }
        if !username.allSatisfy({ $0.isLetter || $0.isNumber || $0 == "_" }) {
            return .invalid("仅支持字母、数字和下划线")
        }
        return .valid
    }

    var emailState: ValidationState {
        guard !email.isEmpty else { return .unknown }
        let pattern = "[A-Z0-a-z._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,64}"
        if email.range(of: pattern, options: .regularExpression) == nil {
            return .invalid("请输入有效的邮箱地址")
        }
        return .valid
    }

    var passwordState: ValidationState {
        guard !password.isEmpty else { return .unknown }
        if password.count < 8 { return .invalid("密码至少 8 个字符") }
        if !password.contains(where: { $0.isUppercase }) {
            return .invalid("密码需要包含大写字母")
        }
        if !password.contains(where: { $0.isLowercase }) {
            return .invalid("密码需要包含小写字母")
        }
        if !password.contains(where: { $0.isNumber }) {
            return .invalid("密码需要包含数字")
        }
        return .valid
    }

    var confirmState: ValidationState {
        guard !confirmPassword.isEmpty else { return .unknown }
        if confirmPassword != password { return .invalid("两次密码不一致") }
        return .valid
    }

    var phoneState: ValidationState {
        guard !phone.isEmpty else { return .unknown }
        if phone.count != 11 { return .invalid("请输入 11 位手机号") }
        if !phone.allSatisfy({ $0.isNumber }) { return .invalid("手机号只能包含数字") }
        return .valid
    }

    var isFormValid: Bool {
        usernameState.isValid
        && emailState.isValid
        && passwordState.isValid
        && confirmState.isValid
        && phoneState.isValid
        && !verificationCode.isEmpty
        && agreeToTerms
    }

    func submit() {
        guard isFormValid else {
            errorMessage = "请完善所有必填信息"
            return
        }
        errorMessage = nil
        showSuccessAlert = true
        print("注册成功：\(username), \(email), \(phone)")
    }
}

enum ValidationState {
    case unknown
    case valid
    case invalid(String)

    var isValid: Bool {
        if case .valid = self { return true }
        return false
    }
}

struct RegistrationView: View {
    @StateObject private var viewModel = RegistrationViewModel()
    @FocusState private var focusField: RegistrationField?
    @State private var showPassword = false
    @State private var countdown = 0
    @State private var timer: Timer?

    var body: some View {
        NavigationStack {
            Form {
                accountSection
                personalSection
                agreementSection
                submitSection
            }
            .navigationTitle("注册")
            .navigationBarTitleDisplayMode(.inline)
            .scrollDismissesKeyboard(.interactively)
            .toolbar {
                ToolbarItemGroup(placement: .keyboard) {
                    Button("收起") {
                        focusField = nil
                    }
                }
            }
            .alert("注册成功 🎉", isPresented: $viewModel.showSuccessAlert) {
                Button("开始使用") {}
            } message: {
                Text("欢迎加入，\(viewModel.username)！")
            }
        }
    }

    var accountSection: some View {
        Section("账号信息") {
            VStack(alignment: .leading) {
                TextField("用户名", text: $viewModel.username)
                    .focused($focusField, equals: .username)
                    .textInputAutocapitalization(.never)
                    .autocorrectionDisabled()
                    .submitLabel(.next)
                    .onSubmit { focusField = .email }

                validationLabel(viewModel.usernameState)
            }

            VStack(alignment: .leading) {
                TextField("邮箱", text: $viewModel.email)
                    .focused($focusField, equals: .email)
                    .keyboardType(.emailAddress)
                    .textInputAutocapitalization(.never)
                    .autocorrectionDisabled()
                    .submitLabel(.next)
                    .onSubmit { focusField = .password }

                validationLabel(viewModel.emailState)
            }

            VStack(alignment: .leading) {
                HStack {
                    if showPassword {
                        TextField("密码", text: $viewModel.password)
                            .focused($focusField, equals: .password)
                            .submitLabel(.next)
                            .onSubmit { focusField = .confirmPassword }
                    } else {
                        SecureField("密码", text: $viewModel.password)
                            .focused($focusField, equals: .password)
                            .submitLabel(.next)
                            .onSubmit { focusField = .confirmPassword }
                    }

                    Button {
                        showPassword.toggle()
                    } label: {
                        Image(systemName: showPassword ? "eye.slash" : "eye")
                            .foregroundStyle(.secondary)
                    }
                }

                validationLabel(viewModel.passwordState)
            }

            VStack(alignment: .leading) {
                SecureField("确认密码", text: $viewModel.confirmPassword)
                    .focused($focusField, equals: .confirmPassword)
                    .submitLabel(.next)
                    .onSubmit { focusField = .phone }

                validationLabel(viewModel.confirmState)
            }
        }
    }

    var personalSection: some View {
        Section("个人信息") {
            VStack(alignment: .leading) {
                TextField("手机号", text: $viewModel.phone)
                    .focused($focusField, equals: .phone)
                    .keyboardType(.phonePad)
                    .submitLabel(.next)
                    .onSubmit { focusField = .verificationCode }

                validationLabel(viewModel.phoneState)
            }

            HStack {
                TextField("验证码", text: $viewModel.verificationCode)
                    .focused($focusField, equals: .verificationCode)
                    .keyboardType(.numberPad)

                Button(countdown > 0 ? "\(countdown)s" : "获取验证码") {
                    sendVerificationCode()
                }
                .disabled(countdown > 0 || !viewModel.phoneState.isValid)
            }

            Picker("性别", selection: $viewModel.gender) {
                ForEach(Gender.allCases) { g in
                    Text(g.rawValue).tag(g)
                }
            }

            DatePicker("生日", selection: $viewModel.birthday, in: ...Date(), displayedComponents: .date)
        }
    }

    var agreementSection: some View {
        Section {
            Toggle(isOn: $viewModel.agreeToTerms) {
                VStack(alignment: .leading) {
                    Text("同意用户协议")
                    Text("我已阅读并同意《用户协议》和《隐私政策》")
                        .font(.caption)
                        .foregroundStyle(.secondary)
                }
            }

            Toggle("订阅新闻和优惠", isOn: $viewModel.subscribeNewsletter)
        }
    }

    var submitSection: some View {
        Section {
            if let errorMessage = viewModel.errorMessage {
                Label(errorMessage, systemImage: "exclamationmark.triangle.fill")
                    .foregroundStyle(.red)
                    .font(.subheadline)
            }

            Button {
                viewModel.submit()
            } label: {
                Text("注册")
                    .font(.headline)
                    .frame(maxWidth: .infinity)
            }
            .disabled(!viewModel.isFormValid)
            .buttonStyle(.borderedProminent)
            .tint(viewModel.isFormValid ? .blue : .gray)
        }
    }

    @ViewBuilder
    func validationLabel(_ state: ValidationState) -> some View {
        switch state {
        case .unknown:
            EmptyView()
        case .valid:
            Label("验证通过", systemImage: "checkmark.circle.fill")
                .font(.caption)
                .foregroundStyle(.green)
        case .invalid(let message):
            Label(message, systemImage: "xmark.circle.fill")
                .font(.caption)
                .foregroundStyle(.red)
        }
    }

    func sendVerificationCode() {
        countdown = 60
        timer = Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { _ in
            countdown -= 1
            if countdown <= 0 {
                timer?.invalidate()
                timer = nil
            }
        }
    }
}
```

## 输入组件速查表

| 组件 | 用途 | 数据绑定 | 常用修饰符 |
|------|------|---------|-----------|
| `TextField` | 单行文本 | `@Binding<String>` | `.keyboardType()`, `.textInputAutocapitalization()` |
| `SecureField` | 密码输入 | `@Binding<String>` | 用法同 TextField |
| `TextEditor` | 多行文本 | `@Binding<String>` | `.scrollContentBackground()`, `.frame()` |
| `Toggle` | 开关切换 | `@Binding<Bool>` | `.tint()`, `.toggleStyle()` |
| `Picker` | 选择器 | `@Binding<Hashable>` | `.pickerStyle()`, `.labelsHidden()` |
| `DatePicker` | 日期选择 | `@Binding<Date>` | `.datePickerStyle()`, `.displayedComponents()` |
| `Slider` | 滑块 | `@Binding<Double>` | `.tint()`, `in:`, `step:` |
| `Stepper` | 步进器 | `@Binding<数值>` | `in:`, `step:` |

## 小结

本章我们学习了 SwiftUI 中所有常用输入组件和表单构建的完整知识：

| 知识点 | 核心内容 |
|--------|---------|
| **Form 容器** | 基础用法、Section 分组、样式选择 |
| **TextField** | 键盘类型、自动大写、提交回调、样式 |
| **SecureField** | 密码输入、显示/隐藏切换 |
| **TextEditor** | 多行输入、字符计数、样式定制 |
| **Toggle** | 开关切换、自定义标签、样式 |
| **Picker** | Wheel/Menu/Segmented 样式、枚举数据源、多选 |
| **DatePicker** | 选择模式、范围限制、日期格式化 |
| **Slider** | 连续值调整、步进值、编辑回调 |
| **Stepper** | 离散值调整、范围限制 |
| **输入验证** | 实时验证、提交验证、验证状态枚举 |
| **键盘管理** | @FocusState、键盘工具栏、收起键盘 |

🔑 **核心记忆点**：
1. Form + Section 是构建设置页面的最佳组合
2. TextField 配合 `.keyboardType()` 和 `.textInputAutocapitalization()` 提升输入体验
3. 用枚举管理验证状态，代码更清晰
4. `@FocusState` 实现焦点跳转和键盘管理
5. `.scrollDismissesKeyboard(.interactively)` 让滚动时交互式收起键盘
6. 复杂表单用 `ObservableObject` 管理数据和验证逻辑
