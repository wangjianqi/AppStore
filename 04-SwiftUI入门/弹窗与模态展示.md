# 弹窗与模态展示

> 🎯 **本章目标**：掌握 SwiftUI 中所有模态展示方式的使用方法，学会在合适的场景选择合适的弹窗类型，处理弹窗的数据传递和生命周期。

---

## .sheet 模态弹窗

`.sheet` 是 SwiftUI 中最常用的模态展示方式，用于从底部滑出一个新页面。

### 基本使用

```swift
struct SheetBasicView: View {
    @State private var showSheet = false

    var body: some View {
        Button("显示 Sheet") {
            showSheet = true
        }
        .sheet(isPresented: $showSheet) {
            Text("这是一个 Sheet 弹窗")
                .font(.title2)
                .presentationDragIndicator(.visible)
        }
    }
}
```

💡 **提示**：`.presentationDragIndicator(.visible)` 在 Sheet 顶部显示一个拖拽指示条，提示用户可以下拉关闭。iOS 16+ 可用。

### 使用 Item 绑定

当 Sheet 的展示依赖于某个数据项时，使用 `item` 绑定更优雅：

```swift
struct SheetItemView: View {
    @State private var selectedItem: Item?

    struct Item: Identifiable {
        let id = UUID()
        let name: String
        let description: String
    }

    let items = [
        Item(name: "Swift", description: "Apple 的现代编程语言"),
        Item(name: "SwiftUI", description: "声明式 UI 框架"),
        Item(name: "UIKit", description: "命令式 UI 框架")
    ]

    var body: some View {
        List(items) { item in
            Button(item.name) {
                selectedItem = item
            }
        }
        .sheet(item: $selectedItem) { item in
            VStack(spacing: 16) {
                Text(item.name)
                    .font(.largeTitle)
                    .bold()
                Text(item.description)
                    .foregroundStyle(.secondary)
                Button("关闭") {
                    selectedItem = nil
                }
                .buttonStyle(.bordered)
            }
            .padding()
            .presentationDragIndicator(.visible)
        }
    }
}
```

### presentationDetents 控制高度

iOS 16 引入了 `presentationDetents`，可以精确控制 Sheet 的高度：

```swift
struct DetentsSheetView: View {
    @State private var showSheet = false
    @State private var selectedDetent: PresentationDetent = .medium

    var body: some View {
        VStack(spacing: 16) {
            Button("半屏 Sheet") {
                showSheet = true
            }

            Button("自定义高度 Sheet") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet) {
            VStack(spacing: 20) {
                Text("Sheet 内容")
                    .font(.title2.bold())

                Text("可以拖拽调整高度")
                    .foregroundStyle(.secondary)

                ForEach(1...10, id: \.self) { i in
                    Text("第 \(i) 行内容")
                }
            }
            .padding()
            .presentationDetents([.medium, .large], selection: $selectedDetent)
            .presentationDragIndicator(.visible)
        }
    }
}
```

#### 自定义高度

```swift
struct CustomDetentView: View {
    @State private var showSheet = false

    var body: some View {
        Button("自定义高度 Sheet") {
            showSheet = true
        }
        .sheet(isPresented: $showSheet) {
            VStack {
                Text("自定义 30% 高度")
                    .font(.title2)
            }
            .padding()
            .presentationDetents([.fraction(0.3)])
            .presentationDragIndicator(.visible)
        }
    }
}
```

| Detent 类型 | 示例 | 说明 |
|-------------|------|------|
| `.medium` | `.medium` | 屏幕高度的一半 |
| `.large` | `.large` | 全屏高度 |
| `.fraction(0.x)` | `.fraction(0.3)` | 屏幕高度的百分比 |
| `.height(300)` | `.height(300)` | 固定高度（pt） |

💡 **提示**：提供多个 detent（如 `[.medium, .large]`）时，用户可以在不同高度之间拖拽切换，体验非常好。

### Sheet 的其他修饰符

```swift
struct SheetModifiersView: View {
    @State private var showSheet = false

    var body: some View {
        Button("显示 Sheet") {
            showSheet = true
        }
        .sheet(isPresented: $showSheet) {
            SheetContent()
                .presentationDetents([.medium, .large])
                .presentationDragIndicator(.visible)
                .presentationBackgroundInteraction(.enabled)
                .presentationCornerRadius(20)
                .interactiveDismissDisabled(false)
        }
    }
}

struct SheetContent: View {
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        NavigationStack {
            List {
                ForEach(1...20, id: \.self) { i in
                    Text("第 \(i) 行")
                }
            }
            .navigationTitle("Sheet 内容")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Button("完成") {
                        dismiss()
                    }
                }
            }
        }
    }
}
```

| 修饰符 | 说明 | iOS 版本 |
|--------|------|---------|
| `.presentationDetents()` | 控制高度 | iOS 16+ |
| `.presentationDragIndicator()` | 拖拽指示条 | iOS 16+ |
| `.presentationBackgroundInteraction()` | 背景交互 | iOS 16.4+ |
| `.presentationCornerRadius()` | 圆角大小 | iOS 16.4+ |
| `.interactiveDismissDisabled()` | 禁止下拉关闭 | iOS 15+ |

⚠️ **警告**：`.interactiveDismissDisabled(true)` 会禁止用户下拉关闭 Sheet。仅在表单未保存等必要场景使用，否则会严重影响用户体验。

### Sheet 数据传递

#### 使用 Binding 传递数据

```swift
struct SheetBindingView: View {
    @State private var showSheet = false
    @State private var text = "初始文本"

    var body: some View {
        VStack(spacing: 20) {
            Text("当前文本：\(text)")
                .font(.headline)

            Button("编辑") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet) {
            SheetEditor(text: $text)
                .presentationDetents([.medium])
                .presentationDragIndicator(.visible)
        }
    }
}

struct SheetEditor: View {
    @Binding var text: String
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        VStack(spacing: 16) {
            Text("编辑文本")
                .font(.headline)

            TextField("输入文本", text: $text)
                .textFieldStyle(.roundedBorder)
                .padding(.horizontal)

            Button("完成") {
                dismiss()
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}
```

💡 **提示**：使用 `@Binding` 传递数据时，Sheet 中的修改会实时反映到父视图。如果需要"确认后才修改"，应该传递值的副本，在关闭时再写回。

#### 使用 onDismiss 回调

```swift
struct SheetOnDismissView: View {
    @State private var showSheet = false
    @State private var result = ""

    var body: some View {
        VStack(spacing: 20) {
            Text("结果：\(result)")
                .font(.headline)

            Button("选择颜色") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet, onDismiss: {
            print("Sheet 已关闭，结果：\(result)")
        }) {
            ColorPickerSheet(result: $result)
                .presentationDetents([.medium])
                .presentationDragIndicator(.visible)
        }
    }
}

struct ColorPickerSheet: View {
    @Binding var result: String
    @Environment(\.dismiss) private var dismiss

    let colors = ["红色", "橙色", "黄色", "绿色", "蓝色"]

    var body: some View {
        VStack(spacing: 16) {
            Text("选择颜色")
                .font(.headline)

            ForEach(colors, id: \.self) { color in
                Button(color) {
                    result = color
                    dismiss()
                }
            }
        }
        .padding()
    }
}
```

## .fullScreenCover 全屏模态

`.fullScreenCover` 以全屏方式展示内容，没有下拉关闭的手势，适合登录、视频播放等沉浸式场景。

### 基本使用

```swift
struct FullScreenCoverView: View {
    @State private var showCover = false

    var body: some View {
        Button("全屏展示") {
            showCover = true
        }
        .fullScreenCover(isPresented: $showCover) {
            FullScreenContent()
        }
    }
}

struct FullScreenContent: View {
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        NavigationStack {
            ZStack {
                Color.indigo.ignoresSafeArea()

                VStack(spacing: 20) {
                    Image(systemName: "play.circle.fill")
                        .font(.system(size: 80))
                        .foregroundStyle(.white)

                    Text("全屏内容")
                        .font(.largeTitle)
                        .foregroundStyle(.white)

                    Button("关闭") {
                        dismiss()
                    }
                    .font(.headline)
                    .foregroundStyle(.indigo)
                    .padding(.horizontal, 32)
                    .padding(.vertical, 12)
                    .background(.white)
                    .clipShape(Capsule())
                }
            }
            .navigationTitle("全屏")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Button("关闭") {
                        dismiss()
                    }
                    .foregroundStyle(.white)
                }
            }
            .toolbarBackground(.hidden, for: .navigationBar)
        }
    }
}
```

### sheet vs fullScreenCover

| 特性 | .sheet | .fullScreenCover |
|------|--------|-----------------|
| 展示方式 | 从底部滑出（部分屏幕） | 全屏覆盖 |
| 下拉关闭 | 默认支持 | 不支持 |
| Detents | 支持 | 不支持 |
| 适用场景 | 编辑、选择、详情 | 登录、视频、引导页 |
| 视觉层级 | 可以看到底层 | 完全覆盖底层 |

⚠️ **警告**：`fullScreenCover` 不支持 `presentationDetents`，也不支持下拉关闭。用户只能通过你提供的按钮关闭，所以一定要提供明显的关闭入口！

## .alert 警告弹窗

`.alert` 用于显示警告信息，通常用于确认操作、提示错误等。

### 基本使用

```swift
struct AlertBasicView: View {
    @State private var showAlert = false

    var body: some View {
        Button("显示 Alert") {
            showAlert = true
        }
        .alert("提示", isPresented: $showAlert) {
            Button("好的") {}
        } message: {
            Text("这是一个警告弹窗")
        }
    }
}
```

### 多按钮 Alert

```swift
struct MultiButtonAlertView: View {
    @State private var showDeleteAlert = false
    @State private var showSaveAlert = false

    var body: some View {
        VStack(spacing: 20) {
            Button("删除操作") {
                showDeleteAlert = true
            }
            .foregroundStyle(.red)

            Button("保存操作") {
                showSaveAlert = true
            }
        }
        .alert("确认删除", isPresented: $showDeleteAlert) {
            Button("取消", role: .cancel) {}
            Button("删除", role: .destructive) {
                print("已删除")
            }
        } message: {
            Text("删除后无法恢复，确定要继续吗？")
        }
        .alert("未保存的更改", isPresented: $showSaveAlert) {
            Button("放弃更改", role: .destructive) {
                print("已放弃")
            }
            Button("保存", role: .none) {
                print("已保存")
            }
            Button("取消", role: .cancel) {}
        } message: {
            Text("你有未保存的更改，要如何处理？")
        }
    }
}
```

### Button 角色

| 角色 | 说明 | 按钮颜色 |
|------|------|---------|
| `.cancel` | 取消操作（默认） | 蓝色/粗体 |
| `.destructive` | 破坏性操作 | 红色 |
| `.none` | 普通操作 | 蓝色 |

💡 **提示**：`.cancel` 角色的按钮在 Alert 中会自动加粗显示，且只能有一个。`.destructive` 角色的按钮会显示为红色，用于删除等危险操作。

### 使用 Item 绑定 Alert

```swift
struct AlertItemView: View {
    @State private var error: ErrorInfo?

    struct ErrorInfo: Identifiable {
        let id = UUID()
        let title: String
        let message: String
    }

    var body: some View {
        VStack(spacing: 16) {
            Button("网络错误") {
                error = ErrorInfo(title: "网络错误", message: "请检查网络连接后重试")
            }
            Button("权限错误") {
                error = ErrorInfo(title: "权限不足", message: "请在设置中开启相机权限")
            }
        }
        .alert(item: $error) { error in
            Alert(title: Text(error.title), message: Text(error.message), dismissButton: .default(Text("知道了")))
        }
    }
}
```

⚠️ **警告**：iOS 15 的新版 `.alert` API 不再使用 `Alert` 结构体，而是使用 ViewBuilder 闭包。旧 API 已废弃，请使用新写法。

## .confirmationDialog 确认对话框

`.confirmationDialog` 是 iOS 15 引入的替代 `.actionSheet` 的新 API，从底部弹出操作列表。

### 基本使用

```swift
struct ConfirmationDialogBasicView: View {
    @State private var showDialog = false
    @State private var selectedAction = ""

    var body: some View {
        VStack(spacing: 20) {
            Button("更多操作") {
                showDialog = true
            }

            if !selectedAction.isEmpty {
                Text("你选择了：\(selectedAction)")
                    .foregroundStyle(.blue)
            }
        }
        .confirmationDialog("选择操作", isPresented: $showDialog, titleVisibility: .visible) {
            Button("复制") {
                selectedAction = "复制"
            }
            Button("移动") {
                selectedAction = "移动"
            }
            Button("分享") {
                selectedAction = "分享"
            }
            Button("删除", role: .destructive) {
                selectedAction = "删除"
            }
            Button("取消", role: .cancel) {}
        } message: {
            Text("请选择要执行的操作")
        }
    }
}
```

### 使用 Item 绑定

```swift
struct ConfirmationDialogItemView: View {
    @State private var selectedItem: PhotoItem?

    struct PhotoItem: Identifiable {
        let id = UUID()
        let name: String
    }

    let photos = [
        PhotoItem(name: "风景照.jpg"),
        PhotoItem(name: "自拍照.png"),
        PhotoItem(name: "美食照.heic")
    ]

    var body: some View {
        List(photos) { photo in
            Button(photo.name) {
                selectedItem = photo
            }
        }
        .confirmationDialog(
            "操作 \"\(selectedItem?.name ?? "")\"",
            isPresented: .init(
                get: { selectedItem != nil },
                set: { if !$0 { selectedItem = nil } }
            )
        ) {
            Button("分享") { sharePhoto() }
            Button("收藏") { favoritePhoto() }
            Button("删除", role: .destructive) { deletePhoto() }
            Button("取消", role: .cancel) {}
        } message: {
            Text("选择对这张照片的操作")
        }
    }

    func sharePhoto() { print("分享") }
    func favoritePhoto() { print("收藏") }
    func deletePhoto() { print("删除") }
}
```

### confirmationDialog vs alert

| 特性 | .alert | .confirmationDialog |
|------|--------|-------------------|
| 展示位置 | 屏幕中央 | 屏幕底部 |
| 按钮排列 | 竖排 | 竖排（底部列表） |
| iPad 适配 | 弹出框 | 弹出框 |
| 适用场景 | 确认/提示信息 | 多操作选择 |
| 视觉风格 | 卡片式 | 列表式 |

💡 **提示**：`confirmationDialog` 在 iPhone 上从底部弹出操作列表，在 iPad 上会以 popover 形式展示。这是 Apple 推荐的替代 `actionSheet` 的方式。

## .popover 气泡弹窗

`.popover` 以气泡形式展示内容，在 iPad 上效果最好，iPhone 上会退化为全屏 Sheet。

### 基本使用

```swift
struct PopoverBasicView: View {
    @State private var showPopover = false

    var body: some View {
        Button("显示 Popover") {
            showPopover = true
        }
        .popover(isPresented: $showPopover) {
            VStack(spacing: 12) {
                Text("气泡弹窗")
                    .font(.headline)
                Text("在 iPad 上以气泡形式展示")
                    .font(.caption)
                    .foregroundStyle(.secondary)
                Divider()
                Button("关闭") {
                    showPopover = false
                }
            }
            .padding()
            .frame(minWidth: 200)
            .presentationCompactAdaptation(.popover)
        }
    }
}
```

### 指定锚点和箭头方向

```swift
struct PopoverAnchorView: View {
    @State private var showInfo = false

    var body: some View {
        HStack {
            Text("重要信息")
                .font(.headline)

            Button {
                showInfo = true
            } label: {
                Image(systemName: "info.circle")
                    .foregroundStyle(.blue)
            }
            .popover(isPresented: $showInfo, attachmentAnchor: .point(.trailing), arrowEdge: .trailing) {
                VStack(alignment: .leading, spacing: 8) {
                    Label("提示", systemImage: "lightbulb.fill")
                        .font(.headline)
                        .foregroundStyle(.yellow)
                    Text("这是一条重要的提示信息，帮助你理解这个功能。")
                        .font(.subheadline)
                }
                .padding()
                .frame(width: 250)
            }
        }
        .padding()
    }
}
```

### 使用 Item 绑定

```swift
struct PopoverItemView: View {
    @State private var selectedItem: ToolItem?

    struct ToolItem: Identifiable {
        let id = UUID()
        let name: String
        let icon: String
        let description: String
    }

    let tools = [
        ToolItem(name: "画笔", icon: "paintbrush.fill", description: "自由绘制图形"),
        ToolItem(name: "橡皮", icon: "eraser.fill", description: "擦除绘制内容"),
        ToolItem(name: "文字", icon: "textformat", description: "添加文字标注")
    ]

    var body: some View {
        HStack(spacing: 20) {
            ForEach(tools) { tool in
                Button {
                    selectedItem = tool
                } label: {
                    Image(systemName: tool.icon)
                        .font(.title2)
                        .frame(width: 44, height: 44)
                }
                .popover(item: $selectedItem) { tool in
                    VStack(alignment: .leading, spacing: 8) {
                        HStack {
                            Image(systemName: tool.icon)
                            Text(tool.name)
                                .font(.headline)
                        }
                        Text(tool.description)
                            .font(.subheadline)
                            .foregroundStyle(.secondary)
                    }
                    .padding()
                }
            }
        }
    }
}
```

| 参数 | 说明 |
|------|------|
| `attachmentAnchor` | 弹窗锚点位置 |
| `arrowEdge` | 箭头指向的边 |
| `.point(.topLeading)` | 锚点在左上角 |
| `.point(.trailing)` | 锚点在右侧 |
| `.rect(.bounds)` | 锚点在整个视图范围 |

⚠️ **警告**：在 iPhone 上，`.popover` 默认会退化为全屏 Sheet。使用 `.presentationCompactAdaptation(.popover)` 可以在 iPhone 上也保持气泡样式（iOS 16.4+）。

## .actionSheet（已废弃）

`.actionSheet` 在 iOS 15 中已被废弃，应迁移到 `.confirmationDialog`。

### 迁移对照

```swift
// ❌ 旧写法（已废弃）
.actionSheet("标题", isPresented: $showActionSheet) {
    Button("操作1") { }
    Button("取消", role: .cancel) { }
}

// ✅ 新写法（推荐）
.confirmationDialog("标题", isPresented: $showConfirmationDialog) {
    Button("操作1") { }
    Button("取消", role: .cancel) { }
}
```

| 旧 API | 新 API | 说明 |
|---------|--------|------|
| `.actionSheet` | `.confirmationDialog` | 底部操作列表 |
| `ActionSheet` 结构体 | ViewBuilder 闭包 | 构建方式 |
| 不支持 titleVisibility | 支持 `titleVisibility` | 控制标题可见性 |

💡 **提示**：如果你的项目最低支持 iOS 15，请全部使用 `.confirmationDialog`。`.actionSheet` 虽然还能用，但未来可能被移除。

## 弹窗的数据传递

### Binding 传递

最直接的方式，适合父子视图之间的双向数据传递：

```swift
struct BindingTransferView: View {
    @State private var showEditor = false
    @State private var profile = UserProfile(name: "张三", age: 25)

    struct UserProfile {
        var name: String
        var age: Int
    }

    var body: some View {
        VStack(spacing: 16) {
            Text("姓名：\(profile.name)")
            Text("年龄：\(profile.age)")
            Button("编辑资料") {
                showEditor = true
            }
        }
        .sheet(isPresented: $showEditor) {
            ProfileEditor(profile: $profile)
                .presentationDetents([.medium])
                .presentationDragIndicator(.visible)
        }
    }
}

struct ProfileEditor: View {
    @Binding var profile: BindingTransferView.UserProfile
    @Environment(\.dismiss) private var dismiss

    var body: some View {
        NavigationStack {
            Form {
                TextField("姓名", text: $profile.name)
                Stepper("年龄：\(profile.age)", value: $profile.age, in: 1...120)
            }
            .navigationTitle("编辑资料")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Button("完成") { dismiss() }
                }
            }
        }
    }
}
```

### Environment 传递

适合只读数据或全局状态的传递：

```swift
struct EnvironmentTransferView: View {
    @State private var showSheet = false
    @State private var themeColor: Color = .blue

    var body: some View {
        VStack(spacing: 16) {
            Circle()
                .fill(themeColor)
                .frame(width: 60, height: 60)

            Button("选择主题色") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet) {
            ThemeColorPicker(selectedColor: $themeColor)
                .presentationDetents([.medium])
                .presentationDragIndicator(.visible)
        }
    }
}

struct ThemeColorPicker: View {
    @Binding var selectedColor: Color
    @Environment(\.dismiss) private var dismiss

    let colors: [(String, Color)] = [
        ("蓝色", .blue),
        ("绿色", .green),
        ("橙色", .orange),
        ("紫色", .purple),
        ("粉色", .pink)
    ]

    var body: some View {
        VStack(spacing: 16) {
            Text("选择主题色")
                .font(.headline)

            HStack(spacing: 12) {
                ForEach(colors, id: \.0) { name, color in
                    Button {
                        selectedColor = color
                        dismiss()
                    } label: {
                        Circle()
                            .fill(color)
                            .frame(width: 44, height: 44)
                            .overlay {
                                if selectedColor == color {
                                    Image(systemName: "checkmark")
                                        .foregroundStyle(.white)
                                        .bold()
```

### onDismiss 回调

适合不需要实时同步，只在关闭时获取结果的场景：

```swift
struct OnDismissTransferView: View {
    @State private var showPicker = false
    @State private var selectedCity = "北京"

    var body: some View {
        VStack(spacing: 16) {
            Text("选择的城市：\(selectedCity)")
                .font(.title3)

            Button("选择城市") {
                showPicker = true
            }
        }
        .sheet(isPresented: $showPicker, onDismiss: {
            print("用户选择了：\(selectedCity)")
        }) {
            CityPicker(selectedCity: $selectedCity)
                .presentationDetents([.medium])
                .presentationDragIndicator(.visible)
        }
    }
}

struct CityPicker: View {
    @Binding var selectedCity: String
    @Environment(\.dismiss) private var dismiss

    let cities = ["北京", "上海", "广州", "深圳", "杭州", "成都"]

    var body: some View {
        NavigationStack {
            List(cities, id: \.self) { city in
                Button {
                    selectedCity = city
                    dismiss()
                } label: {
                    HStack {
                        Text(city)
                        Spacer()
                        if selectedCity == city {
                            Image(systemName: "checkmark")
                                .foregroundStyle(.blue)
                        }
                    }
                }
            }
            .navigationTitle("选择城市")
            .navigationBarTitleDisplayMode(.inline)
        }
    }
}
```

### 数据传递方式对比

| 方式 | 方向 | 适用场景 | 实时性 |
|------|------|---------|--------|
| `@Binding` | 双向 | 编辑表单、实时同步 | 实时 |
| `@Environment` | 单向（只读） | 主题、配置等全局状态 | 只读 |
| `onDismiss` | 关闭时回调 | 只关心最终结果 | 关闭时 |
| `item` 绑定 | 双向 | 展示特定数据 | 关闭时 |

💡 **提示**：如果需要"确认后才修改"的模式，可以在弹窗内部维护一个副本，只在用户点击"确认"时才写回 Binding。

```swift
    @Published var hasUnsavedChanges = false

struct UnsavedEditor: View {

    @Environment(\.dismiss) private var dismiss
    @State private var showDiscardAlert = false

                                showDiscardAlert = true
                            } else {
                                dismiss()
                            }
                        }

                        Button("保存") {

                        }
                        .disabled(!state.hasUnsavedChanges)
                    }

                    Button("放弃", role: .destructive) {
                        dismiss()
                    }
                } message: {

                }
        }

        print("保存内容：\(state.text)")
        state.hasUnsavedChanges = false
        dismiss()
    }
```

```swift
struct CustomAlertModifier: ViewModifier {
    @Binding var isPresented: Bool
    let title: String
    let message: String
    let confirmTitle: String
    let onConfirm: () -> Void

    func body(content: Content) -> some View {
        ZStack {
            content
                .disabled(isPresented)

            if isPresented {
                CustomAlert(
                    title: title,
                    message: message,
                    confirmTitle: confirmTitle,
                    cancelTitle: "取消",
                    onConfirm: {
                        isPresented = false
                        onConfirm()
                    },
                    onCancel: {
                        isPresented = false
                    }
                )
                .transition(.opacity)
            }
        }
        .animation(.easeInOut(duration: 0.2), value: isPresented)
    }
}

extension View {
    func customAlert(
        isPresented: Binding<Bool>,
        title: String,
        message: String,
        confirmTitle: String = "确定",
        onConfirm: @escaping () -> Void = {}
    ) -> some View {
        modifier(CustomAlertModifier(
            isPresented: isPresented,
            title: title,
            message: message,
            confirmTitle: confirmTitle,
            onConfirm: onConfirm
        ))
    }
}
```

### Toast 提示组件

```swift
struct ToastModifier: ViewModifier {
    @Binding var isPresented: Bool
    let message: String
    let icon: String

    init(isPresented: Binding<Bool>, message: String, icon: String = "checkmark.circle.fill") {
        self._isPresented = isPresented
        self.message = message
        self.icon = icon
    }

    func body(content: Content) -> some View {
        content
            .overlay(alignment: .top) {
                if isPresented {
                    HStack(spacing: 8) {
                        Image(systemName: icon)
                            .foregroundStyle(.green)
                        Text(message)
                            .font(.subheadline)
                    }
                    .padding(.horizontal, 16)
                    .padding(.vertical, 10)
                    .background(.regularMaterial)
                    .clipShape(Capsule())
                    .shadow(color: .black.opacity(0.1), radius: 8)
                    .padding(.top, 8)
                    .transition(.move(edge: .top).combined(with: .opacity))
                    .onAppear {
                        DispatchQueue.main.asyncAfter(deadline: .now() + 2) {
                            withAnimation {
                                isPresented = false
                            }
                        }
                    }
                }
            }
            .animation(.spring(response: 0.3), value: isPresented)
    }
}

extension View {
    func toast(isPresented: Binding<Bool>, message: String, icon: String = "checkmark.circle.fill") -> some View {
        modifier(ToastModifier(isPresented: isPresented, message: message, icon: icon))
    }
}
```

## 弹窗选择指南

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| 编辑表单 | `.sheet` + `.medium` | 半屏即可，不离开上下文 |
| 登录/引导页 | `.fullScreenCover` | 沉浸式体验 |
| 确认操作 | `.alert` | 简单明了 |
| 多操作选择 | `.confirmationDialog` | 底部列表更自然 |
| iPad 工具提示 | `.popover` | 气泡指向来源 |
| 操作反馈 | 自定义 Toast | 轻量、不打断 |
| 删除确认 | `.confirmationDialog` + `.destructive` | 明确的危险操作提示 |

🔑 **核心记忆点**：
1. `.sheet` + `presentationDetents` 是最灵活的模态方式
2. `.alert` 用于确认/提示，`.confirmationDialog` 用于多操作选择
3. 用 `@Environment(\.dismiss)` 关闭弹窗，不再用 `isPresented`
4. 避免嵌套 Sheet，改用 NavigationStack 导航
5. 自定义弹窗用 ViewModifier 封装，复用更方便
6. 危险操作（删除等）必须使用 `.destructive` 角色和确认弹窗
