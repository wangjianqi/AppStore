## List 列表

List 是 SwiftUI 中用来展示**滚动列表**的容器，类似于 UIKit 中的 UITableView，但使用起来简单得多。

### 基本列表

最简单的 List 就是把几个视图放进去：

```swift
struct BasicListView: View {
    var body: some View {
        List {
            Text("第一项")
            Text("第二项")
            Text("第三项")
        }
    }
}
```

运行效果：一个带分隔线的滚动列表，每一行显示一行文字。

> 💡 **提示**：List 会自动处理滚动、分隔线、行点击高亮等效果，你只需要关注每一行的内容即可。

### 自定义行

实际开发中，列表的每一行通常不会只是一行文字，而是更复杂的布局。我们可以把每一行抽成一个独立的 View：

```swift
struct MessageRow: View {
    let name: String
    let message: String
    let time: String

    var body: some View {
        HStack {
            Circle()
                .fill(Color.blue)
                .frame(width: 44, height: 44)
                .overlay(
                    Text(String(name.prefix(1)))
                        .foregroundColor(.white)
                        .fontWeight(.semibold)
                )

            VStack(alignment: .leading, spacing: 4) {
                HStack {
                    Text(name)
                        .fontWeight(.semibold)
                    Spacer()
                    Text(time)
                        .font(.caption)
                        .foregroundColor(.secondary)
                }
                Text(message)
                    .font(.subheadline)
                    .foregroundColor(.secondary)
                    .lineLimit(1)
            }
        }
        .padding(.vertical, 4)
    }
}

struct CustomRowListView: View {
    var body: some View {
        List {
            MessageRow(name: "小明", message: "今天天气真好，一起出去散步吧！", time: "10:30")
            MessageRow(name: "小红", message: "SwiftUI 学得怎么样了？", time: "09:15")
            MessageRow(name: "小刚", message: "周末有空一起打球吗？", time: "昨天")
        }
    }
}
```

### 分组列表

使用 `Section` 可以把列表项分组，每组可以有自己的标题和页脚：

```swift
struct SectionListView: View {
    var body: some View {
        List {
            Section("常用设置") {
                Label("飞行模式", systemImage: "airplane")
                Label("Wi-Fi", systemImage: "wifi")
                Label("蓝牙", systemImage: "bluetooth")
            }

            Section("通知与专注") {
                Label("通知", systemImage: "bell")
                Label("专注模式", systemImage: "moon")
            }

            Section("通用") {
                Label("通用", systemImage: "gear")
                Label("控制中心", systemImage: "switch.2")
                Label("显示与亮度", systemImage: "sun.max")
            }
        }
    }
}
```

| Section 特性 | 说明 |
|-------------|------|
| `Section("标题")` | 字符串标题，显示为分组头 |
| `Section(header: Text("标题"))` | 自定义头部视图 |
| `Section(header:footer:)` | 同时自定义头部和底部 |
| 分组样式 | 配合 `.listStyle()` 使用效果更佳 |

> 💡 **提示**：Section 的分组效果和 `.listStyle()` 密切相关。使用 `.insetGrouped` 样式时，分组会有圆角背景，看起来更像 iOS 设置页面。

## ForEach 动态列表

静态列表（手写每一行）适合行数固定的场景。当数据是动态的时候，需要用 `ForEach` 来遍历数据生成列表行。

### 遍历数据

ForEach 的基本用法：

```swift
struct FruitListView: View {
    let fruits = ["苹果", "香蕉", "橙子", "葡萄", "西瓜"]

    var body: some View {
        List {
            ForEach(fruits, id: \.self) { fruit in
                Text(fruit)
            }
        }
    }
}
```

**Identifiable 协议**：更推荐的方式是让数据模型遵循 `Identifiable` 协议，这样就不需要手动指定 `id`：

```swift
struct Student: Identifiable {
    let id = UUID()
    let name: String
    let score: Int
}

struct StudentListView: View {
    let students = [
        Student(name: "小明", score: 95),
        Student(name: "小红", score: 88),
        Student(name: "小刚", score: 72),
        Student(name: "小美", score: 91)
    ]

    var body: some View {
        List {
            ForEach(students) { student in
                HStack {
                    Text(student.name)
                    Spacer()
                    Text("\(student.score) 分")
                        .foregroundColor(student.score >= 90 ? .green : .orange)
                }
            }
        }
    }
}
```

| 方式 | 写法 | 适用场景 |
|------|------|---------|
| `id: \.self` | `ForEach(items, id: \.self)` | 数据是简单类型（String、Int 等），且值唯一 |
| `Identifiable` 协议 | `ForEach(items)` | 数据是自定义模型，推荐方式 |
| `id: \.属性名` | `ForEach(items, id: \.name)` | 数据有某个唯一属性但没遵循 Identifiable |

⚠️ **注意**：使用 `id: \.self` 时，数据值必须唯一！如果有两个相同的字符串，SwiftUI 可能无法正确区分它们，导致列表更新时出现异常。

### 删除与移动

ForEach 配合修饰符可以实现**滑动删除**和**拖拽排序**：

```swift
import SwiftUI

struct EditableListView: View {
    @State private var items = [
        "学习 SwiftUI",
        "完成项目",
        "写技术博客",
        "复习算法",
        "锻炼身体"
    ]

    var body: some View {
        NavigationStack {
            List {
                ForEach(items, id: \.self) { item in
                    Text(item)
                }
                .onDelete { indexSet in
                    items.remove(atOffsets: indexSet)
                }
                .onMove { fromOffsets, toOffset in
                    items.move(fromOffsets: fromOffsets, toOffset: toOffset)
                }
            }
            .navigationTitle("待办事项")
            .toolbar {
                EditButton()
            }
        }
    }
}

#Preview {
    EditableListView()
}
```

| 修饰符 | 说明 | 参数 |
|--------|------|------|
| `.onDelete` | 滑动删除 | 收到 `IndexSet`，表示要删除的行索引 |
| `.onMove` | 拖拽排序 | 收到源索引 `IndexSet` 和目标索引 `Int` |
| `EditButton()` | 编辑模式按钮 | 系统内置，点击切换编辑/完成状态 |

> 💡 **提示**：`.onDelete` 和 `.onMove` 必须加在 `ForEach` 上，不能加在 `List` 上。这是因为 ForEach 才知道具体是哪一行需要删除或移动。

### 列表样式

SwiftUI 提供了多种列表样式，通过 `.listStyle()` 修饰符设置：

| 样式 | 写法 | 外观效果 | 适用场景 |
|------|------|---------|---------|
| 自动（默认） | `.automatic` | 跟随系统风格 | 大多数场景 |
| 内嵌分组 | `.insetGrouped` | 圆角分组卡片 | iOS 设置页风格 |
| 分组 | `.grouped` | 灰色背景分组 | 需要分组但不要圆角 |
| 内嵌 | `.inset` | 无分组，带内边距 | 简单列表 |
| 普通列表 | `.plain` | 无背景，无分组 | 简洁风格 |
| 侧边栏 | `.sidebar` | 侧边栏样式 | iPad 分栏布局 |

```swift
struct ListStyleDemoView: View {
    var body: some View {
        TabView {
            demoList(style: .plain, title: "Plain")
                .tabItem { Label("Plain", systemImage: "list.bullet") }

            demoList(style: .insetGrouped, title: "InsetGrouped")
                .tabItem { Label("分组", systemImage: "square.grid.2x2") }

            demoList(style: .sidebar, title: "Sidebar")
                .tabItem { Label("侧边栏", systemImage: "sidebar.left") }
        }
    }

    func demoList(style: ListStyle, title: String) -> some View {
        List {
            Section("第一组") {
                Text("项目 1")
                Text("项目 2")
            }
            Section("第二组") {
                Text("项目 3")
                Text("项目 4")
            }
        }
        .listStyle(style)
        .navigationTitle(title)
    }
}
```

## NavigationStack 导航

NavigationStack 是 SwiftUI 中的导航容器，用于实现**页面跳转**和**导航栏**。

### 导航栏配置

```swift
struct NavBarView: View {
    var body: some View {
        NavigationStack {
            Text("内容区域")
                .navigationTitle("我的页面")
                .navigationBarTitleDisplayMode(.inline)
                .toolbar {
                    ToolbarItem(placement: .topBarLeading) {
                        Button("编辑") {
                            print("点击编辑")
                        }
                    }
                    ToolbarItem(placement: .topBarTrailing) {
                        Button {
                            print("点击添加")
                        } label: {
                            Image(systemName: "plus")
                        }
                    }
                }
        }
    }
}
```

| 修饰符 / 组件 | 说明 |
|--------------|------|
| `.navigationTitle("标题")` | 设置导航栏标题 |
| `.navigationBarTitleDisplayMode(.large)` | 大标题样式（默认，标题在导航栏下方大字显示） |
| `.navigationBarTitleDisplayMode(.inline)` | 内联标题（标题在导航栏中间，小字显示） |
| `.toolbar { ... }` | 添加导航栏按钮 |
| `ToolbarItem(placement: .topBarLeading)` | 导航栏左侧 |
| `ToolbarItem(placement: .topBarTrailing)` | 导航栏右侧 |
| `ToolbarItem(placement: .principal)` | 导航栏中间（替代标题） |

⚠️ **注意**：`.navigationTitle()` 和 `.toolbar` 必须放在 `NavigationStack` **内部**的视图上，否则不会生效。

### 页面跳转（NavigationLink）

**声明式导航**——用 NavigationLink 直接声明跳转目标：

```swift
struct NavLinkView: View {
    var body: some View {
        NavigationStack {
            List {
                NavigationLink("跳转到详情页") {
                    DetailView(title: "详情页")
                }

                NavigationLink {
                    DetailView(title: "设置页")
                } label: {
                    HStack {
                        Image(systemName: "gear")
                        Text("设置")
                    }
                }
            }
            .navigationTitle("首页")
        }
    }
}

struct DetailView: View {
    let title: String

    var body: some View {
        Text("这是\(title)的内容")
            .navigationTitle(title)
    }
}
```

**编程式导航**——用 `NavigationPath` 动态控制导航栈：

```swift
struct ProgrammaticNavView: View {
    @State private var path = NavigationPath()

    var body: some View {
        NavigationStack(path: $path) {
            VStack(spacing: 20) {
                Button("跳转到第 1 页") {
                    path.append("第 1 页")
                }
                Button("跳转到第 2 页") {
                    path.append("第 2 页")
                }
                Button("跳转到第 3 页") {
                    path.append("第 3 页")
                }
            }
            .navigationTitle("首页")
            .navigationDestination(for: String.self) { value in
                Text("你跳转到了：\(value)")
                    .navigationTitle(value)
            }
        }
    }
}
```

| 导航方式 | 特点 | 适用场景 |
|---------|------|---------|
| NavigationLink | 声明式，点击自动跳转 | 列表项点击、按钮跳转 |
| NavigationPath | 编程式，代码控制跳转 | 需要条件判断后再跳转、深层链接 |

> 💡 **提示**：编程式导航还可以通过 `path.removeLast()` 返回上一页，`path = NavigationPath()` 返回根页面。

### 传值跳转

页面跳转时传递数据，最简单的方式就是通过**构造函数参数**：

```swift
import SwiftUI

struct Book: Identifiable {
    let id = UUID()
    let title: String
    let author: String
    let rating: Int
    let summary: String
}

struct BookListView: View {
    let books = [
        Book(title: "Swift 入门", author: "张三", rating: 5, summary: "从零开始学 Swift，适合完全零基础的读者。"),
        Book(title: "iOS 开发实战", author: "李四", rating: 4, summary: "深入 iOS 开发，涵盖项目实战经验。"),
        Book(title: "SwiftUI 进阶", author: "王五", rating: 5, summary: "掌握 SwiftUI 高级技巧，构建精美界面。")
    ]

    var body: some View {
        NavigationStack {
            List(books) { book in
                NavigationLink {
                    BookDetailView(book: book)
                } label: {
                    BookRowView(book: book)
                }
            }
            .navigationTitle("书架")
        }
    }
}

struct BookRowView: View {
    let book: Book

    var body: some View {
        HStack {
            VStack(alignment: .leading, spacing: 4) {
                Text(book.title)
                    .fontWeight(.semibold)
                Text(book.author)
                    .font(.caption)
                    .foregroundColor(.secondary)
            }
            Spacer()
            HStack(spacing: 2) {
                ForEach(1...5, id: \.self) { star in
                    Image(systemName: star <= book.rating ? "star.fill" : "star")
                        .font(.caption)
                        .foregroundColor(.yellow)
                }
            }
        }
    }
}

struct BookDetailView: View {
    let book: Book

    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: 16) {
                Text(book.title)
                    .font(.largeTitle)
                    .fontWeight(.bold)

                Text("作者：\(book.author)")
                    .font(.subheadline)
                    .foregroundColor(.secondary)

                HStack(spacing: 2) {
                    ForEach(1...5, id: \.self) { star in
                        Image(systemName: star <= book.rating ? "star.fill" : "star")
                            .foregroundColor(.yellow)
                    }
                }

                Divider()

                Text("简介")
                    .font(.headline)
                Text(book.summary)
                    .foregroundColor(.secondary)
            }
            .padding()
        }
        .navigationTitle(book.title)
        .navigationBarTitleDisplayMode(.inline)
    }
}

#Preview {
    BookListView()
}
```

## Sheet 与 FullScreenCover

### Sheet 弹出

Sheet 是从屏幕底部滑出的**半屏弹窗**，常用于编辑、分享、详情等场景。

**方式一：`isPresented` 绑定布尔值**

```swift
struct SheetBoolView: View {
    @State private var showSheet = false

    var body: some View {
        Button("打开 Sheet") {
            showSheet = true
        }
        .sheet(isPresented: $showSheet) {
            VStack(spacing: 20) {
                Text("这是一个 Sheet")
                    .font(.title2)
                Text("点击下方按钮或下拉关闭")
                    .foregroundColor(.secondary)
                Button("关闭") {
                    showSheet = false
                }
                .buttonStyle(.borderedProminent)
            }
            .padding(40)
            .presentationDetents([.medium])
        }
    }
}
```

**方式二：`item` 绑定可选值**

```swift
struct SheetItemView: View {
    @State private var selectedItem: Fruit?

    struct Fruit: Identifiable {
        let id = UUID()
        let name: String
        let color: String
    }

    let fruits = [
        Fruit(name: "苹果", color: "红色"),
        Fruit(name: "香蕉", color: "黄色"),
        Fruit(name: "葡萄", color: "紫色")
    ]

    var body: some View {
        List(fruits) { fruit in
            Button(fruit.name) {
                selectedItem = fruit
            }
        }
        .sheet(item: $selectedItem) { fruit in
            VStack(spacing: 16) {
                Text(fruit.name)
                    .font(.largeTitle)
                    .fontWeight(.bold)
                Text("颜色：\(fruit.color)")
                    .foregroundColor(.secondary)
                Button("关闭") {
                    selectedItem = nil
                }
                .buttonStyle(.borderedProminent)
            }
            .padding(40)
        }
    }
}
```

| 方式 | 触发条件 | 关闭方式 | 适用场景 |
|------|---------|---------|---------|
| `isPresented` | 布尔值为 `true` | 设为 `false` | 简单的显示/隐藏 |
| `item` | 可选值非 `nil` | 设为 `nil` | 需要传递数据给 Sheet |

> 💡 **提示**：`.presentationDetents()` 可以控制 Sheet 的高度。`.medium` 约占屏幕一半，`.large` 几乎全屏，也可以用 `.height(300)` 指定固定高度。

### FullScreenCover 全屏弹出

`fullScreenCover` 和 `sheet` 用法几乎一样，区别是它会**完全覆盖整个屏幕**，没有下拉关闭的手势：

```swift
struct FullScreenCoverView: View {
    @State private var showCover = false

    var body: some View {
        Button("打开全屏弹窗") {
            showCover = true
        }
        .fullScreenCover(isPresented: $showCover) {
            ZStack {
                Color.blue.opacity(0.9)
                    .ignoresSafeArea()

                VStack(spacing: 20) {
                    Image(systemName: "checkmark.circle.fill")
                        .font(.system(size: 80))
                        .foregroundColor(.white)
                    Text("操作成功！")
                        .font(.largeTitle)
                        .fontWeight(.bold)
                        .foregroundColor(.white)
                    Button("确定") {
                        showCover = false
                    }
                    .buttonStyle(.borderedProminent)
                    .tint(.white)
                    .foregroundColor(.blue)
                }
            }
        }
    }
}
```

| 对比项 | Sheet | FullScreenCover |
|-------|-------|-----------------|
| 覆盖范围 | 底部滑出，可自定义高度 | 完全覆盖整个屏幕 |
| 下拉关闭 | 支持手势下拉关闭 | 不支持，必须手动关闭 |
| 背景遮罩 | 半透明黑色遮罩 | 无遮罩（完全覆盖） |
| 适用场景 | 编辑、分享、选择器 | 引导页、成功提示、强制操作 |

⚠️ **注意**：FullScreenCover 没有下拉关闭手势，所以**必须**提供一个关闭按钮或其他关闭方式，否则用户会被困在弹窗里！

### 数据传递与回调

**方式一：通过 Binding 传递数据**

Binding 允许子视图**直接修改**父视图的数据：

```swift
struct BindingSheetView: View {
    @State private var showSheet = false
    @State private var username = "未设置"

    var body: some View {
        VStack(spacing: 20) {
            Text("用户名：\(username)")
                .font(.title2)
            Button("修改用户名") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet) {
            EditNameSheet(name: $username, isPresented: $showSheet)
        }
    }
}

struct EditNameSheet: View {
    @Binding var name: String
    @Binding var isPresented: Bool

    var body: some View {
        VStack(spacing: 20) {
            Text("修改用户名")
                .font(.headline)
            TextField("请输入用户名", text: $name)
                .textFieldStyle(.roundedBorder)
                .padding(.horizontal)
            HStack(spacing: 16) {
                Button("取消") {
                    isPresented = false
                }
                Button("保存") {
                    isPresented = false
                }
                .buttonStyle(.borderedProminent)
            }
        }
        .padding(30)
        .presentationDetents([.height(200)])
    }
}
```

**方式二：通过闭包回调**

闭包回调更灵活，子视图不需要知道父视图的数据结构：

```swift
struct ClosureSheetView: View {
    @State private var showSheet = false
    @State private var selectedColor: Color = .blue

    var body: some View {
        VStack(spacing: 20) {
            RoundedRectangle(cornerRadius: 16)
                .fill(selectedColor)
                .frame(width: 150, height: 150)

            Button("选择颜色") {
                showSheet = true
            }
        }
        .sheet(isPresented: $showSheet) {
            ColorPickerSheet { color in
                selectedColor = color
            } onDismiss: {
                print("颜色选择器已关闭")
            }
        }
    }
}

struct ColorPickerSheet: View {
    let onSelect: (Color) -> Void
    let onDismiss: () -> Void

    let colors: [(String, Color)] = [
        ("红色", .red),
        ("橙色", .orange),
        ("黄色", .yellow),
        ("绿色", .green),
        ("蓝色", .blue),
        ("紫色", .purple)
    ]

    var body: some View {
        VStack(spacing: 20) {
            Text("选择颜色")
                .font(.headline)

            LazyVGrid(columns: Array(repeating: GridItem(.flexible()), count: 3), spacing: 16) {
                ForEach(colors, id: \.0) { name, color in
                    Button {
                        onSelect(color)
                        onDismiss()
                    } label: {
                        VStack {
                            Circle()
                                .fill(color)
                                .frame(width: 50, height: 50)
                            Text(name)
                                .font(.caption)
                                .foregroundColor(.primary)
                        }
                    }
                }
            }
            .padding(.horizontal)
        }
        .padding(20)
        .presentationDetents([.medium])
    }
}
```

| 对比项 | Binding | 闭包回调 |
|-------|---------|---------|
| 数据流向 | 双向（子视图可直接修改父数据） | 单向（子视图通过闭包通知父视图） |
| 耦合度 | 较高（子视图需要知道数据类型） | 较低（子视图只负责通知） |
| 适用场景 | 编辑表单、双向绑定 | 选择器、确认操作、简单回调 |
| 推荐程度 | 简单场景方便 | 复杂场景更灵活 |

> 💡 **提示**：实际开发中，闭包回调更常用也更安全。Binding 适合简单的双向绑定场景，但如果逻辑复杂，闭包回调更容易维护。

## 小结

本章我们学习了 SwiftUI 中列表与导航的核心知识：

| 知识点 | 核心要点 |
|-------|---------|
| **List** | 列表容器，支持静态行、自定义行、Section 分组 |
| **ForEach** | 动态遍历数据生成行，推荐数据遵循 `Identifiable` |
| **.onDelete / .onMove** | 列表行的删除与移动，配合 `EditButton` 使用 |
| **.listStyle()** | 控制列表外观，`.insetGrouped` 最常用 |
| **NavigationStack** | 导航容器，提供导航栏和页面跳转能力 |
| **NavigationLink** | 声明式页面跳转，点击自动导航 |
| **NavigationPath** | 编程式导航，代码控制跳转和返回 |
| **传值跳转** | 通过构造函数参数传递数据到目标页面 |
| **Sheet** | 底部弹出半屏弹窗，支持 `isPresented` 和 `item` 两种方式 |
| **FullScreenCover** | 全屏弹出，必须手动提供关闭方式 |
| **Binding 传值** | 双向绑定，子视图可直接修改父数据 |
| **闭包回调** | 单向通知，子视图通过闭包把结果传回父视图 |

> 💡 **核心心法**：列表 + 导航 + 弹窗是 iOS App 最常见的交互模式。List 负责展示数据，NavigationStack 负责页面流转，Sheet 负责临时交互。三者组合，就能构建出大部分 App 的骨架。
