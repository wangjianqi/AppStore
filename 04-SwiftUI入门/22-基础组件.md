# 22-基础组件：文本、图片与按钮

> 🎯 **本章目标**：掌握 SwiftUI 最常用的基础组件——Text、TextField、SecureField、Image、Button，理解 Modifier 链式调用的原理和顺序重要性，能够组合这些组件搭建简单界面。

## Text 文本

`Text` 是 SwiftUI 中最基础的组件，用来在屏幕上显示一段文字。几乎每个页面都会用到它。

### 基本使用

最简单的用法——显示一行文字：

```swift
struct TextBasicView: View {
    var body: some View {
        Text("Hello, World!")
    }
}
```

就这么简单！`Text("内容")` 就能在屏幕上显示文字。

### 字体与颜色

光有文字还不够，我们通常还需要调整字体大小、颜色和粗细。SwiftUI 通过 **修饰符（Modifier）** 来实现这些调整：

```swift
struct TextStyleView: View {
    var body: some View {
        VStack(spacing: 16) {
            Text("大标题")
                .font(.largeTitle)

            Text("标题")
                .font(.title)

            Text("标题2")
                .font(.title2)

            Text("标题3")
                .font(.title3)

            Text("头条")
                .font(.headline)

            Text("正文")
                .font(.body)

            Text("说明文字")
                .font(.caption)

            Text("红色粗体正文")
                .font(.body)
                .fontWeight(.bold)
                .foregroundColor(.red)
        }
    }
}
```

**字体样式速查表**：

| 修饰符 | 效果 | 适用场景 |
|--------|------|---------|
| `.font(.largeTitle)` | 超大标题 | 页面主标题 |
| `.font(.title)` | 大标题 | 章节标题 |
| `.font(.title2)` | 中标题 | 次级标题 |
| `.font(.title3)` | 小标题 | 小节标题 |
| `.font(.headline)` | 加粗正文 | 强调文字 |
| `.font(.body)` | 正文（默认） | 正文内容 |
| `.font(.callout)` | 略小正文 | 辅助说明 |
| `.font(.subheadline)` | 副标题 | 次要信息 |
| `.font(.footnote)` | 脚注 | 注释、版权 |
| `.font(.caption)` | 说明文字 | 标签、提示 |
| `.font(.caption2)` | 更小说明 | 极小提示 |

**字体粗细**：

| 修饰符 | 效果 |
|--------|------|
| `.fontWeight(.ultraLight)` | 极细 |
| `.fontWeight(.thin)` | 纤细 |
| `.fontWeight(.light)` | 细体 |
| `.fontWeight(.regular)` | 常规（默认） |
| `.fontWeight(.medium)` | 中等 |
| `.fontWeight(.semibold)` | 半粗 |
| `.fontWeight(.bold)` | 粗体 |
| `.fontWeight(.heavy)` | 特粗 |
| `.fontWeight(.black)` | 最粗 |

**颜色**：

```swift
Text("系统红色")
    .foregroundColor(.red)

Text("系统蓝色")
    .foregroundColor(.blue)

Text("自定义颜色")
    .foregroundColor(Color(red: 0.3, green: 0.6, blue: 0.9))

Text("使用 Asset 颜色")
    .foregroundColor(Color("MyCustomColor"))
```

💡 **提示**：推荐使用 `.foregroundStyle()` 替代 `.foregroundColor()`，前者支持更丰富的样式（如渐变），且是 Apple 推荐的新 API：

```swift
Text("新式写法")
    .foregroundStyle(.primary)

Text("渐变文字")
    .foregroundStyle(
        .linearGradient(
            colors: [.purple, .pink],
            startPoint: .leading,
            endPoint: .trailing
        )
    )
```

### 多行文本

当文字很长时，可能需要控制行数和对齐方式：

```swift
struct MultilineTextView: View {
    var body: some View {
        VStack(spacing: 20) {
            Text("这是一段很长的文字，用来演示多行文本的显示效果。SwiftUI 会自动换行，但你可以通过 lineLimit 来限制最多显示几行。超出的部分会被截断，显示省略号……")
                .lineLimit(2)

            Text("左对齐的多行文本\n第二行\n第三行")
                .multilineTextAlignment(.leading)

            Text("居中对齐的多行文本\n第二行\n第三行")
                .multilineTextAlignment(.center)

            Text("右对齐的多行文本\n第二行\n第三行")
                .multilineTextAlignment(.trailing)
        }
        .padding()
    }
}
```

| 修饰符 | 效果 |
|--------|------|
| `.lineLimit(2)` | 最多显示 2 行，超出截断 |
| `.lineLimit(1)` | 单行显示 |
| `.lineLimit(nil)` | 不限制行数（默认） |
| `.multilineTextAlignment(.leading)` | 多行左对齐 |
| `.multilineTextAlignment(.center)` | 多行居中 |
| `.multilineTextAlignment(.trailing)` | 多行右对齐 |

💡 **提示**：`.lineLimit(1)` 和 `.lineLimit(2)` 等是简写形式，完整写法是 `.lineLimit(1...2)` 表示最少 1 行最多 2 行。

## TextField 文本输入

`TextField` 让用户可以输入文字，比如登录页面的用户名输入框、搜索框等。

### 基本使用

```swift
struct TextFieldBasicView: View {
    @State private var username = ""

    var body: some View {
        VStack(spacing: 20) {
            TextField("请输入用户名", text: $username)

            Text("你输入的内容：\(username)")
                .foregroundColor(.secondary)
        }
        .padding()
    }
}
```

拆解一下：

| 代码 | 含义 |
|------|------|
| `@State private var username = ""` | 定义一个状态变量，存储输入内容 |
| `TextField("请输入用户名", text: $username)` | 创建输入框，提示文字为"请输入用户名" |
| `$username` | 绑定（Binding），双向连接输入框和变量 |
| `\(username)` | 字符串插值，在 Text 中显示变量值 |

⚠️ **警告**：`$username` 中的 `$` 不能省略！它表示"绑定"，让输入框的值和变量保持同步。没有 `$` 只是读取值，有 `$` 才是双向绑定。

### 键盘类型

不同场景需要不同的键盘类型，比如输入邮箱时显示带 `@` 的键盘，输入电话号码时显示数字键盘：

```swift
struct KeyboardTypeView: View {
    @State private var email = ""
    @State private var phone = ""
    @State private var website = ""

    var body: some View {
        Form {
            TextField("邮箱", text: $email)
                .keyboardType(.emailAddress)
                .textInputAutocapitalization(.never)

            TextField("电话号码", text: $phone)
                .keyboardType(.phonePad)

            TextField("网址", text: $website)
                .keyboardType(.URL)
                .textInputAutocapitalization(.never)
        }
    }
}
```

常用键盘类型：

| keyboardType | 键盘样式 | 适用场景 |
|-------------|---------|---------|
| `.default` | 标准键盘 | 通用输入 |
| `.numberPad` | 纯数字键盘 | 数量、验证码 |
| `.phonePad` | 电话键盘（数字+符号） | 电话号码 |
| `.emailAddress` | 带 @ 和 .com 的键盘 | 邮箱 |
| `.URL` | 带 . 和 / 的键盘 | 网址 |
| `.decimalPad` | 带小数点的数字键盘 | 金额 |
| `.twitter` | 带 @ 和 # 的键盘 | 社交媒体 |

💡 **提示**：输入邮箱和网址时，建议加上 `.textInputAutocapitalization(.never)` 禁止自动大写，否则用户输入体验很差。

### 输入验证

下面是一个简单的输入验证示例——检查用户名长度是否在 2~10 个字符之间：

```swift
struct ValidationView: View {
    @State private var username = ""

    var isUsernameValid: Bool {
        username.count >= 2 && username.count <= 10
    }

    var body: some View {
        VStack(spacing: 12) {
            TextField("请输入用户名（2~10个字符）", text: $username)
                .textFieldStyle(.roundedBorder)

            if !username.isEmpty {
                HStack(spacing: 4) {
                    Image(systemName: isUsernameValid ? "checkmark.circle.fill" : "xmark.circle.fill")
                    Text(isUsernameValid ? "用户名可用" : "用户名长度需要在2~10个字符之间")
                }
                .foregroundColor(isUsernameValid ? .green : .red)
                .font(.caption)
            }
        }
        .padding()
    }
}
```

💡 **提示**：验证逻辑写在计算属性 `isUsernameValid` 中，而不是直接写在 `body` 里，这样代码更清晰、可复用。

## SecureField 密码输入

`SecureField` 和 `TextField` 用法几乎一样，区别是输入的内容会被隐藏（显示为圆点 ●●●●），适合输入密码等敏感信息。

```swift
struct SecureFieldView: View {
    @State private var username = ""
    @State private var password = ""

    var body: some View {
        VStack(spacing: 16) {
            TextField("用户名", text: $username)
                .textFieldStyle(.roundedBorder)

            SecureField("密码", text: $password)
                .textFieldStyle(.roundedBorder)

            Button("登录") {
                print("用户名：\(username)，密码：\(password)")
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}
```

**TextField vs SecureField 对比**：

| 特性 | TextField | SecureField |
|------|-----------|-------------|
| 输入内容 | 明文显示 | 显示为圆点 ●●●● |
| 复制粘贴 | ✅ 可以复制粘贴 | ❌ 无法复制粘贴 |
| 自动纠错 | ✅ 默认开启 | ❌ 默认关闭 |
| 键盘类型 | 可自定义 | 固定标准键盘 |
| 使用场景 | 用户名、邮箱、搜索 | 密码、PIN 码 |

⚠️ **警告**：`SecureField` 只是防止"肩窥"（别人偷看你的屏幕），并不加密数据。密码的安全传输和存储需要后端配合，不能只靠前端。

## Image 图片

`Image` 组件用来显示图片，支持三种图片来源：本地图片、系统图标（SF Symbols）、网络图片。

### 本地图片

显示添加到项目 Asset Catalog 中的图片：

```swift
struct LocalImageView: View {
    var body: some View {
        VStack(spacing: 20) {
            Image("my_photo")
                .resizable()
                .scaledToFit()
                .frame(width: 200, height: 200)
                .clipShape(RoundedRectangle(cornerRadius: 12))

            Image("banner")
                .resizable()
                .scaledToFill()
                .frame(height: 150)
                .clipped()
        }
    }
}
```

**添加图片到 Asset Catalog 的步骤**：

1. 在 Xcode 左侧导航栏点击 `Assets.xcassets`
2. 点击左下角的 **+** 按钮 → Import
3. 选择图片文件（支持 PNG、JPG、PDF、SVG）
4. 给图片起一个英文名称（如 `my_photo`）
5. 在代码中用 `Image("my_photo")` 引用

⚠️ **警告**：使用 `Image("图片名")` 时，图片名不要加扩展名！比如图片文件是 `my_photo.png`，代码中写 `Image("my_photo")` 而不是 `Image("my_photo.png")`。

**缩放模式对比**：

| 模式 | 修饰符 | 效果 | 类比 |
|------|--------|------|------|
| 适应框架 | `.scaledToFit()` | 完整显示图片，可能有留白 | 像看电影时的"信箱模式" |
| 填充框架 | `.scaledToFill()` | 填满整个框架，可能裁剪 | 像手机壁纸的"填充模式" |

💡 **提示**：使用 `.scaledToFill()` 时一定要配合 `.clipped()`，否则图片会溢出框架范围。

### SF Symbols 图标

Apple 提供了超过 5000 个免费图标，叫做 **SF Symbols**。你不需要添加任何图片文件，直接用名字就能用：

```swift
                Image(systemName: "person.fill")
                Image(systemName: "gearshape.fill")

```

**常用图标推荐**：

| `heart.fill` | ❤️ 实心爱心 | 点赞、喜欢 |

### 网络图片（AsyncImage）

显示网络图片使用 `AsyncImage`，它会自动异步下载图片：

```swift
struct AsyncImageView: View {
    var body: some View {
        VStack(spacing: 20) {
            AsyncImage(url: URL(string: "https://picsum.photos/200/200"))
                .frame(width: 200, height: 200)
                .clipShape(Circle())

            AsyncImage(url: URL(string: "https://picsum.photos/300/200")) { phase in
                switch phase {
                case .empty:
                    ProgressView()
                        .frame(width: 300, height: 200)
                case .success(let image):
                    image
                        .resizable()
                        .scaledToFit()
                        .frame(width: 300, height: 200)
                        .clipShape(RoundedRectangle(cornerRadius: 12))
                case .failure:
                    Image(systemName: "photo")
                        .font(.largeTitle)
                        .foregroundColor(.gray)
                        .frame(width: 300, height: 200)
                @unknown default:
                    EmptyView()
                }
            }
        }
    }
}
```

**AsyncImage 的三种状态**：

| 状态 | 含义 | 应该显示什么 |
|------|------|-------------|
| `.empty` | 正在加载 | 加载指示器（ProgressView） |
| `.success(let image)` | 加载成功 | 显示图片 |
| `.failure` | 加载失败 | 占位图或错误提示 |

⚠️ **警告**：`AsyncImage` 默认不缓存图片！每次视图重新出现都会重新下载。如果需要缓存，建议使用第三方库（如 Kingfisher）或自己实现缓存逻辑。

💡 **提示**：测试网络图片时，可以使用 `https://picsum.photos/宽/高` 这个免费占位图服务，它会随机返回一张指定尺寸的图片。

## Button 按钮

`Button` 是用户交互的核心组件，用户点击后执行某个操作。

### 基本按钮

SwiftUI 提供了两种创建按钮的方式：

```swift
struct ButtonBasicView: View {
    @State private var count = 0

    var body: some View {
        VStack(spacing: 24) {
            Text("点击次数：\(count)")
                .font(.title)

            // 方式1：文字按钮
            Button("点我 +1") {
                count += 1
            }

            // 方式2：自定义标签按钮
            Button(action: {
                count = 0
            }) {
                HStack {
                    Image(systemName: "arrow.counterclockwise")
                    Text("重置")
                }
            }
        }
    }
}
```

两种方式的区别：

| 方式 | 语法 | 适用场景 |
|------|------|---------|
| `Button("标题") { action }` | 简洁写法 | 简单文字按钮 |
| `Button(action:) { label }` | 完整写法 | 需要图标+文字、自定义外观 |

### 按钮样式

SwiftUI 提供了几种内置按钮样式：

```swift
struct ButtonStyleView: View {
    var body: some View {
        VStack(spacing: 16) {
            Button("默认按钮") {}
                .buttonStyle(.automatic)

            Button("边框按钮") {}
                .buttonStyle(.bordered)

            Button("突出按钮") {}
                .buttonStyle(.borderedProminent)

            Button("边框+阴影按钮") {}
                .buttonStyle(.bordered)
                .tint(.purple)

            Button("红色突出按钮") {}
                .buttonStyle(.borderedProminent)
                .tint(.red)

            Button("绿色突出按钮") {}
                .buttonStyle(.borderedProminent)
                .tint(.green)
        }
        .padding()
    }
}
```

**按钮样式对比**：

| 样式 | 效果 | 常用场景 |
|------|------|---------|
| `.automatic` | 根据上下文自动选择 | 默认值 |
| `.bordered` | 灰色背景+圆角边框 | 次要操作 |
| `.borderedProminent` | 填充背景色+圆角 | 主要操作（如"登录""提交"） |
| `.plain` | 无装饰，纯文字 | 工具栏按钮 |

💡 **提示**：`.tint()` 可以改变按钮的主题色。对于 `.borderedProminent`，它会改变整个按钮的背景色；对于 `.bordered`，它会改变边框和文字颜色。

### 自定义按钮

当内置样式不够用时，你可以完全自定义按钮的外观：

```swift
struct CustomButtonView: View {
    @State private var isPressed = false

    var body: some View {
        VStack(spacing: 20) {
            Button(action: {
                isPressed.toggle()
            }) {
                Text("渐变按钮")
                    .fontWeight(.semibold)
                    .foregroundColor(.white)
                    .padding(.horizontal, 32)
                    .padding(.vertical, 12)
                    .background(
                        LinearGradient(
                            colors: [.purple, .blue],
                            startPoint: .leading,
                            endPoint: .trailing
                        )
                    )
                    .clipShape(Capsule())
            }

            Button(action: {
                isPressed.toggle()
            }) {
                HStack(spacing: 8) {
                    Image(systemName: "cart.fill")
                    Text("加入购物车")
                        .fontWeight(.medium)
                }
                .foregroundColor(.white)
                .padding(.horizontal, 24)
                .padding(.vertical, 12)
                .background(Color.orange)
                .clipShape(RoundedRectangle(cornerRadius: 10))
            }

            Button(action: {
                isPressed.toggle()
            }) {
                Image(systemName: "plus")
                    .font(.title2)
                    .foregroundColor(.white)
                    .frame(width: 56, height: 56)
                    .background(Color.blue)
                    .clipShape(Circle())
                    .shadow(color: .blue.opacity(0.4), radius: 8, y: 4)
            }
        }
    }
}
```

💡 **提示**：自定义按钮的关键思路是——先用 `Text`/`Image`/`HStack` 构建按钮内容，然后用 `.padding()` 设置内边距，再用 `.background()` 设置背景，最后用 `.clipShape()` 裁剪形状。

## Modifier 链式调用

在 SwiftUI 中，你一定会频繁使用 **Modifier（修饰符）**。它们以 `.方法名()` 的形式跟在视图后面，像链条一样串联起来，这就是"链式调用"。

### 常用 Modifier 速查表

| Modifier | 效果 | 示例 |
|----------|------|------|
| `.font()` | 设置字体 | `.font(.title)` |
| `.foregroundColor()` | 设置前景色 | `.foregroundColor(.red)` |
| `.foregroundStyle()` | 设置前景样式（推荐） | `.foregroundStyle(.primary)` |
| `.fontWeight()` | 设置字体粗细 | `.fontWeight(.bold)` |
| `.padding()` | 添加内边距 | `.padding()` / `.padding(16)` / `.padding(.horizontal)` |
| `.background()` | 设置背景 | `.background(Color.blue)` |
| `.clipShape()` | 裁剪形状 | `.clipShape(Circle())` |
| `.cornerRadius()` | 圆角 | `.cornerRadius(12)` |
| `.shadow()` | 阴影 | `.shadow(radius: 4)` |
| `.frame()` | 设置尺寸 | `.frame(width: 100, height: 100)` |
| `.offset()` | 偏移位置 | `.offset(x: 10, y: 20)` |
| `.opacity()` | 透明度 | `.opacity(0.5)` |
| `.overlay()` | 叠加内容 | `.overlay(Text("标签"))` |
| `.border()` | 边框 | `.border(Color.red, width: 2)` |
| `.scaledToFit()` | 适应框架 | 配合 Image 使用 |
| `.scaledToFill()` | 填充框架 | 配合 Image 使用 |
| `.multilineTextAlignment()` | 多行对齐 | `.multilineTextAlignment(.center)` |
| `.lineLimit()` | 限制行数 | `.lineLimit(2)` |
| `.keyboardType()` | 键盘类型 | `.keyboardType(.emailAddress)` |
| `.textFieldStyle()` | 输入框样式 | `.textFieldStyle(.roundedBorder)` |
| `.disabled()` | 禁用交互 | `.disabled(true)` |
| `.hidden()` | 隐藏视图 | `.hidden()` |

### Modifier 执行顺序

**顺序很重要！** 不同的 Modifier 顺序会产生完全不同的效果。SwiftUI 按照 Modifier 的书写顺序，从外到内依次应用。

#### 示例1：padding 和 background 的顺序

```swift
struct ModifierOrderView: View {
    var body: some View {
        HStack(spacing: 40) {
            // 先 padding 再 background → 背景包含内边距区域
            Text("先 padding")
                .padding()
                .background(Color.blue)
                .foregroundColor(.white)

            // 先 background 再 padding → 背景只包裹文字，内边距在外面
            Text("先 background")
                .background(Color.red)
                .padding()
                .foregroundColor(.white)
        }
    }
}
```

效果对比：

| 顺序 | 效果 | 原因 |
|------|------|------|
| `.padding().background(.blue)` | 蓝色背景**包含**内边距区域 | 先撑大空间，再画背景 |
| `.background(.red).padding()` | 红色背景**紧贴**文字，内边距在外面 | 先画背景，再撑大空间 |

#### 示例2：frame 和 background 的顺序

```swift
struct FrameOrderView: View {
    var body: some View {
        HStack(spacing: 40) {
            // 先 frame 再 background → 背景填满指定尺寸
            Text("A")
                .frame(width: 80, height: 80)
                .background(Color.green)
                .foregroundColor(.white)

            // 先 background 再 frame → 背景紧贴文字，frame 只是撑大空间
            Text("B")
                .background(Color.orange)
                .frame(width: 80, height: 80)
                .foregroundColor(.white)
        }
    }
}
```

⚠️ **警告**：Modifier 顺序是 SwiftUI 初学者最容易踩的坑！记住一个原则——**先调整内容，再设置装饰**。一般的推荐顺序是：

```
内容 → 字体/颜色 → 尺寸/边距 → 背景/边框 → 阴影 → 其他
```

即：`.font()` → `.foregroundColor()` → `.frame()` → `.padding()` → `.background()` → `.clipShape()` → `.shadow()`
