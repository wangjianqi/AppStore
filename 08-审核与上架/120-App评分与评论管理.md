## App Store 评分机制概述

### 评分如何影响你的 App

App Store 的评分（Rating）是影响 App 下载量的最关键因素之一。大量数据表明，评分与下载转化率之间存在强相关性：

| 评分 | 下载转化率（估算） | 用户信任度 | ASO 排名影响 |
|:----:|:-----------------:|:----------:|:------------:|
| 4.5+ | 基准线 100% | 非常高 | ⭐⭐⭐⭐⭐ |
| 4.0-4.4 | 约 70% | 较高 | ⭐⭐⭐⭐ |
| 3.5-3.9 | 约 40% | 一般 | ⭐⭐⭐ |
| 3.0-3.4 | 约 20% | 较低 | ⭐⭐ |
| < 3.0 | 约 5% | 很低 | ⭐ |

> 💡 **提示**：根据多项行业研究，评分从 4.0 提升到 4.5，下载量可能增加 **50% 以上**。评分是 ASO 中仅次于关键词的核心因素。

### App Store 评分的构成

App Store 的综合评分是所有版本评分的加权平均：

| 评分来源 | 权重 | 说明 |
|----------|:----:|------|
| 当前版本评分 | 较高 | 最近版本的评分权重更大 |
| 历史版本评分 | 较低 | 旧版本评分权重逐渐降低 |
| 每个地区的评分 | 独立计算 | 不同地区显示不同的评分 |

**评分显示规则：**

| 规则 | 说明 |
|------|------|
| 最低评论数 | 需要至少 5 条评分才会显示综合评分 |
| 地区独立 | 每个国家/地区独立计算评分 |
| 版本切换 | 用户可以切换查看"所有版本"或"当前版本"评分 |
| 实时更新 | 新评分会实时影响综合评分 |

### 评分与评论的关系

| 维度 | 评分（Rating） | 评论（Review） |
|------|:--------------:|:--------------:|
| **形式** | 1-5 星选择 | 文字 + 星级 |
| **必填项** | 只需选星级 | 星级必填，文字可选 |
| **影响排名** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |
| **用户决策** | 快速判断 | 深入了解 |
| **开发者可操作** | 引导评分 | 回复评论 |
| **数量** | 远多于评论 | 只有部分用户写评论 |

> ⚠️ **警告**：App Store 的评分和评论是用户真实表达的产物。任何试图操纵评分的行为（如购买好评、刷评分）都违反 Apple 的开发者协议，可能导致 App 被下架甚至开发者账号被封禁。

## SKStoreReviewController：请求评分的正确姿势

### 基本使用

`SKStoreReviewController` 是 Apple 提供的官方 API，用于在 App 内请求用户评分。它会在 App 内弹出一个原生的评分对话框，用户无需离开 App 即可完成评分。

```swift
import StoreKit

func requestReview() {
    if let scene = UIApplication.shared.connectedScenes.first as? UIWindowScene {
        SKStoreReviewController.requestReview(in: scene)
    }
}
```

**SwiftUI 中使用：**

```swift
import SwiftUI
import StoreKit

struct ContentView: View {
    @Environment(\.requestReview) private var requestReview

    var body: some View {
        VStack {
            Text("欢迎使用我的 App")
                .font(.title)

            Button("评价我们") {
                requestReview()
            }
            .buttonStyle(.borderedProminent)
        }
    }
}
```

### SKStoreReviewController 的工作机制

了解 `SKStoreReviewController` 的工作机制非常重要，它并不是每次调用都会弹出评分对话框：

| 行为 | 说明 |
|------|------|
| 调用后不一定弹出 | Apple 有自己的频率限制算法 |
| 每年限 3 次 | 每个 App 每年最多弹出 3 次评分请求 |
| 用户可关闭 | 用户可以点击"不是现在"关闭对话框 |
| 不影响体验 | 对话框是模态的，不会打断用户操作 |
| 无回调 | API 不提供回调，你不知道用户是否评分了 |

**评分对话框的 UI：**

```text
┌─────────────────────────────────────┐
│                                     │
│     享受使用 MyApp 吗？              │
│                                     │
│     ★  ★  ★  ★  ★                  │
│                                     │
│  [不是现在]        [提交]            │
│                                     │
└─────────────────────────────────────┘
```

> 💡 **提示**：Apple 限制每年 3 次弹出是保护用户体验的重要机制。不要试图绕过这个限制，而是要在最合适的时机请求评分。

## 请求评分的时机和频率限制

### 最佳请求时机

选择正确的时机请求评分，是获得好评的关键。以下是经过验证的最佳时机：

| 时机 | 推荐程度 | 原因 | 示例 |
|------|:--------:|------|------|
| 用户完成关键成就后 | ⭐⭐⭐⭐⭐ | 用户处于积极情绪 | 完成关卡、达成目标 |
| 用户连续使用多天后 | ⭐⭐⭐⭐⭐ | 用户已经认可 App 价值 | 连续使用 7 天 |
| 用户主动表达满意时 | ⭐⭐⭐⭐⭐ | 转化率最高 | 反馈中说"很好用" |
| 用户完成核心流程后 | ⭐⭐⭐⭐ | 体验完整 | 完成一次购买、导出文件 |
| 用户使用高级功能后 | ⭐⭐⭐⭐ | 体验了核心价值 | 使用 AI 功能、生成报告 |

### 最差的请求时机

| 时机 | 风险 | 原因 |
|------|:----:|------|
| App 启动时 | 🔴 | 用户还没体验就要求评分 |
| 用户遇到错误时 | 🔴 | 负面情绪导致差评 |
| 用户正在操作中 | 🔴 | 打断用户流程 |
| 首次使用时 | 🔴 | 用户还没形成判断 |
| 付费墙弹出后 | 🔴 | 用户可能感到被强迫 |
| 请求权限后 | 🟠 | 用户可能感到烦躁 |

### 评分请求频率管理

由于 Apple 限制每年最多 3 次弹出评分对话框，你需要精心管理请求时机：

```swift
import Foundation
import StoreKit

final class ReviewManager {
    static let shared = ReviewManager()

    private let userDefaults = UserDefaults.standard
    private let reviewStateKey = "review_state"
    private let lastReviewRequestKey = "last_review_request_date"
    private let reviewCountKey = "review_request_count"
    private let significantEventCountKey = "significant_event_count"

    private var minimumDaysBetweenReviews: Int = 30
    private var significantEventsBeforePrompt: Int = 5

    struct ReviewState: Codable {
        var lastRequestDate: Date?
        var requestCount: Int = 0
        var significantEventCount: Int = 0
        var currentYearRequestCount: Int = 0
        var currentYear: Int = Calendar.current.component(.year, from: Date())
    }

    private var state: ReviewState {
        get {
            guard let data = userDefaults.data(forKey: reviewStateKey),
                  let decoded = try? JSONDecoder().decode(ReviewState.self, from: data) else {
                return ReviewState()
            }
            return decoded
        }
        set {
            if let data = try? JSONEncoder().encode(newValue) {
                userDefaults.set(data, forKey: reviewStateKey)
            }
        }
    }

    func recordSignificantEvent() {
        var currentState = state
        currentState.significantEventCount += 1
        state = currentState
    }

    func requestReviewIfAppropriate(in scene: UIWindowScene) {
        var currentState = state

        let currentYear = Calendar.current.component(.year, from: Date())
        if currentState.currentYear != currentYear {
            currentState.currentYear = currentYear
            currentState.currentYearRequestCount = 0
        }

        guard currentState.currentYearRequestCount < 3 else { return }

        if let lastDate = currentState.lastRequestDate {
            let daysSinceLastRequest = Calendar.current.dateComponents(
                [.day], from: lastDate, to: Date()
            ).day ?? 0
            guard daysSinceLastRequest >= minimumDaysBetweenReviews else { return }
        }

        guard currentState.significantEventCount >= significantEventsBeforePrompt else { return }

        SKStoreReviewController.requestReview(in: scene)

        currentState.lastRequestDate = Date()
        currentState.currentYearRequestCount += 1
        currentState.requestCount += 1
        currentState.significantEventCount = 0
        state = currentState
    }
}
```

## 自定义评分提示的设计

### 为什么需要自定义评分提示

虽然 `SKStoreReviewController` 是官方推荐的评分方式，但在某些场景下你可能需要先自定义一个"软提示"，再决定是否调用官方 API：

| 场景 | 说明 |
|------|------|
| 筛选满意用户 | 先问"喜欢吗？"，满意的才引导评分 |
| 避免浪费弹出次数 | 不满意的不触发官方评分弹窗 |
| 收集反馈 | 不满意的引导到反馈渠道 |
| 双重确认 | 确保用户真的愿意评分 |

### 自定义评分提示实现

```swift
import SwiftUI

struct RatingPromptView: View {
    @Binding var isPresented: Bool
    let onRate: () -> Void
    let onFeedback: () -> Void

    @State private var selectedOption: PromptOption?

    enum PromptOption {
        case loveIt
        case couldBeBetter
    }

    var body: some View {
        VStack(spacing: 24) {
            Text("你觉得 MyApp 怎么样？")
                .font(.title2)
                .bold()

            Text("你的反馈帮助我们变得更好")
                .font(.subheadline)
                .foregroundStyle(.secondary)

            HStack(spacing: 16) {
                Button {
                    selectedOption = .loveIt
                } label: {
                    VStack(spacing: 8) {
                        Image(systemName: "heart.fill")
                            .font(.largeTitle)
                            .foregroundStyle(.pink)
                        Text("很喜欢！")
                            .font(.headline)
                    }
                    .frame(maxWidth: .infinity)
                    .padding()
                    .background(selectedOption == .loveIt ? Color.pink.opacity(0.15) : Color.gray.opacity(0.1))
                    .clipShape(RoundedRectangle(cornerRadius: 12))
                }
                .buttonStyle(.plain)

                Button {
                    selectedOption = .couldBeBetter
                } label: {
                    VStack(spacing: 8) {
                        Image(systemName: "bubble.left.fill")
                            .font(.largeTitle)
                            .foregroundStyle(.blue)
                        Text("可以更好")
                            .font(.headline)
                    }
                    .frame(maxWidth: .infinity)
                    .padding()
                    .background(selectedOption == .couldBeBetter ? Color.blue.opacity(0.15) : Color.gray.opacity(0.1))
                    .clipShape(RoundedRectangle(cornerRadius: 12))
                }
                .buttonStyle(.plain)
            }

            if selectedOption != nil {
                Button {
                    isPresented = false
                    if selectedOption == .loveIt {
                        onRate()
                    } else {
                        onFeedback()
                    }
                } label: {
                    Text(selectedOption == .loveIt ? "去评分" : "告诉我们如何改进")
                        .font(.headline)
                        .foregroundStyle(.white)
                        .frame(maxWidth: .infinity)
                        .padding()
                        .background(selectedOption == .loveIt ? Color.pink : Color.blue)
                        .clipShape(RoundedRectangle(cornerRadius: 12))
                }
            }

            Button("以后再说") {
                isPresented = false
            }
            .foregroundStyle(.secondary)
        }
        .padding(24)
        .background(.regularMaterial)
        .clipShape(RoundedRectangle(cornerRadius: 20))
        .shadow(radius: 20)
    }
}
```

### 通过 API 回复评论

Apple 提供了 App Store Connect API 来管理评论回复：

```swift
import Foundation

struct ReviewResponseManager {
    let apiKeyId: String
    let issuerId: String
    let baseUrl = "https://api.appstoreconnect.apple.com/v1"

    func respondToReview(reviewId: String, responseText: String) async throws {
        let urlString = "\(baseUrl)/customerReviewResponses"
        let url = URL(string: urlString)!
        var request = URLRequest(url: url)
        request.httpMethod = "POST"
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")
        request.setValue("Bearer \(try generateJWT())", forHTTPHeaderField: "Authorization")

        let body: [String: Any] = [
            "data": [
                "type": "customerReviewResponses",
                "attributes": [
                    "responseBody": responseText
                ],
                "relationships": [
                    "review": [
                        "data": [
                            "type": "customerReviews",
                            "id": reviewId
                        ]
                    ]
                ]
            ]
        ]

        request.httpBody = try JSONSerialization.data(withJSONObject: body)
        let (_, response) = try await URLSession.shared.data(for: request)

        guard let httpResponse = response as? HTTPURLResponse,
              (200...299).contains(httpResponse.statusCode) else {
            throw ReviewError.responseFailed
        }
    }

    func getReviews(appId: String, limit: Int = 50) async throws -> [CustomerReview] {
        let urlString = "\(baseUrl)/apps/\(appId)/customerReviews?limit=\(limit)"
        let url = URL(string: urlString)!
        var request = URLRequest(url: url)
        request.setValue("Bearer \(try generateJWT())", forHTTPHeaderField: "Authorization")

        let (data, _) = try await URLSession.shared.data(for: request)
        let decoded = try JSONDecoder().decode(ReviewsResponse.self, from: data)
        return decoded.data
    }

    private func generateJWT() throws -> String {
        fatalError("实现 JWT 生成逻辑")
    }
}

struct CustomerReview: Codable {
    let id: String
    let attributes: ReviewAttributes
}

struct ReviewAttributes: Codable {
    let rating: Int
    let title: String?
    let body: String?
    let reviewerNickname: String?
    let createdDate: String?
}

struct ReviewsResponse: Codable {
    let data: [CustomerReview]
}

enum ReviewError: Error {
    case responseFailed
    case fetchFailed
}
```

| 模板 | 适用场景 | 示例 |

| 致歉+引导 | 误解类差评 | "抱歉让您困惑了！XX 功能实际上在 设置→XX 中可以找到。如有问题欢迎随时联系我们。" |

**回复评论的原则：**

| 原则 | 说明 | ❌ 错误做法 | ✅ 正确做法 |
|------|------|-----------|-----------|
| 及时 | 24 小时内回复 | 几周后才回复 | 每天检查并回复 |
| 礼貌 | 即使差评也要友好 | "你不会用就别用" | "抱歉给您带来不便" |
| 具体 | 针对问题回复 | "谢谢反馈" | "关于您提到的XX问题…" |
| 诚实 | 不夸大不隐瞒 | "这个问题不存在" | "我们已确认这个问题" |
| 简洁 | 不写长篇大论 | 500 字回复 | 3-5 句话回复 |
| 不争论 | 不和用户辩论 | "你理解错了" | "感谢您的看法" |

> ⚠️ **警告**：回复评论时绝对不要：1）要求用户修改评分；2）提供奖励换取好评；3）与用户争论；4）泄露用户隐私；5）包含营销内容。这些行为都违反 Apple 的开发者协议。

## 评分重置请求（Rating Reset Request）

### 什么是评分重置

评分重置（Rating Reset）是 Apple 提供的一项功能，允许开发者在发布新版本时请求重置 App 的综合评分。重置后，App Store 只显示新版本的评分，旧版本的评分不再计入综合评分。

### 评分重置的影响

| 影响 | 说明 |
|------|------|
| 综合评分重置 | 只显示新版本的评分 |
| 旧评分保留 | 旧评分仍可在"所有版本"中查看 |
| 新版本需要积累评分 | 重置后需要用户重新评分 |
| 不可逆 | 一旦重置无法撤销 |

### 何时应该请求评分重置

| 场景 | 是否推荐 | 原因 |
|------|:--------:|------|
| 大版本重构，旧评分已不反映当前质量 | ✅ | 新版本体验完全不同 |
| 长期差评积累，评分 < 3.0 | ✅ | 旧评分严重拖累新版本 |
| 修复了导致大量差评的核心问题 | ✅ | 新版本已解决旧问题 |
| 评分 4.0+ | ❌ | 没必要冒险重置 |
| 只是小更新 | ❌ | 风险大于收益 |
| 想要"清零重来" | ❌ | 不是正当理由 |

### 评分重置的风险

| 风险 | 说明 | 应对策略 |
|------|------|----------|
| 评分暂时降低 | 重置后评分少，一两条差评影响大 | 提前准备好评分引导策略 |
| 用户不信任 | 用户看到评分突然变化可能产生怀疑 | 在更新说明中解释改进 |
| 评分恢复慢 | 需要时间积累足够多的新评分 | 在新版本中优化评分请求时机 |
| 旧好评丢失 | 之前的好评不再计入 | 评估是否值得 |

### 请求评分重置的步骤

| 步骤 | 操作 |
|:----:|------|
| 1 | 在 App Store Connect 中提交新版本 |
| 2 | 在版本信息页面找到"重置评分"选项 |
| 3 | 勾选"重置此版本的评分" |
| 4 | 确认重置操作 |
| 5 | 提交审核 |

> ⚠️ **警告**：评分重置是不可逆操作！在确认重置前，请仔细评估风险和收益。建议只在评分低于 3.5 且新版本有重大改进时才考虑使用。

import NaturalLanguage

struct SentimentAnalyzer {
    private let sentimentPredictor: NLModel?

    init() {
        sentimentPredictor = try? NLModel(mlModel: SentimentClassifier().model)
    }

    func analyzeSentiment(text: String) -> SentimentResult {
        let tagger = NLTagger(tagSchemes: [.sentimentScore])
        tagger.string = text

        let (tag, _) = tagger.tag(at: text.startIndex, unit: .paragraph, scheme: .sentimentScore)

        let score = Double(tag.rawValue) ?? 0.0

        let category: SentimentCategory
        if score > 0.3 {
            category = .positive
        } else if score < -0.3 {
            category = .negative
        } else {
            category = .neutral
        }

        return SentimentResult(
            score: score,
            category: category,
            text: text
        )
    }

    func analyzeReviews(_ reviews: [CustomerReview]) -> SentimentSummary {
        var positiveCount = 0
        var negativeCount = 0
        var neutralCount = 0
        var totalScore = 0.0

        for review in reviews {
            let text = [review.attributes.title, review.attributes.body]
                .compactMap { $0 }
                .joined(separator: " ")

            let result = analyzeSentiment(text: text)
            totalScore += result.score

            switch result.category {
            case .positive: positiveCount += 1
            case .negative: negativeCount += 1
            case .neutral: neutralCount += 1
            }
        }

        let totalCount = reviews.count
        return SentimentSummary(
            totalReviews: totalCount,
            positiveCount: positiveCount,
            negativeCount: negativeCount,
            neutralCount: neutralCount,
            averageScore: totalCount > 0 ? totalScore / Double(totalCount) : 0,
            positiveRatio: totalCount > 0 ? Double(positiveCount) / Double(totalCount) : 0,
            negativeRatio: totalCount > 0 ? Double(negativeCount) / Double(totalCount) : 0
        )
    }
}

struct SentimentResult {
    let score: Double
    let category: SentimentCategory
    let text: String
}

enum SentimentCategory {
    case positive
    case negative
    case neutral
}

struct SentimentSummary {
    let totalReviews: Int
    let positiveCount: Int
    let negativeCount: Int
    let neutralCount: Int
    let averageScore: Double
    let positiveRatio: Double
    let negativeRatio: Double

### 关键词提取

```swift
import NaturalLanguage

struct KeywordExtractor {
    func extractKeywords(from text: String, topK: Int = 10) -> [Keyword] {
        let tagger = NLTagger(tagSchemes: [.lexicalClass, .nameType])
        tagger.string = text

        var wordFrequencies: [String: Int] = [:]
        let options: NLTagger.Options = [.omitWhitespace, .omitPunctuation, .joinNames]

        tagger.enumerateTags(in: text.startIndex..<text.endIndex, unit: .word, scheme: .lexicalClass, options: options) { tag, tokenRange in
            guard let tag = tag, tag == .noun || tag == .adjective else { return true }
            let word = String(text[tokenRange]).lowercased()
            guard word.count >= 2 else { return true }

            let stopwords = Set(["这个", "那个", "什么", "怎么", "可以", "没有", "不是", "但是", "因为", "所以", "如果", "虽然"])
            guard !stopwords.contains(word) else { return true }

            wordFrequencies[word, default: 0] += 1
            return true
        }

        return wordFrequencies
            .map { Keyword(word: $0.key, frequency: $0.value) }
            .sorted { $0.frequency > $1.frequency }
            .prefix(topK)
            .map { $0 }
    }

    func extractKeywordsFromReviews(_ reviews: [CustomerReview], topK: Int = 20) -> [Keyword] {
        let allText = reviews.compactMap { review in
            [review.attributes.title, review.attributes.body]
                .compactMap { $0 }
                .joined(separator: " ")
        }.joined(separator: " ")

        return extractKeywords(from: allText, topK: topK)
    }
}

struct Keyword: Identifiable {
    let id = UUID()
    let word: String
    let frequency: Int
}
```

struct ReviewDashboard {

        return distribution
    }

        return Double(total) / Double(reviews.count)

    }

        reviews
            .filter { $0.attributes.rating <= 2 }
            .prefix(10)
            .map { $0 }
    }

    var ratingTrend: [MonthlyRating] {
        var monthlyData: [String: [Int]] = [:]
        let formatter = DateFormatter()
        formatter.dateFormat = "yyyy-MM"

            guard let dateStr = review.attributes.createdDate else { continue }

                averageRating: Double(ratings.reduce(0, +)) / Double(ratings.count),
                reviewCount: ratings.count
            )

import Foundation

final class ReviewMonitorService {
    private let checkInterval: TimeInterval = 3600

    func startMonitoring(appId: String) {
        Task {
            while true {
                try? await Task.sleep(nanoseconds: UInt64(checkInterval * 1_000_000_000))
                await checkForNewReviews(appId: appId)
            }
        }
    }

    private func checkForNewReviews(appId: String) async {
        do {
            let reviews = try await fetchRecentReviews(appId: appId)
            let newNegativeReviews = filterNewNegativeReviews(reviews)

            if !newNegativeReviews.isEmpty {
                await sendNotification(for: newNegativeReviews)
            }
        } catch {
            print("Review check failed: \(error)")
        }
    }

    private func fetchRecentReviews(appId: String) async throws -> [CustomerReview] {
        return []
    }

    private func filterNewNegativeReviews(_ reviews: [CustomerReview]) -> [CustomerReview] {
        let lastCheckDate = UserDefaults.standard.object(forKey: "last_review_check_date") as? Date ?? Date.distantPast

        return reviews.filter { review in
            guard let dateStr = review.attributes.createdDate,
                  let reviewDate = ISO8601DateFormatter().date(from: dateStr) else {
                return false
            }
            return reviewDate > lastCheckDate && review.attributes.rating <= 2
        }
    }

    private func sendNotification(for reviews: [CustomerReview]) async {
        let count = reviews.count
        let message = "收到 \(count) 条新的差评，请及时处理"

        await PushNotificationService.shared.send(
            title: "新差评提醒",
            body: message
        )
    }
