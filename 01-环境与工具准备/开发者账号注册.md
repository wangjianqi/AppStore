# 开发者账号注册

> 🎯 **本章目标**：了解 Apple 开发者账号的类型区别，完成 Apple Developer Program 的注册，为后续真机调试和 App 上架做好准备。

---

## 免费账号 vs 付费账号

很多新手会疑惑：我一定要花钱注册开发者账号吗？答案是——不一定。Apple 提供了免费和付费两种账号，它们的区别非常大。

### 对比一览

| 对比项 | 免费账号（Apple ID） | 付费账号（Apple Developer Program） |
|---|---|---|
| **费用** | 免费 | 99 美元/年（约 688 元人民币） |
| **Xcode 开发** | ✅ 可以 | ✅ 可以 |
| **模拟器运行** | ✅ 可以 | ✅ 可以 |
| **真机调试** | ❌ 不可以 | ✅ 可以 |
| **App 上架 App Store** | ❌ 不可以 | ✅ 可以 |
| **推送通知（APNs）** | ❌ 不可以 | ✅ 可以 |
| **TestFlight 内测分发** | ❌ 不可以 | ✅ 可以 |
| **App Services（CloudKit 等）** | ❌ 受限 | ✅ 完整使用 |
| **证书有效期** | 7 天（过期需重新签名） | 1 年 |
| **同时安装 App 数量** | 最多 3 个 | 无限制 |
| **App Store Connect 管理** | ❌ 不可以 | ✅ 可以 |
| **Safari Web Inspector** | ✅ 可以 | ✅ 可以 |

### 免费账号能做什么？

如果你只是想**学习 iOS 开发**，免费账号完全够用：

- ✅ 使用 Xcode 编写和编译代码
- ✅ 在模拟器上运行和调试 App
- ✅ 学习 Swift / SwiftUI / UIKit 等技术
- ✅ 使用 Safari 的 Web Inspector 调试网页

> 💡 **提示**：免费账号签名的 App 7 天后会过期，需要重新编译安装。这在学习阶段影响不大，但如果要做长期测试就会比较麻烦。

### 付费账号能做什么？

当你需要以下功能时，就必须升级为付费账号：

- ✅ 在真实 iPhone / iPad 上调试 App
- ✅ 将 App 提交到 App Store 上架
- ✅ 使用推送通知、后台模式等系统能力
- ✅ 通过 TestFlight 邀请用户内测
- ✅ 使用 CloudKit、Sign in with Apple 等服务

### 什么时候需要升级为付费账号？

| 阶段 | 是否需要付费账号 | 说明 |
|---|---|---|
| 刚开始学习 iOS 开发 | ❌ 不需要 | 免费账号 + 模拟器足够 |
| 需要在真机上测试 | ✅ 需要 | 真机调试必须付费账号 |
| 需要推送通知等功能 | ✅ 需要 | 这些系统能力需要付费账号的证书 |
| 准备上架 App Store | ✅ 需要 | 上架是付费账号的核心功能 |

> ⚠️ **建议**：如果你刚开始学习，先用免费账号练手。等你的 App 开发完成、准备上架时再注册付费账号，这样不会浪费年费。

## Apple Developer Program 注册全流程

下面是注册付费开发者账号的完整步骤，请按顺序操作。

### 步骤 1：准备 Apple ID

如果你已经有 Apple ID（就是用来登录 iCloud 的那个账号），可以直接使用。如果没有，需要先创建一个。

创建 Apple ID 的方式：

```text
方式一：在 iPhone 上创建
设置 → 点击顶部"登录你的 iPhone" → 没有 Apple ID？创建一个

方式二：在网页上创建
访问 https://appleid.apple.com → 点击"创建你的 Apple ID"
```

> 💡 **提示**：建议使用一个**常用且稳定**的邮箱作为 Apple ID，后续所有开发者相关通知都会发到这个邮箱。

### 步骤 2：开启双重认证（必须）

Apple 强制要求开发者账号开启双重认证（Two-Factor Authentication，2FA），否则无法注册。

**在 iPhone 上开启双重认证：**

```text
设置 → 点击顶部你的姓名 → 密码与安全性 → 双重认证 → 开启
```

**在 Mac 上开启双重认证：**

```text
系统设置 → 点击顶部你的姓名 → 密码与安全性 → 双重认证 → 开启
```

> ⚠️ **警告**：开启双重认证后，每次登录 Apple ID 都需要验证码。请确保你的受信任设备（iPhone）随时可用，否则可能无法登录。

### 步骤 3：进入 Apple Developer 网站

打开浏览器，访问 Apple Developer 官网：

```
https://developer.apple.com/programs/
```

点击页面上的 **"Enroll"**（注册）按钮。

### 步骤 4：使用 Apple ID 登录

点击 Enroll 后，系统会要求你用 Apple ID 登录：

1. 输入你的 Apple ID 和密码
2. 输入双重认证验证码（发送到你的受信任设备）
3. 登录成功

### 步骤 5：选择账号类型

登录后，你需要选择注册类型：

| 类型 | 说明 |
|---|---|
| **Individual**（个人） | 以个人名义注册，只需身份证/护照 |
| **Organization**（公司/组织） | 以公司名义注册，需要邓白氏编码 |

> 💡 **提示**：如果你是个人开发者，选择 Individual 即可。如果是公司团队开发，选择 Organization。两者的详细区别见下一节。

### 步骤 6：填写个人信息

根据你选择的类型，填写相应的信息：

**个人账号需要填写：**

- ✅ 姓名（与身份证/护照一致）
- ✅ 地址
- ✅ 国家/地区
- ✅ 联系电话

**公司账号额外需要：**

- ✅ 公司全称（英文）
- ✅ 邓白氏编码（D-U-N-S Number）
- ✅ 公司网站（可选）

> ⚠️ **警告**：姓名必须与你的身份证或护照上的姓名一致，否则可能无法通过审核。

### 步骤 7：身份验证

Apple 会对你的身份进行验证，可能的方式包括：

1. **自动验证**：如果你的 Apple ID 已经绑定了信用卡等信息，系统可能自动通过
2. **人工验证**：Apple 可能会打电话给你确认信息

验证过程通常很快，部分用户可能需要等待。

### 步骤 8：支付年费

身份验证通过后，进入支付环节：

| 项目 | 说明 |
|---|---|
| **费用** | 99 美元/年 |
| **人民币参考** | 约 688 元（按汇率浮动） |
| **支付方式** | 信用卡、借记卡、支付宝、微信支付 |

**支付步骤：**

1. 确认注册信息无误
2. 选择支付方式
3. 完成支付

> 💡 **提示**：Apple 官方支持支付宝和微信支付，对中国开发者非常友好。支付时金额会按实时汇率折算为人民币。

> ⚠️ **注意**：支付完成后，Apple 会发送确认邮件到你的 Apple ID 邮箱，请留意查收。

### 步骤 9：等待审核

支付完成后，你的注册申请会进入审核阶段：

| 账号类型 | 审核时间 |
|---|---|
| 个人账号 | 通常 1-2 个工作日 |
| 公司账号 | 通常 3-5 个工作日（需验证邓白氏编码） |

> 💡 **提示**：审核期间你可以在 [App Store Connect](https://appstoreconnect.apple.com) 查看状态。如果超过 5 个工作日仍未通过，可以联系 Apple 开发者支持。

### 步骤 10：注册成功确认

审核通过后，你会收到一封来自 Apple 的欢迎邮件，标题类似：

```
Welcome to the Apple Developer Program
```

此时你可以：

- ✅ 登录 [App Store Connect](https://appstoreconnect.apple.com) 管理你的 App
- ✅ 在 Xcode 中添加你的开发者账号进行真机调试
- ✅ 创建证书和描述文件
- ✅ 提交 App 到 App Store

**在 Xcode 中添加账号：**

```text
Xcode → Settings（快捷键 ⌘,）→ Accounts → 点击 "+" → 选择 Apple ID → 登录
```

## 个人账号 vs 公司账号

注册时你需要选择个人还是公司账号，这是一个重要的决定。下面详细对比两者的区别。

### 对比一览

| 对比项 | 个人账号（Individual） | 公司账号（Organization） |
|---|---|---|
| **注册条件** | 身份证或护照 | 邓白氏编码 + 公司法律实体 |
| **费用** | 99 美元/年 | 99 美元/年 |
| **App Store 显示名称** | 你的个人姓名 | 你的公司名称 |
| **团队协作** | ❌ 不支持多人 | ✅ 支持添加多个团队成员 |
| **功能差异** | 与公司账号完全相同 | 与个人账号完全相同 |
| **审核要求** | 相对宽松 | 需要验证公司资质 |
| **注册时间** | 1-2 个工作日 | 3-5 个工作日 |
| **适合人群** | 独立开发者 | 公司/团队 |

### 个人账号

**优点：**

- 注册简单，只需身份证或护照
- 审核快速，1-2 天即可通过
- 适合独立开发者

**缺点：**

- App Store 上显示的是你的**真实姓名**（不是昵称）
- 无法添加团队成员，所有工作需要自己完成

> ⚠️ **重要**：个人账号在 App Store 的"开发者"栏会显示你的真实姓名。如果你介意隐私，可以考虑注册公司账号。

**App Store 显示效果：**

```text
开发者：张三        ← 显示你的真实姓名
```

### 公司账号

**优点：**

- App Store 显示公司名称，更专业
- 支持添加团队成员，多人协作开发
- 适合商业运营

**缺点：**

- 需要邓白氏编码，申请流程更复杂
- 注册审核时间更长
- 需要有合法的公司/组织

**App Store 显示效果：**

```text
开发者：Beijing Example Technology Co., Ltd.    ← 显示公司英文名称
```

### 如何选择？

| 你的情况 | 推荐选择 |
|---|---|
| 个人学习、练手 | 个人账号 |
| 独立开发者，不介意显示真名 | 个人账号 |
| 独立开发者，介意显示真名 | 公司账号（注册个体工商户） |
| 团队协作开发 | 公司账号 |
| 公司/工作室运营 | 公司账号 |

> 💡 **提示**：个人账号和公司账号的功能完全一样，唯一的区别就是显示名称和团队协作。如果你是独立开发者且不介意显示真名，个人账号就足够了。

## 邓白氏编码（公司账号需要）

如果你选择注册公司账号，就必须提供邓白氏编码（D-U-N-S Number）。下面详细介绍。

### 什么是邓白氏编码？

邓白氏编码（Data Universal Numbering System，简称 D-U-N-S Number）是由邓白氏公司（Dun & Bradstreet）颁发的**全球唯一企业身份标识码**，由 9 位数字组成。

```text
示例：邓白氏编码格式 → 12-345-6789
```

Apple 使用邓白氏编码来验证你的公司是否为合法的法律实体。

### 申请流程

**步骤 1：检查是否已有编码**

很多公司可能已经有邓白氏编码了，先查询一下：

```
访问 https://developer.apple.com/enroll/duns-lookup/
输入公司英文名称和国家 → 查询
```

**步骤 2：如果没有，申请新编码**

```
访问 https://www.dnb.com/duns-number.html
点击 "Get a DUNS Number" → 选择你的国家 → 填写公司信息
```

需要填写的信息：

- ✅ 公司全称（英文）
- ✅ 公司地址（英文）
- ✅ 公司电话
- ✅ 主要联系人信息
- ✅ 公司类型（有限责任公司、个体工商户等）
- ✅ 员工人数
- ✅ 行业类别

**步骤 3：等待审核**

| 项目 | 说明 |
|---|---|
| **审核时间** | 约 7-15 个工作日 |
| **费用** | **免费**（Apple 开发者申请通道免费） |
| **结果通知** | 邮件通知 |

> ⚠️ **警告**：如果你直接在邓白氏官网申请（非 Apple 渠道），可能会被要求付费。请务必通过 Apple Developer 的专用通道申请，这样是免费的。

### 申请注意事项

1. **公司名称必须与营业执照一致**：英文名称要与营业执照上的英文名称或官方翻译一致
2. **地址必须真实有效**：邓白氏可能会通过电话或邮件验证你的公司信息
3. **保持信息一致**：申请邓白氏编码时填写的信息，必须与注册 Apple Developer 时填写的信息一致
4. **耐心等待**：审核期间不要重复提交申请，这可能会导致流程更慢
5. **保存好编码**：收到邓白氏编码后，妥善保存，后续注册和续费都需要用到

> 💡 **提示**：如果你是个体工商户，也可以申请邓白氏编码。但需要确保你的营业执照上有明确的组织名称。

## 费用与续费说明

### 年费标准

| 项目 | 金额 |
|---|---|
| **个人账号** | 99 美元/年 |
| **公司账号** | 99 美元/年 |
| **企业账号（In-House）** | 299 美元/年 |

> 💡 **说明**：企业账号（Enterprise Program）是面向大型企业内部署 App 使用的，不通过 App Store 分发。一般开发者不需要这个账号。

### 续费时间

```text
到期前 30 天 → 可以开始续费
到期后       → 账号进入过期状态，但 App 不会被立即下架
```

续费方式：

```text
登录 App Store Connect → 协议、税务和银行业务 → 续费
```

Apple 会在到期前通过邮件提醒你续费，请留意邮箱。

### 不续费的后果

| 影响项 | 说明 |
|---|---|
| **已上架的 App** | ❌ 不会被下架，但无法提交更新 |
| **App 内购** | ❌ 无法正常工作 |
| **推送通知** | ❌ 证书过期后无法使用 |
| **TestFlight** | ❌ 测试版本将失效 |
| **真机调试** | ❌ 无法安装和调试 |
| **证书和描述文件** | ❌ 全部失效 |
| **App Store Connect** | ❌ 无法登录管理 |

> ⚠️ **重要**：虽然已上架的 App 不会被下架，但所有依赖开发者证书的功能（推送、内购等）都会失效。如果你的 App 有付费用户，不续费会严重影响用户体验。

### 退款政策

Apple 开发者年费**一般不予退款**，具体情况：

| 场景 | 是否可退款 |
|---|---|
| 注册后改变主意 | ❌ 不退款 |
| 重复扣费 | ✅ 可联系支持处理 |
| 账号审核未通过 | ✅ 可申请退款 |
| 其他特殊情况 | ⚠️ 需联系 Apple 开发者支持 |

联系 Apple 开发者支持：

```
https://developer.apple.com/contact/
```

> 💡 **提示**：注册前请确认你确实需要付费账号，避免不必要的费用支出。

## 真机调试配置

> 🎯 **本节目标**：了解为什么需要真机调试，掌握免费账号和付费账号下的真机调试配置步骤，并学会排查常见问题。

### 为什么需要真机调试？

很多新手会问：模拟器不是已经能运行 App 了吗，为什么还要折腾真机？因为模拟器有很多**做不到的事**：

| 局限性 | 说明 |
|---|---|
| **推送通知** | 模拟器无法接收远程推送（APNs），也无法测试本地推送的完整流程 |
| **传感器** | 模拟器没有摄像头、陀螺仪、加速度计、GPS 等硬件，无法测试相关功能 |
| **性能差异** | 模拟器运行在 Mac 的 CPU 上，性能远超真实 iPhone，App 在真机上可能卡顿 |
| **电话/短信** | 模拟器无法拨打电话或发送短信 |
| **蓝牙** | 模拟器不支持蓝牙连接外部设备 |
| **多任务行为** | 真机上的内存警告、后台挂起等行为与模拟器不同 |

> 💡 **简单来说**：模拟器适合写代码时快速预览，但 App 最终是给用户在真机上用的，所以真机调试是开发流程中**必不可少**的环节。

### 配置步骤

#### 第一步：在 Xcode 中登录 Apple ID

无论是免费账号还是付费账号，都需要先在 Xcode 中登录：

```text
Xcode → Settings（快捷键 ⌘,）→ Accounts → 点击左下角 "+" → 选择 Apple ID → 输入账号密码 → 登录
```

登录成功后，你会在 Accounts 页面看到你的 Apple ID 和对应的团队信息：

- **免费账号**：显示为你的个人名称，团队类型为"Personal Team"
- **付费账号**：显示为你的个人/公司名称，团队类型为对应的公司/组织

#### 第二步：用数据线连接 iPhone 和 Mac

1. 用 **Lightning 或 USB-C 数据线**将 iPhone 连接到 Mac
2. 首次连接时，iPhone 上会弹出"信任此电脑？"的提示，点击 **"信任"**
3. 输入 iPhone 的锁屏密码确认

> ⚠️ **注意**：请使用原装或经过 MFi 认证的数据线，劣质数据线可能导致连接不稳定或无法识别设备。

#### 第三步：信任开发者证书

这一步**非常关键**，很多新手会忘记！首次在真机上运行 App 后，iPhone 上需要手动信任开发者：

```text
iPhone 上操作：
设置 → 通用 → VPN与设备管理（iOS 15 及以下叫"描述文件与设备管理"）
→ 在"开发者App"下找到你的 Apple ID → 点击"信任 xxx@xxx.com" → 确认信任
```

> ⚠️ **重要**：如果你跳过了这一步，App 安装后会显示"未受信任的开发者"，点击 App 会闪退，无法打开。

#### 第四步：选择真机作为运行目标

在 Xcode 顶部工具栏中：

1. 点击设备选择器（默认显示的是模拟器名称，如"iPhone 15"）
2. 在列表中找到你的真实 iPhone 设备（设备名称旁边会显示 iOS 版本号）
3. 点击选择你的真机

或者使用快捷方式：

```text
快捷键：⌘ + Shift + D    → 打开设备选择器
快捷键：⌘ + R            → 在选定的设备上运行
```

> 💡 **提示**：如果你的设备没有出现在列表中，请检查数据线连接是否正常，以及 iPhone 是否已经解锁并信任了此电脑。

#### 第五步：首次运行与签名配置

点击运行按钮（▶️）后，Xcode 会自动为你的 App 配置签名。这是新手最容易遇到问题的地方。

**自动签名（推荐新手使用）：**

```text
Xcode → 点击项目文件（左侧导航栏最顶部的蓝色图标）→ Signing & Capabilities
→ 勾选 "Automatically manage signing" → Team 选择你的账号
```

自动签名的工作原理：

- Xcode 自动为你创建和管理证书、描述文件
- 你只需要选择 Team，其他全部自动处理
- **强烈推荐新手使用这种方式**

**手动签名（进阶使用）：**

当你有特殊需求（如多个 App 共用证书、CI/CD 自动化构建）时，可能需要手动签名：

```text
取消勾选 "Automatically manage signing" → 手动选择 Provisioning Profile 和 Signing Certificate
```

> 💡 **建议**：如果你刚开始学习，请使用自动签名。手动签名涉及证书和描述文件的管理，概念较多，等有经验后再尝试。

### 免费账号真机调试限制

使用免费 Apple ID 进行真机调试，有以下重要限制：

| 限制项 | 说明 |
|---|---|
| **签名有效期** | 7 天。过期后 App 无法打开，需要重新编译安装 |
| **最多安装 App 数** | 同时最多 3 个 App |
| **无法上架 App Store** | 只能自己安装测试，不能提交审核上架 |
| **无法使用部分能力** | 推送通知、App Groups、HealthKit 等需要付费证书 |
| **无法使用 TestFlight** | 不能通过 TestFlight 分发测试版本 |
| **无法注册设备** | 不能在开发者后台注册设备 UDID |

> ⚠️ **7 天过期的影响**：过期后，你 iPhone 上的 App 会变成灰色图标，点击提示"无法验证"。你需要回到 Xcode 重新编译运行一次即可恢复。这不会丢失 App 内的数据（如 UserDefaults、本地数据库等），但确实比较麻烦。

**免费账号真机调试操作流程：**

```text
1. Xcode 登录免费 Apple ID
2. 连接 iPhone，选择真机运行
3. 首次运行后在 iPhone 上信任开发者证书
4. App 安装成功，可以正常使用
5. 7 天后签名过期，回到 Xcode 重新运行即可
```

### 付费账号真机调试

付费账号（Apple Developer Program）的真机调试几乎没有限制：

| 对比项 | 免费账号 | 付费账号 |
|---|---|---|
| **签名有效期** | 7 天 | 1 年 |
| **安装 App 数量** | 最多 3 个 | 无限制 |
| **上架 App Store** | ❌ | ✅ |
| **推送通知等能力** | ❌ | ✅ |
| **TestFlight 分发** | ❌ | ✅ |
| **注册设备数量** | 无法注册 | 最多 100 台/年 |
| **证书数量** | 1 个开发证书 | 最多 5 个开发证书 + 3 个分发证书 |

**付费账号真机调试操作流程：**

```text
1. Xcode 登录付费 Apple ID
2. 连接 iPhone，选择真机运行
3. Xcode 自动处理签名（自动签名模式下）
4. App 安装成功，签名有效期 1 年
5. 可在 App Store Connect 中注册设备、管理证书
```

> 💡 **提示**：付费账号可以在 App Store Connect 中注册最多 100 台设备（iPhone + iPad 合计），方便团队多人测试。

### 常见问题排查

#### 问题 1：设备不被 Xcode 识别

**症状**：Xcode 顶部设备列表中看不到你的 iPhone

**排查步骤**：

```text
1. 检查数据线是否连接牢固，换一根数据线试试
2. iPhone 是否已解锁并点击了"信任此电脑"
3. 检查 iPhone 系统版本是否满足 Xcode 最低要求
   → Xcode 15 要求 iOS 17.0+ 的设备才能调试
   → 如果 iPhone 系统太旧，需要升级 iOS 或使用旧版 Xcode
4. 重启 Xcode 和 iPhone
5. 在 Xcode 菜单栏：Window → Devices and Simulators
   → 查看设备是否出现在列表中，是否有错误提示
6. 如果显示"Preparing debugger support"，请等待几分钟
7. Mac 上打开"系统信息"→ USB → 确认 iPhone 是否被系统识别
```

> ⚠️ **注意**：Xcode 每个大版本都有最低支持的 iOS 版本。如果你的 iPhone 系统版本低于 Xcode 支持的最低版本，设备将无法用于调试。你可以从 Xcode → Settings → Platforms 中下载对应 iOS 版本的调试支持包。

#### 问题 2：签名失败

**症状**：运行时弹出错误，如"Failed to create provisioning profile"或"Signing for xxx requires a development team"

**排查步骤**：

```text
1. 确认已在 Xcode → Settings → Accounts 中登录了 Apple ID
2. 确认 Signing & Capabilities 中选择了正确的 Team
3. 确认 Bundle Identifier 是唯一的（不能与其他 App 重复）
   → 建议格式：com.你的名字.App名称
4. 如果使用自动签名，尝试：
   → 取消勾选 "Automatically manage signing" → 重新勾选
5. 如果仍然失败，尝试：
   → Xcode 菜单栏 → Product → Clean Build Folder（快捷键 ⌘+Shift+K）
   → 然后重新运行
6. 如果提示证书问题，可以在 Keychain Access（钥匙串访问）中：
   → 搜索 "iPhone Developer" 或 "Apple Development"
   → 删除过期或冲突的证书
   → 回到 Xcode 重新运行，让 Xcode 自动创建新证书
```

#### 问题 3：证书冲突

**症状**：提示"Multiple certificates found"或"A signing certificate is required"

**排查步骤**：

```text
1. 打开"钥匙串访问"（Keychain Access）
   → 在"登录"钥匙串 → "我的证书"分类中
   → 查看是否有多个 "Apple Development" 或 "iOS Development" 证书
2. 如果有过期或无效的证书：
   → 右键 → 删除
   → 只保留有效的证书
3. 如果证书显示"此证书的签发者无效"：
   → 需要安装 Apple 的中间证书
   → 访问 https://www.apple.com/certificateauthority/ 下载并安装
4. 清理后重启 Xcode，重新运行
```

#### 问题 4：App 安装后闪退

**症状**：App 安装到 iPhone 上，点击图标后立即闪退

**排查步骤**：

```text
1. 最常见原因：没有在 iPhone 上信任开发者证书
   → 设置 → 通用 → VPN与设备管理 → 信任你的开发者账号
2. 签名已过期（免费账号 7 天过期）
   → 回到 Xcode 重新编译运行
3. 如果以上都不是，查看 Xcode 控制台的崩溃日志
   → Xcode 底部 → Show the Debug area（快捷键 ⌘+Shift+Y）
```

> 💡 **总结**：真机调试遇到问题，90% 都是签名和证书相关的问题。记住一个万能方法——**Clean Build Folder（⌘+Shift+K）+ 重新运行**，能解决大部分问题。

## 小结

本章我们学习了以下内容：

1. **免费账号 vs 付费账号**：免费账号适合学习，付费账号才能真机调试和上架
2. **注册全流程**：从准备 Apple ID 到支付年费，共 10 个步骤
3. **个人账号 vs 公司账号**：功能相同，区别在于显示名称和团队协作
4. **邓白氏编码**：公司账号必须提供，通过 Apple 渠道可免费申请
5. **费用与续费**：99 美元/年，不续费会导致证书和功能失效

> 📌 **关键提醒**：
> - 如果你刚开始学习，先用免费账号即可
> - 准备上架时再注册付费账号，避免浪费年费
> - 个人账号和公司账号功能完全一样，按需选择
> - 公司账号需要邓白氏编码，请提前申请（7-15 个工作日）
