# 03-开发者账号注册

> 🎯 **本章目标**：了解 Apple 开发者账号的类型区别，完成 Apple Developer Program 的注册，为后续真机调试和 App 上架做好准备。

---

## 免费账号 vs 付费账号

很多新手会疑惑：我一定要花钱注册开发者账号吗？答案是——不一定。Apple 提供了免费和付费两种账号，它们的区别非常大。

### 对比一览

| 对比项 | 免费账号（Apple ID） | 付费账号（Apple Developer Program） |
|---|---|---|
| **费用** | 免费 | 99 美元/年（约 688 元人民币） |
| **Xcode 开发** | ✅ 可以 | ✅ 可以 |
| **模拟器运行** | ✅ 可以 | ✅ 可以 |
| **真机调试** | ❌ 不可以 | ✅ 可以 |
| **App 上架 App Store** | ❌ 不可以 | ✅ 可以 |
| **推送通知（APNs）** | ❌ 不可以 | ✅ 可以 |
| **TestFlight 内测分发** | ❌ 不可以 | ✅ 可以 |
| **App Services（CloudKit 等）** | ❌ 受限 | ✅ 完整使用 |
| **证书有效期** | 7 天（过期需重新签名） | 1 年 |
| **同时安装 App 数量** | 最多 3 个 | 无限制 |
| **App Store Connect 管理** | ❌ 不可以 | ✅ 可以 |
| **Safari Web Inspector** | ✅ 可以 | ✅ 可以 |

### 免费账号能做什么？

如果你只是想**学习 iOS 开发**，免费账号完全够用：

- ✅ 使用 Xcode 编写和编译代码
- ✅ 在模拟器上运行和调试 App
- ✅ 学习 Swift / SwiftUI / UIKit 等技术
- ✅ 使用 Safari 的 Web Inspector 调试网页

> 💡 **提示**：免费账号签名的 App 7 天后会过期，需要重新编译安装。这在学习阶段影响不大，但如果要做长期测试就会比较麻烦。

### 付费账号能做什么？

当你需要以下功能时，就必须升级为付费账号：

- ✅ 在真实 iPhone / iPad 上调试 App
- ✅ 将 App 提交到 App Store 上架
- ✅ 使用推送通知、后台模式等系统能力
- ✅ 通过 TestFlight 邀请用户内测
- ✅ 使用 CloudKit、Sign in with Apple 等服务

### 什么时候需要升级为付费账号？

| 阶段 | 是否需要付费账号 | 说明 |
|---|---|---|
| 刚开始学习 iOS 开发 | ❌ 不需要 | 免费账号 + 模拟器足够 |
| 需要在真机上测试 | ✅ 需要 | 真机调试必须付费账号 |
| 需要推送通知等功能 | ✅ 需要 | 这些系统能力需要付费账号的证书 |
| 准备上架 App Store | ✅ 需要 | 上架是付费账号的核心功能 |

> ⚠️ **建议**：如果你刚开始学习，先用免费账号练手。等你的 App 开发完成、准备上架时再注册付费账号，这样不会浪费年费。

## Apple Developer Program 注册全流程

下面是注册付费开发者账号的完整步骤，请按顺序操作。

### 步骤 1：准备 Apple ID

如果你已经有 Apple ID（就是用来登录 iCloud 的那个账号），可以直接使用。如果没有，需要先创建一个。

创建 Apple ID 的方式：

```text
方式一：在 iPhone 上创建
设置 → 点击顶部"登录你的 iPhone" → 没有 Apple ID？创建一个

方式二：在网页上创建
访问 https://appleid.apple.com → 点击"创建你的 Apple ID"
```

> 💡 **提示**：建议使用一个**常用且稳定**的邮箱作为 Apple ID，后续所有开发者相关通知都会发到这个邮箱。

### 步骤 2：开启双重认证（必须）

Apple 强制要求开发者账号开启双重认证（Two-Factor Authentication，2FA），否则无法注册。

**在 iPhone 上开启双重认证：**

```text
设置 → 点击顶部你的姓名 → 密码与安全性 → 双重认证 → 开启
```

**在 Mac 上开启双重认证：**

```text
系统设置 → 点击顶部你的姓名 → 密码与安全性 → 双重认证 → 开启
```

> ⚠️ **警告**：开启双重认证后，每次登录 Apple ID 都需要验证码。请确保你的受信任设备（iPhone）随时可用，否则可能无法登录。

### 步骤 3：进入 Apple Developer 网站

打开浏览器，访问 Apple Developer 官网：

```
https://developer.apple.com/programs/
```

点击页面上的 **"Enroll"**（注册）按钮。

### 步骤 4：使用 Apple ID 登录

点击 Enroll 后，系统会要求你用 Apple ID 登录：

1. 输入你的 Apple ID 和密码
2. 输入双重认证验证码（发送到你的受信任设备）
3. 登录成功

### 步骤 5：选择账号类型

登录后，你需要选择注册类型：

| 类型 | 说明 |
|---|---|
| **Individual**（个人） | 以个人名义注册，只需身份证/护照 |
| **Organization**（公司/组织） | 以公司名义注册，需要邓白氏编码 |

> 💡 **提示**：如果你是个人开发者，选择 Individual 即可。如果是公司团队开发，选择 Organization。两者的详细区别见下一节。

### 步骤 6：填写个人信息

根据你选择的类型，填写相应的信息：

**个人账号需要填写：**

- ✅ 姓名（与身份证/护照一致）
- ✅ 地址
- ✅ 国家/地区
- ✅ 联系电话

**公司账号额外需要：**

- ✅ 公司全称（英文）
- ✅ 邓白氏编码（D-U-N-S Number）
- ✅ 公司网站（可选）

> ⚠️ **警告**：姓名必须与你的身份证或护照上的姓名一致，否则可能无法通过审核。

### 步骤 7：身份验证

Apple 会对你的身份进行验证，可能的方式包括：

1. **自动验证**：如果你的 Apple ID 已经绑定了信用卡等信息，系统可能自动通过
2. **人工验证**：Apple 可能会打电话给你确认信息

验证过程通常很快，部分用户可能需要等待。

### 步骤 8：支付年费

身份验证通过后，进入支付环节：

| 项目 | 说明 |
|---|---|
| **费用** | 99 美元/年 |
| **人民币参考** | 约 688 元（按汇率浮动） |
| **支付方式** | 信用卡、借记卡、支付宝、微信支付 |

**支付步骤：**

1. 确认注册信息无误
2. 选择支付方式
3. 完成支付

> 💡 **提示**：Apple 官方支持支付宝和微信支付，对中国开发者非常友好。支付时金额会按实时汇率折算为人民币。

> ⚠️ **注意**：支付完成后，Apple 会发送确认邮件到你的 Apple ID 邮箱，请留意查收。

### 步骤 9：等待审核

支付完成后，你的注册申请会进入审核阶段：

| 账号类型 | 审核时间 |
|---|---|
| 个人账号 | 通常 1-2 个工作日 |
| 公司账号 | 通常 3-5 个工作日（需验证邓白氏编码） |

> 💡 **提示**：审核期间你可以在 [App Store Connect](https://appstoreconnect.apple.com) 查看状态。如果超过 5 个工作日仍未通过，可以联系 Apple 开发者支持。

### 步骤 10：注册成功确认

审核通过后，你会收到一封来自 Apple 的欢迎邮件，标题类似：

```
Welcome to the Apple Developer Program
```

此时你可以：

- ✅ 登录 [App Store Connect](https://appstoreconnect.apple.com) 管理你的 App
- ✅ 在 Xcode 中添加你的开发者账号进行真机调试
- ✅ 创建证书和描述文件
- ✅ 提交 App 到 App Store

**在 Xcode 中添加账号：**

```text
Xcode → Settings（快捷键 ⌘,）→ Accounts → 点击 "+" → 选择 Apple ID → 登录
```

## 个人账号 vs 公司账号

注册时你需要选择个人还是公司账号，这是一个重要的决定。下面详细对比两者的区别。

### 对比一览

| 对比项 | 个人账号（Individual） | 公司账号（Organization） |
|---|---|---|
| **注册条件** | 身份证或护照 | 邓白氏编码 + 公司法律实体 |
| **费用** | 99 美元/年 | 99 美元/年 |
| **App Store 显示名称** | 你的个人姓名 | 你的公司名称 |
| **团队协作** | ❌ 不支持多人 | ✅ 支持添加多个团队成员 |
| **功能差异** | 与公司账号完全相同 | 与个人账号完全相同 |
| **审核要求** | 相对宽松 | 需要验证公司资质 |
| **注册时间** | 1-2 个工作日 | 3-5 个工作日 |
| **适合人群** | 独立开发者 | 公司/团队 |

### 个人账号

**优点：**

- 注册简单，只需身份证或护照
- 审核快速，1-2 天即可通过
- 适合独立开发者

**缺点：**

- App Store 上显示的是你的**真实姓名**（不是昵称）
- 无法添加团队成员，所有工作需要自己完成

> ⚠️ **重要**：个人账号在 App Store 的"开发者"栏会显示你的真实姓名。如果你介意隐私，可以考虑注册公司账号。

**App Store 显示效果：**

```text
开发者：张三        ← 显示你的真实姓名
```

### 公司账号

**优点：**

- App Store 显示公司名称，更专业
- 支持添加团队成员，多人协作开发
- 适合商业运营

**缺点：**

- 需要邓白氏编码，申请流程更复杂
- 注册审核时间更长
- 需要有合法的公司/组织

**App Store 显示效果：**

```text
开发者：Beijing Example Technology Co., Ltd.    ← 显示公司英文名称
```

### 如何选择？

| 你的情况 | 推荐选择 |
|---|---|
| 个人学习、练手 | 个人账号 |
| 独立开发者，不介意显示真名 | 个人账号 |
| 独立开发者，介意显示真名 | 公司账号（注册个体工商户） |
| 团队协作开发 | 公司账号 |
| 公司/工作室运营 | 公司账号 |

> 💡 **提示**：个人账号和公司账号的功能完全一样，唯一的区别就是显示名称和团队协作。如果你是独立开发者且不介意显示真名，个人账号就足够了。

## 邓白氏编码（公司账号需要）

如果你选择注册公司账号，就必须提供邓白氏编码（D-U-N-S Number）。下面详细介绍。

### 什么是邓白氏编码？

邓白氏编码（Data Universal Numbering System，简称 D-U-N-S Number）是由邓白氏公司（Dun & Bradstreet）颁发的**全球唯一企业身份标识码**，由 9 位数字组成。

```text
示例：邓白氏编码格式 → 12-345-6789
```

Apple 使用邓白氏编码来验证你的公司是否为合法的法律实体。

### 申请流程

**步骤 1：检查是否已有编码**

很多公司可能已经有邓白氏编码了，先查询一下：

```
访问 https://developer.apple.com/enroll/duns-lookup/
输入公司英文名称和国家 → 查询
```

**步骤 2：如果没有，申请新编码**

```
访问 https://www.dnb.com/duns-number.html
点击 "Get a DUNS Number" → 选择你的国家 → 填写公司信息
```

需要填写的信息：

- ✅ 公司全称（英文）
- ✅ 公司地址（英文）
- ✅ 公司电话
- ✅ 主要联系人信息
- ✅ 公司类型（有限责任公司、个体工商户等）
- ✅ 员工人数
- ✅ 行业类别

**步骤 3：等待审核**

| 项目 | 说明 |
|---|---|
| **审核时间** | 约 7-15 个工作日 |
| **费用** | **免费**（Apple 开发者申请通道免费） |
| **结果通知** | 邮件通知 |

> ⚠️ **警告**：如果你直接在邓白氏官网申请（非 Apple 渠道），可能会被要求付费。请务必通过 Apple Developer 的专用通道申请，这样是免费的。

### 申请注意事项

1. **公司名称必须与营业执照一致**：英文名称要与营业执照上的英文名称或官方翻译一致
2. **地址必须真实有效**：邓白氏可能会通过电话或邮件验证你的公司信息
3. **保持信息一致**：申请邓白氏编码时填写的信息，必须与注册 Apple Developer 时填写的信息一致
4. **耐心等待**：审核期间不要重复提交申请，这可能会导致流程更慢
5. **保存好编码**：收到邓白氏编码后，妥善保存，后续注册和续费都需要用到

> 💡 **提示**：如果你是个体工商户，也可以申请邓白氏编码。但需要确保你的营业执照上有明确的组织名称。

## 费用与续费说明

### 年费标准

| 项目 | 金额 |
|---|---|
| **个人账号** | 99 美元/年 |
| **公司账号** | 99 美元/年 |
| **企业账号（In-House）** | 299 美元/年 |

> 💡 **说明**：企业账号（Enterprise Program）是面向大型企业内部署 App 使用的，不通过 App Store 分发。一般开发者不需要这个账号。

### 续费时间

```text
到期前 30 天 → 可以开始续费
到期后       → 账号进入过期状态，但 App 不会被立即下架
```

续费方式：

```text
登录 App Store Connect → 协议、税务和银行业务 → 续费
```

Apple 会在到期前通过邮件提醒你续费，请留意邮箱。

### 不续费的后果

| 影响项 | 说明 |
|---|---|
| **已上架的 App** | ❌ 不会被下架，但无法提交更新 |
| **App 内购** | ❌ 无法正常工作 |
| **推送通知** | ❌ 证书过期后无法使用 |
| **TestFlight** | ❌ 测试版本将失效 |
| **真机调试** | ❌ 无法安装和调试 |
| **证书和描述文件** | ❌ 全部失效 |
| **App Store Connect** | ❌ 无法登录管理 |

> ⚠️ **重要**：虽然已上架的 App 不会被下架，但所有依赖开发者证书的功能（推送、内购等）都会失效。如果你的 App 有付费用户，不续费会严重影响用户体验。

### 退款政策

Apple 开发者年费**一般不予退款**，具体情况：

| 场景 | 是否可退款 |
|---|---|
| 注册后改变主意 | ❌ 不退款 |
| 重复扣费 | ✅ 可联系支持处理 |
| 账号审核未通过 | ✅ 可申请退款 |
| 其他特殊情况 | ⚠️ 需联系 Apple 开发者支持 |

联系 Apple 开发者支持：

```
https://developer.apple.com/contact/
```

> 💡 **提示**：注册前请确认你确实需要付费账号，避免不必要的费用支出。

> 📌 **关键提醒**：
